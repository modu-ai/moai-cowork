# 채용공고 분석 가이드

공고 원문과 조회일을 확인한 뒤 직무 요건을 추출합니다. 공고 문구만으로 회사 내부 사정이나 지원자의 합격 가능성을 예측하지 않습니다.

## 요건 읽기

| 항목 | 확인할 내용 |
|---|---|
| 담당 업무 | 실제 수행할 과업과 범위, 모호한 부분 |
| 필수 자격 | 공고에 명시된 자격·경험·기술과 예외 조건 |
| 우대 사항 | 명시된 추가 경험과 활용될 업무 |
| 근무 조건 | 고용 형태, 근무지, 급여 공개 범위, 계약 기간 |
| 지원 절차 | 마감 시각, 제출 자료, 전형 단계 |

- `필수`라고 적힌 요건도 실제 심사 예외나 우선순위는 회사만 알 수 있습니다. 고정 충족률을 합격 기준으로 만들지 않습니다.
- `빠르게 성장`, `수평적 문화` 같은 표현을 인력 부족이나 이직률의 증거로 해석하지 않습니다. 업무 범위와 조직 운영 방식은 면접 질문으로 확인합니다.
- 사용자가 제공한 경력과 JD의 요건을 연결하되, 자료에 없는 경력은 `확인되지 않음`으로 표시합니다.

## 기업 조사

- 공식 사이트·채용 페이지·공고 원문을 먼저 확인하고 게시일을 기록합니다.
- DART 공시가 있는 회사는 사업보고서와 감사보고서의 회사·연도·연결/별도 기준을 확인합니다. 공시가 없으면 재무 수치를 추정하지 않습니다.
- 평판 사이트 후기는 개인 의견과 확인된 사실을 분리합니다.
- 반복 채용 공고만으로 성장률·이직률·채용 시급성을 산정하지 않습니다.

## 출력

1. 확인한 공고의 URL·게시일과 직무 범위
2. 필수·우대 요건별 원문 근거
3. 사용자가 제공한 경력과의 연결, 확인되지 않은 부분
4. 회사와 지원자에게 물어볼 질문
5. 자료의 기준일과 조사 한계
