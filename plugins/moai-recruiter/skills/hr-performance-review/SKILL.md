# 성과평가 (Performance Review)

## 개요

조직 규모와 문화에 맞는 성과평가 체계를 설계하고 실행을 지원한다.
조직의 기존 규정과 평가 목적을 먼저 확인하고, 관찰 가능한 근거에 따라 평가 초안을 만든다. OKR·KPI·MBO·360도 피드백은 필요할 때 선택한다.

## 트리거 키워드

성과평가, 인사 고과, 성과 리뷰, KPI 설정, OKR, MBO, 360도 평가, 피드백 면담, 목표 설정, 성과 관리, 연봉 협상, 직원 평가

## 워크플로우

### 1단계: 조직 현황 및 평가 목적 확인
- 조직 규모 (스타트업 / 중소기업 / 대기업)
- 현재 사용 중인 성과관리 방식
- 평가 목적:
  - 보상 연계 (연봉 인상, 성과급)
  - 성장 지원 (육성, 역량 개발)
  - 조직 목표 정렬 (전사 방향성 공유)

### 2단계: 성과관리 프레임워크 선택

**프레임워크 선택 시 확인할 사항**

| 구분 | MBO | KPI | OKR |
|------|-----|-----|-----|
| 초점 | 책임·보상 연계 | 수치 측정 | 방향·정렬 |
| 주기 | 조직이 정한 평가 기간 | 지표별 측정 기간 | 조직이 정한 목표 기간 |
| 보상 연계 | 조직 규정 확인 | 조직 규정 확인 | 조직 규정 확인 |
| 공유 범위 | 개인정보·업무 필요에 따라 결정 | 지표별로 결정 | 목표별로 결정 |

기존 취업규칙·평가 규정, 직무의 측정 가능성, 평가 자료의 품질, 보상 연계 여부를 확인한 뒤 필요한 방식만 제안한다.

### 3단계: OKR 작성 지원

**OKR 작성 원칙:**
- **Objective (목표)**: 질적, 도전적, 동기 부여적 (1-5개)
  - 예: "고객이 사랑하는 온보딩 경험 구축"
- **Key Results (핵심결과)**: 측정 가능, 시간 한정 (목표당 2-5개)
  - 예: "온보딩 완료율 60% → 85%로 향상 (3개월)"
  - 예: "NPS 점수 32점 → 50점으로 개선"

**OKR 작성 체크리스트:**
- [ ] Objective는 영감을 주는가? (Not: "xx% 달성")
- [ ] Key Results는 수치로 측정 가능한가?
- [ ] Key Results 달성 여부로 Objective 달성을 판단할 수 있는가?
- [ ] 기준값과 목표값의 출처가 있는가?
- [ ] 보상 연계 여부가 조직 규정 및 구성원에게 안내된 방식과 일치하는가?

### 4단계: 평가 설계

**평가 항목 구성 예시 — 가중치는 기존 규정과 직무에 따라 정함:**
```
성과 평가 (What: 목표 달성도)
  - KPI/OKR Key Results 달성률
  - 목표 대비 실적 (정량)
  - 주요 프로젝트 기여도

역량 평가 (How: 관찰된 행동 방식)
  - 직무 역량 (업무 전문성)
  - 리더십/협업 역량
  - 성장 가능성 (잠재력)
```

**360도 평가 설계:**
- 상향 평가: 팀원 → 관리자 (익명 여부와 최소 응답자 수는 실제 운영 방식 확인)
- 동료 평가: 동료 → 동료 (협업 역량 중심)
- 자기 평가: 본인 → 본인 (성찰 및 성장 계획)
- 평가 항목: 5점 척도 + 서술형 피드백

### 5단계: 평가 면담 (Calibration & Feedback)

**평가 면담 스크립트 (기본 구조):**
```
① 시작 (5분): 면담 목적과 분위기 설정
   "오늘은 지난 [기간] 동안의 성장과 다음 [기간] 계획을 함께 이야기해보려 해요."

② 자기 평가 확인 (10분):
   "스스로 가장 잘 해냈다고 생각하는 것은 무엇인가요?"
   "아쉬웠던 부분이나 더 잘할 수 있었던 점은?"

③ 관리자 피드백 (10분):
   - 긍정적 피드백: 구체적 행동 + 영향 + 감사
   - 개선 피드백: 관찰 사실 + 영향 + 기대 행동 (SBI 모델)

④ 다음 기간 목표 합의 (10분):
   OKR/KPI 초안 함께 검토

⑤ 지원 사항 확인 (5분):
   "제가 어떻게 지원해드리면 목표 달성에 도움이 될까요?"
```

**SBI 피드백 모델:**
- **S (Situation)**: "지난 주 고객 미팅에서"
- **B (Behavior)**: "제안서를 충분히 검토하지 않고 발표했을 때"
- **I (Impact)**: "회의록상 계약 결정이 다음 회의로 연기됐습니다" (기록이 확인된 경우)

### 6단계: 평가 결과 보정 (Calibration)

**공정성 확보:**
- 관대화 오류 방지: 평가 근거와 기준을 평가자 간 비교한다. 등급 비율을 임의로 강제하지 않는다.
- 최근 효과 방지: 전체 평가 기간 데이터 기반 평가
- 편향 체크: 성별·나이·국적 등 보호 특성 기반 편향 모니터링

### 7단계: 성과평가 결과 보고서 생성

```
# [이름/팀] 성과평가 결과

## 종합 평가: [조직의 등급 기준이 있으면 기재, 없으면 근거 중심 서술]

## KPI/OKR 달성 현황
| 목표 | 목표치 | 실적 | 달성률 |

## 강점 (계속 유지할 것)

## 개선 기회 (다음 기간 집중 사항)

## 다음 기간 목표 (합의)

## 성장을 위한 지원 계획
```

## 산출물

**텍스트 후처리 체인 (면담 스크립트·평가 보고서 서술 부분 등 산문 산출물)**:

## 참고 사항

### 근거와 개인정보
- 실적·행동 사례는 평가 기간의 실제 자료와 출처를 적는다. 자료가 없으면 관찰 공백으로 표시한다.
- AI가 등급이나 인사 조치를 자동 확정하지 않도록 평가권자가 근거와 맥락을 검토한다.
- 360도 피드백의 익명성·열람 범위·보관 기간은 실제 운영 방침에 맞춰 안내한다.

### 근로기준법 준수 주의사항
- 부당한 성과평가를 이유로 한 해고·강제 퇴직 요구 금지
- 평가 기준은 취업규칙·평가 규정·근로계약 등 적용 문서를 확인한다.
- 평가 결과 공개 시 개인정보보호법 적용
- 연봉 협상 결과는 서면으로 확인 (근로조건 명확화)

## 문제 해결

- **근로기준법 조항 불확실**: 부당 해고, 강등, 임금 삭감이 수반되는 평가는 노무사 검토가 필수입니다. AI가 제공하는 법령 내용은 참고용입니다.
- **직급 체계 정보 부족**: 팀 규모, 직군 분류, 기존 평가 방식을 알려주시면 더 맞춤화된 평가 체계를 설계할 수 있습니다.
- **평가 편향 우려**: 평가 자료의 누락과 기준 적용 차이를 확인하고, 필요한 경우 평가자 간 근거 검토를 진행합니다.
- **OKR 달성률 측정 불가**: 정량 지표가 없는 직무(창의 직군, 지원 부서)는 서술형 평가 + 동료 피드백 비중을 높이는 방향으로 설계하세요.
