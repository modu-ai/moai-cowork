# OKR/MBO 설정 가이드

> moai-recruiter | hr-performance-review 참조 가이드

## 개요

OKR(Objectives & Key Results)과 MBO(Management by Objectives)의 선택과 운영 절차를 안내합니다. 조직의 기존 평가 규정과 목표 기간을 먼저 확인합니다.

---

## 1. OKR vs MBO 선택 기준

| 기준 | OKR | MBO |
|------|-----|-----|
| 평가 연동 | 조직 규정 확인 | 조직 규정 확인 |
| 설정 주기 | 조직의 목표 기간 | 조직의 평가 기간 |
| 달성 기준 | 사전 합의한 측정 기준 | 사전 합의한 측정 기준 |
| 활용 | 목표와 결과의 관계 확인 | 합의한 목표의 이행 확인 |
| 공유 범위 | 업무와 개인정보 기준에 따라 설정 | 업무와 개인정보 기준에 따라 설정 |

---

## 2. OKR 작성법

### Objective (목적) 작성 원칙

- 정성적이고 영감을 주는 문장
- "왜 중요한가?"에 답해야 함
- 측정값 없이 방향성만 표현
- 예: "고객이 우리 서비스를 사랑하게 만든다"

### Key Results (핵심 결과) 작성 원칙

- 완료 여부를 검증할 수 있는 기준 포함. 수치가 있으면 측정 방법과 출처 명시
- 실제 관리 가능한 개수로 설정
- 현재 상태 → 목표 상태 형식
- 예: "[측정 기간]의 온보딩 완료율을 [확인된 기준값]에서 [합의한 목표값]으로 개선"

### OKR 작성 체크리스트

- [ ] Objective는 팀의 분기 우선순위를 반영하는가?
- [ ] Key Results의 달성 여부를 자료로 확인할 수 있는가?
- [ ] 달성 시 Objective가 실질적으로 전진하는가?
- [ ] 상위 팀 OKR과 정렬되어 있는가?
- [ ] 개인이 주도적으로 달성할 수 있는 범위인가?

## 3. MBO 설계

### KPI 설계 원칙 (SMART)

- **Specific**: 구체적인 성과 지표
- **Measurable**: 수치로 측정 가능
- **Achievable**: 도전적이지만 현실적
- **Relevant**: 팀/조직 목표와 연계
- **Time-bound**: 명확한 마감 기한

### MBO 목표 배분

정량·정성·공통 목표의 가중치는 직무, 실제 평가 규정, 근거 자료를 확인해 합의합니다. 임의의 비율을 기본값으로 넣지 않습니다.

---

## 4. 평가 주기 운영

### OKR 사이클 예시 — 조직의 실제 목표 기간에 맞춰 조정

| 시기 | 활동 |
|------|------|
| 기간 시작 | 목표와 검증 기준 합의 |
| 중간 점검 | 진척도와 장애 요인 확인, 필요 시 변경 기록 |
| 기간 종료 | 근거 자료로 결과 검토, 다음 목표 논의 |

### MBO 사이클 예시 — 조직의 실제 평가 기간에 맞춰 조정

| 시기 | 활동 |
|------|------|
| 기간 시작 | 목표·가중치·측정 자료 합의 |
| 중간 점검 | 목표 변경과 지원 필요 사항 기록 |
| 기간 종료 | 합의한 기준으로 결과 검토 |

---

## 5. 공통 실수와 해결책

| 실수 | 해결 방법 |
|------|-----------|
| Key Results가 활동(to-do) 수준 | 성과(outcome) 중심으로 재작성 |
| 관리하기 어려울 만큼 많은 OKR | 우선순위를 재검토하고 실제 관리 가능한 개수로 조정 |
| 목표와 평가의 관계가 불명확함 | 조직의 평가 규정과 구성원 안내 내용을 확인 |
| 목표 변경 없이 방치 | 분기 중반 공식 조정 기회 제공 |
