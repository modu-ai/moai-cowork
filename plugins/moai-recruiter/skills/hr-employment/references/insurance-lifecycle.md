# 4대보험 라이프사이클 가이드 (취득 → 상실 → 퇴직급여)

> moai-recruiter | hr-employment 참조 가이드

## 개요

직원별 가입 대상과 사업장 상태를 확인한 뒤 국민연금·건강보험·고용보험·산재보험의 취득·상실 신고를 진행합니다. 각 보험의 서식·기한·제재는 적용 시점의 담당 기관 안내를 확인합니다.

---

## 1. 4대보험 취득신고 기한 확인

| 보험 | 확인할 사항 | 공식 확인처 |
|------|-----------|-----------|
| 국민연금 | 가입 대상·자격취득일·신고기한 | [국민연금공단](https://www.nps.or.kr) |
| 건강보험 | 가입 대상·자격취득일·신고기한 (공단 해설의 일반적인 취득 신고는 취득일부터 14일 이내) | [국민건강보험공단](https://www.nhis.or.kr) |
| 고용보험 | 피보험자격 취득일·신고기한 | [근로복지공단](https://www.comwel.or.kr) |
| 산재보험 | 근로자 고용 신고 대상·기한 | [근로복지공단](https://www.comwel.or.kr) |

> 온라인 신고를 이용할 때는 [4대사회보험 정보연계센터](https://www.4insure.or.kr/)에서 해당 업무가 지원되는지 확인합니다. 통합 징수와 자격 신고를 같은 업무로 보지 않습니다.

---

## 2. 취득신고 절차

### 단계별 절차

1. **근로계약 조건 확인**: 체결 시 법정 근로조건을 명시하고 필요한 서면을 교부
2. **필요 정보 수집**: 신고 서식이 요구하는 정보만 안전하게 수집; 신분증·등본·통장 사본을 일률적으로 요구하지 않음
3. **신고 방법 선택**:
   - 온라인: 4대사회보험 정보연계센터 또는 해당 기관의 EDI 시스템에서 지원 업무 확인
   - 방문: 각 공단 지사 방문
   - 팩스: 각 공단 지사 팩스 신고
4. **취득신고서 작성**: 해당 보험의 현재 서식과 실제 보수 자료로 작성
5. **신고 완료 확인**: 신고 후 접수증 또는 취득 확인서 수령

---

## 3. 보험 유형별 주요 신고 서류

### 국민연금 (사업장가입자 취득신고)

- 사업장가입자 자격취득신고서
- 첨부 서류는 현재 공단 서식의 요구사항 확인

### 건강보험 (직장가입자 자격취득신고)

- 직장가입자 자격취득신고서
- 피부양자 등록은 별도 요건·증빙 확인

### 고용보험·산재보험 (근로복지공단 통합 신고)

- 피보험자격 취득신고서 (고용보험)
- 근로자 고용신고서 (산재)
- 전자 제출 가능 범위는 해당 기관의 현재 안내 확인

---

## 4. 신고 누락 시 조치

누락을 확인하면 보험별 담당 기관에서 정정·소급 신고 절차와 적용 가능한 제재를 확인합니다. 확인하지 않은 과태료 금액을 미리 고지하지 않습니다.

---

## 5. 실무 체크리스트

- [ ] 근로계약서 서명 완료 (입사 당일 또는 이전)
- [ ] 4insure.kr 또는 EDI 접속 준비 완료
- [ ] 신규 직원 주민등록번호 및 입사일 확인
- [ ] 보험별 보수 산정 기준과 실제 급여 항목 확인
- [ ] 4대보험 취득신고서 제출 완료
- [ ] 접수증 또는 확인서 HR 파일에 보관
- [ ] 직원에게 보험 가입 사실 통보

---

## 6. 퇴직 시 4대보험 상실신고 (취득의 대칭 절차)

직원 퇴사 시 사업주는 상실신고를 기한 내 완료해야 합니다. 상실신고가 늦어지면 퇴직자의 실업급여 신청·지역가입 전환이 지연됩니다.

| 보험 | 확인할 사항 | 공식 확인처 |
|------|--------------|-----------|
| 국민연금 | 자격상실일·신고기한 | [국민연금공단](https://www.nps.or.kr) |
| 건강보험 | 자격상실일·신고기한 | [국민건강보험공단](https://www.nhis.or.kr) |
| 고용보험 | 피보험자격 상실일·신고기한 | [근로복지공단](https://www.comwel.or.kr) |
| 산재보험 | 근로자 고용 종료 신고 대상·기한 | [근로복지공단](https://www.comwel.or.kr) |

### 상실신고 절차 체크리스트

- [ ] 보험별 상실일을 현재 신고 안내와 대조
- [ ] 상실 사유 코드 정확히 기재 (자발적/비자발적 구분 — 실업급여 수급 판정에 직결, 허위 기재 시 제재)
- [ ] 건강보험: 퇴직 정산 보험료 확인 (보수 변동분 정산)
- [ ] 고용보험 이직확인서: 퇴직자의 발급 요청·관할 기관 요청 여부와 [고용보험법 제42조제3항](https://www.law.go.kr) 및 시행규칙 제82조의2의 절차·기한 확인
- [ ] 정보연계센터 또는 EDI의 지원 범위를 확인해 상실신고
- [ ] 마지막 임금·퇴직급여의 지급 기한과 예외를 각각 적용 법령에서 확인

## 7. 퇴직연금 (DC/DB) 설정 의무

- [근로자퇴직급여 보장법](https://www.law.go.kr/lsSc.do?query=%EA%B7%BC%EB%A1%9C%EC%9E%90%ED%87%B4%EC%A7%81%EA%B8%89%EC%97%AC+%EB%B3%B4%EC%9E%A5%EB%B2%95)의 적용 대상과 예외를 확인하고, 사업장의 퇴직금·퇴직연금 제도를 구별합니다. 신설 사업장의 제도 설정 절차도 현행 조문에서 확인합니다.
- **DB(확정급여형)**: 퇴직 시 지급액이 확정 (평균임금 30일분 × 근속연수 이상), 운용 책임은 회사.
- **DC(확정기여형)**: 회사가 연간 임금총액의 1/12 이상을 근로자 계정에 납입 (동법 제20조), 운용 책임은 근로자. 납입 지연 시 지연이자 발생.
- 제도 도입·변경 시 근로자대표 절차와 규약 신고 대상은 제도별 현행 조문으로 확인합니다.
- IRP 이전 여부는 지급 제도와 법정 예외를 확인합니다.
