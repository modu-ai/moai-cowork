# 2026년 제도 변화 확인 메모

이 문서는 모든 사업자에게 같은 의무가 생겼다는 뜻이 아니다. 사건 날짜, 기업 규모·업종·상장 여부와 실제 시행 조문을 확인한 뒤 적용한다. 확인일: 2026-09-24.

| 항목 | 이번 확인에서 확인한 내용 | 후속 적용 확인 |
|---|---|---|
| 개인정보 보호법 | [국가법령정보센터 제23조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027416043)는 2026-09-11 시행 법률에 민감정보의 유출등에 위조·변조·훼손을 포함한다. | 처리하는 정보, 해당 조문과 시행령의 구체 의무를 따로 대조 |
| 노동조합법 | [고용노동부 안내](https://moel.go.kr/news/enews/report/enewsView.do?news_seq=19047)에 따르면 개정 노동조합법 제2·3조가 2026-03-10 시행됐다. | 원·하청 관계와 교섭 당사자 해당 여부 확인 |
| 최저임금 | [고용노동부 확정 고시 안내](https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=18144)는 2026년 시간급 10,320원을 명시한다. | 근로기간·근로시간·산입 임금과 적용 연도 확인 |
| K-IFRS 제1118호 | [금융위원회 발표](https://fsc.go.kr/no010101/85886)는 2027-01-01 이후 시작 회계연도 적용, 2026-01-01 이후 시작 회계연도 조기 적용 허용을 명시한다. | K-IFRS 적용 기업인지와 보고 기간 확인 |
| 지속가능성 공시 | [금융위원회 제도화 방안](https://www.fsc.go.kr/po010106/87280)은 단계적 적용 대상을 설명한다. | 현재 법정 요건과 연결자산·상장 여부 확인 |

과징금률, 이사회 보고, 인증 의무, 유출 통지, 연금 요율, 임금 대지급금은 적용 법령·요건을 건별로 확인하기 전에는 이 메모에서 확정하지 않는다. 이 파일을 다른 플러그인의 공통 정본으로 부르지 않는다.
