# 규제 항목별 판정 기준

검토 대상과 사건 날짜, 사업 유형을 정한 뒤 해당 법령의 공식 원문을 찾는다. 법령 이름이나 주제만으로 조문과 의무를 추정하지 않는다.

| 상태 | 사용 조건 |
|---|---|
| 확인 범위에서 충족 | 적용 의무, 회사의 실제 자료, 시점이 모두 확인됨 |
| 불일치 | 적용 의무와 반대되는 자료가 확인됨 |
| 미확인 | 적용 여부나 운영 증거가 부족함 |
| 비적용 | 법령상 적용 요건과 회사 사실을 대조해 제외됨 |

개인정보, 전자상거래, 표시광고, 노동 항목은 기업과 거래 유형에 따라 달라진다. 예를 들어 청약철회는 상품·서비스 유형, 예외, 고지 내용까지 확인해야 하므로 기간 숫자 하나로 PASS/FAIL을 내리지 않는다. 최저임금은 해당 연도의 공식 고시와 실제 임금 산입 범위를 대조한다.

결과 표의 각 행에 공식 근거 URL, 조항, 시행일, 적용 사유, 확인한 자료, 판정과 미확인 사항을 적는다. 법적 판단을 확정하거나 신고·승인 완료로 표현하지 않는다.
