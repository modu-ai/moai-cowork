# KIPRIS 검색 가이드

현재 연결된 moai-mcp-ip가 제공하는 인자 이름을 먼저 확인한다. 서버가 보이지 않으면 [KIPRIS 공식 웹 검색](https://www.kipris.or.kr/)을 사용한다. 인증키를 URL에 직접 조립하거나 채팅에 기록하지 않는다.

| 목적 | 검색 방법 |
|---|---|
| 기술 분야 | 핵심 단어의 한글·영문 표현과 적합한 IPC를 각각 검토 |
| 특정 출원인 | 법인명 변형·합병 전 이름을 확인 |
| 특정 문헌 | 출원·공개·등록 번호 유형을 구분해 조회 |
| 권리 상태 | 공식 상세 화면과 기준일 기록 |

서버가 제공하는 kipris_patent_search, kipris_patent_detail, kipris_trademark_search 등의 실제 도구 스키마가 가이드 예시보다 우선한다. API 또는 웹 검색 결과의 범위, 페이지 수, 원문 열람 여부를 결과에 명시한다.
