# 계약서 검토 가이드

이 목록은 검토 범위를 잡는 도구다. 조항이 없다는 사실만으로 위법이나 결함을 확정하지 않는다. 계약 유형과 당사자 역할에 맞춰 필요한 항목을 고른다.

| 범주 | 확인할 질문 |
|---|---|
| 당사자·권한 | 실제 법인·개인, 서명 권한, 대리 관계가 맞는가? |
| 목적·범위 | 산출물, 검수 기준, 변경 요청과 추가 비용이 명확한가? |
| 대금 | 지급 조건, 세금, 지연, 상계·환급 조건이 어떻게 작동하는가? |
| 일정·해지 | 지연과 중도 해지, 종료 후 정산·자료 반환이 명확한가? |
| 책임 | 손해 종류·입증·배상 한도·예외가 사용자에게 어떤 영향을 주는가? |
| 지식재산 | 기존 자산과 신규 산출물, 사용권·양도·제3자 자료가 구분되는가? |
| 비밀·정보 | 비밀 범위, 허용 공개, 보존·파기, 개인정보 역할이 맞는가? |
| 분쟁 | 준거법, 관할, 중재 합의와 실제 비용이 맞는가? |

계약 형태에 따라 노동, 소비자, 개인정보, 하도급, 공정거래, 주택·상가 임대차 등 다른 법령이 적용될 수 있다. 해당 법령과 시점은 공식 원문으로 확인한다. 약관이라면 [약관법 제6조·제7조 등](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025032405)의 적용 요건을 개별 조항에 대조한다. `무제한 배상`, `일방 해지`, `책임 없음` 같은 문구는 우선 검토 신호이지만 자동 무효 판정은 아니다.

기존 문구와 제안 문구를 나란히 보여 줄 때는 바뀌는 권리·의무·예외를 설명한다. 업계 평균 금액, 관례적 기간, 법정 최고금리, 계약금액 100% 배상 한도 등을 출처 없이 표준값으로 넣지 않는다. 위험 점수는 원문과 사실관계에서 재현할 수 있는 기준이 없으면 생략한다.

보고서에는 확인한 쪽·조항, 자료가 없는 부분, 적용 법령의 시행일, 전문가 검토가 필요한 쟁점을 포함한다. 원본 계약서는 사용자의 승인 없는 삭제나 외부 전송을 하지 않는다.
