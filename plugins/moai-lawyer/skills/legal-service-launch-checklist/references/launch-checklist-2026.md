# 한국 서비스 출시 점검 후보

이 목록은 모든 서비스에 일률적으로 적용되는 필수 항목이나 단일 진실 소스가 아니다. 법령은 개정될 수 있으므로 출시 기준일의 조문·시행령·고시를 공식 사이트에서 다시 확인한다. 과태료·과징금, 신고 의무, 기한은 위반 유형과 적용 조항을 확인한 뒤에만 적는다.

| 서비스에서 확인된 조건 | 점검할 질문 | 공식 확인처 |
|---|---|---|
| AI 시스템·서비스 제공 | 인공지능기본법상 사업자 역할, 제31조 고지·표시의 대상과 방식은? | [인공지능기본법](https://www.law.go.kr/lsInfoP.do?lsiSeq=276241), [지원데스크](https://www.sw.or.kr/AI_act_helpdesk/main.jsp) |
| 앱 접근권한 요청 | 필수·선택 권한 구분과 실제 기능 필요성은? | [국가법령정보센터](https://www.law.go.kr/) |
| 개인정보 처리 | 처리 근거·처리방침·보호책임자·안전조치는? | [개인정보보호법](https://www.law.go.kr/lsInfoP.do?lsId=011468), [개인정보위](https://www.pipc.go.kr/) |
| 국외 이전 또는 처리위탁 | 실제 이전 국가·수탁자·위탁 업무와 고지·동의 요건은? | [개인정보보호법](https://www.law.go.kr/lsInfoP.do?lsId=011468) |
| 개인정보 유출 또는 유출 의심 | 사고 유형과 인지 시점에 따른 통지·신고 기준과 기한은? | [개인정보보호법 및 시행령 개정이유](https://law.go.kr/LSW/lsRvsRsnListP.do?chrClsCd=010102&lsId=011468) |
| 소비자 대상 온라인 판매 | 통신판매업 신고 대상·예외, 사업자 표시, 청약철회는? | [전자상거래법](https://www.law.go.kr/), [공정거래위원회](https://www.ftc.go.kr/) |
| 무료체험·구독·자동결제 | 유료전환·대금 변경·해지 화면의 고지와 동의는? | [전자상거래법](https://www.law.go.kr/), [공정거래위원회](https://www.ftc.go.kr/) |
| 광고성 메시지 발송 | 수신 동의·광고 표시·수신거부 요건은? | [정보통신망법](https://www.law.go.kr/), [KISA](https://www.kisa.or.kr/) |
| 직접 충전·송금·결제 중개 | 전자금융업 등록이나 다른 금융 규제가 적용되는가? | [금융위원회](https://www.fsc.go.kr/), [국가법령정보센터](https://www.law.go.kr/) |
| 청소년 대상 콘텐츠 | 실제 매체·연령·유해성에 따른 분류·표시 요건은? | [국가법령정보센터](https://www.law.go.kr/) |
| 타인 저작물·AI 보조 산출물 활용 | 저작권·초상권·라이선스·표시광고 문제가 있는가? | [한국저작권위원회](https://www.copyright.or.kr/), [공정거래위원회](https://www.ftc.go.kr/) |

검토 기록에는 해당 조건, 확인한 화면·문서, 공식 조문과 시행일, 판단의 범위를 함께 적는다. 증거가 없으면 위반이나 준수를 단정하지 않는다. AI 기본법 제31조 적용 여부를 결과물 게시 여부만으로 결정하지 않는다. 앱 마켓의 결제 규칙과 앱 마켓 사업자에 대한 규제를 일반 앱 개발자의 의무로 혼동하지 않는다.
