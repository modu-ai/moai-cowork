# 서비스 기능별 적용 조건

플러그인 설치나 산출물 종류가 법적 의무를 자동으로 결정하지 않는다. 실제 서비스 운영을 확인한 뒤 아래 질문을 적용한다.

| 서비스 기능·운영 사실 | 추가로 확인할 사항 |
|---|---|
| 이용자에게 AI 기능 제공 | 인공지능기본법상 사업자 역할, 생성형·고영향 해당 여부, 투명성 방법 |
| 완성된 AI 보조 콘텐츠 게시 | 저작권·초상권·표시광고와 오인 가능성. AI 사업자 해당 여부는 별도 판단 |
| 개인정보 수집·처리 | 수집 근거, 처리방침, 위탁, 국외 이전, 보호조치, 유출 대응 |
| 유료 상품·서비스 판매 | 통신판매업 해당 여부, 사업자 표시, 청약철회, 결제 구조 |
| 자동결제·구독 | 유료전환·대금 변경 고지, 동의와 해지 흐름 |
| 광고성 정보 발송 | 수신 동의, 광고 표시, 수신 거부 |
| 아동·청소년 대상 또는 유해 콘텐츠 | 실제 대상 연령, 콘텐츠 종류와 관련 법령 |
| 의료·금융·법률 등 규제 분야 | 자격·인허가와 업종별 광고·안전 규정 |

각 행은 점검을 시작하는 조건이다. 위험도를 고정 숫자나 색으로 매기지 말고 적용 법령과 확인 자료를 연결한다.
