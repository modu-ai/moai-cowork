# 특허 분석

사용자가 원하는 결과가 동향, 선행기술, 특정 청구항 비교, 실시 자유 검토 자료, 출원서 초안 중 무엇인지 먼저 확인한다. 발명 설명, 실시할 제품과 국가, 기준일, 이미 확보한 문헌을 받는다. 빠진 정보가 결과에 영향을 주면 해당 항목을 미확인으로 두고 필요한 사실을 묻는다.

## 문헌 수집

- 사용자가 준 특허 번호·문헌을 먼저 확인한다. 추가 검색에는 legal-patent-search 또는 legal-ip-search-report를 사용한다.
- 검색 도구가 보이면 실제 도구명과 인자 형식을 확인하고 사용한다. 연결이나 인증이 없으면 공식 특허 검색 웹 화면으로 조사할 수 있다. 자격증명 부재와 검색 결과 0건을 구분한다.
- 검색 국가, 데이터베이스, 검색식, 검색일, 공개·등록 여부, 열람한 결과 수, 원문·청구항·법적 상태 확인 여부를 남긴다. 일부 결과만 봤다면 전체 출원 동향이나 침해 부재로 일반화하지 않는다.

## 분석

| 요청 | 확인할 자료 | 제시할 내용 |
|---|---|---|
| 동향 | 검색 결과의 출원일·출원인·분류·중복 패밀리 | 실제 집계와 검색 범위. 표본이나 누락 가능성을 함께 기록 |
| 선행기술 | 공개일, 발명 구성, 청구항·명세서 원문 | 구성요소별 대응표, 차이와 추가 검토가 필요한 부분 |
| 청구항 비교 | 유효한 청구항 문언, 제품 구현, 관할 국가와 기준일 | 확인된 요소별 대응과 불확실성. 비침해·무효 결론을 단정하지 않음 |
| 출원서 초안 | 발명자에게 확인한 구성, 실시예, 효과 자료 | 명칭·기술분야·배경·상세한 설명·청구항 초안. 모르는 실시예나 효과를 만들지 않음 |

실시 자유 검토는 국가별 권리 상태, 청구항 해석, 제품 사실관계에 좌우된다. 검색한 일부 특허로 포괄적 FTO 의견이나 안전 등급을 만들지 않는다. 등록 전 출원도 향후 권리화 가능성을 별도로 표시한다. 신규성·진보성, 균등침해, 무효 가능성은 검토 쟁점을 제시하고 변리사 판단이 필요한 부분을 명시한다.

## 결과 형식

1. 요청 목적과 기준일
2. 확인한 문헌 및 링크, 검색식과 조회 범위
3. 문헌별 근거와 구성요소 비교
4. 확인된 사실, 분석상 추론, 미확인 사항
5. 추가 문헌 조사나 변리사 검토가 필요한 질문

차트는 실제 집계가 있을 때만 만든다. 서술형 보고서의 문장을 다듬더라도 특허 번호·청구항·인용·유보 조건은 바꾸지 않는다. 실제 출원, 침해·비침해 의견 및 권리 범위 확정은 자격 있는 전문가의 검토가 필요하다.
