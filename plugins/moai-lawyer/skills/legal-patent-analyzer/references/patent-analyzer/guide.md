# 특허 분석 기록지

| 항목 | 기록 |
|---|---|
| 목적·대상 제품·관할 국가·기준일 | 사용자가 확인한 내용 |
| 검색 출처·검색식·실행일·조회 범위 | 실제 검색 기록 |
| 문헌 번호·공개일·출원인·법적 상태 | 공식 원문에서 확인한 내용과 URL |
| 청구항·명세서 열람 여부 | 원문을 못 봤다면 서지정보만 확인했다고 표시 |
| 구성요소별 대응 | 청구항 문구와 제품·발명 자료의 근거를 따로 적기 |
| 누락·미확인 | 미공개 출원, 다른 국가, 패밀리, 상태 변경, 제품 사실관계 |

유사 문헌 수나 정량적 성능 효과를 미리 정하지 않는다. 비교할 문헌은 관련성을 설명할 수 있는 범위에서 선택한다. 출원서 초안에는 발명자가 확인한 실시예와 효과만 넣는다. 등록 가능성이나 실시 자유에 대한 최종 판단은 전문가에게 넘긴다.
