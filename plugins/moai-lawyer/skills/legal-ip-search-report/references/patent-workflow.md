# 특허 정밀조사 워크플로

특허 조사는 목적에 따라 검색식과 판단 기준이 달라집니다. 선행기술·특허 동향·무효 자료·권리상태·FTO 예비조사를 먼저 가릅니다.

## 1. 조사 목적을 고정한다

| 목적 | 판단 기준 |
|---|---|
| 선행기술·특허성 | 기준일 전에 공개된 문헌, 신규성·진보성에 관련된 구성 |
| 특허 동향 | 기간·출원인·분류·기술 갈래별 출원 흐름 |
| 무효 자료 | 해당 청구항의 우선일 전 공개 자료와 공개 입증 가능성 |
| 권리상태 | 국가별 등록·소멸·포기·연차료·심판·소송 기록 |
| FTO 예비조사 | 실시 제품이 존속 청구항의 모든 구성요소를 충족하는지 |

FTO와 특허성 조사를 혼동하지 않습니다. 오래된 문헌은 특허성을 제한할 수 있어도 지금 실시를 막는 유효 권리가 아닐 수 있습니다. 반대로 새 제품이 특허를 받을 수 있더라도 남의 넓은 존속 청구항을 침해할 수 있습니다.

## 2. 기술을 검색 단위로 나눈다

1. 해결하려는 기술적 과제
2. 필수 구성요소와 선택 구성요소
3. 구성요소의 관계·배치·순서·수치 범위
4. 작동 원리와 결과
5. 대체 표현, 상위·하위 개념, 업계 용어
6. 한국어·영어·일본어 동의어와 번역 변형
7. 예상 IPC·CPC·FI·F-term과 인접 분류

제품 홍보 문구를 그대로 검색하지 않습니다. 명사·동사·관계·수치·목적을 나눠 검색 갈래를 만듭니다.

## 3. 검색 사다리

1. 핵심 키워드로 넓게 검색해 용어와 대표 문헌을 찾습니다.
2. 대표 문헌에서 IPC·CPC·FI·F-term과 출원인·발명자 표기를 모읍니다.
3. 키워드와 분류를 결합해 잡음을 줄입니다.
4. 관계·배치·수치·작동 원리까지 넣어 좁게 검색합니다.
5. 인용·피인용 문헌과 심사관 인용을 따라갑니다.
6. 패밀리·우선권 사슬·계속·분할 출원을 확인합니다.
7. 논문·표준·제품 설명서·영상·카탈로그 같은 비특허 문헌을 찾고 공개일을 입증합니다.
8. 주요 문헌의 독립청구항을 읽고 구성요소 대비표를 만듭니다.

초록 유사도는 후보 선별에만 씁니다. 최종 관련성은 청구항·명세서·도면·법적 상태를 함께 보고 판단합니다.

## 4. 국가별 실행

### 한국 — KIPRIS Plus

| 사다리 | 도구 호출 예 |
|---|---|
| 넓은 검색 | `kipris_patent_search(word="전고체 배터리 황화물")` |
| 청구항 중심 | `kipris_patent_search(claim="황화물 고체전해질", ipc_number="H01M")` |
| 출원인 동향 | `kipris_patent_search(applicant="삼성에스디아이", status="R")` |
| 상태 필터 | `status`: 빈 값=전체, `A`=공개, `R`=등록, `J`=거절, `F`=소멸, `G`=포기, `C`=취하, `I`=무효 |
| 정렬 | `sort_spec`: `PD`·`AD`·`GD`·`OPD`·`FD`·`FOD`·`RD` |
| 기간 | `extra_params={"applicationDate": "20200101~20251231"}` 처럼 공식 명세 파라미터를 넘김 |
| 서지 상세 | `kipris_patent_detail(application_number="1020200012345")` |

### 미국 — USPTO ODP

- 검색: `uspto_patent_search(q="solid state battery AND sulfide", limit=50)`
- 조건: `filters=[{"name": "...", "value": ["..."]}]`, `range_filters=[{"field": "...", "valueFrom": "2020-01-01", "valueTo": "2025-12-31"}]`
- 필드 이름은 ODP 문서의 검색 필드 목록을 확인해 씁니다.
- 출원 상세: `uspto_patent_application(application_number="16123456")`
- 같은 키로 동시 호출은 1건입니다. 여러 검색을 병렬로 던지지 않습니다.

### 유럽·국제 — EPO OPS

- 검색: `epo_search(cql='ta="solid state battery" and cpc=H01M10', start=1, end=100)` — 한 번에 100건, 누적 2,000건까지
- CQL 필드 예: `ta`(명칭·요약), `pa`(출원인), `in`(발명자), `ic`/`cpc`(분류), `pd`(공개일)
- 서지: `epo_biblio(reference_type="publication", number="EP.3000000.A1")`
- 패밀리와 국가별 법적 상태: `epo_family(reference_type="publication", number="EP.3000000.A1", constituent="legal")`
- 법적 상태 이력: `epo_legal(...)`
- EPO에는 여러 나라 공개 문헌이 수록되어 있어, 일본·중국 문헌의 후보 발굴에도 쓸 수 있습니다. 응답의 `quota`로 주간 사용량을 확인합니다.

### 일본 — J-PlatPat + JPO API

- 키워드 검색은 J-PlatPat 웹 화면(FI·F-term 검색 포함)이나 EPO 검색으로 하고, 사용한 화면·검색식·열람 범위를 기록합니다.
- 찾은 출원번호로 `jpo_patent_progress`(경과·우선권·분할 정보)와 `jpo_patent_registration`(등록·존속)을 확인합니다.
- 공개·등록번호만 알면 `jpo_case_number_reference(right="patent", kind="publication", number=...)`로 출원번호를 찾습니다.
- 조회마다 일일 상한이 있습니다. 응답의 `remain_access_count`를 증거대장 한계 칸에 적습니다.

## 5. 문헌별 증거를 기록한다

| 항목 | 기록할 내용 |
|---|---|
| 문헌번호 | 공개·등록번호와 국가 |
| 명칭 | 공식 발명의 명칭 |
| 날짜 | 우선일·출원일·공개일·등록일 |
| 당사자 | 출원인·권리자·발명자 |
| 분류 | IPC·CPC·FI·F-term |
| 패밀리 | 대표 패밀리와 국가별 대응 출원 |
| 상태 | 계류·등록·포기·소멸·만료와 확인 출처 |
| 청구항 | 검토한 독립청구항 번호와 핵심 구성 |
| 관련성 | 필수 구성의 일치·부분 일치·불일치 |
| 증거 | 공식 링크·인용 문헌·절차 기록 |
| 한계 | 번역·미공개 출원·상태 반영 지연 |

## 6. 청구항 대비표

필수 구성마다 한 줄을 두고 대상 제품이나 선행 문헌의 근거 위치를 표시합니다.

| 청구항 구성 | 대상에서 확인한 내용 | 근거 위치 | 판정 | 신뢰도 |
|---|---|---|---|---|
| 구성 A | 구체적 사실 | 도면·문단·사양 | 충족 / 부분 / 불충족 / 미확인 | 높음 / 중간 / 낮음 |

문언상 충족·기능적 동일성·균등 가능성을 나눕니다. 해석이 필요한 용어는 단정하지 말고 심사 기록·명세서 정의·판례 확인 대상으로 남깁니다.

## 7. 법적 상태를 검증한다

- 공개와 등록을 구분합니다.
- 출원인과 현재 권리자를 구분하고 양도 기록을 확인합니다.
- 연차료 미납·포기·거절·취하·소멸·만료와 회복 가능성을 구분합니다.
- 같은 패밀리라도 국가별 청구항과 존속 상태가 다름을 표시합니다.
- 분할·계속 출원에 더 넓거나 다른 청구항이 남아 있는지 확인합니다.
- 집행 가능성에 영향을 주는 심판·소송·정정 기록은 따로 검토합니다.

공식 법적 상태 표시는 늦거나 불완전할 수 있으므로, 중요한 권리는 원등록부나 현지 전문가 확인 대상으로 남깁니다.

## 8. FTO 경계를 지킨다

FTO 예비조사는 다음을 모두 고정해야 합니다.

- 출시 국가와 기준일
- 실제 제품 사양과 제조·사용·판매 방식
- 조사할 구성요소와 조합
- 존속 가능한 권리와 관련 패밀리
- 검토한 독립·종속청구항 범위

키워드 결과 0건, 유사 문헌 없음, 자사 특허 출원은 `침해 없음`을 뜻하지 않습니다. 정식 FTO 의견에는 최신 등록원부·청구항 해석·심사 기록·균등론·현지 법을 다루는 변리사·변호사의 검토가 필요합니다.

## 9. 결론 문장을 통제한다

- `현재 검색 범위에서 신규성 판단에 중요한 후보 문헌을 N건 확인했다.`
- `구성 X는 공개됐지만 구성 Y와의 결합은 추가 검토가 필요하다.`
- `이 결과는 FTO 예비조사이며 비침해 의견이 아니다.`
- `검색 결과가 없었다`는 관찰 뒤에는 데이터 범위·미공개 출원·번역·분류 한계를 반드시 붙입니다.
