# IP 조사 보고서 구조

보고서 제목 아래에 조사 수준을 표시합니다. 국가·권리마다 다르면 각각 표시합니다.

- `FULL — 공식 API·공식 사건 기록 검증`
- `LIMITED — API 미사용, 공개 검색 화면 기반` (키가 없어 사용자가 제한 조사를 고른 경우)
- `LIMITED — 공식 API 미제공, 웹 화면 기반` (미국 상표 문자 검색·일본 키워드 검색·국제 상표처럼 API가 없는 경우)

## 1. 표지와 문서 관리

- 조사 대상·권리 유형·국가·기준일
- 작성일·버전·보안 등급
- 조사 수준과 데이터 소스
- 법률 의견이 아니라는 한계

## 2. 경영진 요약

첫 페이지에 모읍니다.

- 한 줄 결론
- 국가·권리별 위험 등급과 신뢰도
- 지금 내려야 할 결정
- 바로 멈추거나 먼저 확보해야 할 행동
- 가장 중요한 미확인 항목

## 3. 평가 매트릭스

| 국가 | 대상 | 권리·류/분류 | 주요 선행권리·문헌 | 위험 | 신뢰도 | 권고 | 조사 수준 |
|---|---|---|---|---|---|---|---|

등급만 적지 않고 근거와 대응을 같은 줄에 둡니다.

## 4. 범위와 방법

- 목적과 포함·제외 범위
- 조사 기준일과 시간대
- 사용한 소스·도구와 `ip_check_access` 확인 결과(값 없이 configured/missing, verify 결과)
- 검색 언어·표장 변형·분류·날짜·상태 필터
- 전체 건수(`total_count`)와 실제 검토 건수
- 호출 한도·반영 지연·비공개 자료·웹 화면 한계·잘린 응답

키가 없어 제한 조사를 했다면, 등록 안내를 먼저 했고 사용자가 제한 조사를 골랐다는 사실을 적습니다. 키 값이나 계정 정보는 적지 않습니다.

## 5. 조사 결과

### 상표
1. 대상 표장과 지정상품·서비스
2. 완전일치·유사 표장 검색 결과
3. 핵심 사건 요약
4. 절대적 거절 위험
5. 상대적 거절·사용 위험
6. 국가별 차이

### 특허
1. 대상 기술과 필수 구성
2. 검색식과 분류
3. 핵심 문헌·패밀리·법적 상태
4. 독립청구항 대비
5. 신규성·진보성 또는 FTO 예비 판단
6. 국가별 권리 범위 차이

관찰과 해석을 눈에 띄게 나눕니다. 사건번호·날짜·상태·문헌 문구는 관찰이고, 등록 전망·유사 판단·회피 전략은 해석입니다.

## 6. 출원·보호 전략

- 권리별 우선순위
- 문자·음역·로고 또는 청구항군의 출원 순서
- 핵심 류·조건부 류와 지정상품 문안
- 개별국 출원·파리 우선권·마드리드·PCT 경로 비교
- 출원인·권리 귀속·사용 증거·비밀 유지 관리
- 이의·거절·충돌이 생겼을 때의 대응 시나리오

공식 수수료와 현지 대리인 견적을 확인하지 않았으면 비용은 범위나 추정이라고 밝힙니다.

## 7. 실행 순서

기간 예측 대신 순서와 완료 조건으로 적습니다.

| 순서 | 조치 | 산출물 | 담당 | 완료 조건 |
|---|---|---|---|---|
| 1 | 즉시 선점·자료 확보 | 출원 표장·발명 자료 확정 | 지정 | 의사결정 승인 |
| 2 | 핵심국 출원·보완 조사 | 출원 서류·의견 | 지정 | 접수증·사건번호 확인 |
| 3 | 우선권 기반 확장·감시 | 해외 출원·감시 체계 | 지정 | 마감일과 담당자 등록 |

파리 우선권처럼 법정 기한이 있으면 기한 자체(예: 최초 출원일로부터 상표 6개월·특허 12개월)를 날짜로 계산해 적습니다.

## 8. 증거대장

검색마다 빠짐없이 적습니다.

`검색 시각 | 국가 | 소스·도구 또는 웹 화면 | 실제 인자·검색식 | 필터 | 전체 건수 | 검토 건수 | 핵심 사건 | 공식 링크 | 한계`

같은 검색을 다시 했으면 기존 줄을 고치지 않고 새 줄을 더합니다.

## 9. 공식 출처

일반 설명 페이지보다 사건별 공식 기록과 현재 기관 지침을 앞에 둡니다. 링크마다 어떤 주장이나 사건을 뒷받침하는지 표시합니다.

## 10. 확인 필요 항목과 면책

- 입력 자료가 없어 판단하지 못한 내용
- API·DB에 들어 있지 않은 범위
- 현지 전문가 확인이 필요한 법률 쟁점
- 출원인·권리자·사용 증거·우선권 마감 등 사용자 결정 사항

면책 문구 취지: `본 조사는 지정된 범위와 기준일의 공개·공식 자료를 바탕으로 한 예비조사이며, 등록 보장·유효성 의견·비침해 법률 의견을 구성하지 않는다.`

## 11. 최종 품질 점검

- 표장·사건번호·날짜·권리자·상태를 원출처와 대조했다.
- 전체 건수와 검토 건수를 섞지 않았다.
- 링크가 사건이나 지침 원문으로 연결된다.
- 상표·특허·디자인, 출원·등록·소멸을 정확히 구분했다.
- 관찰·추론·권고·미확인을 나눴다.
- 등록 보장·침해 없음·FTO 완료 같은 과장 표현이 없다.
- 표와 각주가 잘리지 않고 DOCX·PDF 렌더링이 정상이다.
- 민감 정보와 API 키가 문서·로그·파일 속성에 없다.
