# 상표 정밀조사 워크플로

상표 조사는 같은 글자가 있는지만 찾는 일이 아닙니다. 표장의 외관·호칭·관념과 상품·서비스의 관련성을 함께 보고, 공식 사건 기록과 실제 사용 흔적을 나눠 기록합니다.

## 1. 검색어를 정리한다

먼저 후보군을 만듭니다.

1. 원문 완전일치와 띄어쓰기·하이픈·대소문자 변형
2. 한글·영문·가타카나·한자 음역과 흔한 오기
3. 붙여 쓰기와 띄어 쓰기, 단수·복수, 장음·촉음 같은 발음 변형
4. 식별력이 강한 구성요소와 약한 구성요소 각각의 단독 검색
5. 뜻이 가까운 번역·동의어, 업종에서 흔한 약어
6. 문자상표·도형상표·결합상표를 나눈 도형 분류(비엔나 코드) 검색

후보마다 검색 목적과 예상 충돌 유형을 붙입니다. 검색어 목록만 늘어놓지 않습니다.

## 2. 지정상품·서비스를 구조화한다

- 실제 출시할 상품·서비스를 니스 분류로 매핑합니다.
- 핵심 류, 방어용으로 필요한 류, 지금 사업과 먼 류를 나눕니다.
- 국가별로 허용되는 지정상품 문안을 공식 목록이나 심사 기준에서 확인합니다.
- 류 번호가 같다고 곧바로 유사하다고 보지 않고, 성질·용도·수요자·유통경로와 유사군 코드를 함께 봅니다.
- 넓고 모호한 문안, 사용 의사가 없는 문안, 지금 증명하기 어려운 문안은 따로 표시합니다.

## 3. 검색 사다리를 차례로 오른다

1. **완전일치**: 원문과 정리한 각 표장
2. **포함 검색**: 핵심 구성요소가 들어간 표장
3. **호칭 유사**: 발음·음절 수·강세·장음·탁음·받침 변형
4. **외관 유사**: 철자 교체·문자 배열·로고의 주요 도형
5. **관념 유사**: 번역·동의어·업계에서 통하는 의미
6. **인접 상품**: 핵심 류와 거래상 가까운 류
7. **권리상태 확장**: 존속·계류뿐 아니라 거절·포기·취소·만료도 비교 자료로 확인
8. **공식 DB 밖 실제 사용**: 회사명·상품명·도메인·앱스토어·SNS·마켓플레이스·언론 기사

공식 등록 기록과 미등록 사용은 같은 표에 섞지 않습니다. 공식 권리 충돌과 시장 사용 위험을 따로 평가합니다.

## 4. 국가별 실행

### 한국 — KIPRIS Plus (API)

| 사다리 | 도구 호출 예 |
|---|---|
| 완전일치·포함 | `kipris_trademark_search(trademark_name="모두의코워크")` |
| 유사군 중심 | `kipris_trademark_search(trademark_name="코워크", similarity_code="<유사군 코드>")` |
| 류 중심 | `kipris_trademark_search(trademark_name="coworker", classification="42")` |
| 출원인 중심 | `kipris_trademark_search(applicant_name="(주)경쟁사")` |
| 지정상품 문안 | `kipris_trademark_search(designated_goods="소프트웨어")` |
| 상태 좁히기 | `statuses=["application","registration","publication"]` (비우면 전체) |
| 도형 | `vienna_code="..."`, `compositions=["figure","figureComposition"]` |
| 상세·이력 | `kipris_trademark_detail(application_number="4020210124213")` |

- `total_count`가 크면 `num_of_rows`(최대 500)와 `page_no`로 나눠 보고, 실제 검토 건수를 따로 적습니다.
- 출원·공고·등록·소멸·거절 상태와 사건번호를 구분합니다.
- 선출원주의, 우선권, 불사용 취소, 저명표장·상호 충돌 가능성을 검토합니다.
- 한글과 영문이 둘 다 사업에 중요하면 각 문자상표와 결합상표를 따로 평가합니다.

### 미국 — 웹 화면 + TSDR (부분 API)

- USPTO는 상표 문자 검색 API를 제공하지 않습니다. 후보는 [USPTO Trademark Search](https://tmsearch.uspto.gov/)에서 찾고 이 부분을 `LIMITED`로 기록합니다.
- 찾은 일련번호마다 `uspto_trademark_status(number="97123456", number_type="sn")`로 상태·소유자·식별 문안·절차 기록을 확인합니다.
- 정확 표장과 변형 표장, 관련 상품·서비스의 실제 거래 관계를 검토합니다.
- 연방 등록과 별도로 주 등록·회사명·도메인·웹·마켓플레이스 사용(커먼로 위험)을 확인합니다.
- 출원 근거(`1(a)`·`1(b)`·`44(d)`·`44(e)`·마드리드)를 표시하고 사용 증거 일정을 관리합니다.
- 미국 밖 출원인은 미국 변호사 대리가 필요할 수 있으니 현재 USPTO 요건을 확인합니다.

### 일본 — J-PlatPat + JPO API (부분 API)

- 키워드 검색은 [J-PlatPat](https://www.j-platpat.inpit.go.jp/)에서 하고 `LIMITED`로 기록합니다. 라틴 문자·가타카나 예상 음역·장음·촉음·분절 변형을 모두 넣습니다.
- 찾은 출원번호(서기 4자리 + 6자리)는 `jpo_trademark_progress`로 표시용 상표·음역·지정상품·권리자를, `jpo_trademark_registration`으로 등록 정보를 확인합니다.
- 등록번호만 알면 `jpo_case_number_reference(right="trademark", kind="registration", number=...)`로 출원번호를 찾습니다.
- 핵심 류뿐 아니라 유사군 코드가 겹치는 인접 류를 확인합니다.
- 일본어 호칭이 여러 방식으로 굳어질 수 있으면 후보별 출원 필요성과 시장 사용 위험을 비교합니다.

### 유럽연합·국제(마드리드) — 웹 화면

- EUIPO eSearch, WIPO Madrid Monitor로 확인하고 `LIMITED`로 기록합니다. WIPO Global Brand Database는 자동 조회가 약관상 금지이므로 사람이 직접 조회합니다.

## 5. 핵심 사건을 열람한다

결과 목록의 제목만으로 판단하지 않습니다. 위험 후보마다 다음을 확인합니다.

| 항목 | 기록할 내용 |
|---|---|
| 표장 | 문자·도형·결합 여부와 실제 표기 |
| 사건번호 | 출원번호·등록번호와 공식 링크 |
| 날짜 | 출원일·우선일·등록일·갱신일 또는 소멸일 |
| 권리자 | 현재 명칭과 양도·명의 변경 여부 |
| 상태 | 계류·존속·거절·포기·취소·만료 |
| 범위 | 류·지정상품·서비스·제한·권리 불요구 |
| 유사성 | 외관·호칭·관념·전체 인상 |
| 관련성 | 상품 성질·용도·수요자·유통경로 |
| 대응 | 지정상품 축소·표장 변경·공존·동의 가능성·선행권리 확인 |

## 6. 결론 문장을 통제한다

- 쓸 수 있음: `현재 확인한 공식 기록과 검색 범위에서는 직접 충돌 위험이 낮게 관찰됐다.`
- 쓸 수 있음: `식별력 또는 선행권리 쟁점 때문에 중간 이상의 거절 위험이 있다.`
- 쓰면 안 됨: `등록 가능하다`, `100% 등록된다`, `동일 표장이 없으므로 안전하다`

결론에는 조사 기준일·검색 범위·검토 건수·미확인 영역·신뢰도를 붙입니다. 최종 출원 전에는 현지 변리사의 의견과 최신 사건 기록을 다시 확인합니다.
