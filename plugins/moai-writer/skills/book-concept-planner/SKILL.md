# book-concept-planner

> 책의 목적·독자·차별점을 사용자 자료와 확인된 조사 결과로 정리한다. 자료가 부족하면 가설이나 조사 과제로 표시한다. 후속 스킬은 사용자가 이미 제공한 개요가 있으면 이 문서 없이도 진행할 수 있다.

## 1. 개요

도서 컨셉서는 출판사 투고 직전 단계에서 작성하는 **책 한 권의 정체성 문서**입니다. 다음 4가지 질문에 답해야 합니다.

| 질문 | 산출물 |
|------|--------|
| 이 책은 누구를 위한가? | 확인된 독자 정보 또는 독자 가설 |
| 왜 지금 이 책이어야 하는가? | 확인된 시장 자료와 저자의 목적 |
| 무엇이 다른가? | 실제 비교 도서와의 차이 또는 검토할 가설 |
| 한 줄로 무엇인가? | 책의 핵심 설명 |

분량과 형식은 대상 출판사나 공모의 현재 제출 안내를 따른다. 컨셉서만으로 채택 가능성을 판단하지 않는다.

## 3. 워크플로우 (3단계 인사이트 도출)

### Step 1: 의도 파악 (Why?)

"왜 이 책을 쓰는가"를 명확히 한다. 기존 자료에 답이 없으면 현재 런타임의 사용자 질문 기능으로 다음 5가지를 확인한다. 질문 기능이 없는 실행 환경에서는 누락된 답을 명시하고 사용자 입력을 기다린다.

| # | 차원 | 질문 | 옵션 예시 |
|---|------|------|-----------|
| 1 | Why (저자 동기) | 책을 쓰는 가장 큰 이유는? | ① 표현 욕구 ② 경험·노하우 공유 ③ 흔적 남기기 ④ 시장 진입·수익 |
| 2 | What (타깃) | 누가 이 책을 읽기를 바라나? | 페르소나 1명 (나이·직업·고민) 자유 기술 |
| 3 | What (페인포인트) | 독자의 어떤 문제·고민을 해결하나? | 자유 기술 (3개 이내) |
| 4 | Who (의사결정자) | 출간 여부를 누가 최종 결정하나? | ① 출판사 편집장 ② 자비 출판 (저자 본인) ③ 독립 출판 펀딩 |
| 5 | Check (누락) | 다른 책에서 다루지 않는 영역이 있는가? | 자유 기술 |

책의 목적과 독자에 관한 필수 정보가 없으면 확인을 요청한다. 다른 항목은 `미확인`으로 표시하고 초안을 진행할 수 있다.

### Step 2: 리서치 (Research)

데스크 조사와 가능한 독자 조사를 진행한다. 실제로 수행한 조사와 제안한 조사를 구분한다.

#### 데스크 조사

| 자료 | 목적 | 출처 |
|------|------|------|
| 서점 도서 정보 | 실제 경쟁 도서의 제목·저자·발행일 확인 | 해당 서점·출판사 페이지 |
| 출판 통계 | 조사 연도·대상·지표가 맞는 경우만 인용 | 공식 조사 보고서 |
| 제출 안내 | 대상 출판사의 현재 접수 조건 확인 | 해당 출판사 공식 페이지 |

검색 키워드 팁:
- 한글 키워드 + 영문 키워드 (글로벌 트렌드 비교)
- 책 제목·저자명·ISBN 모두 시도
- 출판사 자체 사이트 (해당 출판사 신간 코너)

#### 필드 서치 (권장, 가능한 범위)

- **잠재 독자 인터뷰** — 가능하고 허락받은 경우 실제 고민과 선택 기준 확인
- **저자·편집자·서점 관계자 의견** — 실제 인터뷰가 이뤄진 경우 발언 맥락과 출처 기록

> 💡 필드 서치 1줄 원칙: **"나보다 조금이라도 잘 아는 사람에게 묻는다"**.

#### MECE 자료 정리

- 책의 주제에 필요한 자료만 묶어 정리한다.
- 확인하지 못한 자료는 별도 조사 항목으로 남긴다.

### Step 3: 컨셉 도출 (Insight)

확인한 자료를 책의 핵심 설명으로 정리한다. 다음 항목은 필요에 따라 작성한다.

#### 3-1. 차별점

실제로 확인한 관련 도서와 비교한다. 자료가 부족하면 차별점을 가설로 표시한다:

```
비교 도서: [확인한 제목·저자·발행 정보]
확인된 차이: [목차·본문 등 실제 비교 근거]
가설: [추가 검토가 필요한 차이]
```

차이가 있다고 해서 판매나 출판 계약이 보장되지는 않는다.

#### 3-2. 한 줄 요약

책의 대상과 내용을 간결하게 설명한다. 실제 사용처의 글자 수 제한이 있으면 그 기준을 따른다:

| 원칙 | 적용 방법 |
|------|----------|
| **구체성** | "많다" 같은 추상어 대신 그림이 그려지는 단어 사용 |
| **낯선 조합** | 평소 만나지 않을 두 단어의 결합으로 시선 끌기 |
| **검색 우선** | 일상에서 듣는 말에서 뽑아내기 (search > make) |

한자어는 우리말로 변환 권장:
- "진가를 발휘" → "제대로 합니다"
- "역부족이었다" → "모자랐다"
- "재발 방지" → "다시는 이런 일이 없도록"

#### 3-3. 짧은 소개문

독자·내용·차별점 중 확인된 요소를 조합한다. 결과나 소요 기간을 근거 없이 약속하지 않는다:

```
"내성적인 직장인을 위한 1:1 영업 책"     (타깃 + 카테고리)
"Next.js 앱 구성과 실습을 다루는 책"       (내용 + 독자)
```

#### 3-4. 시놉시스

책의 주제와 구성을 설명한다. 분량은 실제 제출처나 사용처의 요구에 맞춘다:

| 단 | 내용 |
|----|------|
| 도입 | 확인된 독자 상황과 책의 주제 |
| 전개 | 책이 실제로 다루는 내용 |
| 마무리 | 독자가 기대할 수 있는 학습·독서 경험을 과장 없이 설명 |

#### 3-5. 시장 포지셔닝 (2축 매트릭스)

실제로 확인한 도서만 비교한다. 자료가 부족하면 매트릭스를 생략한다:

```
            깊이 (심화)
                ↑
                │
                │  경쟁작 A    경쟁작 B
                │
실용 ←─────────┼───────────→ 서사
                │
                │  경쟁작 C    경쟁작 D
                │
                ↓
            깊이 (입문)
```

축은 장르별로 변형 가능:
- **실용서**: 깊이(입문 ↔ 심화) × 톤(실용 ↔ 서사)
- **인문서**: 시대(고대 ↔ 현대) × 관점(개인 ↔ 사회)
- **기술서**: 난이도(입문 ↔ 고급) × 범위(좁음 ↔ 넓음)
- **소설**: 분량(중편 ↔ 장편) × 시점(1인칭 ↔ 3인칭)

## 4. 장르별 검토 항목

- 실용서는 실제 독자의 사용 상황과 확인 가능한 사례를 본다.
- 인문·에세이는 저자의 관점과 글의 문체를 본다.
- 기술서는 코드·기술 버전과 실습 환경을 확인한다.
- 소설은 인물·갈등·서사의 고유한 구성을 설명한다.

장르만으로 표준 원고지 매수, 시장 크기, 출판사 접수 가능 여부를 정하지 않는다.

## 6. 시장 포지셔닝
비교 자료가 부족하면 `미확인 — 관련 도서 내용 조사 필요`라고 적고 매트릭스는 생략한다.

자료가 확인된 경우에만 2축 매트릭스의 축과 책의 위치를 근거와 함께 적는다.

| [실제로 확인한 도서만] | [확인] | [확인] | [근거] | [근거 또는 가설] |

- 세부 분류: [사용처 기준 확인 시 기재]

## 8. 자비 출판 vs 출판사 투고 권장 경로
| 기준 | 자비/독립 출판 | 출판사 투고 |
|------|---------------|--------------|
| 제작·편집 | 저자가 직접 준비할 범위 확인 | 계약 범위 확인 |
| 비용·수익 | 실제 견적·유통 조건 확인 | 실제 계약 조건 확인 |
| 일정 | 인쇄·유통 일정을 확인 | 투고·계약·제작 일정을 확인 |

**이 책의 검토 경로**: [저자의 목표·예산·권리 조건을 확인한 뒤 선택]

## 6. 사용 예시

"실용서 컨셉서 초안을 만들어 줘. 책의 목차와 저자의 경험은 제공할게. 독자 인터뷰와 시장 자료는 아직 없어."

→ 제공한 사실로 책의 핵심을 요약하고 독자·시장 정보는 가설이나 조사 과제로 표시한다. 대상 출판사가 정해지면 현재 공식 접수 조건을 확인한다.

## 7. 출판 자료 확인

시장 크기·독서 추세·가격 제도·투고 가능 여부는 실제 조사 연도와 현재 공식 안내를 확인한 뒤에만 적는다. 서점 판매 순위는 해당 서점의 화면과 집계 기준을 함께 기록한다. 신인상과 일반 투고 경로를 혼동하지 않는다.

## 8. 주의사항

### 자비 출판 vs 출판사 투고 의사결정

| 상황 | 권장 |
|------|------|
| 저자의 제작 역량 | 편집·디자인·인쇄·유통에서 직접 맡을 범위 확인 |
| 예산과 권리 | 실제 견적·계약 조건 비교 |
| 일정 | 저자가 원하는 일정과 현실적인 제작·접수 절차 확인 |
| 해외 출판 | 번역권·유통 조건을 해당 계약에서 확인 |

### 차별점 확인

- 관련 도서의 실제 내용과 비교해 독자가 얻을 수 있는 차이를 설명한다.
- 비교 자료가 부족하면 검증된 차별점이라고 표시하지 않는다.

### 외부 자료 직접 인용 금지

- 출판 시장 자료는 출처와 이용 조건을 확인하고, 카피·시놉시스는 제공된 책 내용으로 작성한다.
- 출처 노트의 비유·표현·예시 문장은 그대로 사용하지 않고, **개념·프레임워크만** 추출하여 재구성
- vault 자료 인용 가드 준수

## 9. 관련 스킬

### Before (앞 단계)
- 없음 — 이 스킬이 도서 워크플로우의 **첫 번째 산출물**

### After (체이닝)
- `book-target-reader` — 타깃 독자 페르소나 심화 + JTBD + 페인포인트 매트릭스
- `book-outline-designer` — 목차 설계 (부·장·꼭지) + 분량 배분 + 챕터 시놉시스
- `book-author-bio` — 저자 약력·저자의 말·SNS·강연 통합
- `book-proposal-writer` — 출판사 투고용 제안서 (출판기획서 + 샘플 챕터 + 마케팅 플랜)

### Alternative
- `moai-marketer:content-copywriting` — 도서 외 일반 카피 (광고·랜딩 페이지)
- `moai-consultant:consult-strategy` — 전략 컨셉 (사업·서비스 대상, 책 아님)
- `moai-marketer:marketing-campaign-planner` — 마케팅 캠페인 컨셉

### Post (필요한 경우)
- `moai-writer:korean-spell-check` — 공개 서비스 이용 조건·문서 공개 범위·사용자 의사를 확인
- `moai-coworker:ai-slop-reviewer` — 설치·노출된 경우 상투적 표현 검토
- `moai-writer:korean-humanize` — 필요하면 윤문 뒤 원문·수치·고유명사 대조

검수 스킬을 사용해도 미확인 시장 자료나 독자 가설이 검증된 사실로 바뀌지는 않는다.
