# book-author-bio

> 저자가 타깃 페르소나에게 **"왜 이 사람이 이 책을 쓰는가"**를 설명하는 문서. 본문 내용과 저자의 실제 이력이 함께 신뢰를 만듭니다. book-target-reader의 페르소나·JTBD를 입력받아 장르에 맞는 신뢰 신호를 고릅니다. 출판사나 채널의 실제 분량 요구를 먼저 확인하고, 별도 지정이 없으면 **짧은(50자)·중간(200자)·긴(500자) 약력**과 **저자의 말(500-800자)**을 초안으로 작성합니다.

## 1. 개요

저자 약력은 단순한 자기소개가 아닙니다. 페르소나 관점에서 다음 신호 중 **확인된 것만** 고릅니다.

| 신호 | 의미 | 작용 |
|------|------|------|
| **권위** | 이 분야에 대한 자격·경력·업적 | 책의 정확성·신뢰성 보장 |
| **공감** | 페르소나와 비슷한 경험·고민 | "이 사람도 나와 같았다" 동질감 |
| **변화** | 저자가 이뤄낸 구체적 결과 | "나도 책을 통해 같은 결과를 얻을 수 있다" |

신호가 부족하면 저자에게 필요한 사실을 확인합니다. 균형을 맞추려고 없는 경험이나 성과를 만들지 않습니다.

저자 약력은 **3 길이**(50자·200자·500자)로 동시 작성:

| 길이 | 사용처 |
|------|--------|
| 50자 | 표지 띠지·SNS 프로필·서점 검색 결과 |
| 200자 | 책 표지 뒷날개·온라인 서점 저자 소개 |
| 500자 | 책 뒷부분 저자 소개·언론 보도자료·강연 약력 |

## 2. 트리거 키워드

## 3. 워크플로우 (4단계)

### Step 1: 저자 자료 수집 (5 영역)

기존 자료에 없는 정보는 현재 런타임의 사용자 질문 기능으로 다음 5개 영역을 확인한다. 질문 기능이 없는 실행 환경에서는 누락된 영역을 명시하고 사용자 입력을 기다린다:

| 영역 | 질문 | 예시 |
|------|------|------|
| **학력·자격** | 학위·자격증·교육과정 | 서울대 경영학과·CFA·하버드 MBA |
| **실무 경력** | 회사·직책·연차·산업 | 삼성SDS 10년 / 컨설팅 5년 / 스타트업 창업 |
| **저술·강연** | 이전 저서·기고·강연 | 이전 저서 2권·매일경제 칼럼·삼성전자 사내 강연 |
| **수상·인증** | 수상 이력·언론 인용 | 한국마케팅대상 / 포브스 30 Under 30 |
| **팬덤·플랫폼** | SNS 팔로워·구독자·강의 누적 수강생 | 인스타 10만 / 유튜브 50만 / 클래스101 누적 5천명 |

> **[HARD] 확인되지 않은 이력·성과는 쓰지 않는다.** 학력·경력·저서·수상·판매 순위·SNS 수치는 저자 자료나 현재 원출처로 확인한다. 빈 영역을 그럴듯한 숫자나 사례로 채우지 않는다. 확인할 자료가 없으면 해당 영역을 빼고 확인 필요 항목으로 남긴다. 신호 개수만으로 출판사 채택 가능성을 판정하지 않는다.

### Step 2: 신뢰 신호 우선순위 결정

5 영역 자료를 페르소나 관점에서 **우선순위**로 재정렬. 어떤 신호가 페르소나에게 가장 강력한가?

| 페르소나 유형 | 1순위 신호 | 2순위 신호 |
|--------------|-----------|-----------|
| 입문 학습자 (실용서·기술서) | 실무 경력 + 학력 | 강연·수강생 수 |
| 전문가 (기술 심화서) | 실무 경력 + 저술 | 수상·인증 |
| 공감 추구자 (인문·에세이) | 개인 경험·서사 | 팬덤·SNS |
| 장르 독자 (소설·문학) | 이전 작품·문학상 | 작가 활동 |

페르소나 1순위 신호를 **약력 첫 문장**에 배치.

### Step 3: 3 길이 약력 동시 작성

실제 이력이 부족해 지정 글자 수를 채울 수 없으면 사실을 반복하거나 경험을 만들지 않습니다. 확인된 내용으로 짧은 초안을 작성하고 목표 분량과 부족한 자료를 표시합니다.

#### 50자 약력 (표지 띠지·SNS 프로필용)

**공식**: [정체성] + [핵심 신호] + [현재 활동]

예시:
- "10년 차 마케팅 매니저, 3권의 책을 쓴 저자, 인스타 10만 팔로워."
- "13년 차 백엔드 개발자, 기술서를 펴낸 저자이자 개발 강연자." (실제 저서·강연 이력이 확인된 경우)
- "두 아이 엄마이자 워킹맘, 일과 가족 사이 30대를 기록하는 에세이스트."

50자 작성 원칙:
- 지정된 글자 수 안에서 한 문장 또는 짧은 문장으로 쓴다
- 직업·작품·플랫폼 3 요소 중 최소 2개 포함
- 추상어 ("열정적", "전문가") 금지, 구체적 숫자·이름 우선

#### 200자 약력 (책 뒷날개용)

**공식**: 50자 약력 + [페르소나 공감] + [핵심 변화·결과]

예시 구조 (200자):
```
[50자 약력 도입]
[페르소나와의 공감 — 비슷한 고민·시작점]
[저자가 이뤄낸 구체적 변화·결과 1~2개]
[책을 쓴 이유 한 줄]
```

200자 작성 원칙:
- 첫 문장에 1순위 신호 (Step 2 결정)
- 두 번째 문장에 페르소나 공감
- 변화·결과가 확인됐으면 해당 내용을 넣는다. 확인된 숫자가 없으면 숫자를 만들지 않는다
- 마지막에 책을 쓴 이유 한 줄

#### 500자 약력 (긴 형식)

**공식**: 200자 약력 + [경력 타임라인] + [활동 영역] + [관심 분야]

예시 구조 (500자):
```
[200자 약력 도입]
[학력·자격 1~2줄]
[실무 경력 타임라인 2~3 회사]
[저술·강연·강의 활동 1~2 단락]
[현재 관심 분야·앞으로의 계획 1~2 문장]
[연락처·SNS·웹사이트 1줄]
```

500자 작성 원칙:
- 시간 순서 (오래된 순 → 최근) 또는 영역별 (학력 → 경력 → 저술)
- 구체적 회사명·작품명·수상명 명시
- 추상어 최소화

### Step 4: 저자의 말 작성 (500-800자)

저자의 말은 책의 **첫 페이지**에 들어가는 머리말. 4 단 구조:

| 단 | 분량 | 내용 |
|----|------|------|
| **1단 도입** | 100-150자 | 페르소나가 책을 펴는 순간의 상황 묘사 |
| **2단 공감** | 150-200자 | 저자도 그 자리에 있었다는 고백·서사 |
| **3단 약속** | 150-200자 | 이 책에서 무엇을 다룰지, 어떻게 도울지 |
| **4단 초대** | 100-150자 | 함께 읽기를 권하는 마무리 |

#### 저자의 말 작성 원칙

저자의 경험으로 서술할 장면은 저자가 제공하거나 확인한 자료에서만 가져옵니다. 장면 자료가 없으면 저자에게 묻고, 독자 상황을 예시로 든다면 가정임을 표시합니다.

1. **2인칭 또는 1인칭** — "당신은 지금…", "나는 5년 전…"
2. **구체적 장면** — 시간·장소·감각이 그려지도록
3. **숫자·이름 인용** — 추상 대신 구체 (예: "3년 전 마포구 카페에서…")
4. **공감 우선, 권위 후행** — 공감 신호가 먼저, 권위는 뒤에 자연스럽게
5. **책의 약속을 한 문장으로** — 3단 약속을 짧고 명확하게

```markdown
## 7. 검증 — 페르소나 시뮬레이션

이 약력을 페르소나가 읽었을 때:
- **권위 신호 인식**: ✅ / ❌ (이 사람이 신뢰할만 한가?)
- **공감 신호 인식**: ✅ / ❌ (이 사람이 나와 비슷한가?)
- **변화 신호 인식**: ✅ / ❌ (이 사람을 따라하면 결과를 얻을 수 있나?)
- **확인된 신호의 균형**: ✅ / ❌ / 확인 자료 부족

확인된 신호가 부족하면 약력을 부풀려 재작성하지 않고 필요한 저자 자료를 요청합니다.
```

## 6. 사용 예시

### 예시 1 — 실용서·자기계발 (부업서)

```
"30일 챌린지로 시작하는 부업" 책 저자 약력 작성해줘.
저자: 10년 차 마케팅 매니저, 3년간 부업으로 월 200만원 달성, 인스타 5만.
```

→ 1순위 신호: 실무 경력 + 결과(월 200만원) + 인스타 팬덤  
→ 50자: "10년 차 마케팅 매니저, 부업으로 월 200만원 달성한 N잡 워커, 인스타 5만 팔로워."  
→ 200자: 위의 확인된 이력과 책을 쓴 이유를 확장한다. 시작 시점·첫 매출 시점은 제공되지 않았으므로 넣지 않는다.
→ 500자: 학력·회사명·저술·강연 이력이 제공되지 않았다. 확인된 사실만으로 초안을 쓰고 부족한 이력은 확인 필요로 둔다.
→ 저자의 말: 책의 독자가 처할 수 있는 상황을 가정 사례로 표시하거나 저자에게 실제 장면을 묻는다. 저자가 겪은 일처럼 쓰지 않는다.

### 예시 2 — IT 입문서

```
"Next.js 15 + shadcn/ui" 책 저자 약력 작성해줘.
저자: 13년 차 풀스택, Next.js 컨트리뷰터, 유튜브 5만 구독, 한빛미디어 이전 저서 2권.
```

→ 1순위 신호: 실무 + Next.js 컨트리뷰터(오픈소스 권위)  
→ 50자: "13년 차 풀스택 개발자, Next.js 컨트리뷰터, 한빛미디어 저서 2권." 베스트셀러 여부는 제공되지 않았으므로 넣지 않는다.
→ 200자: 확인된 경력·저서·기고 활동을 확장한다. 주니어 3년 차 독자와 저자의 전환 경험은 입력에 없으므로 추정하지 않는다.
→ 저자의 말: 책의 대상 독자가 겪는 어려움과 확인된 목차의 약속을 연결한다. 실전 프로젝트 수는 목차로 확인될 때만 적는다

### 예시 3 — 인문·에세이 (40대 워킹맘)

```
"엄마이지만 나로 살기" 에세이집 저자 약력 작성. 
저자: 40대 워킹맘, 마케팅 업계 15년, 브런치·인스타 활동.
```

→ 인문 프리셋 → 정체성 강조 + 일상 관찰 서사  
→ 50자: "마케팅 업계에서 15년 일한 40대 저자. 브런치·인스타에서 활동한다."
→ 저자의 말: 워킹맘이라는 확인된 경험과 책의 실제 내용을 연결한다. 새벽 카페처럼 제공되지 않은 경험은 저자에게 확인한다.

## 7. 한국 출판 컨텍스트

### 저자 약력 한국 관행

- **'~다'/'~습니다' 어미**: 투고처의 최신 원고 양식과 저자 문체를 확인해 선택한다. 출판사별 고정 규칙을 추정하지 않는다
- **본명·필명**: 자비 출판·에세이는 필명 OK, 기술서·전문서는 본명 권장
- **국문·영문**: 한국 출판은 국문 우선, 영문 약력은 강연·해외 진출용
- **저자 사진**: 출판사 요구 시 별도 제공, 책에는 보통 단정한 정면 사진

### SNS 약력 한국 채널

| 채널 | 한도 | 특징 |
|------|------|------|
| 인스타그램 | 발행 시 확인 | 프로필 입력란에 맞춰 짧게 작성 |
| 브런치 | 발행 시 확인 | 소개란과 자기소개 페이지 구분 |
| 링크드인 | 영문 권장, 한국어 가능 | 비즈니스·강연 채널 |
| 유튜브 | 발행 시 확인 | 채널 설명에 확인된 활동과 주제 반영 |
| X(트위터) | 발행 시 확인 | 짧은 한 줄 정체성 |
| 카카오톡 채널·블로그 | 발행 시 확인 | 채널별 입력란과 독자층 확인 |

### 강연·강의 약력 한국 컨벤션

- 클래스101·인프런·유데미: 강사 소개 200자 + 강의 분야 키워드 5-10개
- 기업 사내 강연: 약력 500자 + 강의 주제 3-5개 + 사진
- 정부·공공기관 강연: 공식 이력서 형식 (학력·경력·자격증·수상)

## 8. 주의사항

### 약력 함정 회피

| 함정 | 피하는 법 |
|------|----------|
| **자랑 일변도** | 권위만 강조하면 거리감. 공감·변화 신호 추가 |
| **추상어 남용** | "열정적", "전문가" 같은 추상어 금지. 구체적 회사·작품·숫자 |
| **시간 순서 혼란** | 200자·500자 모두 시간 흐름 또는 영역 흐름 명확히 |
| **사적 정보 과다** | 가족·연애·종교 등 책과 무관한 사적 정보 금지 |
| **장르 미스매치** | 인문서에 IT 경력만, 기술서에 에세이만 자랑하지 않기 |
| **페르소나 무시** | 페르소나 1순위 신호를 약력 도입에 배치 |

### 저자의 말 함정

- **자기 변명·이력서식** 금지 — "이런 어려움이 있었지만…" 같은 변명 톤
- **책 내용 스포일러** 금지 — 책의 핵심 결론을 머리말에 다 풀어 놓지 않음
- **너무 긴 도입** — 도입이 200자 초과 시 핵심으로 빨리 진입
- **2인칭 갑작스러운 전환** — 1인칭·2인칭 시점 일관성 유지

### 출처 정책

- 학력·경력·수상 등 **사실 정확성** 필수 (출판 후 검증 가능)
- 부풀린 표현 금지 (예: "베스트셀러 작가" → 실제 베스트셀러 등극 시에만)
- vault 외부 참고 자료 직접 인용 금지
- SNS 팔로워·구독자 수는 작성 시점 기준 명시 (변동 가능)

## 9. 관련 스킬

### Before (앞 단계)
- `book-concept-planner` — USP·시장 포지셔닝
- `book-target-reader` — 페르소나·JTBD (1순위 신호 결정의 근거)
- `book-outline-designer` — 목차 (저자의 말의 약속 부분과 연결)

### After (체이닝)
- `book-proposal-writer` — 출판사 투고용 제안서 (저자 약력 포함)
- `book-publisher-matcher` — 한국 출판사 매칭 (저자 신뢰 신호 기반)

### Alternative
- `moai-career:career-resume` — 일반 이력서 (책 외)
- `moai-consultant:consult-strategy` — 사업 자기소개

### Post (검수 — 정규 체인)
- `moai-writer:korean-spell-check` — 한국어 맞춤법
- `moai-coworker:ai-slop-reviewer` — 별도 설치·노출된 경우 AI 슬롭 검수
- `moai-writer:korean-humanize` — 노출된 경우 문맥을 살린 정밀 윤문

> 약력·저자의 말 산문은 **사실 앵커와 원문 대조**로 마무리합니다. `ai-slop-reviewer`가 현재 호스트에 노출되면 추가로 사용하고, `korean-humanize`가 노출되면 문장 수정의 마지막 단계에 둡니다. 공개 맞춤법 검사는 현행 이용 조건에 맞고 문서가 공개 가능하며 사용자가 브라우저 검사에 동의한 경우에만 결과를 확인합니다.
