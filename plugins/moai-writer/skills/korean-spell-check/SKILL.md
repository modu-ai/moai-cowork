# 한국어 맞춤법·문법 검수

## 검사 전 확인

[바른한글 이전 버전 안내](https://nara-speller.co.kr/old_speller/)에는 비상업적 용도와 개인·학생 무료 이용 범위가 표시됩니다. 해당 범위에 맞는 사용자 주도 검사인지 확인하세요. 상업적·대량 자동 처리가 필요하면 공급자의 계약 가능한 제품이나 API를 확인합니다. 고객 정보·계약서·비공개 원고를 외부 사이트에 입력하기 전에는 사용자의 공개 범위와 동의를 확인합니다.

## 작업 순서

1. 원문을 보존하고 검사 범위를 정합니다. 코드, URL, 고유명사, 인용, 전문 용어는 별도로 표시합니다.
2. 이용 조건에 맞으면 사용자가 브라우저에서 공개 검사기 화면을 열어 텍스트를 검사합니다. 현재 화면에 표시된 제안과 이유만 가져옵니다. 외부 사이트의 숨은 결과 엔드포인트에 직접 POST하거나 브라우저 제한을 우회하지 않습니다.
3. 문맥과 의미를 대조합니다. 검사기 제안이 이름·수치·인용·전문 용어를 바꾸면 그대로 수용하지 않습니다.
4. 교정 문장, 바뀐 부분과 이유, 검사하지 못한 부분을 구분해 보고합니다. 실제 검사기를 열지 못했으면 자체 검토라고 표시하고 검사기 검수 완료로 쓰지 않습니다.

관련 작업: `moai-coworker:ai-slop-reviewer`는 문체 검수, `moai-writer:korean-humanize`는 문맥을 살린 윤문에 사용합니다. 두 작업의 결과도 맞춤법 검사기의 실제 실행 증거를 대신하지 않습니다.
