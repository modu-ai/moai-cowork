# book-proposal-writer

> 책의 개요, 실제 독자 자료, 목차, 저자 이력과 실행 가능한 홍보 계획을 투고처의 현재 요구 사항에 맞춰 정리한다. 제출 조건과 사실 자료가 확인되지 않은 항목은 초안에 표시하고 제출 준비가 끝난 것으로 판정하지 않는다.

## 1. 개요

다음 구성은 참고용이다. 대상 출판사나 공모가 요구하는 파일·분량·항목을 먼저 확인한다.

| 자료 | 목적 |
|------|------|
| **출판기획서** | 책의 주제·독자·구성을 설명 |
| **샘플 원고** | 실제 원고의 문체와 내용을 보여 줌 |
| **홍보 계획** | 저자가 실제로 할 수 있는 활동을 설명 |

편집자의 검토 시간이나 채택 확률을 임의 수치로 제시하지 않는다.

## 2. 트리거 키워드

자동 호출 트리거 (frontmatter description 참조). 슬래시 호출: `/book-proposal-writer`.

## 3. 워크플로우 (4단계)

### Step 1: 출판기획서 구성 (5 섹션)

다음 항목 중 투고처가 요구하는 것만 구성한다.

#### 1-1. 표지 (1 페이지)

| 요소 | 내용 |
|------|------|
| 가제 | book-concept-planner의 가제 |
| 한 줄 소개 | 확인된 책의 핵심 설명 |
| 저자 | 본명 또는 필명과 확인된 소개 |
| 장르·분량 | 책의 성격과 실제 계산 기준에 따른 분량 |
| 제출일·연락처 | 제출 단계에서 저자가 제공한 정보만 기재 |

#### 1-2. 책 개요

| 항목 | 분량 | 내용 |
|------|------|------|
| 시놉시스 | 투고처 요구 분량 | 제공된 책 개요를 요약 |
| 차별점 | 필요한 분량 | 실제 비교 자료로 설명 |
| 한 문장 요약 | 필요한 분량 | 책의 대상과 내용 설명 |

#### 1-3. 시장·독자 분석

| 항목 | 내용 |
|------|------|
| 시장 자료 | 실제 자료의 연도·정의·출처가 확인된 경우에만 규모·성장률 제시 |
| 타깃 페르소나 | book-target-reader의 확인된 항목을 요약하고 가설은 별도 표시 |
| JTBD | 확인된 독자 필요만 제시하고 빈 항목은 조사 과제로 표시 |
| 페인포인트 | 강도·빈도의 근거가 있는 고민만 우선순위화; 나머지는 미확인 |
| 비교 도서 | 실제 확인한 관련 도서와 차이를 설명 |

#### 1-4. 목차 + 시놉시스

| 항목 | 내용 |
|------|------|
| 전체 목차 | book-outline-designer가 실제 구성한 수준만 반영 |
| 분량 배분 | 실제 목표와 계산 기준을 확인한 경우 기재 |
| 챕터 시놉시스 | 제공된 개요에서 확인된 내용만 사용 |
| 부록·자료 | 템플릿·체크리스트·GitHub 등 |

#### 1-5. 저자 약력

| 항목 | 내용 |
|------|------|
| 저자 소개 | 실제 경력과 책 주제의 연결만 기재 |
| 이전 활동 | 확인된 저서·강연·채널만 기재 |
| 연락처 | 제출 단계에서 저자가 제공한 정보만 기재 |

### Step 2: 샘플 원고 준비

샘플 분량과 파일 형식은 투고처의 현재 안내를 따른다. 사용자가 제공한 원고가 없으면 별첨이 준비됐다고 표시하지 않는다.

#### 샘플 챕터 선정

| 선택 | 이유 |
|------|------|
| **실제로 완성한 장** | 책의 문체·구성을 보여 줄 수 있는 부분 |
| **USP가 가장 잘 드러나는 장** | 책의 차별점을 미리 보여줌 |
| **기타 발췌** | 투고처가 허용한 범위에서 선택 |

#### 샘플 챕터 작성 원칙

1. **분량**: 투고처가 지정한 기준을 확인한다.
2. **완성도**: 실제 원고와 별첨 파일을 대조한다.
3. **시각 자료**: 필요한 자료만 포함하고 사용 권한을 확인한다.
4. **인용·각주**: 출처와 이용 조건을 확인한다.
5. **문체**: 저자의 의도와 원고 전체의 흐름에 맞춘다.

샘플의 특정 쪽수만으로 채택 여부를 예측하지 않는다.

### Step 3: 실행 가능한 홍보 계획 작성

저자가 실제로 운영하는 채널, 약속할 수 있는 활동, 필요한 출판사 협의를 구분한다. 미확정 출연·강연·판매 목표를 확정 일정처럼 쓰지 않는다.

#### 검토할 활동

| 카테고리 | 활동 | 측정 지표 |
|---------|------|----------|
| **SNS 활동** | 인스타·유튜브·브런치·블로그 시리즈 | 팔로워·구독자·도달수 |
| **강연·강의** | 사내 강연·온라인 클래스·북토크 | 강연 횟수·참석자 |
| **언론·미디어** | 칼럼 기고·인터뷰·팟캐스트 출연 | 매체 수·도달 |
| **북클럽·커뮤니티** | 트레바리·문토·사내 북클럽 추천 | 북클럽 수·구성원 |
| **출간 이벤트** | 출간 기념 강연·사인회·온라인 라이브 | 행사 횟수·참석자 |

#### 홍보 계획 표기

```
활동: [저자가 실제로 할 수 있는 일]
근거: [기존 채널·협의 내역 또는 미확인]
시기: [출판 일정이 정해진 경우만]
출판사 협의: [상대의 승인이나 자원이 필요한 일]
```

#### 계획 점검

1. 현재 운영 중인 채널과 새로 제안할 활동을 구분한다.
2. 숫자와 일정은 실제 근거가 있을 때만 제시한다.
3. 출판사의 협력이 필요한 일은 제안으로 표시한다.

### Step 4: 투고처 양식 확인

투고처의 현재 공식 안내에서 접수 여부, 제출 경로, 파일 형식, 분량, 동시 투고 제한을 확인한다. 확인되지 않으면 제출 경로를 만들지 않고 `미확인`으로 남긴다.

## 4. 장르별 설명 조정

- 실용서는 실제 사용 장면과 검증 가능한 사례를 설명한다.
- 인문·에세이는 저자의 관점과 문체를 보여 준다.
- 기술서는 검증한 코드·버전·실습 조건을 적는다.
- 소설은 작품의 인물·갈등·서사를 설명한다.

이 조정은 출판사별 양식이나 분량을 뜻하지 않는다. 제출 형식은 해당 투고처의 공식 안내에서 확인한다.

## 6. 사용 예시

"기술서 출판 제안서 초안을 작성해 줘. 목차와 저자 이력은 줄게. 대상 출판사의 접수 안내는 아직 확인하지 못했어."

→ 제공된 목차와 이력으로 초안을 만들고, 시장 수치·독자 조사·제출 경로는 확인 전까지 `미확인`으로 둔다. 샘플 원고 파일이 없으면 첨부 완료로 표시하지 않는다.

## 7. 투고처별 제출 조건

대상 출판사 또는 공모의 현재 공식 안내에서 접수 여부, 작품·장르 적합성, 분량·파일 형식, 권리·동시 투고 조건, 제출 경로와 마감일을 확인한다. 확인한 페이지와 확인일을 제안서에 기록한다. 신인상과 일반 투고는 별도 경로일 수 있으므로 서로 대체하지 않는다. 공식 안내가 없으면 임의 이메일 주소나 응답 기간을 제시하지 않는다.

## 8. 주의사항

### 거절 신호 사전 검출

다음 항목은 제출 전 검토할 자료의 빈틈이다. 채택 확률이나 거절 사유를 예측하지 않는다:

| 거절 신호 | 보완 방법 |
|----------|----------|
| **USP 약함** | book-concept-planner Step 3 재방문, 경쟁작 매트릭스 강화 |
| **독자 자료 부족** | 확인된 독자 정보와 가설을 분리하고 조사 과제 표시 |
| **목차 분량 불균형** | book-outline-designer Step 2·4 검증 통과 |
| **저자 이력 미확인** | 제공된 이력만 쓰고 증빙 없는 항목은 보류 |
| **샘플 원고 미첨부** | 실제 파일을 확인하고 투고처 요구 분량과 대조 |
| **홍보 계획 불확실** | 실행 가능한 활동과 협의가 필요한 제안을 구분 |
| **투고처 양식 미확인** | 현재 공식 제출 안내 확인 |

### 투고 함정 회피

| 함정 | 피하는 법 |
|------|----------|
| **이력서식 제안서** | 책의 가치(USP·페르소나·시장)를 중심으로, 저자 약력은 후반 |
| **분량 부적합** | 투고처의 현재 분량 기준과 대조 |
| **숫자 부풀리기** | SNS 팔로워·강연 횟수 등 사실 정확성 필수 |
| **출판사 일괄 메일** | 받는 사람·인사말 일괄 복사 금지, 출판사별 맞춤 |
| **후속 연락 시점 추정** | 접수처가 안내한 절차·기간을 확인 |
| **사적 정보 과다** | 가족·종교·정치 등 책과 무관한 사적 정보 금지 |

### 출처 정책

- 시장 데이터·인용은 **출처 명시** (KPIPA·교보문고·잡코리아 등)
- SNS 수치·강연 횟수 등 **사실 정확성** 필수
- vault 외부 참고 자료 직접 인용 금지

- `book-outline-designer` — 목차·시놉시스
- `book-author-bio` — 확인된 저자 약력이 필요한 경우

### After (체이닝)
- `book-publisher-matcher` — 출판사 매칭 (제안서 완성 후 어디에 보낼지)
- `book-chapter-writer` — 샘플 원고가 필요한 경우

### Alternative
- `moai-consultant:consult-strategy` — 사업 제안서 (책 아님)
- `moai-tutor:education-grant-writer` — 정부지원사업 신청

### Post (필요한 경우)
- `moai-writer:korean-spell-check` — 공개 서비스 이용 조건·문서 공개 범위·사용자 의사를 확인
- `moai-coworker:ai-slop-reviewer` — 설치·노출된 경우 산문 검토
- `moai-writer:korean-humanize` — 필요하면 윤문 뒤 원문·수치·고유명사 대조

최종 검토에서는 실제 별첨 파일, 저자 이력, 시장 자료, 투고처 조건을 다시 확인한다. 미확인 항목이 있으면 제출 준비 완료로 표시하지 않는다.
