# 출판사 투고처 조사

## 입력

책의 장르·주제·독자, 원고 완성도, 분량, 저자 이력, 선호하는 출판 방식과 권리 조건을 받습니다. 없는 이력이나 독자 규모를 추정해 채우지 않습니다.

## 조사

1. 후보 출판사의 **현재 공식 홈페이지**에서 투고 접수 여부, 원고 형식, 제출 주소·폼, 답변 정책을 확인합니다. 공모전은 현재 모집 공고와 자격·마감일을 별도로 확인합니다. 확인 날짜와 직접 링크를 남깁니다.
2. 최근 출간 목록과 후보 책의 장르·독자 적합성을 비교합니다. 확인되지 않은 임프린트 관계, 담당 편집자 연락처, 접수 성공 확률을 적지 않습니다.
3. 인세율·선인세·계약 기간·전자책·해외 판권은 실제 제안이나 계약서가 있을 때만 비교합니다. 일반적인 숫자를 해당 출판사의 제안 조건처럼 제시하지 않습니다. 계약 판단이 필요하면 전문 검토를 받도록 안내합니다.
4. 자비 출판·독립 출판·펀딩을 비교할 때는 현재 가격과 수수료, 저자 부담, 유통 범위를 공식 자료로 확인합니다.

## 결과

검증된 후보만 우선순위와 선정 이유, 확인한 투고 경로, 확인 날짜, 미확인 조건으로 정리합니다. 다섯 곳을 채우기 위해 부적합하거나 접수 여부가 불명확한 출판사를 넣지 않습니다. 사용자의 요청 없이 원고나 제안서를 출판사에 보내지 않습니다. 답변 지연이나 거절 이후의 재투고 시점은 각 출판사의 현행 안내와 사용자 일정에 맞춰 결정합니다.
