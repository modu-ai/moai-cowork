# book-target-reader

> 도서 타깃 독자의 필요와 독서 상황을 정리하는 스킬. 사용자 자료가 있으면 그 자료를 우선하고, 없으면 가설 페르소나라고 표시한다. 조사에서 확인하지 않은 생활·구매·완독 행동을 실제 독자의 특성으로 쓰지 않는다.

## 1. 개요

인구통계만으로 독자의 필요를 단정하지 않는다. 다음 세 차원을 살피되 자료가 없는 항목은 `미확인` 또는 조사 질문으로 남긴다.

| 차원 | 정의 | 산출물 |
|------|------|--------|
| **WHO** (누구) | 인구통계·라이프스타일·정체성 | 페르소나 카드 (4축) |
| **WHY** (왜) | 책을 통해 해결하려는 일 | 확인된 JTBD와 조사 질문 |
| **WHAT** (무엇) | 현재 겪고 있는 구체적 문제 | 페인포인트 매트릭스 (강도·빈도) |

`book-concept-planner`의 독자 정의나 사용자가 제공한 독자 자료를 입력으로 받는다. 확인된 내용과 추가 조사가 필요한 내용을 카드에 나눠 적는다.

## 2. 트리거 키워드

자동 호출 트리거 (frontmatter description 참조). 슬래시 호출: `/book-target-reader`.

## 3. 워크플로우 (4단계)

### Step 1: 페르소나 카드 (4축)

입력 자료에서 확인된 항목만 다음 축으로 정리한다. 빈칸을 채우려고 수치나 구매 이력을 만들지 않는다:

| 축 | 질문 | 예시 (실용서·30대 워킹맘) |
|----|------|---------------------------|
| **인구통계** | 실제 조사에서 필요한 나이·직업 등 | 확인된 범위만 기재 |
| **라이프스타일** | 독서 시간·정보 채널 등 | 인터뷰·설문 자료가 있으면 기재 |
| **정체성** | 스스로 설명한 가치관·관심사 | 당사자 표현을 확인한 경우만 기재 |
| **소비 신호** | 구매·이용 경험 | 실제 자료가 있으면 기재 |

**페르소나 작성 원칙** (vault 카피라이터 노트의 통찰 적용):
- **상품보다 사람을 본다** — 책의 기능을 묘사하지 말고 책을 읽는 사람을 묘사
- **당사자 자료를 확인한다** — 가능하면 실제 독자 인터뷰나 설문으로 가설을 검토한다. 표본 수와 한계를 함께 적는다.
- **고정관념 회피** — 성별·나이별 역할을 당연하게 단정하지 않음 (예: "엄마=집안일"·"아빠=출근")

### Step 2: JTBD (Jobs To Be Done) 정의

독자가 책을 통해 이루려는 일을 자료에 맞춰 정의한다. 기능적·감정적·사회적 결과는 검토 항목이며 세 가지를 모두 만들어 낼 필요는 없다.

#### JTBD 작성 공식

```
[상황] 에서, [동기] 때문에, [기능적/감정적/사회적 결과] 를 원한다.
```

#### 3 차원 JTBD

| 차원 | 정의 | 예시 (30대 워킹맘 부업서) |
|------|------|---------------------------|
| **기능적 JTBD** | 명확히 측정 가능한 결과 | "월 50만원 추가 수입을 얻고 싶다" |
| **감정적 JTBD** | 내면적 감정 변화 | "회사에 의존하지 않는다는 안정감을 얻고 싶다" |
| **사회적 JTBD** | 타인의 인식·관계 변화 | "동료들에게 능력있는 사람으로 보이고 싶다" |

확인된 결과와 가설을 구분한다. 자료가 부족하면 독자에게 물을 질문으로 남긴다.

### Step 3: 페인포인트 매트릭스

페인포인트(고민·문제·불편)를 **강도 × 빈도** 매트릭스로 정리.

```
              빈도 (자주 ↑)
                │
        [핵심 페인]    [긴급 페인]
강도 약 ←──────┼──────→ 강도 강
        [잠재 페인]    [희귀 페인]
                │
              빈도 (드물 ↓)
```

| 분면 | 의미 | 책의 대응 |
|------|------|----------|
| 핵심 페인 (약·자주) | 매일 겪는 작은 고민 | 책의 **본문 핵심 챕터**로 다룸 |
| 긴급 페인 (강·자주) | 매주 폭발하는 큰 고민 | **30자 카피·시놉시스 도입부**로 직격 |
| 잠재 페인 (약·드물) | 가끔 떠오르는 불안 | **부록·심화 챕터**로 다룸 |
| 희귀 페인 (강·드물) | 극단적 상황 | **사례·인터뷰** 정도 |

#### 페인포인트 추출

사용자 자료나 실제 조사에서 확인된 고민을 다음 영역으로 정리한다. 자료가 없으면 조사 질문으로 남긴다:
- 시간 (시간 부족·우선순위 갈등)
- 돈 (수입·지출·노후)
- 관계 (가족·동료·상사)
- 자기인식 (자존감·성취·정체성)
- 미래 (불확실성·기회 부족)
- 신체·건강
- 공간·환경

### Step 4: 독서 행동 데이터

페르소나가 **어떻게 책을 사고 읽나** 정리. 책 마케팅·유통 의사결정의 기반.

| 항목 | 질문 | 예시 |
|------|------|------|
| 정보 채널 | 신간을 어디서 알게 되나? | 인스타·유튜브·동료 추천 |
| 구매 채널 | 어디서 사나? | 알라딘·교보문고·로컬 서점 |
| 가격 민감도 | 가격에 따른 선택이 달라지는가? | 조사 결과가 있으면 범위와 조건 기재 |
| 형식 선호 | 종이책 vs 전자책 vs 오디오북? | 통근시 전자책·주말 종이책·운전 오디오북 |
| 읽는 시간대 | 언제 읽나? | 출근길 30분·취침 전 20분 |
| 완독률 | 실제 측정 자료가 있는가? | 자료가 없으면 미확인 |
| 후기 행동 | 다 읽으면 무엇을 하나? | 인스타 인증·동료 추천·재독 |

국민독서실태조사는 문화체육관광부의 실제 발행 연도와 질문·표본을 확인한 뒤 관련 수치만 인용한다. 전국 조사 결과를 특정 페르소나의 완독률이나 구매 행동으로 대체하지 않는다.

## 4. 장르별 조사 질문 예시

아래는 조사할 주제의 예시다. 비중·완독률·독서 시간은 장르만으로 추정하지 않는다.

### 4-1. 실용서·자기계발

| 차원 | 분기 |
|------|------|
| 조사할 결과 | 책에서 얻고 싶은 실용적·감정적 변화 |
| 페인포인트 영역 | 시간·돈·자기인식 |
| 독서 상황 | 실제 독자가 언제 읽는지 확인 |

### 4-2. 인문·교양·에세이

| 차원 | 분기 |
|------|------|
| 조사할 결과 | 독자가 기대하는 관점·감정·지식 |
| 페인포인트 영역 | 자기인식·관계·미래 |
| 독서 상황 | 실제 독자가 어떤 속도로 읽는지 확인 |

### 4-3. 기술·전문서·IT 입문서

| 차원 | 분기 |
|------|------|
| 조사할 결과 | 학습·업무·취미 중 독자가 원하는 변화 |
| 페인포인트 영역 | 시간(학습)·미래(커리어)·자기인식(역량) |
| 독서 상황 | 실습 가능 시간과 장비를 확인 |
| 독자 수준 | 사용자가 제공한 경험과 선행 지식을 확인 |

### 4-4. 소설·문학

| 차원 | 분기 |
|------|------|
| 조사할 결과 | 작품에서 기대하는 경험과 취향 |
| 페인포인트 영역 | 일상 탈출·정서 위로·상상력 |
| 독서 상황 | 실제 독자가 책을 고르고 읽는 방식 확인 |

## 5. 출력 형식 (페르소나 카드 + JTBD + 페인포인트 매트릭스)

```markdown
# 타깃 독자 페르소나 — [도서 가제]

## 1. 페르소나 카드 (4축)

### 인구통계
- 나이·성별·직업: ___
- 연봉·거주지: ___
- 가족 구성: ___

### 라이프스타일
- 하루 일과: ___
- 취미·여가: ___
- 주요 정보 채널: ___

### 정체성
- 자기 인식: ___
- 가치관·신념: ___
- 불리고 싶은 이름: ___

### 소비 신호
- 비슷한 책·강의·앱: ___
- 평균 도서 구매 빈도: ___

## 2. JTBD (해당하는 항목만)

| 차원 | JTBD 정의 |
|------|----------|
| 기능적 | [상황]에서 [동기] 때문에 [측정 가능한 결과]를 원한다 |
| 감정적 | [상황]에서 [동기] 때문에 [내면 감정 변화]를 원한다 |
| 사회적 | [상황]에서 [동기] 때문에 [타인 인식 변화]를 원한다 |

## 3. 페인포인트 매트릭스

| 페인포인트 | 강도 (1~5) | 빈도 (1~5) | 분면 | 책 대응 |
|-----------|:---------:|:---------:|------|--------|
| [확인된 고민] | [조사값/미확인] | [조사값/미확인] | [근거 있을 때 분류] | [검토할 대응] |
| ... |

## 4. 독서 행동 데이터

| 항목 | 값 |
|------|----|
| 신간 정보 채널 | ___ |
| 구매 채널 | ___ |
| 가격 민감도 | 조사값 또는 미확인 |
| 형식 선호 | 조사값 또는 미확인 |
| 읽는 시간대 | ___ |
| 완독률 | 측정값과 표본 또는 미확인 |
| 후기 행동 | ___ |

## 5. 카피·시놉시스 적용 가이드

이 페르소나에 맞춘 카피·시놉시스 작성 시 다음을 활용:
- **사람 우선 표현**: 책의 기능 대신 책을 읽는 사람·결과 묘사
- **JTBD 반영**: 실제 자료로 확인한 독자의 필요만 카피에 반영
- **페인 강도 정렬**: 강도·빈도가 조사된 경우에만 우선순위에 반영
- **고정관념 회피**: 성별·나이·직업 역할 단정 금지

## 6. 검증 — 실제 독자 자료

사용 가능한 인터뷰·설문·독자 행동 자료의 출처, 표본, 수집 시점과 한계를 적는다. 자료가 없으면 페르소나는 가설로 유지한다. 소수 인터뷰의 임의 점수나 고정 합격선을 실제 시장 검증으로 표시하지 않는다.
```

## 6. 사용 예시

### 예시 1 — 실용서·자기계발

```
book-concept-planner에서 "30대 워킹맘" 페르소나로 컨셉서 완성.
이제 book-target-reader로 4축 페르소나 카드 + JTBD + 페인 매트릭스 작성해줘.
```

→ 가설 카드: 실제 직업·정보 채널·자기 표현은 미확인
→ JTBD 질문: 원하는 변화, 불안, 주변 관계에서 중요하게 보는 점
→ 페인포인트 질문: 시간·돈·관계 중 무엇이 실제 문제인지 확인
→ 독서 행동: 채널·시간·완독률 자료가 없으면 미확인

### 예시 2 — IT 입문서

```
"Next.js 15 + shadcn/ui" 책 페르소나로 주니어 3년차 백엔드 개발자 설정.
JTBD와 페인포인트 매트릭스 만들어줘.
```

→ 제공된 사실: 백엔드 개발 경력 3년
→ 확인할 질문: Next.js 학습 목적, 선행 지식, 실습 가능 환경
→ 추가 조사 전에는 성별·연봉·독서 시간·완독률을 추정하지 않음

## 7. 한국 독자 조사 자료 확인

### 국민독서실태조사

문화체육관광부의 현재 공개 보고서에서 필요한 지표의 조사 연도·대상·질문·수치를 확인해 출처와 함께 적는다. 확인하지 않은 연간 독서율, 권수, 전자책·오디오북 이용률, 구매 채널 순위는 기입하지 않는다. 2025년 보고서가 공개돼 있으며, 이후 발행 자료가 있는지도 사용할 때 확인한다.

전국 평균은 특정 장르나 개인의 구매·완독 행동을 증명하지 않는다.

### 독자 행동 질문

- 어떤 경로로 책을 발견하고 구입했는가?
- 어떤 형식과 독서 환경을 선호하는가?
- 이 주제의 기존 책에서 무엇이 부족했는가?

## 8. 주의사항

### 페르소나 함정 회피

| 함정 | 피하는 법 |
|------|----------|
| **인구통계만 정의** | WHY·WHAT 차원까지 채움 (JTBD + 페인포인트) |
| **너무 광범위한 페르소나** | "30-50대 직장인" 같은 광범위 페르소나 금지. 1명에 집중 |
| **저자 자신의 투영** | 저자와 독자를 동일시하지 않고 실제 자료로 가설 확인 |
| **고정관념 (성·나이·직업)** | "엄마=육아"·"아빠=출근" 같은 단정 금지 |
| **JTBD 임의 보완** | 근거 있는 필요만 적고 나머지는 조사 질문으로 유지 |
| **페인 강도 추정** | 강도·빈도 자료가 없으면 점수를 만들지 않음 |

### 검증 의무

- 인터뷰나 설문을 수행하지 않았으면 `가설`이라고 표시한다.
- 조사 결과가 있으면 표본·질문·수집 시점·한계를 적고 페르소나를 수정한다.

### 출처 정책

- vault 외부 참고 자료 직접 인용 금지
- 인사이트·프레임워크만 추출, 비유·예시 표현은 자체 작성
- 한국 독자 통계는 문화체육관광부의 실제 조사 보고서에서 연도·대상·질문을 확인하고 출처 명시

## 9. 관련 스킬

### Before (앞 단계)
- `book-concept-planner` — 1줄 페르소나 + USP·시장 포지셔닝 입력

### After (체이닝)
- `book-outline-designer` — 페르소나·JTBD 기반 목차 설계
- `book-author-bio` — 저자가 페르소나에게 신뢰를 주는 약력
- `book-proposal-writer` — 출판사 투고용 제안서 (페르소나·JTBD 인용)

### Alternative
- `moai-seller:commerce-jtbd-persona` — 이커머스 상품용 JTBD·페르소나 (도서 외)
- `moai-marketer:marketing-campaign-planner` — 마케팅 캠페인 페르소나

### Post (필요한 경우)
- `moai-writer:korean-spell-check` — 공개 서비스 이용 조건·문서 공개 범위·사용자 의사를 확인
- `moai-coworker:ai-slop-reviewer` — 설치·노출돼 있으면 상투적 표현 검토
- `moai-writer:korean-humanize` — 필요하면 서술만 윤문하고 자료·수치·가설 표기를 원문과 대조

검수 스킬을 사용했더라도 가설이 검증된 독자 데이터로 바뀌지 않는다.
