# 도서 출판 작업 경로

1. 책의 분야·장르, 대상 독자, 기존 원고, 제출 대상과 필요한 산출물을 확인한다. 필수 자료가 없으면 현재 런타임의 질문 채널로 묻고, 질문할 수 없는 하위 실행에서는 누락 자료를 blocker로 반환한다.
2. 콘셉트 → 목표 독자 → 목차 → 챕터 → 퇴고 → 제안서·출판사 조사 순서로 해당 `book-*` 스킬을 따른다. 웹툰·웹소설·시나리오·IP 피치는 `moai-story:story-project`로 연결한다.
3. 한국어 원고의 마감은 `book-revision-coach` 뒤 `korean-spell-check`, `korean-humanize` 지침을 따른다. 윤문 전후 고유명사·수치·날짜·인용을 대조하고 `korean-humanize`의 변경률 기준을 적용한다.
4. 출판사·공모전·인세·투고 기한은 현재 출처로 확인한다. 식별 가능한 타 작품 표현을 복제하지 않고 인용과 참고 자료를 표시한다.
5. 제출 전 `book-manuscript-audit` 기준으로 원고 일관성과 제안서 근거를 검수한다. 같은 주체의 자기 검수는 독립 감사라고 부르지 않는다.

Claude의 `writer-director` 에이전트와 목적이 겹친다. ChatGPT 플러그인에서는 이 스킬이 발견 가능한 진입점이다.
