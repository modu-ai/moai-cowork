# 데이터 출처와 계산 검수

원본 파일과 외부 데이터 서비스를 변경하지 않고 산출물의 근거를 대조한다.

- 인용된 KOSIS 통계표 ID, DART 접수번호, data.go.kr 데이터셋 또는 건축물 질의 조건을 찾고 지역·기간·단위가 주장한 수치와 맞는지 확인한다. 원문을 볼 수 없으면 출처 확인은 미검증으로 남긴다.
- 표·차트·본문·요약의 수치와 축 단위, 날짜가 원자료와 같은지 확인한다. 합계·증감률·평균·면적당 가격 등 계산은 입력값으로 다시 산출한다.
- 주민등록번호, 전화번호, 개인 주소, 계좌번호 등 불필요한 개인 식별 정보가 산출물에 드러나는지 확인한다.
- 조회 실패를 추정값으로 바꿔 적었는지, 실측·추정·예측을 구분했는지 확인한다.

보고서는 `판정(PASS/FAIL/미확인)`, `확인 자료`, `위치·근거가 있는 발견`, `재계산 표`, `출처 범위 대조`, `미검증 항목`으로 쓴다. 확인하지 못한 수치를 PASS로 채우지 않는다. 독립된 검수자를 실행하지 않았다면 독립 감사라고 부르지 않는다.
