# 데이터 작업 경로 선택

1. 데이터 분야, 지역·대상, 기간, 산출물, 성공 기준을 확인한다. 필수 입력이 빠지면 현재 런타임의 질문 채널로 묻고, 질문할 수 없는 하위 실행에서는 누락값을 blocker로 반환한다.
2. KOSIS·공공데이터는 `data-public`, 실거래가는 `data-realestate`, 법원 경매는 `data-court-auction`, 종목 데이터는 `data-stock`, 건축물 자료는 `data-building-ledger` 지침을 따른다. 사용자가 준 CSV·Excel은 `data-explorer`로 점검한 뒤 필요한 경우 `data-visualizer`로 시각화한다.
3. 현재 세션에서 필요한 데이터 연결 도구가 실제로 노출되는지 확인한다. 연결이 없으면 `연결 불가`, 조회했지만 결과가 없으면 `[NOT_FOUND]`와 조회 범위를 기록한다. 어느 경우에도 값을 만들어 채우지 않는다. 대체 자료를 찾을 때는 원래 요청과 출처·기준 시점이 다른지 밝힌다.
4. 공개 수치에는 통계표 ID, 공시 접수번호, 데이터셋 이름 또는 질의 조건을 연결한다. 원자료의 값·날짜·단위를 표와 차트로 옮길 때 다시 대조하고, 개인 식별 정보가 불필요하게 노출되지 않게 한다.
5. 중요한 수치가 포함된 결과는 `data-provenance-audit` 기준으로 대조한다. 같은 주체가 수행한 확인은 독립 감사라고 부르지 않는다. 결과에는 실제 조회 경로와 미검증 항목을 함께 적는다.

Claude의 `data-analyst` 에이전트와 목적이 겹친다. ChatGPT 플러그인에서는 이 스킬이 발견 가능한 진입점이다.
