# 소상공인365 PDF 자료 확인표

소상공인365의 간단·상세 분석에 실제로 표시된 항목만 추출합니다. [소상공인시장진흥공단 교육 안내](https://edu.sbiz.or.kr/edu/online/onlineEduForm.do?cseqno=542)는 매출·점포 수·인구 특성의 비교를 설명하지만 모든 PDF에 같은 필드가 있다는 뜻은 아닙니다.

| 범주 | 확인할 값 | 기록할 조건 |
|---|---|---|
| 보고서 정보 | 분석 지역, 업종, 유형, 기준 기간 | PDF 표제·쪽 번호·발행 또는 조회일 |
| 인구 | 유동·주거·직장 인구, 연령·성별·시간대 분포 | 실제 표의 집계 범위·단위 |
| 매출 | 업종 집계 매출, 거래 건수, 시간대 분포 | 추정값 여부·표본·기준 기간 |
| 점포 | 같은 업종의 점포 수, 개·폐업 등 | 지역 경계·업종 분류·집계 기간 |
| 환경 | 교통·집객 시설, 배달 관련 수치 | PDF에 실제 제공된 경우만 기록 |

- 항목이 없으면 `자료 없음`으로 표시합니다. 다른 지역·전체 업종의 값을 관심 업종의 값으로 대체하지 않습니다.
- 비율을 재계산할 때는 분자와 분모가 같은 지역·기간·업종인지 확인합니다.
- 연령별 비율과 성별 비율만으로 특정 연령·성별의 교차 비율을 만들지 않습니다.
- PDF의 추정 매출을 실제 점포의 매출이나 향후 매출로 바꾸어 쓰지 않습니다.
