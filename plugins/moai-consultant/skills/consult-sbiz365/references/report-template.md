# 상권분석 보고서 작성 가이드

소상공인365 PDF에서 확인한 값, 해석, 추가 조사 항목을 구분해 작성합니다. Word 파일은 사용자가 요청하고 현재 앱에서 문서 생성 기능을 쓸 수 있을 때 만듭니다.

## 보고서 구성

1. **분석 범위:** 지역·업종·PDF 유형·기준 기간·원본 파일명.
2. **확인한 자료:** 인구·매출·점포·입지별 실제 표의 값, 단위, 쪽 번호.
3. **비교와 해석:** 같은 정의의 기간·지역·업종끼리 비교한 결과와 자료 한계.
4. **확인할 위험:** 계약 임대료, 실제 동선, 경쟁점, 원가, 운영비 등 PDF에 없는 변수.
5. **다음 조사:** 사용자가 창업 결정을 내리기 전 필요한 현장 조사와 재무 계산 입력값.

## 요약 예시

> **관찰:** [지역·업종·기간] PDF의 [쪽]에서 [확인한 수치]를 확인했습니다.
>
> **해석:** [같은 기준의 비교 결과]. 이 수치는 개별 점포의 예상 매출이나 수익률이 아닙니다.
>
> **자료 공백:** [누락된 값]. 매출 전망이나 투자 회수 기간은 [필요한 입력값]을 받은 뒤 별도로 계산할 수 있습니다.
>
> **다음 확인:** [현장 동선·경쟁점·임대 조건 등].

## 검토

- 모든 숫자가 PDF의 쪽·표·기준 기간으로 추적되는가?
- 집계 매출을 신규 점포 매출로 오해하게 쓰지 않았는가?
- 자체 점수나 `창업 적합` 판정을 만들지 않았는가?
- 자료 누락과 사업자별 재무·현장 확인 사항을 명시했는가?
- 파일을 만든 경우 사용자가 정한 저장 위치에 저장하고 다시 열어 확인했는가?
