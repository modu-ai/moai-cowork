# 경영 컨설팅 작업 경로

1. 사업과 창업자 현황, 필요한 산출물, 의사결정 기준, 예산과 대상 시장을 확인한다. 사업 설명·재무 자료·상권 보고서·공고문 등 필수 입력이 없으면 현재 런타임의 질문 채널로 묻고, 질문할 수 없는 하위 실행에서는 누락 자료를 blocker로 반환한다.
2. 사업 전략은 `consult-strategy`, 창업 계획은 `consult-startup`, 컨설팅 제안은 `consult-brief`, 시장 규모와 경쟁사는 `consult-market`, 지원사업은 `consult-gov-grant`, 소상공인365 상권 분석은 `consult-sbiz365` 지침을 따른다.
3. 시장 규모·성장률·경쟁사·유동인구·예상 매출의 출처와 기준 시점을 붙인다. 추정치는 산식과 가정을 표시하고, TAM/SAM/SOM의 축소 단계마다 데이터와 필터 근거를 남긴다.
4. 계획에는 하방 시나리오와 주요 가정을 포함한다. 지원 자격은 해당 공고의 평가 기준과 대조하고 불명확한 조건은 기관 확인 사항으로 남긴다. 타당성 판정은 근거·위험을 함께 제시하는 의사결정 자료로 작성한다.
5. 제출 전 `consult-feasibility-audit` 기준으로 수치·출처·자격요건을 대조한다. 같은 주체의 자기 검수는 독립 감사라고 부르지 않는다. 확인하지 못한 항목을 명시한다.

Claude의 `strategy-consultant` 에이전트와 목적이 겹친다. ChatGPT 플러그인에서는 이 스킬이 발견 가능한 진입점이다.
