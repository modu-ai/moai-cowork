# 경영 타당성 검수

원본을 수정하지 않고 주장마다 근거를 추적한다.

- TAM/SAM/SOM 각 단계의 방법·기준 수치·필터를 확인하고 산식을 다시 계산한다. 요약과 본문, 인력 계획과 예산에서 재사용된 수치가 일치하는지 대조한다.
- 시장 규모·성장률·경쟁사·유동인구·매출 기준값이 실제 인용 자료에 있는지 확인한다. 찾을 수 없는 수치는 출처 미확인으로 남기고, 출처가 주장을 뒷받침하지 않으면 위치와 함께 결함으로 기록한다.
- 매출 전망의 가정과 하방 시나리오를 확인한다. 급격한 성장·마진 수치가 근거 없이 제시됐는지 검토한다.
- 지원사업 자격 주장과 현재 공고문의 해당 기준을 항목별로 대조한다. 공고문이 없으면 자격을 PASS로 판정하지 않는다.
- 타당성 결론이 보고서의 근거와 위험을 반영하는지 확인한다. 근거 없는 단정은 결함으로 기록한다.

보고서는 `판정(PASS/FAIL/미확인)`, `확인 자료`, `주장별 출처·재계산 결과`, `심각도·위치·근거가 있는 발견`, `미검증 항목`으로 작성한다. 판단 대상의 모든 사실·수치·자격 주장을 대조한다. 확인된 계산 오류나 허위 근거가 있으면 전체 사실성 판정은 FAIL이다. 그런 오류가 없더라도 확인하지 못한 주장이 하나라도 남으면 `미확인`으로 제한한다. 모든 주장이 확인되고 오류가 없을 때만 PASS를 쓴다. 독립된 검수자를 실행하지 않았다면 독립 감사라고 부르지 않는다.
