# 대한민국 정부지원사업 통합 분석·신청 스킬

정부·공공 지원사업의 현재 공고를 확인하고 신청서 초안을 돕습니다. 신청 자격과 평가 기준은 공고 원문과 신청자의 증빙 자료로 판단합니다.

> 이 스킬은 범용 지원사업 전반을 다룹니다. 학술·R&D 연구비 과제는 `moai-tutor:education-grant-writer`가 설치돼 있으면 연결합니다. 없으면 현재 공고의 자격·평가·서식 중 확인 가능한 항목만 이 스킬에서 정리하고, 전문 과제 검토가 이뤄지지 않았음을 밝힙니다.

---

## 시작: 신청자 유형 파악

요청이 들어오면 먼저 신청자가 어떤 상황인지 **핵심 2가지만** 파악합니다. 이미 대화에서 알 수 있으면 묻지 않습니다.

**① 신청자 유형** (해당하는 것 하나)
- 예비창업자 (아직 사업자 없음)
- 사업자등록을 마친 창업자 (업력은 공고 기준으로 확인)
- 소상공인·자영업자
- 중소·중견기업
- 연구자·연구기관
- 비영리단체·협동조합·사회적기업
- 개인 (프리랜서·청년·농업인 등)

**② 원하는 지원 목적** (해당하는 것 하나 이상)
- 창업 자금 / 사업화 / R&D 기술개발
- 시설·장비 / 운영자금
- 마케팅·수출 / 해외진출
- 인력 채용·교육 / 컨설팅
- 공간·플랫폼 / 콘텐츠 제작

> 업종·지역·업력 등 자격 요건에 필요한 정보가 없으면 공고 후보만 제시하고 신청 가능 여부는 판정하지 않습니다.

---

## MODE 1 — 지원사업 탐색·추천

**트리거:** "맞는 지원사업 찾아줘", "어떤 거 받을 수 있어", "지원금 뭐 있어" 등

### 탐색 절차

1. 신청자 유형·목적 파악 (위 항목 참고)
2. `references/programs.md`의 공식 공고 출발점과 주관기관 사이트에서 현재 공고 원문을 찾음
3. 사업명·접수 상태·대상·마감 시각·지원 방식·자부담·중복 제한을 공고 원문과 첨부파일에서 확인
4. 신청자의 증빙 정보와 대조한 뒤 아래 형식으로 결과 제공. 원문을 읽지 못하면 적격 여부를 보류

### 출력 템플릿

```
## [신청자 상황] 맞춤 지원사업 추천

### 1순위: [사업명]
- 주관기관:
- 지원 규모:
- 지원 대상:
- 신청 가능 여부: 가능 / 조건 확인 필요 / 해당 없음
- 추천 이유: (신청자 상황과의 매칭 근거 2~3줄)
- 핵심 평가 지표:
- 접수 상태와 마감 시각: [공고 확인값 또는 확인 불가]
- 공식 정보: [공고 원문 URL·조회일]

[2순위, 3순위 동일 형식]

---
### 현재 조건으로 신청 불가한 사업 및 이유
### 다음 단계
1. 공고문 원문 확인: K-Startup(k-startup.go.kr) 또는 각 기관 사이트
2. 신청서 작성 필요 시: "○○ 신청서 써줘"라고 말씀해 주세요
```

### 공고 탐색 참고

공식 공고 출발점과 원문 확인 항목은 `references/programs.md`를 따릅니다. 신청서 작성 절차는 `references/grant-writer.md`를 참고합니다. 특정 지원사업을 연령·업력·지원 금액만으로 추천하지 않습니다.

---

## MODE 2 — 신청서·사업계획서 초안 작성

**트리거:** "신청서 써줘", "사업계획서 초안 만들어줘", "지원서 작성 도와줘" 등

### 필수 파악 정보

없는 항목은 `[추후 기입]`으로 표시하고 보강 포인트에서 안내합니다.

```
1. 어떤 사업에 신청하는가?
2. 사업 아이템 한 줄 소개 (무엇을 / 누구에게 / 어떻게)
3. 핵심 차별점 (왜 우리만 할 수 있는가)
4. 신청자·팀 역량 (대표 경력, 핵심 팀원)
5. 보유 성과 (매출, 특허, 수상, 투자, 고객 등)
```

### 작성 원칙

공고의 실제 평가 항목에 맞춰 확인된 사실과 증빙을 분명하게 전달하는 것이 목표입니다.

- **수치 근거**: 시장 규모·성장률·매출은 확인한 자료와 산식이 있을 때만 기재. 자료가 없으면 검증 필요로 표시
- **차별성 선공**: 첫 문단에 경쟁 우위를 명확히
- **평가 항목 대응**: 해당 공고에 실제로 기재된 평가 항목과 배점을 사용
- **약점 선제 대응**: 특허 없음·매출 없음 등 약점이 있으면 보완 전략 먼저 제시
- **사업별 언어 사용**: 창업 지원은 "혁신·시장 검증", R&D는 "TRL 단계·정량 목표", 전통시장은 "지역 상생·활성화"

### 항목 출력 형식

```
## [항목 번호]. [항목명]

### 작성 가이드
이 항목에서 심사위원이 보고 싶은 것: ...
주의할 점: ...

### 초안
[실제 신청서에 들어갈 내용]

### 보강 포인트
- 추가하면 점수 올라가는 내용: ...
- 현재 약점 및 대응 방안: ...
```

### 공고별 항목 구조

사업계획서의 필수 항목·순서·분량·서식은 현재 공고의 첨부 양식을 따릅니다. 공고를 받지 못했다면 문제·해결안·시장 근거·실행 계획·팀 역량·예산 근거의 빈 초안을 제안하고, 제출 서식으로 완성했다고 표시하지 않습니다.

### 문서 파일 출력

신청서 초안 작성 후 파일로 원하면 아래 스킬을 체인합니다.
현재 앱에서 사용 가능한 문서 스킬을 확인해 선택합니다.

- **Word(.docx)**: 사용 가능하면 `moai-officer:doc-docx` 또는 앱의 문서 기능
- **한글(.hwpx)**: 사용 가능하면 `moai-officer:doc-hwp`
- **Excel(.xlsx)** (일정표·예산표): 사용 가능하면 `moai-officer:doc-xlsx` 또는 앱의 스프레드시트 기능

## MODE 3 — 서류 검토·피드백

**트리거:** "신청서 검토해줘", "사업계획서 봐줘", "심사 기준으로 보면 어때" 등

사용자가 신청서 내용을 붙여넣거나 파일로 제공하면 아래 기준으로 분석합니다.

### 심사 기준별 체크포인트

공고 원문에 적힌 평가 항목·배점·가점·필수 서류를 표로 옮겨 신청서와 대조합니다. 공고가 없으면 일반적인 사업성·실행 가능성·팀 역량을 참고 질문으로만 사용하고, 배점이나 합격 가능성을 산정하지 않습니다.

### 출력 템플릿

```
## 종합 평가
검토 범위: [공고 원문 확인 여부와 제공된 서류]

### 강점
- [구체적 강점]

### 반드시 보완 (TOP 3)
1. [항목] — 현재: "..." → 개선안: "..."
2. [항목] — 현재: "..." → 개선안: "..."
3. [항목] — 현재: "..." → 개선안: "..."

---
## 항목별 상세 피드백
### 사업성 / 기술성 / 팀 역량 / 실현가능성 / 전달력
[각 항목별 세부 의견 + 구체적 수정 방향]
```

## MODE 4 — 일정 관리·서류 체크리스트

**트리거:** "마감일 체크리스트", "준비 일정표", "언제까지 뭘 해야 해" 등

### 일정과 서류 확인

공고의 접수 시작·마감 **날짜와 시각, 시간대**, 제출 경로, 첨부 서류 목록을 원문에서 확인합니다. 마감 정보를 확인하지 못했다면 역산 일정표를 만들지 않습니다. 실제 마감일이 확인되면 사용자의 준비 상황에 맞춰 작업 순서를 작성합니다. 시스템 혼잡이나 제출 실패 위험은 일반적인 주의로 안내하되 특정 시각의 장애를 단정하지 않습니다.

필수 서류는 공고별로 다릅니다. 사업자등록증·재무제표·특허 증빙 등의 필요 여부를 공고 원문과 신청자 유형에 따라 표시하고, 준비되지 않은 서류는 누락으로 기록합니다.

---

## 마지막 단계 — 사실·문안 검수

사업계획서·신청서·검토 피드백의 자격요건·평가 기준·금액·마감 시각을 현재 공고와 다시 대조합니다. 서술 본문의 과장·어색한 표현을 이 스킬 안에서 고칩니다. `moai-coworker:ai-slop-reviewer`와 `moai-writer:korean-humanize`가 현재 앱에 설치돼 사용 가능하면 신청자 식별값과 금액·날짜 등 수치를 제외한 서술 부분만 추가로 다듬습니다. 윤문 뒤 원래 수치를 정확히 유지하고 공고 기준·의미를 다시 확인하며, 사용하지 않은 스킬을 실행했다고 기록하지 않습니다. 표·수치·공고 링크·신청자 개인정보는 추가 윤문에 넘기지 않습니다.

## 웹 검색 활용 원칙

마감일·지원 규모·선발 인원 등 변동 정보는 **항상 최신 공고를 웹 검색으로 확인**합니다.

주요 공고 확인 사이트:
- 창업 지원: https://www.k-startup.go.kr
- 중소기업 지원: https://www.bizinfo.go.kr
- R&D 과제: https://www.iris.go.kr / https://www.nrf.re.kr
- 전통시장: https://www.semas.or.kr
- 문화·관광: https://www.mcst.go.kr / https://www.kto.or.kr
- 농식품: https://www.mafra.go.kr

출처 URL을 반드시 명시하고 "공고문 원문 확인을 권장합니다"라고 안내합니다.

## 사용하지 말아야 할 상황

- 법인 등기·세금 신고 등 법적 서류 작성 (법무사·세무사 영역)
- 금융 투자 상품 추천 (주식·펀드 제외)
- 종료된 공고의 신청서 작성 (먼저 현재 공고 여부 확인 권장)
- 신청 대행·실제 제출 행위 (정보 제공 및 초안 작성만 지원)
- 학술·연구 중심 과제는 `moai-tutor:education-grant-writer`가 설치돼 있으면 연결하고, 없으면 확인 가능한 공고 항목과 전문 검토 공백을 구분
