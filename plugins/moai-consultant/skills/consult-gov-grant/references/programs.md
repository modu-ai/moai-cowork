# 정부·공공 지원사업 공고 탐색

이 문서는 고정된 지원사업 목록이 아닙니다. 사업명·모집 여부·지원 금액·대상·지역·마감일·중복 수혜 조건은 공고마다 달라지므로 신청 시점의 원문으로 확인합니다.

## 공식 공고 출발점

- [K-Startup 사업공고](https://www.k-startup.go.kr/web/main/mainSection0.do): 창업 단계·연령·관심 분야로 공고를 찾습니다.
- [기업마당](https://www.bizinfo.go.kr/web/index.do): 지역과 지원 분야의 기업 지원 공고를 찾습니다.
- R&D·지역·문화·농업 분야는 검색 결과의 주관기관 공고 원문과 첨부 서류를 다시 확인합니다.

## 공고별 확인 항목

| 항목 | 기록할 내용 |
|---|---|
| 출처 | 주관기관의 공고 URL, 공고 번호, 조회일 |
| 현재 상태 | 접수 중·예정·마감·확인 불가 |
| 대상 | 업력, 기업 형태, 연령, 업종, 지역 등 원문 조건 |
| 지원 | 금액·자부담·지원 방식·집행 제한 |
| 절차 | 접수 경로, 마감 시각, 제출 서류, 평가 단계 |
| 중복 제한 | 해당 공고와 운영 지침에 적힌 중복 수혜·신청 제한 |

공고 원문을 확인하지 못했다면 사업명만 후보로 표시하고 적격 여부나 지원 금액을 확정하지 않습니다. 사용자의 기업 정보를 모르면 자격 판정도 보류합니다. 링크가 살아 있다는 사실만으로 해당 연도의 모집이나 접수를 확인한 것으로 보지 않습니다.
