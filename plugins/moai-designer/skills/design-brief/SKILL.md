# 디자인 브리프

사용자의 요청을 디자인 도구나 담당자에게 전달할 수 있는 명확한 브리프로 정리한다. [Claude Design 공식 안내](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)에 따르면 디자인은 Claude 대화, Artifacts, Claude Code, `claude.ai/design`에서 시작할 수 있다. 브리프의 내용은 이 중 어느 경로에서도 사용할 수 있게 작성한다. ChatGPT Work에서도 같은 브리프를 읽고 현재 사용 가능한 디자인·이미지 도구에 맞게 활용할 수 있다.

## 작성 순서

1. 사용자가 이미 준 목표, 대상 사용자, 필요한 화면·문서, 브랜드 자료, 참고 이미지·URL, 사용 환경과 제약을 추출한다. 없는 항목을 실제 사실처럼 채우지 않는다.
2. 디자인 결정에 꼭 필요한 정보만 묻는다. 답을 기다리지 않아도 초안을 만들 수 있다면 미정·가정 항목을 표시하고 진행한다. 호스트 전용 질문 도구 이름을 절차의 필수 조건으로 두지 않는다.
3. 참고 URL·이미지는 실제 제공되었거나 조회한 경우에만 넣는다. 특정 회사나 디자이너의 경력·소속을 프롬프트 속 가상 권위로 만들지 않는다.
4. 브랜드 서체·색·레이아웃을 일괄 금지하거나 강제하지 않는다. 제공된 디자인 시스템과 사용 목적을 기준으로 정하고, 접근성·반응형·콘텐츠 길이 같은 확인할 제약을 명시한다.
5. 원하는 산출물과 검토 기준을 적는다. Claude Design을 사용할 경우 실제 이용 가능한 앱 표면에서 브리프를 붙여 넣거나 대화에 전달한다. 디자인이 생성·내보내기·동기화됐다는 주장은 결과를 확인한 뒤에만 한다.

## 브리프 틀

```markdown
# 디자인 브리프

## 목표
[사용자가 달성하려는 결과와 근거]

## 대상과 사용 맥락
[확인된 사용자·기기·상황 / 미정 사항]

## 필요한 화면·산출물
[각 화면의 목적과 핵심 콘텐츠]

## 브랜드와 참고 자료
[제공된 디자인 시스템·파일·URL / 출처]

## 제약과 검토 기준
[접근성·반응형·기술·문구·제외 범위]

## 결정 대기
[확인할 항목과 현재 가정]
```

사용자가 Claude Design용 복사 프롬프트를 원하면 이 브리프를 자연어 지시문으로 합쳐 제공한다. 디자인 시스템 준비는 `moai-designer:design-system-prep`, 특정 영역의 프롬프트는 `moai-designer:design-prompt-builder`, 생성된 결과 검수는 `moai-designer:design-slop-check`를 사용한다.
