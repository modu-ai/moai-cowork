# 선택적 핸드오프 보조 파일

MoAI Path A가 다섯 파일을 요구하거나 사용자가 분리 문서를 원할 때 아래 파일을 만든다. 파일 내용은 실제 입력과 결정만 담는다.

| 파일 | 내용 |
|---|---|
| `prompt.md` | 디자인 세션에 전달할 목적·범위·브랜드·결과 조건 |
| `context.md` | 원자료의 요약과 출처, 이해관계자의 결정, 아직 열린 질문 |
| `references.md` | 실제 확인한 URL·이미지·기존 화면과 참고할 이유 |
| `acceptance.md` | 사용자가 정한 확인 기준과 아직 구현 검사가 필요한 항목 |
| `checklist.md` | 자료 누락·내부 경로 노출·수치 근거·전달 상태 점검 |

레퍼런스가 없으면 파일에 `제공된 참고 자료 없음`이라고 적는다. 경쟁사나 참고 URL을 채우기 위해 임의로 고르지 않는다. 웹 접근성 기준을 사용할 때는 적용할 [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) 성공 기준과 실제 검사 방법을 적고, 프롬프트 작성만으로 준수 판정을 하지 않는다. 모바일·태블릿·데스크톱 폭은 프로젝트의 실제 대상 기기를 기준으로 정한다.

초안 생성 후 파일이 존재하는지 읽어 확인하고, Claude Design 전달·화면 생성·코드 구현은 각각 별도의 완료 상태로 기록한다.
