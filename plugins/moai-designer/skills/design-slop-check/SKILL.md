# design-slop-check — 디자인 카피 검수

사용자가 제공한 카피를 원문 그대로 읽고, 화면 위치·독자·브랜드 말투·제품 사실을 확인한다. 자료가 없으면 판단 범위를 적는다. 패턴에 맞는 문구는 **검토 후보**이며, 한 표현만으로 AI 작성 여부를 확정하지 않는다.

## 검수 순서

1. 실제 텍스트와 사용처를 수집한다. 파일·URL은 현재 세션에서 열 수 있을 때만 읽었다고 말한다. 추출하지 못한 PDF·이미지 속 문구는 미검토로 남긴다.
2. 아래 신호를 문맥에 맞춰 살핀다.

   | 신호 | 예시 | 확인할 점 |
   |---|---|---|
   | 추상적인 자기 평가 | 혁신적인, 차세대, world-class | 무엇이 실제로 달라지는지 설명하는가 |
   | 누구에게나 붙는 약속 | 손쉽게, seamlessly, effortlessly | 어떤 과업이 어떻게 줄어드는지 근거가 있는가 |
   | 의미 없는 나열 | 빠르게·쉽게·정확하게 | 각 단어가 구체적인 기능을 가리키는가 |
   | 틀처럼 반복되는 구조 | “A에서 B로”, “No more X. Just Y.” | 브랜드가 의도적으로 쓰는 표현인가 |
   | 확인되지 않은 사실 | 고객 수, 절약 시간, 무료 체험, 후기 | 사용자 자료나 공개 근거로 확인됐는가 |

3. 수치·가격·성과·고객 사례는 출처와 적용 기간을 확인한다. 확인되지 않으면 지우거나 `[확인 필요]`로 남긴다. 더 구체적으로 보이게 하려고 숫자를 만들어 넣지 않는다.
4. 원문이 자연스럽고 정확하면 그대로 둔다. 불필요한 수정을 건수로 채우지 않는다. 문장이 어색하면 뜻과 조사·어순을 살려 1~2개 대안을 쓴다.
5. 한국어 전반의 윤문이 필요하고 해당 스킬이 설치돼 있으면 `moai-writer:korean-humanize`로 후속 검토한다. 그 스킬이 없거나 실행하지 않았다면 후속 게이트가 통과했다고 말하지 않는다.

## 판정 경계

- `표현 검토`: 상투적일 수 있으나 제품·브랜드 맥락이 필요하다.
- `근거 확인`: 사실 주장에 출처가 없다. 출처가 없다는 것은 거짓이라는 판정이 아니다.
- `수정 권고`: 문구가 실제 사용처에서 뜻을 흐리거나, 제공된 브랜드 말투와 충돌한다.
- `유지`: 문구가 목적에 맞고 바꿀 이유가 없다.
- `미검토`: 원문·화면·필요한 자료에 접근하지 못했다.

브랜드가 의도한 용어, 고유한 제목, 완결된 명사구를 자동으로 금지하지 않는다. 대시, 콜론, 짧은 문장, “A에서 B로” 같은 구조도 단독으로 AI 작성의 증거가 아니다.

## 출력

| 위치 | 원문 | 판정 | 근거 | 제안 |
|---|---|---|---|---|
| [화면·섹션] | [원문] | [위 판정] | [실제 문맥·출처] | [유지 또는 수정안] |

끝에 확인하지 못한 자료와 후속 검토가 필요한 주장만 적는다. 사용자가 수정 적용을 요청하면 승인된 문구를 해당 결과물에 반영하고 다시 읽어 의미가 유지됐는지 확인한다.

관련 스킬: `design-copywriting`(카피 초안), `moai-writer:korean-humanize`(한국어 윤문), `moai-coworker:ai-slop-reviewer`(일반 텍스트 검토).
