# 한국 디자인 시스템과 서체 참고 경로

디자인 시스템 문서가 공개됐다는 사실과, 그 안의 코드·토큰·로고·서체를 다른 브랜드에 재사용할 권리는 별개다. 실제 산출물에 넣기 전에는 해당 자산의 현재 공식 라이선스를 확인한다. 아래 목록은 조사 출발점이며 모든 자산의 사용을 일괄 허가하지 않는다.

## 공개 자료

| 자료 | 확인할 곳 | 활용 경계 |
|---|---|---|
| 당근 SEED | [공식 저장소](https://github.com/daangn/seed-design) | 저장소가 Apache-2.0 배포를 안내한다. 특정 파일·상표·서체가 같은 조건인지 배포 전에 확인한다. |
| 채널톡 Bezier | [공식 저장소](https://github.com/channel-io/bezier-react) | 사용할 패키지·플랫폼의 `LICENSE`를 확인한다. |
| 정부 KRDS | [공식 사이트](https://www.krds.go.kr/) | 공공 자료와 코드·이미지의 재사용 조건을 각각 확인한다. |
| LINE Design System | [공식 이용 조건](https://designsystem.line.me/about/terms-en) | 공식 조건은 사이트의 열람을 허용하고, 별도 허가 없는 복사·수정·배포를 제한한다. 문서 사례 참고와 자산 재사용을 구분한다. |
| 원티드 Montage | 공식 저장소·Figma 배포본 | 대상 파일의 라이선스와 상표 사용 조건이 확인될 때만 사용한다. |

공개 자료의 색·간격 구조에서 배울 수 있지만, 특정 회사의 로고·서체·화면을 자기 브랜드 자산처럼 복제하거나 제휴를 암시하지 않는다.

## 한글 서체

| 서체 | 확인할 곳 | 메모 |
|---|---|---|
| Pretendard | [공식 LICENSE](https://github.com/orioncactus/pretendard/blob/main/LICENSE) | SIL OFL 1.1. 배포·수정 시 라이선스와 Reserved Font Name 조건을 따른다. |
| 나눔글꼴·마루 부리 | 네이버 공식 배포 페이지 | 사용할 파일의 실제 라이선스를 확인한다. |
| 배달의민족 서체 | 우아한형제들 공식 배포 페이지 | 서체별 라이선스를 확인한다. |
| Kakao Sans | 카카오 공식 저장소 | 사용할 파일의 라이선스를 확인한다. |
| Tossface | [공식 저작권 안내](https://toss.im/tossface/copyright) | OFL로 간주하지 않는다. 출처 표시와 수정·재배포 조건을 원문에서 확인한다. |

폰트 파일을 HTML에 포함하거나 서버에 올릴 때는 사용·재배포·수정 조건을 별도로 확인한다. CDN에서 로드할 때도 해당 서비스와 서체 조건을 따른다. 상표·로고·전용 서체의 사용권은 오픈소스 컴포넌트 라이선스에서 자동으로 나오지 않는다.
