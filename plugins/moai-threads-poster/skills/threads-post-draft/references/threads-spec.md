# Threads 게시 규격 확인

[Meta의 Threads 공식 소개](https://about.fb.com/news/2023/07/introducing-threads-new-app-text-sharing/)는 일반 게시글을 최대 500자로 설명한다. 이는 UTF-8 500바이트라는 뜻이 아니다. 서버는 Python `len(text)`로 사전 확인하며, 한글 200자를 바이트 수 때문에 500자 한도로 잘라서는 안 된다. 결합 문자·복합 이모지의 세부 계산은 실제 API 오류를 기준으로 확인한다.

## 게시 전 점검

- 감사와 사용자의 발행 승인 뒤에 **최종 본문**의 글자 수를 다시 확인한다.
- 토픽 태그·링크·이미지·비디오의 현재 허용 형식과 개수는 [Threads 개발자 문서](https://developers.facebook.com/docs/threads)와 계정 화면을 확인한다. 이 문서의 오래된 고정 수치를 근거로 발행 가능하다고 단정하지 않는다.
- 이미지·비디오 요청은 해당 미디어의 공개 URL, 형식, 권리, 계정 권한과 실제 서버 도구를 확인한다.
- 발행 도구가 실패했을 때 응답을 읽고 실제 게시 여부를 확인한다. 성공 신호가 없다는 이유만으로 다시 발행하지 않는다.

멀티 채널 포맷 결과는 `chars`, `max_chars`, `truncated`로 글자 수와 잘림 여부를 표시한다. `truncated: true`면 잘린 본문을 사용자가 읽고 의미가 유지됐는지 확인한 뒤 발행 절차로 넘긴다.
