# HTML 학습자료의 선택형 라이브러리

이 파일은 학습자료에서 **필요한 기능만** 고르는 참고표다. 라이브러리 버전·CDN 주소·라이선스는 바뀔 수 있으므로 HTML 생성 시 공식 문서와 실제 URL 응답을 확인한다. 설치·인증이 필요한 도구를 강제하지 않는다.

| 내용 | 후보 | 공식 사용법 | 자바스크립트가 없을 때 |
|---|---|---|---|
| 개념 관계도 | Mermaid | [렌더링과 `mermaid.run`](https://mermaid.js.org/config/usage) | 정의문과 텍스트 설명 |
| 수치 추이 | Apache ECharts | [`echarts.init`·`setOption`](https://echarts.apache.org/handbook/en/get-started/) | 원본 데이터 표 |
| 수식 | KaTeX | [auto-render](https://katex.org/docs/autorender) | 수식 원문·설명 |
| 코드 | highlight.js 또는 기본 `<pre><code>` | [공식 안내](https://highlightjs.org/) | 평문 코드 |
| 등장 효과 | CSS 전환 | 기능 없이도 내용이 보이도록 구성 | 정적 내용 |

## 적용 순서

1. 먼저 HTML·CSS만으로 목적을 달성할 수 있는지 확인한다. 텍스트·표·코드 평문에는 라이브러리가 필요 없다.
2. 라이브러리가 필요한 요소가 있으면 공식 문서의 현재 예시를 확인하고, 실제 사용한 버전을 고정한다. 메이저 버전만 적은 CDN 주소는 나중에 다른 코드로 바뀔 수 있다.
3. 사용자 데이터와 도식 원문을 HTML 문맥에 맞게 이스케이프한다. 외부 문장을 스크립트 문자열로 직접 삽입하지 않는다.
4. 스크립트가 로드된 화면과 차단된 화면에서 모두 핵심 학습 내용이 읽히는지 확인한다. CDN이 필요하면 HTML이 완전한 오프라인 단일 파일이라고 부르지 않는다.
5. 도식·차트의 색, 설명문, 데이터 표를 확인하고 키보드·작은 화면·인쇄 상태를 점검한다.

폰트는 문서의 목적과 실제 디자인 토큰에 맞춰 고른다. 외부 웹폰트가 차단돼도 시스템 폰트로 읽히게 한다.
