# 논문 검색

## 검색

주제·핵심어·기간·분야·필요한 언어를 확인한다. 한국어와 영어 동의어를 만들어 검색 범위를 넓힌다. 현재 사용할 수 있는 공식 사이트·연결 도구를 먼저 확인하고, [KCI 논문 검색](https://www.kci.go.kr/kciportal/mindex.kci?locale=ko), RISS, 학술지 사이트, 기관 저장소 등을 이용한다.

KCI API 키나 특정 MCP가 없다는 이유만으로 작업을 멈추지 않는다. 공식 웹 검색으로 진행할 수 있다. API가 필요하면 해당 서비스의 현재 안내와 호스트·권한을 확인한다. 비밀 키를 대화나 저장소 파일에 적거나 `CLAUDE_PLUGIN_DATA` 경로를 전제하지 않는다.

## 검증

1. 검색어·검색일·검색원·필터와 결과 범위를 기록한다. 접근하지 못한 데이터베이스를 검색했다고 쓰지 않는다.
2. 논문마다 제목, 저자, 발행 연도, 학술지·학위기관, DOI 또는 안정적 URL을 실제 기록과 대조한다.
3. 초록만 읽었다면 **초록 기반 요약**으로 표시한다. 전문을 읽지 않고 연구 방법·효과 크기·한계를 확정하지 않는다.
4. 인용 수와 등재 상태는 확인한 사이트·조회일을 붙인다. 값이 없으면 비워 둔다.
5. 연구 동향은 수집한 표본의 기간·건수·검색식과 함께 기술한다. 검색 결과 몇 편을 분야 전체의 추세로 일반화하지 않는다.
6. 참고문헌 형식은 실제 서지를 근거로 변환하고 원문과 다시 대조한다.

## 출력

검색 방법, 확인된 논문 목록, 확인 수준(서지/초록/전문), 주제별 요약, 누락 가능성과 미확인 항목을 제공한다. 논문 초안이 필요하면 `moai-tutor:education-paper-writer`로 연결한다. 추가 점검 항목은 `references/paper-search/guide.md`를 따른다.
