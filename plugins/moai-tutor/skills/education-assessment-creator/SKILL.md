# 평가 도구 제작 (Assessment Creator)

## 개요

시험·평가 문항과 해설, 오답 분석표를 만든다. 공인 시험의 형식과 출제 범위는 해당 시험의 공식 안내 및 사용자가 제공한 실제 자료를 확인한 뒤 적용한다.

## 트리거 키워드

시험, 기출, 자격증, 수능, 문제 출제, 평가, 퀴즈, 학습 평가, 모의고사, TOEIC, TOEFL, 공무원 시험, 내신, 형성평가, 총괄평가, Bloom's Taxonomy

## 워크플로우

### 1단계: 평가 목적 파악

**평가 유형:**
- **형성평가**: 학습 중 이해도 확인 (퀴즈, 단답형)
- **총괄평가**: 학습 후 성취도 측정 (시험, 자격증 모의고사)

**대상 시험 종류:**
- 수능 (대학수학능력시험)
- 공무원 시험 (행정·기술직)
- 자격증 시험 (정보처리기사, 공인중개사 등)
- 어학 시험 (TOEIC, TOEFL, OPIC)
- 내신 (학교 성취도 평가)

### 2단계: 출제 범위 설정

**학습 목표 설정:**
- 단원, 주제, 핵심 개념 정의
- 학습자 수준과 평가 목적에 맞춰 난이도 비율 결정
- Bloom's Taxonomy 수준별 배분

**Bloom's Taxonomy 기반 문항 설계:**
| 인지 수준 | 설명 | 문항 유형 예시 |
|-----------|------|---------------|
| 기억(Remember) | 사실 암기 | 용어 정의, 연도 매칭 |
| 이해(Understand) | 개념 설명 | 요약, 비교, 분류 |
| 적용(Apply) | 실제 사용 | 문제 해결, 계산 |
| 분석(Analyze) | 구조 파악 | 원인 분석, 관계 파악 |
| 평가(Evaluate) | 판단·비판 | 타당성 평가, 비판 |
| 창조(Create) | 새로운 산출 | 설계, 작문, 프로젝트 |

### 3단계: 문항 유형 선택

**선택형:**
- 4지선다형 (일반)
- 5지선다형 (해당 시험의 현행 형식 확인 후)

**단답형·서술형:**
- 단답형 (키워드)
- 단순 서술형 (2-3줄)
- 논술형 (장문)

**OX형·빈칸 채우기:**
- OX 퀴즈
- 빈칸 채우기

**혼합 구성:**
- 학습 목표와 시험 형식에 맞춰 선택형·단답형·서술형 비율 결정

### 4단계: 문항 작성

**문항 작성 원칙:**
- 학습 목표와 직접 연결
- 명확하고 모호하지 않은 문장
- 적정 난이도: 대상 학습자의 실제 응답 자료가 없으면 정답률을 예측치로 단정하지 않는다
- 오답 선택지는 논리적 오류 유형

**정답 및 해설 포함:**
- 정답 표시
- 해설 (오답 선택지 why wrong 포함)
- 수학·코드 문항은 풀이를 독립적으로 재계산하고, 사실형 문항은 확인 가능한 출처와 대조한다. 확인하지 못한 정답은 검증 완료로 표시하지 않는다.

### 5단계: 검토 및 오답 분석표

**문항별 핵심 개념 연결:**
- 해당 문항이 평가하는 핵심 개념
- 관련 단원·주제

**오답 시 보충 학습 방향:**
- 오답 선택지별 오류 유형 분석
- 보충 학습 링크·자료 추천

## AI 보조 평가의 경계

- 문항 초안과 피드백 초안은 만들 수 있지만, 자동 채점 결과를 교사의 확정 판정처럼 제시하지 않는다.
- 학습자별 오답 자료가 있을 때만 반복 오류를 분석한다. 자료가 없으면 예상 약점을 실제 진단 결과로 쓰지 않는다.
- 인지 수준 분류는 문항 설계 보조값이다. 학습 성취도를 측정했다는 뜻으로 쓰지 않는다.

### 한국 주요 시험별 특성

| 시험 | 특징 | AI 활용 포인트 |
|------|------|---------------|
| 수능 | 영역별 문항 유형은 해당 학년도 한국교육과정평가원 안내 확인 | 공개 기출과 성취기준에 맞춘 연습 |
| 공무원 시험 | 직렬·과목·연도별 공고 확인 | 공개 기출과 범위에 맞춘 연습 |
| TOEIC/TOEFL | 시험별 영역·문항 형식 확인 | 공식 시험 안내를 기준으로 연습 |
| 자격증 | 종목별 상이, 실기 포함 | 이론 문제 자동 생성, 실기 준비 체크리스트 |
| 내신 | 학교별 출제 기준 다양 | 교과서 기반 예상 문제, 수행평가 준비 |

## 사용 예시

**예시 1**: "정보처리기사 실기 모의문제 10개를 만들어줘"
→ 단원 선택 → 난이도 배분 → 문항 생성 → 정답 및 해설

**예시 2**: "이 단원에서 나올 수 있는 내신 예상 문제를 출제해줘"
→ 학습 목표 확인 → Bloom's 수준 배분 → 혼합 문항 출제

**예시 3**: "TOEIC 700점 목표 4주 학습 계획을 세워줘"
→ 현재 점수 확인 → 약점 분석 → 주차별 학습 계획 → 모의고사 스케줄

**예시 4**: "수강생 이해도를 평가할 형성평가 문항을 설계해줘"
→ 학습 목표 확인 → 퀴즈 문항 생성 → 오답 분석표

## 산출물

- 시험·평가 문제지 (정답 및 해설 포함)
- 모의고사 (자격증, 공무원, 내신)
- 학습 계획 (주차별, 목표 점수별)
- 오답 분석표 (보충 학습 방향 포함)
- 기출 분석 보고서 (실제 기출 자료를 확인한 경우)

## 주의사항

**교육 자료 접근:**
- 교육 자료 접근 불가 시 학습 목표와 핵심 개념 목록만 알려주시면 문항 생성 가능
- 특정 출판사 교과서 기반 출제 시 교과서 단원 제목과 핵심 내용 입력 필요

**학습 목표 불명확 시:**
- 시험 유형과 대상 수준을 먼저 확인하고 목표를 함께 설정

**난이도 조절:**
- 상/중/하 비율 지정 시 그에 맞춰 배분

**공인 시험 기출문제 저작권:**
- 저작권이 있는 기출 자료는 허락 없이 무단 복제할 수 없음
