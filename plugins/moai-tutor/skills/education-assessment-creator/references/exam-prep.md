# 시험 대비

사용자가 지정한 시험의 **현행 공고·출제 범위·문항 형식**을 확인한 뒤 모의 문항과 학습 계획을 만든다. 공식 자료에 접근하지 못했다면 확인한 범위만 적고, 특정 시험과 동일한 형식이라고 말하지 않는다.

## 입력 확인

- 시험명·시행 연도·과목, 학습자의 현재 수준과 목표
- 사용자가 제공한 실제 성적표·오답 기록·기출문제의 출처
- 문항 수·시간·평가 방식 등 사용자가 원하는 산출물

성적표나 오답 기록이 없으면 **약점 진단**을 완료한 것처럼 쓰지 않는다. 자기 점검 질문을 제공하고, 답을 받은 뒤 분석한다.

## 작업 순서

1. 시험 주관기관의 현행 안내로 범위와 형식을 확인하고 출처를 기록한다. 공식 자료가 없는 경우 확인 불가를 표시한다.
2. 실제 기출 또는 사용자가 제공한 문항이 있으면 과목·개념별로 분류한다. 표본 수와 수집 연도를 함께 적는다.
3. 학습 목표별 문항을 새로 작성한다. 모든 문항에 목표, 난이도 설정 이유, 정답과 해설을 붙인다.
4. 수학·코드 정답은 독립적으로 풀거나 실행하고, 사실형 정답은 확인 가능한 자료와 대조한다. 미검증 문항은 배포 전 확인 대상으로 둔다.
5. 학습자가 푼 결과가 있을 때만 오류 유형과 우선 보완 영역을 제안한다. 계획은 남은 기간·가용 시간·실제 수준에 맞춘다.

## 결과에 표시할 것

| 항목 | 기록 |
|---|---|
| 시험 기준 | 주관기관·시행 연도·확인한 안내 URL |
| 분석 자료 | 실제 기출·성적·오답의 출처와 건수 |
| 문항 검증 | 독립 재풀이·자료 대조 여부와 미확인 항목 |
| 학습 계획 | 학습자 입력을 반영한 일정과 우선순위 |
| 제한 | 접근하지 못한 자료, 추정에 머문 판단 |

AI가 만든 모의 문항을 공식 기출로 표시하거나, 연습 정답률을 실제 시험 합격 가능성으로 환산하지 않는다.
