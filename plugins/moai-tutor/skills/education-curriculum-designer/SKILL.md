# 커리큘럼 설계

## 입력 확인

학습자, 현재 수준과 선수 지식, 교육 목적, 기간과 수업 방식, 강사·도구·자료 제약을 확인한다. 기존 강의계획서나 직무 자료가 있으면 읽고 출처를 기록한다. 시험 대비 과정은 해당 시험의 현행 공식 범위와 형식을 확인한다. 자료가 없는 값은 **가정**으로 표시한다.

## 설계 순서

1. 수료 후 학습자가 실제로 할 수 있어야 하는 행동을 학습 목표로 쓴다. 목표마다 수행 조건과 확인할 산출물을 붙인다.
2. 목표를 증명할 평가 증거를 정한다. 문항·실습·프로젝트 중 적합한 방식을 고르고 목표와 평가의 대응표를 만든다.
3. 목표 달성에 필요한 선수 지식부터 차시를 배열한다. 차시마다 개념, 활동, 피드백, 예상 소요를 적는다.
4. 전체 일정에 수업·실습·휴식·평가 시간을 합산해 과밀 여부를 검토한다. 비율과 문항 수를 근거 없이 고정하지 않는다.
5. 접근성, 기기·네트워크, 학습 자료의 이용 권한 등 실제 운영 조건을 확인하고 대안을 제시한다.
6. 사용자가 요청한 형식으로 결과를 정리한다. 파일을 만들었다면 읽어 확인하고, 미확인 가정과 남은 검증을 보고한다.

## 출력

| 항목 | 내용 |
|---|---|
| 대상·제약 | 학습자 수준, 기간, 방식, 확인한 자료 |
| 학습 목표 | 관찰 가능한 수행과 성취 기준 |
| 차시 계획 | 목표·내용·활동·소요·필요 자료 |
| 평가 대응 | 목표별 평가 증거와 채점 기준 |
| 확인 필요 | 가정, 자료 공백, 시험·현장 조건 |

현재 점수·오답 기록이 없으면 개인의 약점을 진단한 것으로 쓰지 않는다. 역량 모델은 실제 직무 자료가 있을 때만 현재 수준과 목표 수준의 차이를 산출한다.
