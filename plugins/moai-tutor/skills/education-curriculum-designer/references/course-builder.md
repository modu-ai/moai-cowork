# 온라인 강좌 설계

## 확인할 입력

대상 학습자, 선수 지식, 강좌 목표, 수업 방식, 가용 시간, 실습 도구, 자료 이용 권한을 확인한다. 기존 강좌나 운영 플랫폼의 실제 제약이 있으면 반영한다.

## 제작 순서

1. 강좌 목표를 관찰 가능한 수행으로 적는다.
2. 목표별 평가 방법과 통과 기준을 정한다.
3. 선수 지식 순서로 모듈과 차시를 배치한다.
4. 차시마다 설명, 활동, 실습, 피드백, 평가를 연결한다. 영상 길이·퀴즈 수·난이도 비율은 대상과 목적에 맞춘다.
5. 실습 환경에서 예제를 직접 실행할 수 있으면 실행 결과를 확인한다. 실행하지 못했다면 검증 필요로 남긴다.
6. 강의 계획·퀴즈·실습을 목표와 대조한다. 평가되지 않은 목표와 목표에 연결되지 않은 문항을 고친다.

## 산출물

필요한 범위만 작성한다: 강좌 개요, 차시 계획, 강사 노트, 학습자 자료, 평가 문항, 실습 안내. 파일을 요청받으면 실제로 만든 파일과 확인한 내용을 보고한다. 에이전트 기능이 없어도 순서대로 작성할 수 있다.
