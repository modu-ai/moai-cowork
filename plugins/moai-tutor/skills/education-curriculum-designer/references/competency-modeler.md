# 직무 역량 모델

조직의 실제 직무 자료와 업무 성과 기준으로 역량을 정의한다. 자료 없이 산업·조직 규모의 기본값을 만들어 현재 상태처럼 쓰지 않는다.

## 입력

- 직무 기술서, 실제 업무·책임·작업 결과
- 모델의 목적: 교육·개발, 채용, 평가 중 무엇인지
- 기존 역량 정의와 평가 자료, 적용할 인사 정책
- 대상 직급과 관계자의 검토 권한

## 순서

1. 직무별 핵심 업무와 산출물을 확인한다. 외부 직무 표준을 쓸 때는 판본과 해당 직무의 일치 여부를 기록한다.
2. 각 업무에 필요한 지식·기술·태도를 정의한다. 역량 개수나 숙련도 단계를 미리 고정하지 않는다.
3. 수준별로 관찰 가능한 행동과 증거를 적는다. 인상 평가나 성격 추정으로 사람을 분류하지 않는다.
4. 루브릭 초안을 만들고 동일 사례를 여러 평가자가 적용해 해석 차이를 확인한다.
5. 실제 평가 자료가 있을 때만 현재 수준과 목표 수준의 차이를 계산한다. 교육 투자 수익은 실측 데이터와 비용 가정이 있을 때만 추정한다.
6. 개발 계획에는 담당자, 활동, 확인할 결과를 넣는다. 채용·승진에 사용할 모델은 운영자의 별도 검토가 필요하다고 표시한다.

## 결과

직무·업무 출처, 역량 정의, 행동 지표, 평가 근거, 미확인 가정과 검토자를 한 표에 기록한다. 역할별 독립 에이전트가 없으면 같은 순서를 한 세션에서 수행하고, 독립 검수가 필요한 결과만 별도로 요청한다.
