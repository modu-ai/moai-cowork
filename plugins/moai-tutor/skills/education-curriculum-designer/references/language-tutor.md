# 외국어 학습 경로

학습자의 **목표 언어**, 현재 경험, 사용 목적, 가용 시간부터 확인한다. 언어가 없으면 영어로 가정하지 않는다.

## 순서

1. 사용자가 제공한 성적·학습 기록이나 짧은 진단 과제를 확인한다. 자가 진단과 공인 시험 결과를 구분한다.
2. 듣기·말하기·읽기·쓰기 중 필요한 영역을 고르고 구체적 목표를 세운다.
3. 목표에 맞는 회화·어휘·문법·읽기·쓰기 활동을 구성한다. 한 번에 모든 기능을 같은 비율로 넣지 않는다.
4. 학습한 내용으로 짧은 퀴즈와 피드백을 만들고 정답·표현의 자연스러움을 검토한다.
5. 실제 응답 결과에 맞춰 다음 차시와 복습을 조정한다. 응답 자료가 없으면 성장이나 약점 개선을 측정했다고 말하지 않는다.

CEFR 수준은 공식 설명자와 충분한 평가 자료가 있을 때만 신중하게 참조한다. AI가 만든 짧은 진단만으로 공인 CEFR 등급을 확정하지 않는다. 복습 간격은 학습자의 일정과 실제 수행 결과에 맞춘다.
