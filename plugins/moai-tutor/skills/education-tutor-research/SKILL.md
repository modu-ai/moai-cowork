# 학습 질문 조사

## 순서

1. 질문과 학습자 수준을 확인하고 필요한 하위 주제만 나눈다.
2. 소프트웨어·제도·시험처럼 변할 수 있는 내용은 공식 문서와 현재 판본을 확인한다. 사용 가능한 웹 도구나 연결 앱을 사용하고, 도구가 없으면 확인할 수 없는 항목을 명시한다.
3. 서로 독립적인 자료는 한 번에 조회할 수 있으면 묶어 확인한다. 병렬 호출이나 하위 에이전트가 없는 환경에서는 순서대로 조사한다.
4. 출처의 실제 본문과 날짜·버전을 읽고 주장에 연결한다. 검색 결과 제목만으로 내용을 확정하지 않는다.
5. 설명, 예제, 자주 헷갈리는 점, 출처, 미확인 사항을 학습자 수준에 맞춰 정리한다. 코드 예제는 실행한 경우에만 실행 결과를 적는다.
6. 도식이나 HTML 자료가 필요하면 `education-learning-material`에 확인된 내용과 출처를 넘긴다. 파일을 만들지 않았다면 파일 제공으로 보고하지 않는다.

## 결과 구조

| 부분 | 내용 |
|---|---|
| 질문 | 학습자가 이해하려는 개념 |
| 핵심 설명 | 확인한 사실과 쉬운 풀이 |
| 예제 | 출처·버전·실행 여부 |
| 비교 | 혼동하기 쉬운 개념의 차이 |
| 출처 | 직접 열어 확인한 문서 링크 |
| 남은 확인 | 접근하지 못한 자료와 버전 차이 |

공식 문서와 다른 자료가 충돌하면 적용 버전·맥락을 비교한다. 출처만 있다고 정확성이 보장되는 것은 아니므로 실제 주장과 해당 문단을 대조한다. 연구 논문을 체계적으로 검색·인용할 때는 `education-research-assistant`를 사용한다.
