# 연구 설계·원고 점검

1. 연구 질문, 자료 수집 계획, 측정 변수와 분석 방법을 연결한다. 계획과 실제 수행을 별도 열에 기록한다.
2. 원자료가 있다면 보관 위치와 접근 권한을 확인하고, 필요한 경우 분석 코드를 실행해 수치를 재계산한다. 개인 정보가 포함된 자료는 사용자 권한 범위에서만 다룬다.
3. 결과 섹션에는 실제 출력값과 표본 수를 적는다. 계획한 분석을 실행한 것처럼 서술하지 않는다.
4. 논의에서는 결과가 뒷받침하는 주장과 대안 설명을 구분한다. 통계적 유의성과 실제적 의미를 혼동하지 않는다.
5. 대상 학술지의 현행 투고 규정을 확인하고 초록·표·그림·참고문헌 형식을 적용한다.
6. 제출 패키지는 사용자가 요청하고 자료가 갖춰진 범위에서만 만든다. 실제 투고는 별도 권한과 확인이 필요하다.

독립 에이전트가 없는 호스트에서도 이 순서대로 진행할 수 있다. 방법·분석·원고를 서로 대조했는지 증거를 남긴다.
