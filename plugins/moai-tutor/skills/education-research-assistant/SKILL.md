# 학술 연구 보조

## 입력

연구 질문, 대상 분야와 독자, 자료 수집 범위, 기존 논문·원자료·분석 코드, 발표 지면의 규정을 확인한다. 사용자가 논문 검색만 원하면 `education-paper-search`, 원고 문장 작성이 목적이면 `education-paper-writer`를 우선 사용한다.

## 진행

1. 검색어·기간·데이터베이스·포함 기준을 정하고 실제 접근한 자료만 목록에 넣는다.
2. 각 문헌의 서지와 열람 범위(서지/초록/전문)를 확인한다. 연구 방법·표본·결과는 읽은 자료가 뒷받침하는 범위에서만 요약한다.
3. 공통 결과와 상충 결과를 주제별로 정리한다. 검색하지 못한 영역을 연구 공백이라고 단정하지 않는다.
4. 데이터가 제공되면 변수·결측·표본·분석 목적을 확인하고 적합한 방법을 고른다. 검정을 실행하지 않았다면 유의확률과 효과 크기를 쓰지 않는다.
5. 연구 설계와 분석의 한계, 대안 설명, 재현에 필요한 자료를 적는다.
6. 초안을 다듬은 뒤 원문 인용·수치·방법과 다시 대조한다.

## 보고

검색 범위, 확인한 문헌, 원문 열람 범위, 수행한 계산·코드, 근거가 없는 주장, 다음 검증을 구분해 제공한다. 자료가 없으면 방법 제안만 작성하고 결과 보고서로 부르지 않는다.
