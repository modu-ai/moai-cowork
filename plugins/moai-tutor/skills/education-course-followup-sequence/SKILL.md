# 강의 후속 연락과 후기 요청

## 입력

강의명, 종료일, 수강생과의 연락 관계, 발송 채널, 후속 연락의 목적을 확인한다. 이미 안내한 연락 빈도와 수신 거부 방식이 있으면 반영한다. 정보가 없으면 발송 문구의 빈칸으로 남기고 발송 준비가 끝난 것처럼 쓰지 않는다.

## 작성 순서

1. 감사 인사와 자료 공유, 학습 적용 확인, 피드백 요청 중 사용자가 원하는 단계를 고른다. D+1·D+3·D+7·D+14·D+30은 사용자가 요청한 경우의 일정 예시일 뿐 기본 발송 횟수가 아니다.
2. 각 메시지의 목적을 하나로 정하고, 답하기 쉬운 질문과 선택 가능한 응답 방식을 제시한다. 응답하지 않는 선택도 존중한다.
3. 성과 수치·적용 사진·영상은 학습자가 실제로 제공한 경우에만 요청하거나 인용한다. 수집하지 않은 성과를 암시하지 않는다.
4. 할인·코칭·무료 청강 등 혜택은 운영자가 제공 가능 여부, 대상, 기간, 조건을 확인했을 때만 문구에 넣는다.
5. 후기를 모집 페이지나 SNS에 재사용하려면 당사자가 허락한 범위와 표시할 이름·사진·영상 여부를 확인한다. 내부 피드백과 공개 홍보용 후기를 구분한다.
6. 요청한 파일이 있으면 저장하고 실제 경로를 확인한다. 발송 도구를 호출하지 않았다면 결과는 **발송용 초안**으로 표시한다.

## 출력

| 단계 | 내용 |
|---|---|
| 발송 목적 | 감사 / 학습 적용 확인 / 피드백 / 공개 후기 동의 |
| 채널과 시점 | 운영자가 확인한 값 또는 미정 |
| 메시지 | 복사해 사용할 최종 문안 |
| 확인 필요 | 수신 대상·발송 권한·혜택 조건·후기 재사용 동의 |
| 상태 | 초안 / 발송 준비 완료 / 실제 발송 확인 |

맞춤법과 문체 검수는 사용 가능한 스킬이 있으면 적용한다. 검수 도구가 없더라도 문구를 직접 읽어 어색한 표현과 사실 주장을 확인한다. 실제 발송 여부는 별도의 발송 도구 또는 운영자 확인으로 판단한다.

## 경계

- 강의 운영 시간표와 현장 체크리스트는 `education-course-operations-manual`을 사용한다.
- 범용 광고 카피는 `moai-marketer:content-copywriting`을 사용한다.
- 카카오톡·이메일·문자 자동 발송이나 수신자 DB 변경은 이 스킬의 작업이 아니다.
