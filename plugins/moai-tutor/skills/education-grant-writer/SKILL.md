# 연구비 신청서 초안

## 먼저 확인할 자료

지원 기관과 **정확한 사업명·공고 연도·공고 링크**, 공식 신청 서식, 평가 기준, 신청 자격, 제출 방식과 기한을 확인한다. 같은 기관 안에서도 사업별 양식과 접수처가 다르다. 공식 공고를 보지 못했다면 기관 양식에 맞췄다고 말하지 않고 일반 연구계획서 초안으로 표시한다.

연구 주제·방법·팀·기간·예산은 사용자가 제공한 값과 확인 가능한 자료만 쓴다. 미제공 실적·특허·파트너·시장 규모·연구 성과를 만들어 넣지 않는다.

## 작업 순서

1. 공고와 첨부 서식을 읽어 필수 섹션·페이지 제한·제출 파일 형식·평가항목을 표로 뽑는다.
2. 사용자 자료를 각 섹션에 배치하고 빠진 근거를 표시한다.
3. 목표, 선행연구, 방법, 검증 계획, 팀 역할, 기대성과, 예산 근거를 작성한다. 논문은 `moai-tutor:education-paper-search`로 실제 서지를 확인한다.
4. 예산 합계와 연차별 수치를 다시 계산하고 공고의 비목·상한과 대조한다. 정해진 금액이 없다면 빈칸으로 남긴다.
5. 평가 기준별로 초안의 근거 위치를 연결한다. 기준을 확인하지 못한 항목은 임의 점수나 가중치로 평가하지 않는다.
6. 문체를 다듬은 뒤 숫자·고유명사·인용·서식이 원자료와 일치하는지 다시 확인한다. 결과는 **신청서 초안**으로 표기하고 실제 제출 여부를 별도로 보고한다.

## 산출물

| 항목 | 포함할 내용 |
|---|---|
| 공고 기준 | 기관·사업·연도·공고 URL·서식 판본 |
| 본문 초안 | 공식 서식 순서의 확인된 내용 |
| 근거 대응 | 평가항목과 초안의 근거 위치 |
| 예산 | 원자료·계산·미확정 비목 |
| 확인 필요 | 자격, 증빙, 서명, 파일 형식, 제출 상태 |

일반 정부 지원사업은 `moai-consultant:consult-gov-grant`를 사용한다. 이 스킬은 신청을 제출하거나 선정 가능성을 보증하지 않는다.
