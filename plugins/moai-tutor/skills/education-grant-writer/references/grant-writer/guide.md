# 연구비 신청서 점검 가이드

기관명만으로 양식과 평가 비중을 정하지 않는다. **해당 사업·연도의 공식 공고와 첨부 서식**을 기준으로 아래 항목을 채운다.

| 확인 항목 | 기록할 증거 |
|---|---|
| 사업 식별 | 기관, 정확한 사업명, 공고 번호·연도, URL |
| 제출 자격 | 신청 주체, 참여 제한, 필수 협약·증빙 |
| 서식 | 필수 항목, 분량, 파일 형식, 공식 양식 판본 |
| 평가 | 공고에 적힌 평가항목과 실제 배점 |
| 예산 | 비목, 허용·제외 비용, 기관부담금, 기간별 합계 |
| 제출 | 접수처, 기한, 최종제출·접수증 확인 방법 |

일반적인 본문 초안에는 연구 목표, 필요성, 선행연구, 방법, 일정, 팀 역할, 기대성과, 예산과 참고문헌을 넣을 수 있다. 공고 서식이 다르면 그 서식을 따른다. 출처 없는 고정 배점(예: 20/30/25/15/10)은 사용하지 않는다.

[KIAT 공고 예시](https://www.kiat.or.kr/front/board/boardContentsView.do?contents_id=93c94f0c299d480d922a7d268a4e7628)는 공고별 연구개발계획서와 제출 서식을 첨부한다. 이 예시는 다른 사업의 제출 요건을 대신하지 않는다.
