# 강의 운영 매뉴얼

## 입력 확인

강의명, 날짜·장소·형식(대면/온라인/혼합), 세션별 학습 목표, 시작·종료 시간, 휴식, 참여자 수, 강사·조교 인원과 역할을 확인한다. 장소의 네트워크·화면·음향·접근성 조건, 외부 도구와 계정, 자료 배포 경로도 확인한다. 확인하지 못한 값은 **미정**으로 적고 예시값을 확정 일정처럼 쓰지 않는다.

## 작성 순서

1. 실제 시작·종료 시간과 세션 길이를 합산해 시간표를 만든다. 강의·휴식·이동·설치 시간을 모두 포함하고 겹침이나 빈 구간을 확인한다.
2. 강사와 조교에게 실제 인원 수에 맞춰 역할을 배정한다. 조교가 없으면 조교 업무를 자동 배정하지 않고 운영자에게 선택지를 제시한다.
3. 수강생 준비물과 운영진 점검표를 분리한다. 기기·계정·자료·접근성 요구는 해당 강의에서 실제로 쓰는 것만 적는다.
4. 장소와 도구에 맞는 장애 신호, 즉시 조치, 대체 수업 방식, 담당자를 표로 만든다. 비상 영상·대체 장비·핫스팟이 실제 준비되지 않았다면 사용 가능한 대안으로 표시하지 않는다.
5. 준비 안내 메시지는 발송 시점을 운영자가 정한 뒤 작성한다. 메시지 초안과 실제 발송 상태를 분리한다.
6. 사용자가 문서 파일을 요청하면 Markdown으로 저장한 뒤 읽어 확인한다. Word 파일이 필요하고 `moai-officer:doc-docx`를 사용할 수 있으면 변환하고 결과 파일을 확인한다.

## 산출물 구조

| 섹션 | 필수 점검 |
|---|---|
| 일정 | 세션 시작·종료, 휴식, 총 소요 시간 |
| 역할 | 실제 담당자별 준비·진행·마감 업무 |
| 수강생 안내 | 접속·장소·준비물·지원 연락처 |
| 환경 점검 | 네트워크·화면·음향·계정·접근성 |
| 장애 대응 | 감지 조건·조치·대체 수업·담당자 |
| 미확정 | 사용자 확인이 필요한 값과 준비되지 않은 대안 |

## 검증

- 시간표의 총 소요 시간과 각 세션·휴식의 합을 다시 계산한다.
- 담당자 이름과 수가 입력 자료와 일치하는지 확인한다.
- 링크·장소·계정·장비를 직접 확인하지 못했다면 점검 완료로 표시하지 않는다.
- 요청된 파일만 만든다. `.docx` 변환을 실행하지 않았다면 제공했다고 말하지 않는다.

커리큘럼 설계는 `education-curriculum-designer`, 평가 문항은 `education-assessment-creator`, 수강생 후속 연락은 `education-course-followup-sequence`를 사용한다.
