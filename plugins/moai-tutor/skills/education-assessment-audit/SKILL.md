# 교육 산출물 검수

원본을 수정하지 않고 학습 목표, 문제, 답안, 인용 자료를 대조한다.

- 각 문항이 어떤 학습 목표를 평가하는지 연결하고 평가되지 않은 목표를 찾는다. 목표와 관계없는 문항도 기록한다.
- 정답과 해설은 수학·코드·사실 확인 등 필요한 방법으로 독립 재풀이한다. 재풀이할 자료가 없으면 정답을 PASS로 판정하지 않는다.
- 문항 난이도가 선언된 학습자 수준과 맞는지 확인한다. 차시 합계, 선수 과목 순서, 채점 비중과 일정도 다시 계산한다.
- 논문·저자·학술지·연도를 실제 검색 기록이나 원문과 대조한다. 찾지 못한 인용은 미확인으로 남긴다.

보고서는 `판정(PASS/FAIL/미확인)`, `확인 자료`, `목표·문항 대응표와 재풀이`, `심각도·위치·근거가 있는 발견`, `미검증 항목`으로 작성한다. 핵심 근거가 없으면 해당 범위를 PASS로 판정하지 않는다. 독립된 검수자를 실행하지 않았다면 독립 감사라고 부르지 않는다.
