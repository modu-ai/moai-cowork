# 교육 설계 작업 경로

1. 학습자 수준, 학습 목표, 주제 범위, 차시·형식과 평가 방식을 확인한다. 필수 입력이 없으면 현재 런타임의 질문 채널로 묻고, 질문할 수 없는 하위 실행에서는 누락 자료를 blocker로 반환한다.
2. 학습 목표를 먼저 정하고 이를 확인할 평가 증거를 설계한 뒤 수업 순서를 구성한다. 커리큘럼·자료·문항·운영은 해당 전담 스킬을, 논문 검색·작성·연구 보조는 해당 학술 스킬을 따른다.
3. 모든 평가 문항을 명시된 학습 목표와 연결한다. 학습자 수준에 맞지 않는 선수 지식은 별도 확인 항목으로 남긴다.
4. 논문·저자·학술지·연도는 실제 검색 결과와 대조한다. 인용 범위와 출처를 표시하고, AI가 만든 정답·해설은 재풀이 전까지 검증 완료로 표시하지 않는다.
5. 제출 전 `education-assessment-audit` 기준으로 목표·평가 정렬과 답안을 확인한다. 같은 주체의 자기 검수는 독립 감사라고 부르지 않는다. 타인 명의 과제 제출·연구 데이터 조작·자격 인증 주장은 수행하지 않는다.

Claude의 `curriculum-designer` 에이전트와 목적이 겹친다. ChatGPT 플러그인에서는 이 스킬이 발견 가능한 진입점이다.
