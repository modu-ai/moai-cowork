# 학술 논문 초안

## 시작 전 확인

연구 질문, 대상 학술지나 학위 과정의 실제 투고 규정, 연구 방법, 수집 자료, 분석 결과, 확인된 참고문헌을 받는다. 규정이 없으면 IMRaD 같은 일반 구조를 **제안**하고 공식 서식이라고 부르지 않는다. 초록 길이·키워드 수·인용 스타일은 대상 저널의 현행 지침을 따른다.

## 작성 순서

1. 사용자 자료에 근거해 연구 질문과 주장·증거 대응표를 만든다.
2. 논문의 성격에 맞춰 서론, 선행연구, 방법, 결과, 논의, 결론 중 필요한 섹션을 구성한다.
3. 결과에는 제공된 데이터와 실제 분석값만 쓴다. 분석하지 않은 통계, 참가자 수, 유의확률이나 효과를 채워 넣지 않는다.
4. 선행연구는 `moai-tutor:education-paper-search`로 확인한 논문만 인용한다. 제목·저자·연도·DOI를 원문 기록과 대조한다.
5. 주장과 인용의 연결, 표·그림 번호, 방법과 결과의 일치, 연구 한계, 학술지 규정을 확인한다.
6. 문체를 다듬은 뒤 사실·수치·인용이 바뀌지 않았는지 다시 대조한다. 미완성 섹션과 필요한 연구자 확인을 명시한다.

## 결과 상태

| 구분 | 표기 |
|---|---|
| 확인된 사실 | 사용자 자료 또는 검색된 원문 출처 |
| 작성 초안 | 원자료를 바탕으로 만든 문장 |
| 미제공 자료 | 빈칸 또는 연구자 확인 필요 |
| 서식 | 확인한 저널 규정과 판본 |
| 제출 | 실제 투고 도구가 확인되지 않았다면 미제출 |

참고문헌 서식을 자동 변환할 때도 확인되지 않은 페이지·권호·DOI를 채우지 않는다. 논문 투고·과제 제출은 이 스킬의 작업이 아니다. 참고: `references/paper-writer/guide.md`.
