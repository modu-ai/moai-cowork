# 결산 관리 (Close Management)

## 개요

월간·분기·연간 회계 결산 업무를 지원한다. 결산 체크리스트, 계정별 마감 순서, 보험료·급여 정산과 보고서 초안을 제공한다. 먼저 사업자의 회계 기준, 결산월, 급여·세무 신고 유형을 확인한다.

**면책 고지: 이 스킬은 AI 보조 분석이며 공인 회계사·세무사의 전문 자문을 대체하지 않습니다.**

## 트리거 키워드

결산, 월말 마감, 분기 결산, 연간 결산, 회계 마감, 급여 정산, 4대보험, 재무 마감, 클로징, 결산 체크리스트

## 워크플로우

### 1단계: 결산 유형 선택

- **월간 결산** (매월 말일)
- **분기 결산** (3, 6, 9, 12월)
- **반기 결산** (회사의 회계연도·공시 의무 확인)
- **연간 결산** (회사의 결산월·법인세 신고 유형 확인)

### 2단계: 적용 연도 기준 확인

**2026년 최저임금 및 4대보험 요율**

> 2026년 최저임금·4대보험 요율표는 `moai-accountant:finance-tax-helper` references/2026-rates.md 단일 SSOT를 참조한다.

2026년 급여를 계산할 때는 참조 표를 공식 보험기관 자료와 다시 대조한다. 다른 연도에는 해당 연도의 고시를 확인한다. 보험 가입 대상과 노동법 적용은 고용 형태·사업장별로 판단한다.

### 3단계: 월간 결산 체크리스트

**전월 거래 마감 — 회사 일정에 따라 배치**
- [ ] 전월 매출 전표 확정 (세금계산서 발행 확인)
- [ ] 매입 세금계산서 수취 확인 및 회계 처리
- [ ] 카드 매출/지출 정산
- [ ] 경비 보고서 취합 및 승인

**급여 정산 — 지급일·신고기한에 따라 배치**
- [ ] 급여 대장 작성 (최저임금 충족 여부 확인)
- [ ] 보험별 가입 대상·산정 기준·해당 연도 요율로 공제액 계산
- [ ] 소득세·지방소득세 원천징수
- [ ] 원천세 신고·납부 기한과 반기납부 승인 여부를 [국세청](https://www.nts.go.kr/)의 해당 연도 안내에서 확인
- [ ] 소득 종류별 간이지급명세서 제출 대상·주기를 확인
- [ ] 급여 이체 및 급여명세서 발급
- [ ] 4대보험 신고 (EDI 또는 4대보험 정보연계센터)

**계정 마감 — 회사 일정에 따라 배치**
- [ ] 감가상각비 계상
- [ ] 선급비용·미지급비용 조정
- [ ] 재고자산 실사 (필요 시)
- [ ] 매출채권·매입채무 잔액 검토
- [ ] 외화 자산·부채 환산 (월말 기준환율 적용)

**결산 보고서 — 승인 일정에 따라 배치**
- [ ] 시산표 검토 및 오류 수정
- [ ] 손익계산서 초안 작성
- [ ] 전월 대비 주요 지표 변동 분석
- [ ] 경영진 보고용 결산 요약 작성

### 4단계: 연간 결산 추가 작업

**법인세 신고 준비 (결산월·사업자 유형·연장 여부 확인)**
- 세무조정 사항 검토 (접대비 한도, 감가상각 방법 등)
- 이월결손금 활용 검토
- 연구·인력개발비 세액공제 확인

**급여 연말정산 (해당 연도 국세청 일정 확인)**
- 근로자 연말정산 서류 수취
- 소득공제·세액공제 항목 확인
- 원천징수영수증 발급 시점 확인

적용 회계기준과 새 기준서의 시행·조기 적용 가능 여부는 한국회계기준원 원문에서 확인한다.

### 5단계: 결산 보고서 생성

```
# [YYYY년 MM월] 결산 보고서

## 손익 요약
- 매출액: xxx원 (전월 대비 ▲▼ xx%)
- 영업이익: xxx원 (영업이익률 xx%)
- 당기순이익: xxx원

## 주요 비용 분석

## 4대보험 납부 현황

## 다음 달 주요 일정
```

## 사용 예시

**예시 1**: "3월 월말 마감 체크리스트 만들어줘"
→ 결산 유형 확인 → 회사 일정별 작업 → 적용 연도 보험료율 확인 → 체크리스트 생성

**예시 2**: "우리 회사 2026년 급여 정산 방법 알려줘. 직원 5명이야"
→ 급여 대장 형식 → 4대보험 계산 → 원천징수 → 신고 절차

**예시 3**: "연간 결산 보고서 초안 작성해줘"
→ 전년 대비 분석 → 주요 지표 → 경영진 요약 → 개선 권고

## 산출물

- 월간/분기/연간 결산 체크리스트
- 급여 대장 및 4대보험 계산 내역
- 결산 보고서 (경영진용 요약 포함)
- 세무 신고 일정 캘린더

## 주의사항

**면책 고지: AI 보조 분석이며 공인 회계사·세무사의 전문 자문을 대체하지 않습니다.**

### 주요 신고 일정

부가가치세·법인세·원천세·지급명세서 일정은 과세 기간, 사업자 유형, 공휴일, 신고 특례에 따라 달라진다. 사용자 사업장의 정보를 받아 [국세청의 해당 연도 신고 안내](https://www.nts.go.kr/)와 대조해 캘린더를 작성한다.

### 4대보험 신고 기한

취득·상실 신고와 보수총액 신고의 기한은 보험별로 다르다. [국민연금공단](https://www.nps.or.kr/), [국민건강보험공단](https://www.nhis.or.kr/), [근로복지공단](https://www.comwel.or.kr/)의 현재 안내에서 각각 확인한다.

## 문제 해결

- **세율·요율 변경 확인 불가**: 국세청(nts.go.kr) 또는 4대보험 정보연계센터(4insure.or.kr)에서 최신 요율을 직접 확인하세요. AI가 제시하는 수치는 참고용이며 실제 신고 시 반드시 공식 고시를 확인해야 합니다.
- **과거 회계 데이터 미제공**: 이전 기간 재무 데이터 없이는 전기 대비 분석이 불가능합니다. 분석 대상 기간의 손익계산서·총계정원장을 함께 제공해 주세요.
- **ERP 연동 오류**: SAP·더존·iCUBE 등 ERP에서 내보낸 CSV/Excel 파일을 직접 붙여넣으면 결산 체크리스트 자동화가 가능합니다.
- **외화 환산 기준일 불일치**: 한국은행 기준환율(ecos.bok.or.kr)에서 월말 고시 환율을 확인한 후 입력해 주세요.

## 관련 스킬

- **moai-accountant:finance-financial-statements**: K-IFRS 재무제표 작성
- **moai-accountant:finance-variance-analysis**: 예산 대비 실적 분석
- **moai-accountant:finance-tax-helper**: 세금 신고, 홈택스 안내

### 후처리 체인 (결산 보고서·경영진 요약 등 서술형 산출물)

결산 보고서, 경영진 요약, 비용 분석 코멘트처럼 문장 산출물을 작성한 뒤에는 반드시 아래 체인으로 마무리한다.

```
finance-close-management → moai-coworker:ai-slop-reviewer → moai-writer:korean-humanize → 최종 검수
```

- **moai-coworker:ai-slop-reviewer**: AI 티 나는 표현·과장·상투구 검수 및 수정
- **moai-writer:korean-humanize**: 한국어 자연스러움 보정 (서술 산출물 한정)

> 급여 대장·4대보험 계산 내역·세무 일정 캘린더 같은 표·숫자 산출물은 체인 대상이 아니며, 엑셀화가 필요하면 `moai-officer:doc-xlsx`로 라우팅한다.

## 이 스킬을 사용하지 말아야 할 때

- **실제 세금 신고·납부**: AI가 작성한 결산 초안을 그대로 세무서에 제출하지 마세요. 세무사에게 검토를 의뢰하세요.
- **재무제표 공식 작성**: 외부 감사 또는 공시용 재무제표가 필요하면 `moai-accountant:finance-financial-statements` 스킬과 공인회계사 검토를 함께 활용하세요.
- **예산 대비 실적 분석**: 전략적 원가·수익 분산 분석은 `moai-accountant:finance-variance-analysis` 스킬이 더 적합합니다.
- **세무 상담**: 종합소득세·부가가치세 신고 방법 상담은 `moai-accountant:finance-tax-helper` 스킬을 사용하세요.
