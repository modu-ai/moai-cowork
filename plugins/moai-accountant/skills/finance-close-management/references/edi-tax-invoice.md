# 전자세금계산서 EDI 가이드

## 개요

전자세금계산서는 국세청 홈택스를 통해 발행·수취·수정·취소를 처리하는 디지털 세금계산서입니다.
[국세청의 의무발급 대상 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=&nttSn=1330709)에 따르면 법인사업자와 직전연도 공급가액(과·면세 합계) 8천만원 이상 개인사업자로 2024년 7월부터 확대됐습니다. 실제 적용 여부는 사업장·공급시기별 최신 안내를 확인합니다.

## 발행 절차

### 1. 홈택스 직접 발행
1. 홈택스 로그인 → 전자세금계산서 → 발급
2. 공급자/공급받는자 사업자번호 입력
3. 품목, 수량, 단가, 공급가액, 세액 입력
4. 발급 → 국세청 전송 (자동)

### 2. ERP/회계 프로그램 연동 (EDI)
1. ERP에서 매출 전표 생성
2. 전자세금계산서 자동 생성 (API 연동)
3. 국세청 ASP 사업자를 통해 전송
4. 전송 결과 확인 (성공/실패)

ASP 사업자의 현재 서비스·인증·연동 가능 여부는 사용 중인 ERP와 국세청 전송 결과에서 확인합니다.

## 수정 세금계산서

수정이 필요한 경우 사유에 맞는 **수정세금계산서** 발급 절차를 확인합니다. 원본을 임의로 삭제하거나 모든 사유를 취소·재발행으로 처리하지 않습니다.

| 사유 | 수정 유형 | 기한 |
|------|----------|------|
| 기재사항 착오 | 기재사항 착오 정정 | 현행 국세청 안내에서 확인 |
| 공급가액 변동 | 공급가액 변동 | 현행 국세청 안내에서 확인 |
| 환입 (반품) | 환입 | 현행 국세청 안내에서 확인 |
| 계약 해제 | 계약의 해제 | 현행 국세청 안내에서 확인 |
| 착오에 의한 이중 발급 | 착오에 의한 이중 발급 | 현행 국세청 안내에서 확인 |

## 가산세 기준

| 위반 유형 | 발급자 가산세 예시 — 적용 요건 확인 |
|----------|--------|
| 미발급 | 공급가액의 2% |
| 지연 발급 (해당 과세기간 확정신고기한 내) | 공급가액의 1% |
| 전자 외 발급 (종이) | 공급가액의 1% |
| 미전송 (국세청) | 공급가액의 0.5% |

구체 요건·수취자 가산세·중복 배제는 [국세청 가산세 안내](https://j.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7790&mi=2464)에서 확인합니다.

## 실무 체크리스트

- [ ] 공급시기와 발급기한을 거래 유형별로 확인
- [ ] 공급받는자 사업자번호 사전 확인 (휴폐업 조회)
- [ ] 수정 세금계산서는 원본 번호 참조하여 발행
- [ ] 월말 미전송 건 일괄 확인 (홈택스 → 전송 현황 조회)
- [ ] 부가세 신고 전 매출/매입 세금계산서 대사 완료
