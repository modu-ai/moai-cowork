# 재무 작업 경로 선택

1. 법인·개인 등 대상, 기간, 산출물, 그 숫자로 결정할 일을 확인한다. 원장·사업자 유형·과세 연도 등 필수 입력이 없으면 현재 런타임의 질문 채널로 묻는다. 질문할 수 없는 하위 실행에서는 누락 입력을 blocker로 반환한다.
2. `finance-financial-statements`, `finance-close-management`, `finance-variance-analysis`, `finance-investor-relations`, `finance-tax-helper` 등 해당 스킬을 선택해 지침을 따른다. 필요한 법령·요율·공시가 현재 기준인지 확인한다. 연결된 DART 도구가 있으면 공시 번호와 보고서명을 기록하고, 연결되지 않았으면 공시를 조회했다고 쓰지 않는다.
3. 모든 숫자의 출처를 원장, 공시, 법령 또는 명시한 추정 가정으로 표시한다. 합계·세액·비율을 재계산하고, 전망치와 실적치를 구분한다.
4. 재무제표·세액·IR 핵심 수치는 `finance-audit`의 검수 기준으로 별도 대조한다. 같은 주체가 수행한 대조는 독립 감사로 표기하지 않는다.
5. 결과에는 대상 기간과 과세 연도, 사용한 자료, 확인한 계산, 남은 확인 사항을 적는다. 실제 신고·거래·회계 시스템 변경은 사용자의 별도 지시와 해당 도구의 권한 확인 없이는 하지 않는다.

Claude의 `finance-analyst` 에이전트와 목적이 겹친다. ChatGPT 플러그인에서는 이 스킬이 발견 가능한 진입점이다.
