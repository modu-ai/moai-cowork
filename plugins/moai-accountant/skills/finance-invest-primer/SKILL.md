# 투자 입문 (Investment Primer)

## 개요

투자를 처음 시작하는 사람이 "뭘 사야 하지" 이전에 "어떤 원칙으로, 어떤 자산에, 얼마나 나눠서"를 이해하도록 돕는다. 개별 종목을 추천하는 것이 아니라 투자 사고의 뼈대와 위험 관리를 세운다.

**면책 고지: 일반적인 투자 교육 정보이며 특정 종목·상품 추천이나 투자 자문이 아닙니다. 모든 투자에는 원금 손실 위험이 있으며 투자 결정과 결과는 본인 책임입니다.**

## 트리거 키워드

투자, 투자 입문, 주식 초보, ETF, 분산투자, 포트폴리오, 적립식, 장기투자, 리스크 관리, 투자 시작, 채권, 펀드

## 워크플로우

### 1단계: 투자 전 점검 (시작해도 될까)

투자 전에 갖춰야 할 전제를 확인한다.

- 비상금 목표와 생활비·부양 의무 확인 — `finance-wealth-roadmap`
- 부채의 실제 이자율·상환 조건 확인
- 투자 손실이 생활·주거 자금에 미치는 영향 확인
- 돈이 필요한 시점과 상품의 매도 가능성 확인

→ 정보가 부족하면 투자 비중을 제시하지 않고 필요한 입력을 먼저 확인한다.

### 2단계: 3대 원칙

- **분산**: 한 종목·한 자산·한 시점에 몰지 않는다(종목·자산군·시간 분산)
- **장기**: 단기 등락 예측은 어렵다 → 시간을 우군으로(복리)
- **리스크 관리**: 기대수익보다 "최악에 얼마 잃을 수 있나"를 먼저 본다

### 3단계: 자산군 이해

| 자산군 | 확인할 위험 | 특징 |
|--------|-------------|------|
| 예적금·CMA | 예금자보호 대상 여부, 상품별 원금손실 가능성 | 단기 자금 용도와 인출 조건 확인 |
| 채권 | 금리·신용·만기·환금성 | 만기 전 매도 가격 변동 |
| ETF | 기초자산·환율·운용보수·추적오차·레버리지 여부 | 여러 자산을 담아도 원금손실 가능 |
| 개별 주식 | 기업·시장·유동성 위험 | 개별 기업에 집중될 수 있음 |
| 부동산/리츠 | 가격·공실·금리·환금성 위험 | 실물과 상장 리츠의 유동성 차이 확인 |

→ 적립식·분산의 효과와 한계를 설명하되 상품 가입이나 수익을 보장하지 않는다.

### 4단계: 초보 포트폴리오 (예시)

목표 시점, 손실 감내 범위, 소득·부채, 기존 자산, 세금·수수료를 먼저 확인한다. 비중 예시는 사용자의 조건과 가정을 명시한 교육용 시나리오로만 작성한다. 자동 매수나 리밸런싱 주기도 사용자의 선택과 상품 조건에 맞춘다.

### 5단계: 세금·계좌 + 사기 회피

- **절세 계좌**: 연금저축·IRP(세액공제), ISA(비과세·분리과세) 활용 → `finance-personal-tax-saver`
- **투자 사기 경고 신호**: "원금 보장 + 고수익", 비상장·코인 리딩방, 확정 수익률 P2P, 지인 권유 폐쇄형 상품 → 거의 사기. 제도권(금융감독원 등록) 여부 먼저 확인.

## 사용 예시

**예시 1**: "주식 처음인데 어떻게 시작해?"
→ 투자 전 점검 → 3원칙 → 지수 ETF 적립식 개념 → 소액 자동매수부터

**예시 2**: "ETF랑 개별 주식 뭐가 달라?"
→ 분산 내장 vs 집중, 위험·관리 부담 비교 → 초보 비중 가이드

**예시 3**: "1천만 원 있는데 어떻게 나눠 투자해?"
→ 사용 시점·비상금·부채·손실 감내 범위 확인 → 가정을 표시한 배분 시나리오와 위험 설명

## 산출물

- 투자 전 점검 체크리스트
- 3대 원칙 요약
- 자산군 비교표
- 성향별 초보 포트폴리오 예시
- 절세 계좌 + 사기 회피 가이드

## 주의사항

- **면책**: 특정 상품·종목을 권유하지 않는다. 모든 투자는 원금 손실 가능.
- 과거 수익률이 미래를 보장하지 않는다.
- 레버리지·신용·빚투는 초보에게 권하지 않는다.

## 이 스킬을 사용하지 말아야 할 때

- **개별 종목 매수 추천·타이밍**: 본 스킬은 자문이 아니다.
- **단기 트레이딩·코인 시그널**: 다루지 않는다.
