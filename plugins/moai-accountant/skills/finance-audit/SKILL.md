# 재무 산출물 검수

원본 파일이나 외부 회계 시스템을 수정하지 않고 근거 자료와 산출물을 대조한다.

- 합계, 대차 평형, 세액, 마진, 성장률, 밸류에이션 배수를 입력값에서 다시 계산한다. 재계산에 사용한 식과 값을 기록한다.
- 재무상태표의 자산 = 부채 + 자본을 확인하고, 손익·자본변동·현금흐름 및 주석의 연결 숫자를 대조한다. 자료가 없으면 그 부분은 미검증이다.
- 외부 숫자는 공시 번호·원장 항목·법령·해당 연도 요율표까지 추적한다. 과세 연도가 다른 자료를 현재 기준으로 쓰지 않는다.
- 전망과 실적이 구분됐는지 확인한다. 세무·회계 조언이 전문가 자문을 대체한다고 표현하지 않는다.

보고서는 `판정(PASS/FAIL/미확인)`, `자료와 기준 연도`, `위치·근거가 있는 발견`, `재계산 표`, `미검증 항목`으로 작성한다. 계산 오류나 근거 없는 핵심 수치는 FAIL로 기록하고, 자료가 없다는 이유로 PASS를 내리지 않는다. 독립된 검수자를 실행하지 않았다면 독립 감사라고 부르지 않는다.
