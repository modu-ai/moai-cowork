# 세무/회계 도우미 (Tax Helper & Bookkeeping Automation)

인적용역 종사자, 개인사업자, 소상공인의 세무 자료 정리와 신고 준비를 돕습니다. 소득 유형·과세 연도·업종을 확인하기 전에는 세액이나 절세 효과를 확정하지 않습니다.

## Overview

> **주의**: 이 스킬은 세무 정보 제공 및 문서 정리 도구입니다.
> 실제 세무 신고는 반드시 홈택스(hometax.go.kr) 또는 세무사를 통해 진행하세요.
> 현재 앱의 AI 답변은 세무사의 검토를 대신하지 않습니다.

---

## 핵심 세무 일정

대상 소득·사업자 유형·과세 기간을 확인한 뒤 [국세청 해당 연도 세무 일정](https://www.nts.go.kr/nts/ad/taxSchdul/selectList.do?mi=&taxYear=2026)에서 신고 항목과 기한을 조회합니다. 사업장현황신고는 면세사업자 중 해당 대상인지 확인하고, [국세청의 2025년 수입분 안내](https://j.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7699&mi=2283)에 적힌 2026년 2월 10일 기한을 다른 연도에 복사하지 않습니다.

## 프리랜서 세무 가이드 (3.3%)

### 기본 구조
```
수입금액 (원천징수 전 계약·지급 자료의 총액 확인)
- 필요경비 (경비율 적용 또는 장부 기장)
= 소득금액
- 소득공제 (인적공제, 연금, 보험 등)
= 과세표준
× 세율
= 산출세액
- 세액공제/감면
- 기납부세액 (3.3% 원천징수분)
= 납부/환급세액
```

### 경비율 구분

단순경비율·기준경비율 및 장부 의무의 기준은 업종과 직전연도 수입금액, 신규 사업 여부에 따라 달라집니다. 2,400만원이나 7,500만원을 모든 업종에 적용하지 않고 [국세청 안내](https://www.nts.go.kr/)에서 업종별 기준을 확인합니다.

### 소득세율표

과세 연도를 정한 뒤 [국세청 기본세율표](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7675&mi=2315)를 확인합니다. 과세표준은 총수입이 아니며 공제·감면·기납부세액을 별도로 반영합니다.

## 개인사업자 세무 가이드

### 부가세 신고 준비 체크리스트
```
□ 매출 자료 정리
  - 세금계산서 발행 내역 (전자세금계산서)
  - 카드 매출 (POS 데이터)
  - 현금영수증 발행 내역

□ 매입 자료 정리
  - 매입 세금계산서
  - 사업용 신용카드 사용 내역 (등록·조회 가능 여부 확인)
  - 현금영수증 (지출증빙)

□ 공제/불공제 구분
  - 매입세액 공제 가능 여부는 거래 성격·사업 관련성·적격증빙과 불공제 규정을 확인

□ 서류 준비
  - 사업자등록증 사본
  - 통장거래내역
  - 임대차계약서 (해당 시)
```

### 간편장부 vs 복식부기

업종·직전연도 수입금액·신규 사업 여부에 따라 장부 의무를 확인합니다. 복식부기 기장과 세액공제의 대상·한도도 과세 연도별로 확인하며, 장부 방식을 임의의 절세 상품처럼 추천하지 않습니다.

---

## 절세 핵심 전략

### 프리랜서 절세 3가지
1. **적격증빙 챙기기**: 사업 관련 모든 지출에 대해 세금계산서, 카드 영수증, 현금영수증 확보
2. **사업용 카드 자료 정리**: 카드 등록과 거래 조회 가능 여부를 확인하고, 매입세액 공제 가능성은 거래별로 판단
3. **장부 방식 확인**: 기장세액공제 대상·한도와 실제 기장 비용을 함께 검토

### 사업자 등록 검토 기준
- 사업자등록 필요 여부는 활동 성격과 관련 법령을 확인; 단일 매출액 기준으로 단정하지 않음
- 시설/장비 투입이 큰 업종은 매입세액 공제를 위해 사업자등록 유리
- 창업 감면은 업종·지역·창업 이력·과세 연도별 요건을 공식 자료로 확인

## 제공 기능

### 1. 세금 시뮬레이션
사용자의 수입, 경비 정보를 입력받아 예상 세금을 계산합니다.

**입력:**
- 연 총수입
- 항목별 경비
  - 사무실 임차료
  - 통신료
  - 광고비
  - 교육비
  - 기타 경비
- 소득공제 (인적공제, 연금, 보험)

**출력:** 적용 과세 연도, 총수입·필요경비·공제·감면·기납부세액의 출처와 산식을 단계별로 제시합니다. 입력이 비어 있으면 납부세액을 만들지 않고 필요한 자료를 요청합니다.

### 2. 매출/매입 정리 엑셀 생성

**매출 정리표 구조:**
| 날짜 | 거래처 | 품목 | 공급가액 | 부가세 | 합계 | 증빙유형 |
|------|--------|------|---------|--------|------|---------|

**매입 정리표 구조:**
| 날짜 | 거래처 | 품목 | 공급가액 | 부가세 | 합계 | 공제여부 | 증빙유형 |
|------|--------|------|---------|--------|------|---------|---------|

**경비 정리표 구조:**
| 날짜 | 항목 | 내용 | 금액 | 증빙유형 | 비고 |
|------|------|------|------|---------|------|

### 3. 신고 체크리스트 생성
신고 유형별 필요 서류와 절차를 체크리스트로 제공합니다.

**항목:**
- [ ] 사업자등록증 사본
- [ ] 통장거래내역 (전년도 및 신고연도)
- [ ] 세금계산서 (발행분, 수취분)
- [ ] 현금영수증 발행 내역
- [ ] 카드 매출 (POS, 신용카드 명세)
- [ ] 임대차계약서 (해당 시)
- [ ] 대리 신고 시 실제 절차에서 요구하는 위임 자료 확인

### 4. 절세 분석 리포트
수입/경비 데이터를 분석하여 절세 가능한 항목을 찾아줍니다.

**분석 항목 예시:** 장부·증빙 누락, 사업 관련 경비의 적격 여부, 공제 대상, 기납부세액을 확인합니다. 카드 등록만으로 매입세액이 자동 공제되거나 일정 금액을 절약한다고 쓰지 않습니다. 홈오피스 비용도 사업 관련성·증빙·사적 사용분 구분이 확인된 경우에만 검토합니다.

## 출력 형식

- 매출/매입/경비 정리표: 현재 앱에서 생성 가능한 형식과 사용자 요청에 맞춤
- 세무 요약 리포트: 현재 앱에서 생성 가능한 형식과 사용자 요청에 맞춤
- `.md`: 체크리스트, 가이드 텍스트
- 텍스트: 세금 계산 결과, 절세 팁

## 워크플로우

```
사용자 요청 → 세무 유형 파악 (부가세/종소세/경비정리)
→ 필요 정보 수집 (수입, 경비, 사업 유형)
→ 계산/정리/분석 → 결과 출력 → 전달
```

## 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| 계산 결과 다름 | 세율 변경, 공제 누락 | 홈택스 공식 계산기와 비교 |
| 경비 범위 불확실 | 개인/사업 구분 애매 | 세무사 상담 (판단 필요) |
| 신고 기한 놓침 | 일정 확인 부족 | 홈택스 달력 확인, 알림 설정 |
| 증빙 부족 | 영수증 미보관 | 향후 카드/현금영수증 반드시 수집 |
| 역산입세액공제 불가 | 공급자가 세금계산서 미발행 | 공급자에게 재요청 |
