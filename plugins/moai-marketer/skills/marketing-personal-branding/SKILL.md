# 개인 브랜딩

개인이 어떤 일을 누구에게 어떤 근거로 소개할지 정리합니다. 기업·제품 브랜드 아이덴티티까지 요청받으면 설치된 경우 moai-coworker:collab-brand-identity를 활용하고, 없으면 확인된 브랜드 자료로 범위를 한정합니다. 실제 SNS 글 작성은 content-sns-content를 사용합니다.

## 입력

- 공개해도 되는 경력·역할·작업물·자격과 실제 기여 범위
- 만나고 싶은 독자, 브랜딩 목표, 현재 운영 중인 채널과 사용 가능한 시간
- 회사·고객의 기밀, 로고·사진·추천서 사용 허가, 개인 계정 공개 범위

자료가 부족하면 확인할 질문을 간단히 묻거나 임시 문구로 표시합니다. 가상의 수치·프로젝트·고객사를 프로필에 넣지 않습니다.

## 진행

1. 현재 경험과 확인 가능한 증거를 목록으로 만들고 공개 가능 여부를 구분합니다.
2. 대상 독자가 겪는 문제와 제공할 수 있는 도움을 한 문단으로 설명합니다. 경쟁자 분석은 공개 자료의 사실만 쓰고 팔로워 수가 곧 전문성이라고 보지 않습니다.
3. 프로필 소개·작업물 설명·연락 경로를 실제 채널 규격에 맞게 작성합니다. 채용·강연·고객 상담 등 목표에 따라 강조점을 달리합니다.
4. 꾸준히 설명할 수 있는 주제와 실제 사례를 골라 콘텐츠 후보를 만듭니다. 숏폼·롱폼을 모두 만들거나 채널 수·발행 빈도를 고정하지 않습니다.
5. 현재 독자가 있는 채널, 필요한 형식, 제작 부담과 문의 경로를 비교해 운영 채널을 정합니다. 게시·예약·발행 상태를 각각 구분합니다.

## 이미지와 영상

프로필·콘텐츠의 일반 이미지는 ChatGPT Work의 현재 대화에 제공된 이미지 도구로 만듭니다. GPT Image 2.5를 정확히 지정했다면 모델을 확인하고, 확인되지 않으면 설치된 moai-media:media-codex-image의 별도 API 경로와 비용·승인 절차를 따릅니다. Higgsfield 지정 요청은 공식 연결의 실제 모델을 확인하고 설치된 경우 moai-media:media-higgsfield-image를 사용합니다. 실제 인물의 사진·초상과 생성 인물의 표시·사용권을 확인합니다. 이미지 생성만으로 전문 경력이나 성과를 증명하지 않습니다.

## 검수

수치·자격·후기·추천·프로젝트 기여는 원본 자료와 대조합니다. 회사·고객 자료는 공개 권한을 확인합니다. AI 작성 비율의 고정 상한이나 무조건 공개 의무를 만들지 않고, 채널 정책과 독자의 신뢰를 고려해 실제 제작 과정을 설명합니다. [Google의 생성형 AI 콘텐츠 안내](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content)는 정확성·품질·관련성을 강조하며, 가치 없는 대량 생성 콘텐츠가 스팸 정책을 위반할 수 있다고 설명합니다.

## 산출물

요청 범위에 맞는 프로필 문구, 포지셔닝 설명, 주제 목록, 채널별 계획을 제공합니다. 다섯 개 파일을 항상 만들지 않습니다. 실제 채널 계정과 성과 데이터를 보지 않았다면 최적화·성과를 검증했다고 쓰지 않습니다. 서술 검수 스킬이 설치돼 있으면 활용하고 원본과 대조하며, 없으면 직접 사실·문장을 검수합니다.
