# 개인 브랜드 자기 분석

## 경험과 증거

| 경험·기술 | 본인 역할 | 확인 자료 | 공개 가능 여부 | 독자에게 줄 수 있는 도움 |
|---|---|---|---|---|
| 실제 작업 | 팀 기여와 개인 기여를 구분 | 포트폴리오·발표·문서 | 회사·고객 허가 확인 | 적용 가능한 지식 |

숙련도를 임의 5점 척도로 업계 상위라고 판정하지 않습니다. 경력·자격·매출 기여·전환 개선 수치는 실제 원본과 기간이 있을 때만 사용합니다. 가상 사례는 프로필 문구로 복사하지 않습니다.

## 포지셔닝

1. 만나고 싶은 독자와 그들이 실제로 겪는 문제를 자료로 확인합니다.
2. 본인이 제공할 수 있는 방법과 경험의 범위를 적습니다.
3. 비슷한 분야의 공개 사례를 참고하되 타인의 성과·약점을 근거 없이 평가하지 않습니다.
4. 독자가 이해할 수 있는 소개 문장으로 묶고, 과장된 결과 보장은 뺍니다.

예시 틀: 어떤 사람에게 어떤 상황에서 어떤 방식으로 도움을 주는지 설명합니다. 숫자는 검증된 경우에만 붙입니다.

## 회사 소속과 공개 범위

사내 자료·고객 정보·미공개 프로젝트·로고·추천서는 회사 규정과 당사자 허가를 확인합니다. 팀 성과를 단독 성과로 바꾸지 않습니다. 채용·협업을 위한 공개 프로필과 사내 비공개 자료를 구분합니다.

## 검토

사용자의 실제 목표와 현재 채널을 기준으로 부족한 증거와 다음에 모을 자료를 적습니다. 임의의 개인 브랜드 건강도 100점이나 추천서·게시 빈도 기준으로 사람의 전문성을 판정하지 않습니다.
