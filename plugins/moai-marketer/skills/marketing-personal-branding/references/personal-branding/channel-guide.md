# 개인 브랜드 채널 선택

채널은 목표 독자, 현재 관계, 제작 가능한 형식과 유지 부담을 보고 선택합니다. 채널별 최고 ROI, 고정 게시 시각·빈도·성과 도달 시점은 일반 규칙으로 제시하지 않습니다.

## 비교 질문

| 채널 | 확인할 것 |
|---|---|
| LinkedIn | 목표 독자가 활동하는지, 공개 가능한 직무 경험·작업물이 있는지 |
| 브런치·개인 블로그 | 긴 글을 꾸준히 작성할 자료가 있는지, 검색·구독 경로가 필요한지 |
| 네이버 블로그 | 국내 독자의 실제 검색 질문과 검증 가능한 경험 자료가 있는지 |
| Instagram·Threads·X | 사진·짧은 글·대화 중 어떤 형식이 본인에게 맞는지 |
| YouTube | 촬영·편집·자막·초상·음원 권리를 감당할 수 있는지 |
| 카카오 채널 | 이미 동의한 고객과의 연락 목적이 있는지 |

## 프로필 점검

- 직함·소속·자격·사례를 현재 자료와 맞춥니다.
- 연락 경로와 공개 범위, 회사·고객 자료의 사용 허가를 확인합니다.
- 약속하는 서비스와 실제 제공 조건을 일치시킵니다.
- 프로필 길이·링크·이미지 규격은 발행 시점의 해당 채널 화면에서 확인합니다.

## 콘텐츠 운영

기존 글을 다른 채널에 맞게 바꿀 수 있지만 원문의 사실·맥락은 유지합니다. 모든 글을 여섯 채널로 변환하거나 일정한 시간 간격을 강제하지 않습니다. 예약 도구가 연결돼도 초안·예약·게시 상태를 각각 확인합니다. 이 플러그인의 Typefully MCP는 지원하는 채널에서만 사용하며, 다른 채널 발행을 약속하지 않습니다.

[YouTube Shorts 공식 안내](https://support.google.com/youtube/answer/15424877?hl=en)는 길이가 최대 3분일 수 있다고 설명합니다. [네이버 D.I.A. 안내](https://help.naver.com/service/5626/contents/22926?osType=COMMONOS)는 경험·정보성 등 여러 요소를 설명하지만 글자 수·사진 장수·댓글 시간의 고정 공식을 제시하지 않습니다. 채널 규격과 노출 기준은 게시 시점의 공식 도움말로 다시 확인합니다.

## 측정

게시물 노출보다 실제 목표와 연결되는 프로필 방문·문의·상담·채용 제안 등의 관찰을 우선합니다. 결과가 없다면 채널이 실패했다고 단정하지 않고 기간·제작량·독자 적합성을 확인합니다.
