# 개인 브랜드 콘텐츠 전략

## 주제 선정

실제 경험·전문성·독자의 질문이 만나는 주제를 고릅니다. 주제 수를 세 개로 고정하거나 출처 없는 검색량 점수를 붙이지 않습니다. 공개 가능한 사례가 부족한 주제는 조사·학습 중이라고 표시합니다.

| 주제 후보 | 가진 근거 | 독자의 질문 | 제작 형식 | 공개 제약 |
|---|---|---|---|---|
| 실제 주제 | 작업물·자료 | 상담·댓글·검색 등 | 글·영상·도표 | 회사·고객 허가 |

## 원고 구성

- 실제 문제와 맥락을 설명합니다.
- 본인이 한 일과 팀·타인의 기여를 구분합니다.
- 확인된 결과가 있으면 기간·분모·출처를 적습니다. 없으면 배운 점과 남은 질문을 씁니다.
- 다른 자료를 인용할 때 출처와 사용권을 확인합니다.
- 독자에게 다음 행동을 안내할 수 있지만 클릭·댓글을 억지로 유도하는 고정 공식은 쓰지 않습니다.

## 재활용과 이미지

기존 글을 요약하거나 영상 대본으로 바꿀 때 원래 의미와 숫자를 유지합니다. 일반 이미지는 ChatGPT 대화의 이미지 도구를 확인해 만들고, ChatGPT Images 2.5 요청도 기본 이미지 도구로 생성·편집하고, 모델 표시가 없으면 개별 호출의 정확한 모델은 미확인으로 보고합니다. Flare·Sunburst API 모델 ID 지정은 설치된 `moai-media:media-codex-image`의 별도 인증·과금 경로를 확인합니다. Higgsfield 지정 요청은 공식 연결의 실제 모델을 확인하고 설치된 경우 moai-media:media-higgsfield-image를 사용합니다. 실제 이미지·대본을 생성하거나 게시했는지 상태를 구분합니다.

## AI 활용

AI는 자료 정리·초안·교정에 쓸 수 있습니다. 본인의 경험·고객 사례·컨퍼런스 참석·성과를 만들어 넣지 않습니다. AI 사용 비율의 임의 상한과 채널별 공개 의무를 일반 규칙으로 쓰지 않습니다. 게시 전 사실과 플랫폼 정책을 확인합니다. [Google의 생성형 AI 콘텐츠 안내](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content)는 가치 없는 대량 생성 콘텐츠를 경계하고 정확성·관련성을 강조합니다.

## 측정과 다음 편

목표에 맞는 관찰 지표의 정의·분모·기간을 기록합니다. 고정 참여율·팔로워 증가율 벤치마크 없이 자신의 이전 자료와 비교합니다. 발행 빈도는 제작 역량과 실제 반응을 보고 정합니다.
