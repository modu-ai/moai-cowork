# 마케팅 성과 보고서

광고·검색·CRM·판매 데이터가 있으면 출처와 정의를 맞춰 분석합니다. 경영진용 요약만 필요하면 collab-exec-summary로 넘길 수 있습니다.

## 자료 확인

- 보고 기간·시간대·통화·세금 포함 여부와 비교 기간
- 채널별 비용, 클릭·노출, 주요 전환 건수와 전환 가치, 주문·환불·배송·원가
- 각 플랫폼의 전환 이벤트, 기여 기간·모델, 중복 집계 가능성
- 데이터 출처: 사용자가 준 파일, 공식 도구에서 실제 조회한 결과, 수동 추정 여부

접근 권한이 없거나 자료가 빠졌다면 받은 범위만 분석하고 누락을 적습니다. GA4·Meta·네이버·카카오·Google Ads에 연결됐다고 가정하지 않습니다.

## 계산과 대조

- 광고 지출 대비 전환 가치(ROAS) = 귀속된 전환 가치 / 해당 광고비. 전환 가치를 금액으로 기록하지 않았거나 비용과 기간이 맞지 않으면 계산하지 않습니다.
- CPA = 해당 전환에 든 광고비 / 정의한 전환 건수. 전환 행동의 정의를 함께 적습니다.
- 클릭률과 전환율은 플랫폼별 분모가 다를 수 있습니다. 원본 열 이름과 계산식을 남기고 같은 이름만 보고 통합하지 않습니다.
- 플랫폼별 귀속 매출 합계를 실제 총매출로 단순 합산하지 않습니다. 중복 귀속·환불·세금·통화 차이를 확인합니다.
- LTV·CAC·이익은 필요한 원가, 보유 기간, 고객 수와 산정 방식이 있을 때만 계산합니다. 고정 3:1 비율을 모든 업종의 합격선으로 쓰지 않습니다.

Google Ads의 [전환 추적 열 설명](https://support.google.com/google-ads/answer/6270625?hl=en)은 전환 가치/비용의 정의와 전환 열의 차이를 설명합니다. 채널별 정의는 실제 계정 설정으로 확인합니다.

## 분석 순서

1. 원본 데이터의 결측·중복·기간과 단위를 확인하고 수정 여부를 기록합니다.
2. 목표 지표와 이전 기간을 비교하되 계절성·예산·상품·추적 설정 변경을 함께 봅니다.
3. 관찰된 변화와 가능한 원인 가설을 분리합니다. 광고 소재나 알고리즘을 원인으로 단정하려면 추가 증거를 확인합니다.
4. 액션마다 기대 근거, 비용·위험, 측정 방법과 담당자를 적습니다. 예산 변경·광고 중단은 실제 계정 권한과 사용자 요청 범위에 따라 별도 실행합니다.

## 보고 형식

요약에는 확인된 결과와 중요한 한계만 적습니다. 상세 표에는 채널·기간·비용·전환 정의·전환 가치·지표·출처를 표시합니다. 추천안은 관찰, 가설, 다음 확인 순으로 씁니다. 데이터가 없으면 빈 보고서를 채우지 않고 필요한 추출 항목을 안내합니다.

Chrome의 제3자 쿠키 전면 종료를 이미 확정된 사실로 전제하지 않습니다. Google의 [Privacy Sandbox 업데이트](https://privacysandbox.google.com/blog/privacy-sandbox-next-steps)는 사용자 선택 접근을 유지한다고 설명합니다. 추적 제약과 동의 상태는 실제 브라우저·지역·계정에서 확인합니다.

서술 검수 스킬이 설치돼 있으면 활용하고 숫자와 의미를 원본과 대조합니다. 없으면 직접 검수합니다. 시각화가 필요하면 moai-analyst:data-visualizer, 표 파일이 필요하면 moai-officer:doc-xlsx를 사용할 수 있습니다.
