# 광고 전환 측정 점검

사이트와 광고 계정의 전환 측정이 목표 행동을 정확히 기록하는지 확인합니다. 광고 성과 해석은 marketing-performance-report와 marketing-meta-ads-analyzer로 연결합니다.

## 접근 범위 확인

- 사이트 URL, 운영 국가, 광고 채널, 주요 전환 행동과 확인할 테스트 주문 또는 신청 흐름
- 브라우저·태그 관리자·Meta Events Manager·Google Ads/GA4 중 실제로 접근 가능한 화면
- 쿠키·광고 데이터 수집 동의와 개인정보 처리 방식

접근할 수 없는 계정 설정·서버 이벤트·고객 목록은 미검증으로 둡니다. 공개 사이트에서 스크립트가 보인다는 사실만으로 전환값·중복 제거·CAPI 작동을 확정하지 않습니다.

## 점검 순서

1. 브라우저에서 실제 동의 상태별로 페이지·상품·장바구니·구매 등 필요한 행동을 수행하고 태그 요청·이벤트 이름·값·통화를 기록합니다. 테스트 주문은 실제 결제에 영향을 줄 수 있으므로 사용자가 제공한 안전한 테스트 경로를 사용합니다.
2. Meta Events Manager에 접근할 수 있으면 실제 이벤트 수신·진단, 브라우저와 서버 이벤트의 중복 제거 설정, 구매 가치와 상품 ID의 일치를 확인합니다. CAPI가 없다는 사실만으로 측정 손실률을 추정하지 않습니다.
3. Google Ads·GA4에 접근할 수 있으면 전환 행동 정의, 중복 집계, 링크 설정, 태그 진단과 동의 상태를 확인합니다. Google의 [향상된 전환 안내](https://support.google.com/google-ads/answer/13258081?hl=en)는 사용 조건과 고객 데이터 정책 검토를 요구합니다.
4. 동의 배너가 있으면 선택이 태그 동작에 반영되는지 검사합니다. [Google 동의 모드 안내](https://developers.google.com/tag-platform/security/concepts/consent-mode)에 따라 실제 선택과 태그 신호를 대조합니다.
5. Meta·Google·CRM에 이메일이나 전화번호를 업로드하라는 권고는 수집 목적·동의·플랫폼 정책·계정 권한을 확인한 경우에만 합니다. 기존 구매자 제외나 유사 타겟은 캠페인 목적에 따라 판단합니다.

## 판정

| 항목 | 확인한 증거 | 결과 | 다음 확인 |
|---|---|---|---|
| 이벤트 발화·값·통화 | 테스트 행동과 요청 로그 | 확인/오류/미검증 | 계정 진단 등 |
| 서버 이벤트·중복 제거 | Events Manager 기록 | 확인/오류/미검증 | event ID 등 |
| Google 전환 행동 | Ads/GA4 설정과 진단 | 확인/오류/미검증 | 정의·기여 설정 |
| 동의 반영 | 실제 동의 상태별 검사 | 확인/오류/미검증 | 개인정보 검토 |

임의의 100점 점수, 고정 추적률, 고정 Lookalike 비율·갱신 주기, CAPI 필수 여부를 보편 기준으로 제시하지 않습니다. 문제의 원인과 예상 손실액은 실제 측정 자료가 있을 때만 계산합니다. 개선을 실행하지 않았다면 점검과 수정 완료를 구분합니다. 서술 검수 스킬이 설치돼 있으면 활용하고 사실·수치를 원본과 대조합니다.
