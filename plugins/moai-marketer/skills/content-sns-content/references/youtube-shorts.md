# YouTube Shorts

[YouTube 공식 도움말](https://support.google.com/youtube/answer/15424877?hl=en)은 일정 조건의 정사각형·세로 영상을 최대 3분 Shorts로 안내한다. 실제 업로드 계정, 영상 길이, 종횡비와 음악·Content ID 조건을 확인한다. 특정 길이나 해시태그가 Shorts 분류 또는 노출을 보장한다고 하지 않는다.

## 제작

- 첫 장면에서 영상의 주제와 실제 내용을 이해할 수 있게 한다. 조회수를 위해 근거 없는 충격 표현이나 낚시성 제목을 쓰지 않는다.
- 자막은 원고·음성과 맞추고 모바일 화면에서 읽히는지 확인한다. 자동 자막의 고유명사·숫자 오타를 검수한다.
- 타인의 영상·음악·이미지는 사용 권한과 해당 Shorts의 저작권 조건을 확인한다.
- 장편 영상을 재활용할 때는 원본의 맥락·출처·사용권을 유지한다.

스크립트, 영상 파일, 업로드, 공개 상태는 다른 산출물이다. 영상 생성 도구와 YouTube 게시 연결을 실제로 확인하지 않았다면 스크립트만 제공하고 게시를 완료했다고 쓰지 않는다. 성과는 해당 채널의 Analytics에서 기간과 지표를 확인한다.
