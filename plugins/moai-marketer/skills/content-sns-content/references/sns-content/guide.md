# SNS 콘텐츠 제작 점검

1. 대상 채널과 계정을 확인한다. 초안만 필요한지, 예약·게시까지 요청했는지 구분한다.
2. 원본 자료의 날짜·출처·권리와 브랜드 말투를 확인한다. 실제 고객 사례나 제품 성과를 만들지 않는다.
3. 채널 형식에 맞는 제목·본문·캡션·자막을 작성한다. 글자 수와 파일 규격은 현재 편집 화면에서 확인한다.
4. 이미지·영상이 필요하면 사용할 도구를 확인한다. ChatGPT 기본 생성과 사용자가 지정한 Higgsfield 생성은 다른 경로다. 프롬프트만 작성한 경우 제작 완료로 표시하지 않는다.
5. 링크·표시광고·광고성 메시지·접근성·저작권을 검수한다. 카카오 메시지는 [카카오 비즈니스 가이드](https://business.kakao.com/guide.html)의 정보성/광고성 구분을 확인한다.
6. 게시 권한과 사용자 승인 범위를 확인한 뒤 도구를 실행한다. 결과 URL 또는 예약 목록을 확인하고 상태를 보고한다.

네이버 블로그 검색은 기계적인 글자 수·키워드 반복으로 보장되지 않는다. [네이버 C-Rank](https://help.naver.com/service/5626/contents/22927?osType=COMMONOS)와 [D.I.A.](https://help.naver.com/service/5626/contents/22926?osType=COMMONOS)는 여러 품질 요소를 설명한다. 동영상의 조회수·도달률·최적 업로드 시간은 해당 계정 데이터로 평가한다.
