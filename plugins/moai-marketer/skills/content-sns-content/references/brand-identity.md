# SNS 제작을 위한 브랜드 자료

기업 브랜드의 이름·슬로건·색·로고·금지 표현은 사용자가 제공한 정본에서 가져온다. 자료가 없으면 임의의 브랜드 역사, 고객층, 시각 토큰을 확정하지 않는다. SNS 게시물 제작에 필요한 범위만 묻고, 전체 브랜드 전략이 필요하면 설치된 경우 moai-coworker:collab-brand-identity를 활용한다. 없으면 확인된 자료에 한정한 게시물 초안과 필요한 브랜드 질문을 제공한다.

| 확인할 자료 | 사용처 |
|---|---|
| 브랜드 표기와 제품명 | 게시물·이미지·해시태그 |
| 로고·색·서체의 사용 규칙 | 카드·영상의 시각 일관성 |
| 사실 확인된 제품 특징 | 혜택 문구 |
| 승인 담당자와 금지 표현 | 발행 전 검수 |

상표·도메인 가능성은 실제 공식 검색 결과 없이 확인됐다고 하지 않는다. 참고 이미지의 스타일을 사용할 때는 권리를 확인한다.
