# Threads 게시물

짧은 의견, 질문, 참고 링크, 연속 게시물 중 목적을 정한다. 한 게시물에 다 담기 어렵다면 의미 단위로 나누되 고정된 연속 게시물 수를 강제하지 않는다.

현재 계정과 게시 화면에서 글자·이미지·영상 제한을 확인한다. Instagram 계정과 연결 상태, 공유 설정은 사용자 계정마다 다르다. 답글이나 재게시의 알고리즘 가중치를 공식 근거 없이 순위로 제시하지 않는다.

[Typefully MCP](https://support.typefully.com/en/articles/13128440-typefully-mcp-server)가 연결되면 Threads 계정의 초안·예약을 다룰 수 있다. 실제 연결 계정, 예약 시간대, 승인 범위와 결과를 확인한다. 연결되지 않았다면 복사 가능한 초안을 제공한다.
