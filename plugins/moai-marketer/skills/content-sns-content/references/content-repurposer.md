# 원본 콘텐츠 재활용

원본 파일이나 URL을 열어 실제 내용을 확인한다. 저작권과 재사용 권한, 기준일, 이미 게시한 채널을 기록한다. 원본을 받지 못했다면 변환을 완료했다고 말하지 않는다.

| 단계 | 확인 |
|---|---|
| 핵심 추출 | 원본의 주장·근거·단서 |
| 채널 선택 | 독자와 형식이 맞는 채널 |
| 변환 | 사실·인용을 유지하면서 길이와 시각 구성을 조정 |
| 검수 | 원본과 문장·숫자·맥락을 대조 |
| 성과 | 게시 후 실제 채널 자료로 측정 |

원본 영상에서 클립을 만드는 경우 발언의 앞뒤 맥락과 음악·영상 권리를 보존한다. 채널마다 여러 게시물을 만들더라도 중복 도달이나 성과 향상을 보장하지 않는다. 실제 파일을 제작하지 않았으면 스크립트·편집 지시와 제작 완료를 구분한다.
