# Instagram 게시물

피드·캐러셀·릴스·스토리 중 사용자가 요청한 형식을 확인한다. 이미지·영상 비율, 파일 개수, 자막과 길이는 현재 Instagram 편집 화면과 공식 도움말에서 다시 확인한다.

- 캡션 첫 부분에 실제 콘텐츠의 요지를 둔다. 근거 없는 충격 통계나 허위 긴급성으로 시작하지 않는다.
- 해시태그는 관련성이 있을 때만 사용한다. 고정 개수·조회수 구간·게시 시간대가 노출을 보장한다고 말하지 않는다.
- 이미지 속 글자, 제품·인물 표현, 로고 사용권과 모바일 크롭을 확인한다.
- 릴스는 영상의 실제 첫 장면과 자막이 내용을 제대로 전달하는지 확인한다. 일률적인 3초 후크나 길이를 강제하지 않는다.

Typefully MCP가 Instagram 게시를 지원한다고 가정하지 않는다. 현재 앱에서 공식 게시 연결이 확인되지 않으면 원고·이미지 파일과 게시 안내를 제공한다.
