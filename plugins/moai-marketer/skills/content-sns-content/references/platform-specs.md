# 플랫폼 규격 확인표

플랫폼 규격과 계정 기능은 바뀔 수 있다. 게시 전 대상 계정·게시 형식·현재 앱 편집 화면 또는 공식 도움말을 확인한다. 아래는 확인 출발점이며 모든 채널의 고정 최대값 표가 아니다.

| 채널 | 공식 확인처 | 게시 전 확인할 것 |
|---|---|---|
| 네이버 블로그 | [네이버 검색 고객센터](https://help.naver.com/service/5626/contents/22927?osType=COMMONOS) | 제목·본문·이미지·출처, 실제 계정의 작성 화면 |
| 카카오 채널 | [카카오 비즈니스 가이드](https://business.kakao.com/guide.html) | 소식과 메시지의 차이, 광고성 여부, 발송 대상·버튼 |
| X | [X Premium 도움말](https://help.x.com/en/using-x/x-premium) | 계정 유형별 글·영상 제한, 연결된 게시 도구 |
| LinkedIn | [LinkedIn 게시 도움말](https://www.linkedin.com/help/linkedin/answer/a527226) | 개인·페이지 권한, 현재 게시물 제한, 링크 미리보기 |
| YouTube Shorts | [YouTube Shorts 도움말](https://support.google.com/youtube/answer/15424877?hl=en) | 길이·종횡비·저작권 음원·자막과 업로드 상태 |
| Threads·Instagram·Facebook | 해당 앱의 현재 게시 화면과 Meta 공식 도움말 | 형식별 비율·파일·개수·권한 |

현재 [LinkedIn 도움말](https://www.linkedin.com/help/linkedin/answer/a527226)은 게시물 3,000자를 안내하고, [X Premium 도움말](https://help.x.com/en/using-x/x-premium)은 Premium의 긴 게시물을 설명한다. [YouTube 도움말](https://support.google.com/youtube/answer/15424877?hl=en)은 조건에 맞는 Shorts를 최대 3분으로 안내한다. 이 값도 계정·형식·날짜가 달라지면 재확인한다.

최적 게시 시간, 해시태그 개수, 댓글 반응의 효과는 보편적인 플랫폼 규격이 아니다. 해당 계정의 인사이트에서 기간·대상·측정값을 확인한 후 가설로 시험한다. 서비스가 노출이나 조회수를 보장하지 않는다.
