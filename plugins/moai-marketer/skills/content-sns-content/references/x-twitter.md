# X 게시물

사용자 계정의 유형과 글·미디어 제한을 확인한다. [X Premium 공식 도움말](https://help.x.com/en/using-x/x-premium)은 Premium의 긴 게시물 등 추가 기능을 설명한다. 계정 기능을 확인하지 않은 채 일반 계정의 한도를 Premium에 그대로 적용하지 않는다.

게시물에는 현재 확인된 정보와 출처를 적는다. 실시간 이슈를 다루면 사건 날짜와 공식 자료를 확인한다. 긴 내용은 스레드로 나눌 수 있지만 고정된 게시물 수나 태그 수를 강제하지 않는다. 링크를 무조건 댓글에 옮기거나 초기 반응을 인위적으로 만들지 않는다.

이 플러그인의 Typefully MCP가 연결되면 X 계정의 초안·예약·게시 기능을 현재 도구 스키마로 확인한다. 게시·예약은 계정과 승인 범위를 확인한 뒤 실행하고 실제 결과를 확인한다. 해당 계정이 없다면 글 초안만 제공한다.
