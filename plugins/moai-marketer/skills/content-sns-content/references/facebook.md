# Facebook 게시물

페이지·그룹·개인 계정 중 대상과 게시 권한을 확인한다. 원고는 해당 독자가 알고 싶은 사실과 질문을 중심으로 쓴다. 페이지 글, 그룹 대화, Reels는 목적과 게시 형식이 다르므로 하나의 도달 공식으로 묶지 않는다.

사진·영상·링크를 올릴 때 현재 게시 화면에서 비율과 미리보기를 확인한다. 외부 링크를 무조건 첫 댓글로 옮기거나 댓글을 인위적으로 모으지 않는다. 그룹은 각 그룹의 자체 규칙과 판매 허용 여부를 확인한다.

도달률·초기 댓글 효과·릴스 우위·유료 광고 학습 기간에 관한 고정 수치는 계정 실측이나 현재 Meta 문서가 없으면 제시하지 않는다. 광고 지표가 나빠도 무조건 기다리라고 지시하지 않는다. 예산·활성화 변경은 사용자의 승인 범위를 확인한다.

원저작자 참고: [social-media-skills/skills](https://github.com/social-media-skills/skills), MIT. 이 파일의 과거 플레이북 수치와 현재 공식 플랫폼 규격은 구분한다. 오픈소스 크레딧은 사이트의 open-source 페이지에 기록돼 있다.
