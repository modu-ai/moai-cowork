# 채널별 콘텐츠 작성

이 파일은 참고 가이드이며 특정 Claude 모델이나 하위 에이전트의 실행을 요구하지 않는다.

1. 대상 독자, 채널, 목적과 사용자 자료를 확인한다.
2. 최신 이슈·밈·제품 정보는 현재 출처를 확인한 경우에만 반영한다.
3. 게시물의 주장·사진·인용·링크가 원본 자료와 맞는지 확인한다.
4. 채널의 실제 글자·파일 제한과 게시 권한을 확인한다.
5. 원고, 이미지·영상 파일, 초안 저장, 예약, 공개 게시를 구분해 결과를 기록한다.

광고성 내용은 표시광고 및 메시지 발송 규칙을 추가 검토한다. 한국어라고 해서 같은 감정·관계 중심 카피를 모든 독자에게 강제하지 않는다.
