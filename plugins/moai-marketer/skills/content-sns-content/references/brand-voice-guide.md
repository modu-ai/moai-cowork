# SNS 브랜드 말투

기존 게시물, 브랜드 가이드와 사용자가 선호하는 문장을 먼저 읽는다. 반말·존댓말, 전문 용어, 이모지, 고객 호칭, 피해야 할 말을 정리한다. 독자 조사 자료가 없으면 독자의 감정이나 구매 동기를 확인된 사실로 쓰지 않는다.

| 항목 | 기록 |
|---|---|
| 기본 말투 | 사용자 자료의 실제 예문 |
| 채널별 조정 | 격식·문장 길이·질문 사용의 이유 |
| 고정 표기 | 브랜드명·제품명·법적 문구 |
| 사용하지 않을 표현 | 사용자 지정 금지어와 근거 없는 약속 |

한 채널의 문구를 다른 채널에 옮길 때 사실과 약속은 유지하고 형식만 조정한다. 사용자의 예문이 없다면 제안 말투를 초안으로 표시한다.
