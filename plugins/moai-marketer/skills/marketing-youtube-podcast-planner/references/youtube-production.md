# 유튜브 영상 제작 기획

## 전략

시청자의 질문, 채널 목적, 제작 가능한 형식과 자료를 확인한다. 경쟁 영상은 실제 검색 결과와 게시 시점·조회수를 기록한 경우만 비교한다. 조회수·검색량을 보지 않고 인기 주제라고 단정하지 않는다.

## 대본

제목과 썸네일이 약속한 내용을 영상 초반과 본문에서 실제로 다룬다. 도입, 설명·시연, 정리와 다음 행동을 정보량에 맞게 구성한다. 시각 자료·화면 녹화·자막이 필요한 곳은 제작 지시로 적는다. 첫 장면의 길이, 영상의 총길이, 고정 업로드 횟수를 알고리즘 보장 조건으로 쓰지 않는다.

## 제목·설명·자막

제목·설명은 실제 영상 내용과 출처를 반영한다. 태그·해시태그·키워드의 고정 수량이나 순서를 순위 공식으로 제시하지 않는다. [YouTube 챕터 안내](https://support.google.com/youtube/answer/9884579?hl=en)의 현재 조건에 맞추려면 완성 영상에서 시간을 확인한 뒤 설명란에 시작 시각과 제목을 넣는다. [YouTube 자막 안내](https://support.google.com/youtube/answer/4792576?hl=en)에 따라 언어와 자막을 검토한다. 대본만으로 정확한 SRT 타임코드를 만들었다고 주장하지 않는다.

## 썸네일

영상의 핵심 장면과 시청자가 얻는 정보를 시각화한다. 권리가 있는 원본 이미지나 사용자가 승인한 생성 이미지로 방향을 정한다. ChatGPT에서 이미지를 요청하면 기본 이미지 생성 경로를 검토하고, 사용자가 Higgsfield를 지정하면 해당 공식 연결의 실제 사용 가능 여부를 확인한다. 이미지가 생성되지 않았으면 컨셉과 프롬프트만 전달한다. 과장된 수치나 영상에 없는 장면을 썸네일에 넣지 않는다.

## 검수와 상태

대본의 주장·인용·이미지 권리, 제목·썸네일·본문의 일치, 실제 영상 파일의 길이·오디오·자막을 확인한다. 파일이 없으면 제작 계획과 게시 초안으로 표시한다. YouTube Studio의 업로드·검토·공개 상태는 계정에서 확인할 때만 보고한다. 분담 기능이 없어도 전략 → 대본 → 자산 → 메타데이터 → 검수 순서로 진행할 수 있다.
