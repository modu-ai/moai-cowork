# 책·전자책 기획 보조

사용자가 책 출판까지 요청한 경우에만 적용한다. 이 스킬의 기본 범위는 영상·팟캐스트 기획이며, 원고 전체 편집이나 실제 유통은 별도 작업이다.

## 입력

원고 유무, 장르와 독자, 저자명·권리 관계, 출판 방식, 목표 유통처, 기존 표지·계약·ISBN 상태를 확인한다. 원고가 없으면 목차와 장별 개요만 기획한다. ISBN과 유통 규격은 선택한 국가·플랫폼의 최신 공식 안내를 확인하고, 발급·등록된 것처럼 쓰지 않는다.

## 순서

1. 원고의 구조와 중복, 출처·인용 권리를 점검한다.
2. 장별 흐름을 편집하고 변경 이력을 남긴다. 사실·수치는 원출처를 대조한다.
3. 표지의 콘셉트, 제목·부제·저자 표기를 확정한다. 표지 이미지 요청 시 ChatGPT 기본 이미지 생성 또는 사용자가 지정한 Higgsfield 경로를 실제 사용 가능 여부에 따라 고른다. 결과 이미지가 없으면 텍스트 콘셉트로 표시한다.
4. 책 소개·분류·키워드·가격은 선택한 유통처의 현재 입력 항목과 저자의 확정 정보를 기준으로 정한다.
5. 원고·표지·메타데이터 사이의 제목, 저자, 판권, 인용을 대조한다. 출판 준비와 유통 완료를 구분한다.

작업을 나눌 수 있는 환경이면 편집·표지·메타데이터를 분담할 수 있다. 에이전트 기능이 없는 데스크톱 환경에서도 같은 순서로 진행한다. 검수 오류가 남으면 오류와 미완료 상태를 보고한다.

## 산출물

목차 또는 편집 원고, 교정 사항, 표지 콘셉트 또는 실제 이미지, 메타데이터 초안, 권리·규격 확인 목록을 요청 범위만큼 낸다. 파일이 생성되면 다시 열어 내용을 확인한다. 외부 유통 계정의 등록·판매 상태는 계정 화면이나 공식 확인 자료가 있어야 주장한다.
