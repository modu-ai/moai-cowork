# 유튜브·팟캐스트 기획

주제, 청중, 제작 여건에 맞춰 영상 또는 오디오 콘텐츠를 설계한다. 영상 제작은 `moai-media`의 해당 기능, 출판 원고 작업은 요청 범위에 따라 관련 문서 스킬로 연결한다.

## 시작할 때

- 목적과 청중, 기존 채널·에피소드, 공개 가능한 자료를 확인한다.
- 제작 가능한 인력·장비·예산·발행 빈도를 확인한다. 고정 업로드 횟수나 영상 길이를 알고리즘 필수 조건으로 제시하지 않는다.
- 배포 플랫폼, 저작권·초상권·게스트 동의, 광고·협찬 표기 필요 여부를 확인한다.
- 조사와 촬영·녹음, 편집, 게시를 각각 현재 상태로 기록한다.

## 유튜브

`references/youtube-production.md`를 읽고 주제·시청자 질문·영상 형식·대본 구조·시각 자료·제목과 설명 초안을 만든다. 경쟁 영상의 조회수와 게시 시점은 직접 관찰한 경우만 쓴다. 도입·본문·정리의 길이는 정보량과 형식에 맞게 정한다.

제목·썸네일은 영상이 실제로 제공하는 내용을 약속하게 한다. 챕터 타임코드는 완성 영상에서 확인한다. [YouTube 챕터 안내](https://support.google.com/youtube/answer/9884579?hl=en)에 따라 첫 타임스탬프, 순서, 구간 길이 등 현재 조건을 확인한다. 대본만으로 정확한 자막 SRT나 챕터 시각을 완성했다고 표시하지 않는다.

실제 썸네일 이미지를 원하면 사용 중인 ChatGPT에서는 기본 이미지 생성 경로를 우선한다. 사용자가 Higgsfield를 지정하거나 영상 제작에 그 도구가 적합하면 해당 공식 연결을 사용한다. 제작 경로·접근 권한·생성 결과를 관찰하기 전에는 이미지를 만들었다고 적지 않는다.

## 팟캐스트

`references/podcast-studio.md`를 읽고 솔로·인터뷰·토론 중 적합한 형식, 질문, 진행 순서, 녹음 준비, 쇼노트 초안을 만든다. 게스트 정보와 인용·음원 사용 허가를 확인한다. 실제 녹음이 없으면 쇼노트 시간표와 인용문을 확정하지 않는다.

RSS가 있더라도 모든 플랫폼에 자동으로 배포된다고 가정하지 않는다. 예를 들어 [Spotify for Creators RSS 안내](https://support.spotify.com/dm/creators/article/your-rss-feed/)는 다른 플랫폼 제출을 별도로 하도록 설명한다. 호스팅·RSS 공개·플랫폼 등록·게시 상태를 각각 확인한다.

## 출판 보조

책 또는 전자책 기획을 함께 요청한 경우에만 `references/book-publishing.md`를 읽는다. 제목·목차·표지 컨셉·메타데이터 초안을 만들 수 있으나, ISBN·출판 계약·판매 계정·유통 완료는 실제 증거가 있을 때만 기록한다.

## 산출물과 검수

요청 범위에 맞는 기획서, 대본 개요, 쇼노트 초안, 제목·설명·썸네일 방향, 조사 출처, 제작·배포 확인 목록을 낸다. 사실·통계·인용의 원출처와 이용 허가를 대조한다. 서술형 대본·쇼노트는 `moai-coworker:ai-slop-reviewer` → `moai-writer:korean-humanize`로 다듬은 뒤 사실을 다시 확인한다. 영상 길이·자막·타임코드·이미지 등 비문장 결과는 실제 파일로 검증한다.

배포 플랫폼의 규격과 계정 상태는 게시 직전에 공식 안내와 계정 화면에서 확인한다. 사용자가 게시를 요청해 승인한 경우에도 업로드와 공개 상태를 각각 관찰한다.
