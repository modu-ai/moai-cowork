# 광고 캠페인 카피 협업

캠페인 전체 기획을 사용자가 요청했을 때만 사용한다. 목표, 고객군, 예산, 기간, 판매 조건, 기존 성과 자료를 확인한다. 자료가 없는데도 경쟁사 동향이나 채널 성과를 조사한 것처럼 쓰지 않는다.

| 순서 | 확인할 것 | 산출물 |
|---|---|---|
| 목표 | 인지·문의·구매 등 실제 전환 목표와 측정 방법 | 측정 가능한 목표 |
| 고객 | 사용자 조사·고객 인터뷰·기존 성과 등 실제 근거 | 메시지 가설 |
| 카피 | 제품 사실·가격·제약·브랜드 문체 | 채널별 문구 후보 |
| 시각 | 브랜드 자료·사용 허가된 이미지 | 크리에이티브 지시 또는 실제 제작 파일 |
| 집행 | 현재 계정 정책·예산·추적 설정 | 예산·일정안 |
| 검수 | 주장 근거·랜딩 화면·예산 계산 | 발견 사항과 미확인 항목 |

이미지를 생성할 때 ChatGPT 기본 경로와 명시적 Higgsfield 경로를 구분한다. 생성·편집·광고 계정 변경·게시 상태도 각각 구분한다. 웹 검색이 실패하면 시장 사실을 일반 지식으로 채우지 않고 조사 범위와 미확인을 적는다. 외부 게시와 광고 계정 변경은 사용자의 승인 범위를 확인한다.
