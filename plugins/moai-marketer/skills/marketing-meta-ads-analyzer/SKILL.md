# Meta 광고 성과 분석

보고서 파일 또는 현재 연결에서 실제로 조회한 광고 데이터를 분석합니다. 이 스킬 폴더에는 자동 분석 실행 코드가 없으므로 자료를 읽고 필요한 계산과 검증을 수행한 범위만 보고합니다. 광고를 만들거나 바꾸는 요청은 marketing-meta-ads-manager로 연결합니다.

방법론 참고: [AgriciDaniel/claude-ads](https://github.com/AgriciDaniel/claude-ads) (MIT, 저장소 루트 NOTICE §1.3). 원본 프로젝트의 검사 개수·점수·도구 실행을 이 스킬이 수행한 것으로 간주하지 않습니다.

## 자료와 권한

- 사용자가 제공한 XLSX·CSV 등 보고서 파일의 실제 시트, 헤더, 행, 기간, 통화와 시간대를 확인합니다.
- Meta 공식 MCP가 연결된 경우에는 이 세션에서 발견한 읽기 도구와 계정 권한으로 조회합니다. 연결이 없으면 파일 분석만 합니다.
- 캠페인 목표, 주요 전환 행동, 기여 설정과 비교하려는 기간을 확인합니다. 해석에 필요하지 않은 상품 분류·운영 철학 설문은 강제하지 않습니다.
- 여러 광고 계정 또는 클라이언트가 섞인 자료는 계정별로 분리합니다.

## 집계 규칙

1. 원본 행의 단위를 파악합니다. 광고·광고세트·캠페인 합계와 지면·연령 등 분해 행을 중복 합산하지 않습니다.
2. 비용·노출·클릭·전환 가치 등 더할 수 있는 원시 수치를 같은 단위·기간 안에서 합산합니다.
3. CTR은 총 링크 클릭 / 총 노출, CPC는 총 비용 / 총 링크 클릭, CPA는 총 비용 / 해당 전환 수, ROAS는 총 귀속 전환 가치 / 총 비용으로 다시 계산합니다. 분모가 없거나 0이면 계산 불가로 표시합니다.
4. 파일마다 클릭 종류·전환 이벤트·기여 기간·통화가 다른지 확인합니다. 다르면 같은 표에서 직접 비교하지 않거나 차이를 명시합니다.
5. 지면별 표와 연령·성별 표가 각각 따로 있으면 각 표의 주변 분포만 분석합니다. 동일한 광고·기간으로 맞춰도 지면×연령×성별 교차값은 복원할 수 없습니다. 같은 행에 필요한 차원이 함께 있는 원본이 있어야 교차 분석합니다.
6. 구매 0건은 관찰 결과입니다. 낮은 노출·짧은 기간·추적 오류 가능성을 확인하지 않고 누수나 중단 근거로 단정하지 않습니다.

## 분석과 권고

보고서 목표에 맞는 지표와 분해 차원만 선택합니다. 관찰된 수치, 해석 가설, 추가 확인, 가능한 조치를 분리합니다. 고정 ROAS 등급, 제품가의 배수로 정한 일예산, 주간 전환 수만으로 정한 학습 상태, 소재 이름으로 추정한 제작일은 사용하지 않습니다. 시나리오 수치는 실제 가정과 계산식이 있을 때만 예시로 제시하며 통계적 신뢰 구간이라고 부르지 않습니다.

광고 변경은 분석 결과로 자동 실행하지 않습니다. 계정·대상·예산·상태를 확인한 뒤 사용자가 요청한 범위에서 manager 스킬로 연결합니다.

## 결과물

요청한 형식의 요약 또는 보고서를 작성합니다. HTML·DOCX·PPTX가 필요하면 설치된 문서 제작 도구로 실제 생성·열기 검증을 수행합니다. 생성하지 않은 형식은 완료로 표시하지 않습니다. 기본 Markdown 보고서에는 자료 출처, 기간·단위, 계산식, 확인한 결과, 한계와 다음 확인 항목을 적습니다. 서술 검수 스킬이 설치돼 있으면 활용하고 숫자·의미를 원본과 대조합니다.
