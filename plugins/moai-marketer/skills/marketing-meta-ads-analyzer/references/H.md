# 부록 H — 데이터 정합성

## 파일별 확인

1. 실제 시트·헤더·행 수, 기간, 시간대, 통화, 광고 계정과 캠페인 ID를 기록합니다.
2. 합계 행과 분해 행이 섞였는지 확인해 중복 집계를 피합니다.
3. 원시 비용·노출·클릭·전환·전환 가치의 빈칸·음수·문자형 값을 점검합니다. 이상값은 원본에 표시하고 임의로 지우지 않습니다.
4. 클릭 종류, 전환 행동, 기여 기간·모델이 같은지 확인합니다.
5. 연령·성별 등 분해가 일부 행에만 있을 경우 분해 범위를 별도로 표시합니다.

## 계산

- CTR = 총 링크 클릭 / 총 노출. 노출이 없으면 CTR 열과 클릭 종류가 정확히 대응하는지 확인하기 전에는 노출을 역산하지 않습니다.
- ROAS = 총 귀속 전환 가치 / 총 광고비. 플랫폼이 수치를 비율 또는 백분율로 표시하는지 확인합니다.
- CPC·CPA·ROAS 같은 비율은 원시 분자·분모 합계에서 다시 계산합니다. 비용 가중평균을 모든 비율에 일괄 적용하지 않습니다.
- 보고 시작·끝 날짜를 모두 포함하는 기간이라면 일수는 끝 날짜와 시작 날짜 차이에 1을 더합니다. 일평균 환산은 실제 월별 매출이 아닙니다.

## 여러 보고서

광고 이름만으로 다른 파일 행을 결합하지 않습니다. 안정적인 ID·기간·계정·집계 단위를 맞춰도 각기 다른 분해 표의 공동 분포는 알 수 없습니다. 합계 검산과 각 표의 단일 차원 분석만 수행합니다.

## 연결 도구

Meta MCP 읽기 도구가 현재 호스트에 설치·인증됐는지 확인합니다. 없으면 업로드된 파일만 분석합니다. 원본 claude-ads의 50개 검사, 점수 체계나 EMQ 기준을 실제 도구 실행 없이 수행했다고 표시하지 않습니다.
