# 부록 B — 보고서 필드와 집계 단위

## 필요한 필드

| 목적 | 필요한 원본 값 | 없을 때 |
|---|---|
| 기간과 대상 식별 | 보고 시작·종료, 광고 계정·캠페인·광고 ID | 기간·대상 확인 요청 |
| 지출 | 비용, 통화 | 비용 분석 제외 |
| 노출과 클릭 | 노출수, 클릭 종류가 명시된 클릭수 | 해당 비율 계산 제외 |
| 전환 | 전환 행동 이름, 건수, 기여 설정 | 전환 분석 제외 |
| 전환 가치 | 금액·통화와 반환·환불 처리 | ROAS 계산 제외 |
| 분해 | 지면·연령·성별 등 실제 행에 있는 차원 | 없는 차원 제외 |

헤더의 한국어·영어 표현은 내보내기 설정에 따라 달라질 수 있습니다. 부분 문자열만으로 필드를 확정하지 말고 원본 예시 행과 플랫폼 정의를 확인합니다. CTR·CPC·ROAS 열은 검산 자료이며, 집계할 때는 가능한 한 원시 분자·분모에서 다시 계산합니다.

## 교차 분석의 경계

지면 보고서와 연령·성별 보고서가 별개면 같은 광고 ID와 기간으로 매칭해도 합계 수준의 일치만 확인할 수 있습니다. 지면×연령×성별 교차값은 원본 행에 그 차원이 함께 있을 때만 계산합니다. 주변 분포를 결합해 고객군 성과를 만들어 내지 않습니다.
