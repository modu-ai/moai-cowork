# 부록 F — 권고안 작성

| 구분 | 작성 내용 |
|---|---|
| 확인된 관찰 | 기간·계정·지표·분모·출처 |
| 가능한 설명 | 여러 가설과 각 가설에 필요한 확인 자료 |
| 선택지 | 유지·작은 변경·중단 등 실제 가능한 조치 |
| 영향과 위험 | 지출, 도달, 학습, 측정의 변화 가능성 |
| 판정 방법 | 변경 전 기준과 사후 비교 지표 |

모든 발견에 세 가지 선택지를 기계적으로 붙이지 않습니다. 구매 0건이나 낮은 ROAS만으로 지면을 즉시 중단하라고 하지 않습니다. 예상 절감액은 실제로 제거할 비용 범위가 정해진 경우에만 계산하며, 매출 증가로 둔갑시키지 않습니다. 계정 변경은 별도 요청과 실제 권한을 확인한 후 marketing-meta-ads-manager로 전달합니다.
