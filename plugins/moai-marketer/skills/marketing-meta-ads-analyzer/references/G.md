# 부록 G — 결과물 형식

기본 결과는 Markdown으로 작성합니다. 사용자가 요청한 경우 실제 문서 제작 도구로 HTML·DOCX·PPTX를 만들 수 있습니다. 파일이 생성됐으면 열어 표·숫자·한글·차트·링크가 보이는지 확인합니다. 실제 파일을 만들지 않았으면 해당 형식 완료로 표시하지 않습니다.

## 내용

- 분석 대상 계정·기간·통화·전환 정의와 자료 출처
- 핵심 관찰 표와 계산식
- 해석 가설과 필요한 추가 확인
- 가능한 조치와 실행 전 확인 항목
- 데이터 한계·미검증 항목

차트는 실제 자료가 있을 때만 사용하고 원시 수치와 축·단위를 함께 보여줍니다. 특정 React·CDN·차트 라이브러리·슬라이드 수·팔레트를 모든 보고서에 강제하지 않습니다. 기존 브랜드나 문서 디자인 시스템이 있으면 따릅니다. 온라인 문서에 결과를 게시할 때는 해당 사이트의 아이콘·색 규칙을 따릅니다.
