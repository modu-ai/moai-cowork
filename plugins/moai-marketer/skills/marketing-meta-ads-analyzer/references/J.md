# 부록 J — 인접 작업 연결

| 요청 | 연결 |
|---|---|
| 실제 광고 생성·중지·예산 변경 | marketing-meta-ads-manager |
| 전환 추적 설치·픽셀·CAPI 점검 | marketing-pixel-audit |
| 광고 클릭 후 랜딩 화면 진단 | marketing-landing-page-conversion-audit |
| 새 캠페인 목표·채널·예산 기획 | marketing-campaign-planner |
| 확인된 상품 조건을 바탕으로 광고 문안 작성 | content-copywriting |

가상의 meta-ads-creative-generator, meta-ads-budget-planner, meta-ads-curriculum-builder는 배포된 스킬로 안내하지 않습니다. 실시간 계정 분석은 Meta MCP가 실제 연결되고 읽기 도구가 발견된 경우에만 수행합니다. 분석 결과만으로 계정에 변경을 가하지 않습니다.
