# 부록 C — 상품과 캠페인 맥락

성과 해석에 실제로 필요한 정보만 확인합니다.

- 캠페인 목표와 최적화 전환 행동: 구매, 리드, 방문, 도달 등
- 상품 가격·마진·환불·재구매 정보: 사업자가 제공한 자료가 있을 때만
- 운영 기간과 변경 기록: 소재·예산·타게팅·추적 설정이 언제 바뀌었는지
- 광고 계정의 기여 설정과 판매 시스템의 매출 집계 방식

상품군이나 가격만으로 저·중·고관여도를 자동 판정하지 않습니다. 식품·교육·B2B에 고정 ROAS 합격선을 적용하지 않습니다. 구매 캠페인이 아닌데 구매 ROAS로 실패를 판정하지 않습니다. 사업자가 손익분기 계산을 원하면 실제 마진·고객 획득비·반품 조건을 받아 계산합니다.
