# 부록 D — 자료가 있을 때 가능한 분석

아래 항목은 자동 실행 모듈이 아닙니다. 실제 자료와 요청에 맞는 것만 계산합니다.

## 기본 지표

- 비용·노출·링크 클릭·전환 건수·전환 가치: 같은 범위의 원시 값을 합산합니다.
- 링크 CTR = 링크 클릭 / 노출, CPC = 비용 / 링크 클릭, CPA = 비용 / 지정 전환 건수, ROAS = 귀속 전환 가치 / 비용.
- 전환 가치와 구매 주문 금액은 다를 수 있습니다. 실제 주문 매출·환불 자료 없이 AOV나 이익을 확정하지 않습니다.
- 0으로 나누는 경우는 0이 아니라 계산 불가로 표시합니다.

## 분해

지면·플랫폼·광고·연령·성별 차원이 실제 행에 있고 합산 가능한 경우에만 분해합니다. 교차 표는 같은 행에 모든 축이 있어야 합니다. 작은 셀의 수치를 과대 해석하지 말고 노출·비용·전환 건수도 같이 표시합니다. 광고 이름 문자열만으로 메시지 컨셉·제작일·소재 피로도를 확정하지 않습니다.

## 변화와 선택

기간 비교는 기간 길이, 전환 지연, 계절성, 추적 설정·예산 변경을 함께 봅니다. 구매 0 지출은 관찰 신호로 보고 추적 오류와 표본 크기를 확인합니다. ROAS 하락만으로 소재 노후화나 알고리즘 문제를 확정하지 않습니다. 예산 적정성은 제품 가격의 고정 배수가 아니라 실제 목표·마진·전환 지연·계정 설정을 기준으로 검토합니다.

시나리오를 요청받아 실제 가정을 놓고 계산할 수는 있습니다. 낙관·중간·비관 값을 임의 분위수나 신뢰 구간으로 포장하지 않습니다.
