# 랜딩 브랜드·상품 정보

아래 항목 중 확인 가능한 것을 수집합니다. 없는 칸을 그럴듯한 값으로 채우지 않습니다.

| 항목 | 확인할 자료 |
|---|---|
| 브랜드 이름·로고·색·서체 | 기존 가이드 또는 사이트 |
| 상품·서비스와 고객 문제 | 제품 자료·사용자 제공 설명 |
| 대상 고객과 사용 맥락 | 인터뷰·상담·기존 분석 또는 가설 표시 |
| 가격·할인·기간·반품·배송 | 현재 판매 조건 |
| 후기·평점·인증·효과 주장 | 실제 출처와 사용권 |
| 페이지의 목표 행동 | 신청·구매·문의 등 |
| 기존 사이트·디자인 시스템 | URL 또는 저장소 경로 |
| 이미지 자산과 사용권 | 원본 파일·라이선스 |

브랜드 자료가 없으면 시각 방향을 임시안으로 제시하고 확정 사실로 표시하지 않습니다. 경쟁사 페이지는 참고 대상일 뿐 그대로 복제하지 않습니다.
