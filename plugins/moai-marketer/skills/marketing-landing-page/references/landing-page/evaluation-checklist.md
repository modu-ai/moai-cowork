# 랜딩 제작 검수

| 항목 | 증거 | 결과 |
|---|---|---|
| 상품·가격·혜택·후기·보증 문구가 원본 자료와 일치 | 원본과 화면 대조 | 확인/수정/미검증 |
| 광고와 랜딩의 약속·조건이 일치 | 광고와 도착 화면 | 확인/수정/미검증 |
| 모바일·데스크톱의 주요 행동이 읽히고 작동 | 실제 화면과 클릭 기록 | 확인/수정/미검증 |
| 링크·폼·결제 또는 신청 흐름이 작동 | 테스트 결과 | 확인/수정/미검증 |
| 색 대비·키보드·대체 텍스트·폼 오류 안내 | 실제 검사 결과 | 확인/수정/미검증 |
| 이미지·로고·폰트의 권리와 성능 | 출처·측정 결과 | 확인/수정/미검증 |

실행하지 않은 항목은 미검증으로 둡니다. 근거 없는 가중 점수나 배포 가능 등급을 계산하지 않습니다. Lighthouse나 성능 지표는 실행한 명령·대상·출력을 남긴 경우에만 보고합니다.
