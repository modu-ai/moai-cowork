# 랜딩 카피 점검

## 사실과 조건

- 숫자, 후기, 수상, 고객 수, 가격, 할인, 무료 체험, 환불 보장, 성능 비교는 실제 근거가 있을 때만 씁니다.
- 모호한 표현을 고칠 때 새 수치를 만들어 넣지 않습니다. 검증 가능한 기능·과정·대상 고객을 구체적으로 설명합니다.
- 광고 문구와 페이지의 핵심 약속·조건을 맞춥니다. 같은 단어를 반복할 필요는 없습니다.
- 의료·금융·법률 등 규제 주장은 해당 분야 근거와 현재 표시 규정을 별도로 확인합니다.

## 읽기 쉬운 문장

고객이 얻을 수 있는 것과 다음 행동을 분명히 쓰고, 브랜드 말투를 따릅니다. 고정 단어 수나 모든 페이지에 동일한 후기·FAQ·보증 섹션을 강제하지 않습니다. 버튼 문구는 누르면 실제로 일어나는 행동을 나타냅니다.

## 최종 대조

원고·화면·폼·가격 정보를 원본 자료와 비교합니다. 디자인 과정에서 문구를 바꿨으면 원고와 화면의 승인 버전을 함께 갱신합니다.
