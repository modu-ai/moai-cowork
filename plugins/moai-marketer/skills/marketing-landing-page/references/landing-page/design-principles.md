# 랜딩 화면 디자인 원칙

## 기준 자료

브랜드 디자인 시스템과 기존 사이트가 있으면 이를 먼저 따릅니다. 새 시각 언어가 필요한 경우 색·타이포·여백·반경·이미지 사용 방식을 간단한 표로 정리합니다. 고정 팔레트나 특정 분위기를 보편 규칙으로 강제하지 않습니다.

## 내용과 위계

- 첫 화면에서 상품·서비스가 무엇이고 누가 어떤 행동을 할 수 있는지 이해되게 합니다.
- 가격·혜택·제약·신청 조건은 읽기 쉬운 위치에 둡니다.
- 실제 증거가 있는 경우에만 후기·평점·로고를 사용합니다.
- 차트와 애니메이션은 실제 데이터와 사용 목적이 있을 때만 추가합니다. 움직임 감소 설정을 존중합니다.

## 구현 시 확인

텍스트 대비, 키보드 순서, 폼 라벨·오류 설명, 이미지 대체 텍스트, 다양한 화면 폭에서의 잘림을 확인합니다. 자동 검사 수치만으로 접근성 전체를 통과했다고 하지 않습니다. 배경과 글자색은 함께 정해 대비를 검사합니다.

## 스택

HTML, 기존 프레임워크, shadcn/ui 등 사용자가 선택한 구현 방식에 맞춰 토큰을 정의합니다. shadcn/ui의 현재 테마 변수는 [공식 문서](https://ui.shadcn.com/docs/theming)를 확인합니다. Tailwind CSS v4에서는 [공식 테마 변수 문서](https://tailwindcss.com/docs/theme)를 참고합니다. 한 파일 구조나 고정 YAML 계약을 필수로 만들지 않습니다.
