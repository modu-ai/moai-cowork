# shadcn/ui 선택 시 테마 확인

이 문서는 새 페이지에 shadcn/ui를 쓰기로 결정했을 때만 참고합니다. 기존 브랜드·프로젝트가 있으면 그 설정을 우선합니다. 질문 도구 이름이나 특정 호스트의 호출 형식을 필수로 두지 않습니다.

## 확인할 항목

1. 브랜드 색과 밝은·어두운 화면 요구사항이 이미 있는가?
2. 기존 화면의 서체·반경·아이콘·버튼 규칙을 이어받아야 하는가?
3. 새 테마가 필요하다면 원하는 분위기와 피해야 할 표현은 무엇인가?
4. 실제 데이터 시각화나 움직임이 필요한가? 필요하지 않으면 차트·모션 라이브러리를 추가하지 않습니다.

사용자가 이미 답했거나 빠른 초안을 원하면 반복해서 묻지 않습니다. 가정한 시각 방향은 임시안으로 표시합니다. macOS·Windows에서 같은 일반 대화 방식으로 확인할 수 있어야 합니다.

## 구현

[shadcn/ui 설치 안내](https://ui.shadcn.com/docs/installation)와 [테마 문서](https://ui.shadcn.com/docs/theming)를 확인하고 사용 중인 프로젝트 구조에 맞춥니다. components.json은 shadcn CLI를 쓸 때 필요하며, Tailwind CSS v4 프로젝트에서는 config 파일을 자동으로 필수 목록에 넣지 않습니다. 테마 토큰을 실제 CSS에 반영하고 사용한 색 조합의 대비를 검사합니다. 단일 HTML 요청에서는 shadcn/ui 설치를 강제하지 않습니다.

디자인 선택은 사용자 자료와 현재 구현에 맞춰 결정합니다. 고정 Neutral/System/효과 세트를 무조건 적용하지 않습니다.
