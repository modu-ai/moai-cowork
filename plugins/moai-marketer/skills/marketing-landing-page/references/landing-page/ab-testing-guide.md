# 랜딩 변경 실험 가이드

카피·이미지·폼 등 변경의 효과는 실제 방문자 데이터로 확인합니다. 모든 랜딩에 같은 실험 횟수, 클릭 수, 기간, 기대 상승률을 적용하지 않습니다.

## 설계

1. 현재 문제를 관찰 자료로 적고, 하나의 주요 지표와 안전 지표를 고릅니다.
2. 대조군과 변경안, 대상 방문자, 배정 단위를 정합니다.
3. 기존 기준선과 최소 검출 효과를 확인해 필요 표본과 분석 시점을 사전에 계산합니다. 자료가 없으면 추정 표본을 사실처럼 제시하지 않습니다.
4. 가격·조건·폼 항목을 바꾸는 실험은 법적·운영 조건과 고객 영향도 검토합니다.
5. 실제 실행 여부와 결과 수집 범위를 기록합니다. 유의성이나 승자를 미실행 상태에서 쓰지 않습니다.

참고: marketing-growth-experiment가 실험 설계 전반을 다룹니다.
