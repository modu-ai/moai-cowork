# 성장 실험

개별 실험의 가설·설계·측정에 집중합니다. 목표·채널·예산을 묶은 전체 캠페인은 marketing-campaign-planner를 사용합니다.

참고 방법론: [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) (MIT, 저장소 루트 NOTICE에 고지).

## 입력 확인

- 바꾸려는 고객 행동과 현재 관찰 자료, 주요 지표의 분모·집계 기간
- 실험 대상 수, 무작위 배정 가능 여부, 측정 도구와 접근 권한
- 실행 비용, 고객 연락 동의, 제휴·인센티브 조건
- 없는 수치와 확인되지 않은 인과관계는 가정으로 기록합니다.

## A/B 테스트

1. 관찰과 가설을 구분하고 대조군·실험군의 차이를 정의합니다.
2. 주요 지표 하나와 보조·안전 지표를 정합니다.
3. 기준선, 최소 검출 효과, 검정력과 유의수준, 배정 단위, 필요한 표본과 분석 시점을 사전에 정합니다. 입력이 없으면 표본 숫자를 임의로 제시하지 않습니다.
4. 중간 확인이나 여러 지표 비교가 필요하면 그에 맞는 분석 계획을 먼저 정합니다. 사전 계획 없이 수치를 반복 확인해 유리한 시점에 멈추지 않습니다.
5. 결과는 실제 집계 자료가 있을 때만 효과 크기와 불확실성을 함께 보고합니다. 통계적 유의성만으로 사업 효과를 단정하지 않습니다.

## 실험 백로그

ICE 또는 PIE는 후보를 비교하는 보조 도구입니다. 점수 기준과 각 점수의 관찰 근거를 함께 적고, 자료가 없으면 미확인으로 표시합니다. 높은 점수만으로 실행을 확정하지 않고 필요한 승인·자원·측정 가능성을 확인합니다.

## 성장 루프

- 추천: 실제 고객이 공유하는 계기, 초대 흐름, 보상 비용, 부정 사용 방지, 추적 가능한 전환을 설계합니다. 초대 수와 전환율이 없으면 바이럴 계수를 계산하지 않습니다.
- 무료 도구: 고객 문제와 도구의 가치, 유지비, 개인정보 수집 필요성, 제품으로 이어지는 경로를 확인합니다. 이메일 수집을 기본값으로 강제하지 않습니다.
- 공동 마케팅: 실제 파트너의 고객 적합성, 제작·배포 책임, 리드 소유와 공유 동의, 측정 방법을 합의할 항목으로 적습니다. 파트너십이 성립하기 전 성과를 약속하지 않습니다.

## 결과물

요청에 맞는 실험 설계표 또는 우선순위표를 먼저 제공합니다. 실제 실행과 결과 분석은 별도 상태로 표시합니다. 실험 횟수나 승률을 보편적 목표로 강제하지 않습니다. 서술을 다듬을 때 ai-slop-reviewer·korean-humanize가 설치돼 있으면 활용하고 원문과 대조합니다. 해당 스킬이 없으면 직접 사실·수치·의미를 검수합니다.

## 연결 스킬

- marketing-campaign-planner: 전체 캠페인 계획
- marketing-landing-page-conversion-audit: 랜딩 문제 진단
- marketing-performance-report: 실제 성과 보고
- content-email-sequence: 동의 상태를 확인한 후속 이메일 초안
