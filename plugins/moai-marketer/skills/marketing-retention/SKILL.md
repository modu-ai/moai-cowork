# 리텐션

고객의 상태 변화에 맞는 마케팅 메시지와 측정 계획을 만든다. 고객 유지 비용이나 윈백 성과가 언제나 신규 획득보다 낫다고 가정하지 않는다. 실제 캠페인 비용, 고객 가치, 실험 결과를 비교한다.

참고 원본: github.com/coreyhaines31/marketingskills (MIT — 전문 고지: 저장소 루트 `NOTICE`). churn-prevention 방법론을 이 스킬의 책임 범위에 맞게 재구성했다.

## 먼저 확인할 정보

- 제품과 계약 형태: 일회 구매, 무료 계정, 유료 구독 중 무엇인지.
- 이탈의 정의와 관측 기간: 해지, 결제 실패, 핵심 행동 중단, 미접속을 구분한다.
- 고객별 상태와 데이터: 활동·계약·결제·지원 기록을 확인할 수 있는지, 기록의 누락과 지연은 없는지.
- 발송 자격: 채널별 수신 동의, 철회·수신거부, 제외 목록, 국가와 고객 유형, 이미 종료된 관계인지.
- 실제 가능한 조치: 할인·일시정지·지원·제품 변경 중 승인되고 제공 가능한 것만 쓴다.
- 목표와 기준 기간: 이탈률, 재활성화율, 취소 세이브율, 메시지 비용을 어떤 모집단에서 재는지.

정보가 없으면 빈칸을 남긴 설계안과 필요한 확인 항목을 제시한다. 업종 평균이나 임의의 할인율을 실측값처럼 채우지 않는다.

## 진단

### 이탈 유형과 신호

고객이 직접 해지한 경우와 결제 실패·카드 만료 등으로 중단된 경우를 분리한다. 실제 비중은 해당 서비스의 기록에서 계산한다. 결제 재시도 로직과 던닝 운영은 구독 운영 담당자에게 넘기고, 이 스킬은 승인된 안내 문구를 돕는다.

방문·핵심 행동·지원 문의·해지 화면 진입 같은 후보 신호를 고객 상태와 비교한다. 예를 들어 방문 감소가 휴가나 계절성 때문일 수도 있다. 신호의 관측 기간과 기준선은 코호트별 데이터로 정하고, 실제 이탈을 얼마나 앞서 예측하는지 검증한다. 특정 감소율이나 몇 주 전이라는 수치를 보편 기준으로 쓰지 않는다.

헬스 스코어가 필요하면 입력 지표, 결측 처리, 가중치, 경계값, 갱신 주기를 명시한다. 과거 자료에서 이탈과의 관계를 확인한 뒤 구간을 정한다. 검증 전 점수는 우선순위 가설이며 고객의 확정 진단이 아니다.

### 코호트와 지표

| 지표 | 계산에 앞서 정할 것 |
|---|---|
| 기간 이탈률 | 기간 시작 고객 중 이탈한 고객 / 기간 시작 고객. 신규 가입·재가입 처리와 이탈 정의를 명시 |
| 고객 잔존율 | 코호트 시작 고객 중 해당 기간에도 기준 행동 또는 계약을 유지한 고객 / 코호트 시작 고객 |
| 총매출 이탈률 | 기간 시작 반복 매출 대비 해지·축소로 잃은 매출. 확장 매출을 빼는 순매출 이탈률과 구분 |
| 취소 세이브율 | 세이브 오퍼를 본 취소 시도 중 정해진 관찰 기간에 해지하지 않은 고객 / 해당 취소 시도. 중복 시도 처리와 이후 재해지를 추적 |
| 재활성화율 | 적격 발송 대상 중 정의한 행동을 다시 한 고객 / 적격 발송 대상. 발송·도달·클릭을 재활성화와 혼동하지 않음 |

획득 경로·가입 시기·요금제·활동 수준·이탈 사유별로 보되, 작은 표본과 관측 기간 차이를 밝힌다. 목표값은 기존 코호트 기준선과 캠페인 실험을 통해 정한다. 그래프 모양만으로 제품 적합성이나 원인을 단정하지 않는다.

## 개입 설계

### 취소 화면

해지 경로와 결과를 분명하게 보여준다. 선택적 사유 질문 뒤에 실제 제공 가능한 지원·요금제 변경·일시정지·할인을 사유에 맞춰 제시할 수 있다. 제공 조건과 기간을 명시하고, 선택하지 않아도 해지를 마칠 수 있게 한다. 출시 예정 기능과 시점은 확인된 계획만 언급한다. 세이브 오퍼의 효과는 실험과 후속 재해지로 평가한다.

### 재참여와 윈백

재참여는 현재 고객의 활동이 줄어든 상태, 윈백은 정의된 이탈이 이미 일어난 상태다. 두 집단의 자격과 메시지를 분리한다. 트리거, 첫 발송 시점, 메시지 사이 간격, 종료 조건은 고객의 실제 이용 주기와 채널 반응으로 정한다. 일률적인 D+0/3/7/30/90 시퀀스를 기본값으로 강요하지 않는다.

메시지는 확인된 가치, 실제 제품 변화, 이용 가능한 지원과 혜택만 담는다. 고객 사례·성과·희소성·마감 시점은 근거와 공개 허가가 있어야 쓴다. 이미 재활성화하거나 거부한 고객에게 후속 마케팅 메시지가 계속 나가지 않도록 제외 조건을 둔다.

### 발송 전 확인

광고성 정보인지 거래·서비스 운영에 필요한 안내인지 목적과 내용을 기준으로 분류한다. 광고성 발송은 대상 채널과 관할 법령에 따라 사전 동의 또는 적용 가능한 예외, 전송자 표시, 광고 표시, 수신거부 방법, 야간 발송 제한, 철회 반영을 확인한다. 한국 발송은 [정보통신망법 제50조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025127785)와 [KISA 불법스팸 방지 안내서](https://spam.kisa.or.kr/spam/na/ntt/selectNttInfo.do?bbsId=1002&mi=1020&nttSn=3001)를 현재 버전으로 확인한다. 메시지 초안에 표시 문구를 넣었다는 사실만으로 발송 적격성을 주장하지 않는다.

계정·동의 기록에 접근할 수 없으면 발송 가능한 대상이라고 단정하지 않는다. 결과를 `초안`, `자격 확인 대기`, `발송 준비`, `발송 완료` 중 관측된 상태로 표기한다. 실제 전송은 승인된 도구와 권한을 확인한 뒤 진행한다.

## 작업 순서

1. 고객 상태, 이탈 정의, 코호트, 발송 자격과 제공 가능한 혜택을 확인한다.
2. 실제 데이터로 이탈 유형과 신호를 분석한다. 데이터가 없으면 측정 설계를 먼저 낸다.
3. 사전 개입, 취소 화면, 사후 윈백 중 개입 지점을 고른다. 대상·제외·종료 조건을 쓴다.
4. 시점별 메시지 목적과 제목·본문을 초안으로 작성한다. 광고성 발송 요건과 실제 혜택을 대조한다.
5. 지표의 분모·관찰 기간, 대조군, 비용, 부정 반응과 재해지를 포함한 평가 계획을 제시한다.

## 출력

- 진단 근거와 미확인 정보
- 고객 상태별 대상·제외 조건과 개입 지점
- 취소 화면 또는 재참여·윈백 메시지 초안
- 발송 자격 확인표와 현재 실행 상태
- 코호트·지표 정의, 기준선, 실험 및 후속 측정 계획
