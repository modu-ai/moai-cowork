# Ghost 발행 준비

Ghost는 자체 사이트, 게시물, 뉴스레터, 멤버십을 운영할 수 있다. [Ghost 공식 SEO 안내](https://ghost.org/help/seo/)는 메타데이터, 사이트맵, canonical 태그, 구조화 데이터 등 내장 기능을 설명한다. 실제 테마와 접근 제한 설정에 따라 검색 노출이 달라진다.

## 글과 발행 상태

1. 대상 사이트, 게시물 접근 수준(공개·회원·유료), 태그, 대표 이미지와 글의 출처를 확인한다.
2. 뉴스레터 발송 여부와 수신 대상은 게시와 별개의 결정으로 확인한다.
3. [게시물 설정 안내](https://ghost.org/help/post-settings/)에 따라 제목, URL, 메타데이터와 미리보기를 점검한다.
4. 현재 앱에 Ghost 공식 연결이 확인되지 않으면 원고와 발행 설정안을 전달한다. 발행했다고 보고하지 않는다.

요금과 플랜 기능은 [현재 Ghost 공식 요금표](https://ghost.org/pricing/)에서 확인한다. 오래된 가격을 고정해 안내하지 않는다. 결제 제공업체·지역별 지원도 현재 사이트 설정에서 확인한다.
