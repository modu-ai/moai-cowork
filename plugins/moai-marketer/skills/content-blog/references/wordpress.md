# WordPress 글과 MCP 발행

이 플러그인의 wordpress 커넥터는 [WordPress.com 공식 MCP](https://wordpress.com/support/mcp/)를 가리킨다. 일반 WordPress 설치에 자동으로 적용된다고 가정하지 않는다. WordPress.com 사이트 또는 공식 문서가 지원하는 Jetpack 연결 사이트인지, 현재 계정과 플랜에 MCP 접근이 가능한지 확인한다.

## 작성

- 독자의 질문에 맞춘 제목, 본문, 필요한 소제목과 실제 출처를 준비한다.
- 메타 설명과 대표 이미지는 사이트 편집 화면이 지원하는 범위에서 설정한다.
- 이미지 대체 텍스트는 이미지의 의미를 설명한다. 키워드를 기계적으로 넣지 않는다.
- 캐시·보안·SEO 플러그인을 무조건 설치하거나 특정 유료 플랜을 권하지 않는다. 현재 테마와 설치 플러그인, 필요 기능을 먼저 확인한다.
- 성능 검토가 필요하면 [Google Core Web Vitals의 LCP·INP·CLS](https://developers.google.com/search/docs/appearance/core-web-vitals)를 실제 사이트에서 측정한다.

## MCP 사용

대상 사이트를 확인한 뒤 연결된 도구의 실제 스키마로 초안을 저장한다. [WordPress.com MCP 도구 문서](https://developer.wordpress.com/docs/mcp/tools-reference/)에 따르면 게시물 생성은 기본적으로 초안이며 publish 상태 지정은 즉시 공개될 수 있다. 공개 요청의 대상·내용·승인 범위를 확인하고 실행 후 공개 URL과 상태를 확인한다. MCP 연결이 없으면 복사 가능한 원고를 준다.
