# 브런치스토리 글 작성

브런치스토리용 원고는 작성자의 관점과 실제 경험을 중심으로 구성한다. 독자, 주제, 공개 가능한 사례, 사용자가 원하는 문체를 먼저 확인한다. 에세이라면 장면과 생각의 흐름을 살리고, 정보성 글이라면 사실과 해석을 분리한다.

## 원고 확인

- 본인 경험과 타인 이야기를 구분하고, 타인의 신원이나 사생활을 노출하지 않는다.
- 실제로 겪지 않은 사건·직장 경력·독자 반응을 만들어 넣지 않는다.
- 제목이 본문을 과장하지 않는지 확인한다.
- 이미지·인용문 사용 권리를 확인한다.
- 현재 계정의 작가 신청·발행 권한과 편집 화면을 확인한다. 심사 기간, 선정 기준, 추천 노출, 권장 글자 수를 고정 규칙으로 제시하지 않는다.

발행 기능을 직접 확인하지 않았다면 원고와 이미지 설명을 전달한다.
