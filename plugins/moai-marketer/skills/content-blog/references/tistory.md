# 티스토리 글 작성

티스토리 글은 독자가 찾는 정보와 실제 경험에 맞춰 작성한다. 사이트 설정을 변경하거나 광고를 배치하기 전에 사용자의 블로그 스킨, 연결된 검색 도구, 광고 계정 상태를 확인한다.

## 발행 전

- 제목·본문·카테고리·대표 이미지가 일치하는지 확인한다.
- 확인한 사실과 출처를 밝히고, 이미지 대체 텍스트는 이미지 내용을 설명한다.
- 검색 노출을 원하는 경우 현재 블로그의 검색 허용·사이트맵·검색 콘솔 연결 상태를 확인한다. 계정에서 제어할 수 없는 설정은 필수 단계로 강요하지 않는다.
- 애드센스 광고 위치나 발행 시간에 따른 수익 상승을 근거 없이 약속하지 않는다. 광고 게재는 현재 정책과 실제 성과 자료를 확인한 뒤 결정한다.

[Google의 유용한 콘텐츠 안내](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)를 기준으로, 기계적인 글자 수·키워드 비율·이미지 장수보다 독자가 얻는 정보를 검수한다. 게시 기능이 연결되지 않았으면 발행 가능한 초안을 준다.
