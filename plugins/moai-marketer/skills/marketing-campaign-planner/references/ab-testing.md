# A/B 테스트 설계

## 먼저 확인할 것

- 검증할 행동 변화와 주요 지표를 하나씩 정의합니다. 지표의 분모·집계 기간·데이터 출처를 적습니다.
- 현재 전환율이나 평균값, 최소 검출 효과, 실험 단위, 사용 가능한 표본을 확인합니다.
- 노출 대상·제외 대상, 무작위 배정 방식, 동시에 진행하는 실험을 기록합니다.

## 설계와 판정

1. 가설과 대조군·실험군의 차이를 한 가지로 정합니다.
2. 기준선과 최소 검출 효과를 바탕으로 필요한 표본을 계산합니다. 입력값이 없으면 숫자를 꾸며 내지 않고 수집 계획을 제시합니다.
3. 분석 방법, 중지 시점, 여러 지표나 반복 확인의 처리 방식을 사전에 정합니다.
4. 결과에는 집계 기간·표본 수·효과 추정치·불확실성과 한계를 함께 적습니다.
5. 통계적으로 뚜렷하지 않은 결과를 효과가 없다는 증거로 단정하지 않습니다.

## 산출물

하나의 실험 설계표와 판정 기록을 기본으로 제공합니다. 실제 실험이 실행되지 않았다면 결과 분석을 작성하지 않습니다.
