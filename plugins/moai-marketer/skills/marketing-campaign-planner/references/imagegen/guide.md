# 캠페인 이미지 요청 가이드

이 문서는 캠페인 기획 중 필요한 이미지의 요구사항을 정리하는 참고자료입니다. 생성 도구와 모델은 현재 호스트의 실제 기능을 확인합니다. 과거 Nano Banana·Imagen 4 경로, 고정 생성 시간·수량·해상도는 적용하지 않습니다.

## 연결 경로

- ChatGPT Work의 일반 이미지는 현재 대화에 제공된 이미지 도구로 만듭니다. GPT Image 2.5를 정확히 지정했다면 모델을 확인하고, 확인되지 않으면 설치된 moai-media:media-codex-image의 별도 API 경로와 비용·승인 절차를 따릅니다.
- Higgsfield 지정 요청은 공식 연결의 실제 모델을 확인하고 설치된 경우 moai-media:media-higgsfield-image를 사용합니다.
- Claude Cowork에서는 설치된 이미지 도구와 인증 상태를 먼저 확인합니다. 연결되지 않았으면 프롬프트와 제작 사양을 제공하고 생성 완료라고 표시하지 않습니다.

## 요청에 담을 정보

- 사용처, 대상 고객, 피사체, 구도, 비율, 브랜드 색·서체, 필요한 문구와 금지 요소
- 제품·인물 사진 등 사용자 자산의 출처와 사용권
- 법적·의학적·기술적 정확성이 중요한 장면에 필요한 검증 자료
- 필요한 결과물 개수와 저장 형식은 사용자의 목적 및 도구가 지원하는 옵션으로 확정

## 결과 확인

1. 실제 생성된 이미지를 열어 피사체·브랜드·비율·잘림을 확인합니다.
2. 이미지 안의 한국어, 가격, 수치, 로고와 제품 사양을 원본 자료와 대조합니다. 틀리면 편집하거나 다시 생성합니다.
3. 상업 사용·초상·상표·원본 자산의 권리는 해당 도구 약관과 실제 소재의 권리 관계를 확인합니다. 생성되었다는 이유만으로 사용권을 보증하지 않습니다.
4. 생성·편집·검수·게시 상태를 따로 기록합니다.
