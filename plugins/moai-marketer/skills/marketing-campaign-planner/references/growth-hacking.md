# 성장 실험

## 준비

목표 행동, 현재 기준선, 데이터 접근 범위와 실험 가능한 채널을 확인합니다. 확보되지 않은 성과 수치나 바이럴 효과를 가정으로만 다룹니다.

## 진행

1. 관찰된 문제와 성장 가설을 구분해 기록합니다.
2. 예상 가치, 실행 비용, 검증 가능성을 근거로 실험 후보를 우선순위화합니다.
3. 대상·대조군·주요 지표·안전 지표·실행 기간·중지 기준을 정합니다.
4. 개인정보나 광고 집행이 걸린 실험은 실제 동의·계정 권한·승인 절차를 확인합니다.
5. 실험 전 계획과 실행 후 결과를 별도로 기록합니다. 미실행 상태에서 성과를 보고하지 않습니다.

## 산출물

성장 가설과 첫 실험 설계표를 기본으로 제공합니다. 추정 효과는 추정임을 표시하고 결과는 실제 데이터가 있을 때만 분석합니다.
