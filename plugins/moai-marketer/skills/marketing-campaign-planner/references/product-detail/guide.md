# 캠페인에서 상세페이지 연결하기

이 문서는 캠페인 메시지와 이커머스 상세페이지의 연결을 검토하는 참고자료입니다. 실제 카피·이미지·페이지 제작은 moai-seller의 상세페이지 스킬과 판매 채널의 현재 요구사항을 따릅니다.

## 캠페인 기획자가 확인할 것

- 광고에서 약속한 상품명·구성·가격·할인·배송·반품 조건이 실제 상세페이지와 일치하는가
- 랜딩 위치가 해당 캠페인의 목표와 맞고 모바일에서도 구매 경로가 작동하는가
- 상품 사진·후기·평점·재고·인증·효과 문구의 출처가 있는가
- 고객이 결제 전 알아야 할 조건이 숨겨지지 않았는가
- 전환 측정에 필요한 이벤트와 동의 범위가 확인되었는가

## 산출물 경계

캠페인 단계에서는 광고 문구와 상세페이지의 일치 점검표, 필요한 소재 목록, 제작 요청 브리프를 제공합니다. 실제 사이트 코드를 만들거나 배포하라는 요청이 있으면 판매 채널·기존 저장소·결제 연동을 먼저 확인해 적절한 제작 스킬로 넘깁니다. 디자인 구조, 이미지 크기, SEO 메타 길이, 파일 트리, 장바구니 구현을 고정값으로 강제하지 않습니다.

## 검증

실제 페이지가 없으면 전환율·SEO 순위·장바구니 동작을 검증했다고 쓰지 않습니다. 샘플 제품의 가격·후기·배송 조건은 예시라는 표시 없이 실상품 정보로 옮기지 않습니다.
