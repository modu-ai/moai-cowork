# CRM 전략

## 현재 상태

사용 중인 CRM, 고객 접점, 데이터 출처, 수집 목적, 수신 동의와 거부 상태를 먼저 확인합니다. 자료가 없으면 세그먼트나 고객 가치 수치를 만들어 내지 않습니다.

## 설계

1. 재구매·이탈 방지·문의 응답 등 하나의 목표와 측정 지표를 정합니다.
2. 실제로 보유한 데이터만으로 분류 가능한 고객군을 정의합니다.
3. 각 고객군에 보낼 메시지의 목적·조건·채널·중복 방지 규칙을 정합니다.
4. 광고성 연락은 적용 지역과 채널의 동의·표시·발송 제한을 확인한 뒤 실행합니다.
5. 자동화 제안과 실제 연결·발송 상태를 구분합니다. 고객 데이터 접근 권한이 없으면 설계안으로 표시합니다.

## 산출물

고객군·트리거·메시지·중지 조건·측정 방법을 한 표로 정리합니다. 필요한 경우에만 시스템 구성도를 추가합니다.
