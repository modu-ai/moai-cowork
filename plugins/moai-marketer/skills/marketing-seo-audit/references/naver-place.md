# 네이버 플레이스 점검표

`marketing-seo-audit`에서 오프라인 사업장·방문 예약 사업자를 점검할 때 사용한다. 공개 업체 페이지와 사업주 계정의 확인 범위를 구분한다. 노출 순위나 광고 수익은 보장하지 않는다.

## 확인 순서

1. 실제 업체와 스마트플레이스 페이지의 이름·주소·전화·영업시간·휴무일을 대조한다. 업체가 아직 등록되지 않았으면 [신규 등록 공식 안내](https://help.naver.com/service/30026/contents/20366?osType=COMMONOS)를 확인한다.
2. 업종·대표키워드·메뉴·가격·사진은 실제 제공 내용과 맞는지 확인한다. 수정 가능 항목과 횟수는 [업체 정보 수정 공식 안내](https://help.naver.com/service/30026/contents/20379?lang=ko&osType=MOBILE)를 따른다. 검색어를 넣기 위해 사실과 다른 업체명이나 업종을 쓰지 않는다.
3. 주차·예약·포장 등 편의 정보와 예약·주문·문의 기능은 실제 운영되는 것만 표시한다. 버튼이 있는지와 연결 후 고객이 완료할 수 있는지 따로 확인한다.
4. 대표사진·메뉴사진·공지의 정확성과 권리 보유 여부를 확인한다. 가격·휴무·메뉴가 바뀌면 관련 표시를 갱신한다. 월간 게시 횟수를 순위 기준으로 제시하지 않는다.
5. 리뷰의 내용·날짜와 사업자 답글을 확인한다. 고객 개인정보를 답글에 노출하지 않는다. 리뷰 요청이나 혜택 제공은 현재 네이버 정책과 경제적 이해관계 표시 규정을 확인하고, 조작·대행 리뷰를 권하지 않는다.
6. 광고를 검토하면 실제 광고 계정에서 상품·노출 조건·과금·예산을 확인한다. [네이버 검색광고](https://searchad.naver.com/)의 현재 안내와 계정 화면이 근거다. 자연 검색 위치만으로 광고 집행을 자동 결정하지 않는다.

## 결과 기록

| 영역 | 관찰한 사실과 증거 | 미확인 사항 | 조치 | 재확인 방법 |
|---|---|---|---|---|
| 업체 정보 | 공개 페이지와 실제 정보 비교 | 사업주 계정 설정 | 잘못된 항목 수정 | 공개 페이지 재조회 |
| 메뉴·사진 | 실제 메뉴·이미지 비교 | 이용 권리 | 사실에 맞게 갱신 | 페이지 재조회 |
| 리뷰·응대 | 공개 리뷰와 답글 | 내부 운영 정책 | 정중한 응대 절차 | 새 리뷰 표본 확인 |
| 예약·주문·문의 | 공개 버튼과 고객 흐름 | 내부 처리 상태 | 연결 오류 수정 | 실제 예약 경로 확인 |
| 광고 | 계정에서 관찰된 설정 | 비용·성과 자료 | 검토 또는 보류 | 광고 보고서 대조 |

점수·순위·리뷰 효과·예상 매출은 측정 자료가 있을 때만 쓴다. 예시 업체의 리뷰 수나 결함을 실제 감사 결과처럼 채우지 않는다.
