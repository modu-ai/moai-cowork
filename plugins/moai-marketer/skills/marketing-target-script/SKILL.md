# 타겟 메시지 설계

고객이 실제로 겪는 문제와 제품이 확인된 범위에서 제공하는 가치를 한 문장으로 연결한다. 제품과 고객 자료가 없으면 연구 질문과 검증할 초안을 제시한다. 인구통계만으로 심리·소득·건강 상태를 단정하지 않는다.

## 입력 확인

- 고객 집단과 근거: 인터뷰·리뷰·문의·영업 기록 등 출처, 표본, 수집 시점
- 제품 정보: 기능, 제공 지역, 가격, 체험·할인 조건, 이용 제한
- 주장 근거: 수치·비교·고객 사례·인증·안전성·효능의 출처와 공개 허가
- 캠페인 목적: 고객의 다음 행동, 전환 정의, 측정 가능한 지표
- 채널: 실제 사용 채널, 현재 글자·형식 제한, 광고 심사 정책, 수신 동의 여부
- 브랜드 어조와 금지 표현

녹취·상담·후기에서 고객 표현을 가져올 때 개인정보와 공개 허가를 확인한다. 가상의 페르소나는 가설로 표시한다.

## 메시지 작성

1. 고객 집단마다 관찰된 문제, 제기된 반론, 아직 모르는 점을 나눈다.
2. 제품 기능과 고객 가치 사이의 인과를 확인한다. 증명되지 않은 절감률·치료 효과·보안 인증은 제외한다.
3. 핵심 메시지를 고객의 말에 가깝게 쓴다. 구체적 수치나 비유는 사실 확인과 맥락 설명이 가능할 때만 쓴다.
4. 이메일·SNS·랜딩·광고용 초안을 채널의 현재 규격과 고객 행동에 맞게 조정한다. 고정 글자 수나 게시 시간, 알고리즘 효과를 보편 규칙으로 쓰지 않는다.
5. 각 초안에 하나의 분명한 다음 행동을 넣고 실제 도착 페이지·제공 조건과 대조한다.

AIDA나 PAS 같은 틀은 필요할 때 문장 정리에 쓴다. 불안·죄책감을 과장하거나 근거 없는 희소성을 만들지 않는다. 영상의 첫 장면은 주목을 돕는 가설로 다루며 특정 초 이내 후크가 노출을 결정한다고 단정하지 않는다.

## 검증과 실험

한 번에 비교할 핵심 차이를 정하고 가설, 대상, 배분, 주요 지표, 제외 조건, 관찰 기간을 기록한다. 표본과 예산이 작으면 다수 변형을 동시에 노출하는 설계를 강요하지 않는다. 오픈율·클릭률·전환율의 분모를 구분하고, 결과가 없는 경우 승자를 선언하지 않는다.

건강·안전 관련 주장에는 판매 지역의 적용 기준과 적절한 근거를 확인한다. 예를 들어 [FTC 건강 제품 광고 안내](https://www.ftc.gov/business-guidance/resources/health-products-compliance-guidance)는 건강 효능 주장에 신뢰할 만한 입증을 요구한다. 미국 HIPAA 적용 여부는 제품 이름만으로 판단할 수 없고 [HHS의 적용 주체 안내](https://www.hhs.gov/hipaa/for-professionals/covered-entities/index.html)에 따라 확인한다. 확인 전에는 준수한다고 쓰지 않는다. 한국 광고는 해당 품목의 표시·광고 기준과 실제 증빙을 별도로 확인한다.

## 출력

- 확인된 고객 관찰과 미검증 가설
- 고객 문제 → 제품 근거 → 핵심 메시지의 연결표
- 채널별 초안과 각 채널에서 확인할 정책·규격
- 수치·인증·사례·가격 주장에 대한 근거 목록
- A/B 실험 가설과 측정 계획
- 발행 전 승인·수신 동의·법적 검토가 필요한 항목

문장 산출물은 근거와 대조해 사실·수치·의미·표현을 직접 검수한다. `moai-coworker:ai-slop-reviewer`와 `moai-writer:korean-humanize`가 설치돼 있으면 보조로 사용하고 다시 근거와 대조한다. 후처리를 거쳤다는 이유만으로 광고 문구가 승인되거나 발행 가능한 상태가 되지는 않는다.
