# Meta 광고 운영

Meta의 Ads AI Connectors는 Meta가 공개한 광고 계정 연결 기능입니다. 이 플러그인은 원격 MCP 주소 https://mcp.facebook.com/ads를 제공합니다. [Meta 발표 자료](https://s21.q4cdn.com/399680738/files/doc_financials/2026/q1/META-Q1-2026-Prepared-Remarks.pdf)는 오픈 베타 도입을 확인하지만, 호스트·계정마다 사용 가능한 기능과 권한은 실제 연결에서 확인해야 합니다.

## 연결

Claude Cowork 또는 ChatGPT Work의 연결 기능에서 이 플러그인의 Meta 광고 MCP가 보이는지 확인하고, 앱에 표시되는 Meta 로그인·권한 절차를 따릅니다. 연결이 없거나 인증이 실패하면 초안과 설정 안내만 제공하고 계정을 바꿨다고 말하지 않습니다. 비개발자에게 CLI 설치나 토큰 복사를 기본 경로로 요구하지 않습니다. 토큰·광고 계정 비밀값을 문서나 응답에 노출하지 않습니다.

## 실행 전 확인

1. 사용자의 요청이 조회인지 생성·수정·중지·활성화인지 구분합니다.
2. 연결된 도구 목록과 대상 광고 계정·페이지·캠페인 ID를 실제로 조회합니다. 베타 도구가 없으면 지원한다고 약속하지 않습니다.
3. 변경 대상, 목표, 일예산 또는 총예산, 기간, 소재, 타게팅, 전환 이벤트를 명확히 합니다. 모호하면 변경안을 작성해 필요한 값만 묻습니다.
4. 지출이 발생하는 활성화·예산 증액·결제 관련 동작은 구체적인 계정·금액·상태를 사용자에게 보여주고 그 범위의 명시적 요청 또는 승인을 확인합니다. 이미 같은 구체적 동작을 승인했다면 반복해서 묻지 않습니다.

## 안전한 변경

- 생성 도구가 상태를 받을 수 있으면 PAUSED로 생성하고 결과를 조회해 확인합니다. 도구가 자동 활성화를 강제하면 생성 전에 지출 영향과 사용자의 지시를 다시 확인합니다.
- 도구가 반환한 성공 메시지만으로 최종 적용을 단정하지 않고 가능하면 ID·상태·예산을 다시 조회합니다.
- 쓰기 호출이 타임아웃되거나 결과가 모호하면 대상 상태를 조회한 뒤 재시도합니다. 중복 캠페인을 막기 위해 무작정 같은 쓰기를 반복하지 않습니다.
- 현재 연결에서 제공하지 않는 픽셀·카탈로그·결제 기능은 별도 도구와 권한을 확인하기 전에는 실행 가능하다고 말하지 않습니다.

## 결과 보고

광고 계정, 변경 대상 ID, 전후 상태, 예산·기간, 실제 확인한 도구 결과를 적습니다. 생성된 PAUSED 광고와 활성 광고를 구분합니다. 조회·초안·생성·활성화·검증의 상태를 섞지 않습니다. 광고 성과 해석은 marketing-meta-ads-analyzer, 픽셀 설치 점검은 marketing-pixel-audit, 전체 계획은 marketing-campaign-planner로 연결합니다.
