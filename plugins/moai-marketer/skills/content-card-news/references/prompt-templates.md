# 카드 구성과 이미지 지시

주제에 맞는 원고 구조를 고른다. 패턴은 선택지이며 카드 수와 순서는 정보량에 따라 바꾼다.

| 패턴 | 전개 |
|---|---|
| 비교 | 같은 기준으로 선택지의 장단점과 적합한 상황 비교 |
| 순서 | 시작 조건, 실행 단계, 확인 방법 |
| 체크리스트 | 사용자가 실제로 확인할 수 있는 항목과 판단 기준 |
| 질문과 답 | 독자의 질문, 검증된 답, 필요한 예외 |
| 문제와 해결 | 관찰된 문제, 원인 근거, 가능한 행동 |
| 사례 | 출처와 사용 권한이 확인된 실제 사례의 조건·행동·결과 |

## 이미지 생성 지시

카드마다 제목·본문·강조할 시각 요소를 분리해 적는다. 브랜드 자료, 종횡비, 사용 가능한 로고와 사진을 지정한다. 사용자가 확인하지 않은 수치나 인물 사진을 만들지 않는다.

ChatGPT Work에서는 [데스크톱 이미지 생성 안내](https://learn.chatgpt.com/docs/image-generation)에 따라 기본 이미지 도구로 생성·편집을 요청한다. 사용자가 GPT Image 2.5를 정확히 지정했다면 `moai-media:media-codex-image`의 별도 API 경로 확인 절차를 따른다. 사용자가 Higgsfield를 지정하면 현재 Higgsfield 도구의 모델과 옵션을 확인해 요청한다. 이미지 모델은 텍스트를 잘못 그릴 수 있으므로 결과의 한국어 문구와 숫자를 원고와 대조한다. 한 번에 여러 장을 요청해도 파일별 결과와 누락을 확인한다.

채널 캡션은 카드의 핵심을 짧게 설명하고, CTA와 태그는 실제 목적에 필요한 만큼만 넣는다. 해시태그의 고정 개수나 특정 문구가 노출을 보장한다고 쓰지 않는다.
