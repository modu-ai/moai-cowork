# 카드뉴스 디자인 가이드

브랜드 자료와 배포 채널의 현재 규격을 먼저 확인한다. 색상 비율·주제별 고정 팔레트·폰트 하나를 보편 규칙으로 강제하지 않는다. 타사 브랜드 색은 해당 브랜드를 다루거나 사용 권한이 있을 때만 사용한다.

## 화면 구성

- 표지: 주제와 독자가 얻게 될 정보를 바로 알 수 있게 한다.
- 정보 카드: 한 장에 한 가지 판단이나 행동을 담고, 카드 간 제목·번호·여백을 일관되게 유지한다.
- 비교 카드: 두 선택지의 같은 항목을 같은 기준으로 비교한다.
- 마지막 카드: 핵심을 정리하고 필요한 경우에만 한 가지 다음 행동을 제시한다.

본문과 배경은 함께 정한다. [WCAG 2.2 대비 기준](https://www.w3.org/TR/WCAG22/)의 보통 글자 4.5:1, 큰 글자 3:1을 최소 점검 기준으로 삼되, 카드가 이미지로 게시되면 실제 기기의 축소 화면에서도 읽히는지 눈으로 확인한다. 이미지 생성 모델의 결과는 글자·번호·로고가 틀릴 수 있으므로 원고와 대조한다.

폰트는 브랜드가 허용한 서체와 라이선스를 확인한다. 파일 크기, 해상도, 종횡비는 게시할 채널의 현재 업로드 화면과 공식 안내에서 확인한다. 용량을 낮추려고 글자를 읽기 어렵게 압축하지 않는다.

진행 표시나 해시태그 수가 완독·저장을 특정 비율로 높인다는 주장은 실측 자료가 없으면 하지 않는다.
