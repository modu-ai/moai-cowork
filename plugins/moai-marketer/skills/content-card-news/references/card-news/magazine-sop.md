# 매거진형 카드뉴스 제작 절차

매거진형 레이아웃이 요청됐을 때만 사용한다. 사용자가 준 브랜드와 참고 디자인의 사용 권한을 먼저 확인한다.

1. 편집: 독자, 핵심 주장, 근거 자료를 정하고 카드별 원고를 작성한다.
2. 디자인: 브랜드 색·폰트·그리드와 표지·본문의 일관성을 정한다. 사용자의 참고 이미지를 실제로 열람했다면 관찰한 특성을 기록한다.
3. 이미지: ChatGPT 기본 경로 또는 사용자가 지정한 Higgsfield 경로로 생성한다. 사용한 도구와 결과 파일을 구분한다.
4. 검수: 글자·숫자·출처·인물·로고·대비·잘림을 원고와 대조한다.
5. 납품: 실제 제작한 카드 파일, 캡션, 편집 가능한 원본의 유무와 남은 수정 사항을 적는다.

도구가 제공하지 않는 HTML 변환, Figma 파일, API 모델, 이미지 파일을 이미 만든 것처럼 적지 않는다. 역할을 여러 명으로 나누는 절차는 작업 규모가 필요할 때만 사용한다. 긴 작업을 이어갈 때는 카드별 확정 원고, 사용한 이미지, 미확인 사항을 기록해 다음 작업에 넘긴다.
