# 키워드 리서치

새 콘텐츠나 페이지에 어떤 고객 질문을 다룰지 정합니다. 이미 발행된 사이트의 기술·콘텐츠 진단은 marketing-seo-audit가 담당합니다.

참고 방법론: [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) (MIT, 저장소 루트 NOTICE에 고지).

## 입력

- 상품·서비스, 고객, 지역, 검색 채널, 제작 가능한 콘텐츠와 사업 목표
- 기존 페이지와 Search Console·네이버 검색광고 등 접근 가능한 자료
- 자료의 날짜·국가·기기·집계 기간과 숫자의 출처

## 조사

1. 고객이 실제로 쓰는 표현을 상담·검색어 보고서·사이트 검색·공식 검색 화면에서 수집합니다. 자동완성은 아이디어 출처이며 검색량의 증거가 아닙니다.
2. 질의별로 정보 탐색, 특정 사이트 탐색, 비교, 구매·신청 등의 의도를 추정하고 실제 검색 결과를 확인합니다. 하나의 질의에 여러 의도가 섞일 수 있습니다.
3. 기존 페이지로 답할 수 있는 질문과 새 페이지가 필요한 질문을 나눕니다. 내용이 겹치는 페이지를 기계적으로 늘리지 않습니다.
4. 검색량·경쟁 수치가 있으면 도구·기간·지역을 함께 기록합니다. 없으면 미확인으로 두고 사용자 적합성과 제작 가능성 중심으로 우선순위를 제안합니다.
5. 관련 질문은 필요한 경우 주제별로 묶어 내부 링크를 설계합니다. 필러 페이지나 클러스터 개수를 고정하지 않습니다.

## AI 검색 관련 판단

Google의 [AI 기능 안내](https://developers.google.com/search/docs/appearance/ai-features)는 AI Overviews와 AI Mode에서 관련 질의를 추가로 검색할 수 있다고 설명합니다. 동시에 별도 AI 검색 최적화 기술 요건은 없고 기존 SEO 기본 원칙이 적용된다고 밝힙니다. 특정 문단 길이·표·검색 순위가 인용을 보장한다고 말하지 않습니다. ChatGPT나 다른 AI 제품에 직접 질문한 결과도 해당 시점의 관찰 예시이며 실제 사용자 검색량이나 인용 확률로 해석하지 않습니다.

## 산출물

| 질의 후보 | 고객 의도 | 확인한 자료와 날짜 | 기존 페이지 | 새 콘텐츠 필요성 | 우선순위 근거 |
|---|---|---|---|---|---|
| 실제 조사한 질의 | 확인 또는 추정 | 도구·기간 또는 미확인 | URL 또는 없음 | 이유 | 근거 |

요청이 있으면 주제 묶음과 내부 링크 방향을 덧붙입니다. 검색량·난이도·AI 인용률은 실제 데이터가 없으면 빈칸이나 미확인으로 남깁니다. 추천 문장은 ai-slop-reviewer·korean-humanize가 설치돼 있으면 활용하고 원문과 대조하며, 없으면 직접 사실·의미를 검수합니다.

## 연결 스킬

- marketing-seo-audit: 기존 사이트 점검
- content-blog: 확인한 질의로 글 작성
- content-editorial-calendar: 제작 일정 편성
- marketing-campaign-planner: 검색 콘텐츠와 광고 계획 통합
