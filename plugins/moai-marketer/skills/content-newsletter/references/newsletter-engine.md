# 뉴스레터 편집·발송 점검

## 큐레이션

각 항목의 원문 URL, 발행일, 이번 호에서 인용할 사실, 편집자의 해석을 기록한다. 링크를 열어 실제 대상과 날짜를 확인한다. 다른 글의 요약만 모아 놓지 말고 독자가 이번 호에서 얻을 판단이나 정보를 밝힌다.

## 작성과 검수

- 제목과 프리헤더가 본문을 과장하지 않는가?
- 제품·가격·혜택·인용·후기에 출처와 조건이 있는가?
- 링크가 실제 의도한 페이지로 열리는가?
- 광고성 정보 여부와 수신 동의·거부 처리 근거가 확인됐는가?
- 테스트 발송 화면에서 모바일·데스크톱 읽기가 가능한가?

## 성과

제목·발송 시각·CTA를 바꿔 시험할 수 있다. 한 번에 무엇을 바꿨는지와 대상 규모를 기록한다. 외부 업계 수치를 사용한다면 현재 출처와 모수·기간을 밝힌다. 사용자의 발송 데이터가 없으면 오픈율·클릭률 목표나 효과를 실측처럼 쓰지 않는다.

원고, 웹 초안, 공개 게시, 예약, 이메일 발송, 실제 전달 결과는 각각 다른 상태다. 확인한 상태만 보고한다. 소규모 요청에 가상의 편집국 역할이나 여러 중간 파일을 필수로 만들지 않는다.
