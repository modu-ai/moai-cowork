# AI 도입 검토 가이드

사용자의 조직과 업무에 관한 실제 자료를 기준으로 검토한다. 도입 여부를 미리 정하지 않는다.

1. **현재 업무**: 반복 작업, 오류, 병목을 관찰된 자료와 함께 기록한다. 담당자 진술은 진술로 표시한다.
2. **데이터와 권한**: 데이터 위치·품질·접근 권한을 확인한다. 개인정보와 외부 서비스 전송 여부는 해당 환경에서 검토할 쟁점으로 적는다.
3. **적용 후보**: 기존 방식, 자동화, AI 사용을 각각 비교한다. 예상 편익은 측정 방법과 전제 조건을 붙인다.
4. **작은 검증**: 사용자에게 중요한 품질·시간·비용 기준을 정하고, 현재 방식과 비교할 시험을 설계한다. 기준값이 없다면 먼저 수집한다.
5. **결정**: 시험 결과, 운영 책임, 비용과 실패 시 대응을 검토해 도입·보류·중단을 제안한다.

산출물에는 확인된 사실, 가설, 검증 과제, 결정 대기 사항을 구분한다. ROI, 투자액, 인력 계획, 법적 준수 여부, 일정은 실제 근거가 있을 때만 확정한다. 문서나 표는 요청한 형식으로 만들며 별도 작업 폴더나 역할별 에이전트 구성을 전제로 하지 않는다.
