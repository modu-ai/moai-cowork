# 일반 운동 계획 가이드

운동 목적, 현재 활동 수준, 좋아하는 활동, 가용 시간, 통증·부상·질환·임신 같은 안전상 제약을 확인한다. 정보가 부족하면 낮은 부담의 활동 선택지와 상태를 확인할 질문을 제시한다.

- [WHO 신체활동 지침](https://www.who.int/publications-detail-redirect/9789240015128)의 적용 대상과 권고 범위를 확인한다. 집단 권고를 개인의 치료 계획으로 바꾸지 않는다.
- 운동 종목·빈도·강도는 실제 현재 수준과 선호에 맞춰 조정 가능한 초안으로 쓴다. 통증이나 이상 증상을 참고 밀어붙이도록 권하지 않는다.
- 질환·재활·약물·부상 이력이 관련되면 의료진이나 자격 있는 전문가에게 안전한 활동 범위를 확인하도록 안내한다.
- 기록을 원하면 활동 시간과 주관적 부담을 사용자가 정한 방식으로 남긴다. 실제 기록 없이 진도나 효과를 보고하지 않는다.

보충제 추천, 치료 효과 보장, 임의의 칼로리 소모량은 운동 계획에 넣지 않는다. 별도 파일이나 에이전트 팀 없이도 요청한 계획을 작성한다.
