# 일반 식사 계획 가이드

식사 인원·기간·예산·기피 식품·알레르기·식이 제한·조리 여건을 확인한다. 사용자가 제공한 목표 열량은 출처와 대상자를 확인하되 개인에게 적절한 처방값으로 단정하지 않는다.

1. 메뉴는 다양한 식품군과 현실적인 조리 여건을 고려한 선택지로 제시한다. 영양소 양을 계산하려면 검증 가능한 식품 성분 자료와 실제 분량이 필요하다.
2. 알레르기와 교차 접촉 위험이 있으면 성분표·조리 환경을 직접 확인하도록 안내한다. 확인하지 않은 대체 재료를 안전하다고 보장하지 않는다.
3. 임신·영유아·고령·질환·섭식 문제에 따른 치료 식단은 의료진 또는 영양 전문가와 정한다. 영양 부족을 식단만 보고 진단하거나 영양제를 자동 추천하지 않는다.
4. 장보기 목록과 비용은 실제 메뉴·분량과 최신 가격이 있을 때만 계산한다. 가격 자료가 없으면 예산 확인 항목으로 남긴다.

한국인 영양소 섭취기준 등 공적 기준은 해당 대상과 최신 판본을 확인해 참고한다. 문서 초안과 식품 구매·주문 완료를 구분한다.
