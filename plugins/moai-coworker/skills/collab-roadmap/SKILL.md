# 로드맵 관리 (Roadmap Manager)

## 개요

프로젝트 및 파트너십 전문 스킬입니다. 프로젝트 트래커(일정, 마일스톤, 리소스 관리), 파트너십 개발(전략적 제휴, MOU, 공동사업 기획), 지속가능성 감사(환경 영향 평가, 지속가능성 지표), 다양성 & 포용(DEI 전략, 포용적 조직 문화 설계)을 지원합니다.

## 트리거 키워드

로드맵, 마일스톤, 프로젝트 관리, 일정, 리소스, 파트너십, MOU, 제휴, 지속가능성, DEI

## 워크플로우

### 전략 가이드 로드 및 실행

사용자 요청 수신 → 해당 전략 가이드 판별 → `references/{id}.md` 로드 → 전략 가이드에 따라 실행 → 결과물 생성 후 사용자 검토 요청

복잡한 판단은 실제 자료·제약·가정을 분리해 검토합니다. 현재 앱에서 제공되지 않는 추론 도구나 키워드를 필수 실행 경로로 가정하지 않습니다.

## 사용 예시

- "신규 서비스 출시 6개월 로드맵을 만들어줘"
- "분기별 마일스톤과 담당자를 정리해줘"
- "스타트업과의 MOU 협력 초안을 작성해줘"
- "ESG 공시 대응 지속가능성 감사 체크리스트를 만들어줘"
- "조직 내 DEI 정책 도입 로드맵을 설계해줘"

## 출력 형식

- 프로젝트 로드맵 (마일스톤, 일정, 리소스 배분)
- 파트너십 MOU 초안
- 지속가능성 감사 보고서
- DEI 전략 문서

## 주의사항

| 상황 | 해결 방법 |
|------|-----------|
| 이해관계자 요구사항 상충 | 우선순위 기준(고객 영향도 vs 기술 난이도 vs 비즈니스 가치)으로 정렬 매트릭스를 만들어 드립니다 |
| 우선순위 기준 불명확 | RICE(Reach·Impact·Confidence·Effort) 또는 MoSCoW 방법론으로 기준을 함께 설계합니다 |
| 리소스 배분 충돌 | 담당자 역할·책임 매트릭스(RACI)를 작성해 역할을 명확히 합니다 |
| ESG 규정 파악 어려움 | 현재 금융위원회·KSSB 발표와 대상 기업의 적용 여부를 확인합니다 |

### 한국 기업 파트너십 개발 특성

- **MOU 체결 문화**: MOU는 사업 협력 공식화의 첫 단계. 구속력보다 협력 의지 표명 성격 강함
- **대기업 협력**: 실제 상대 기업의 협력사 등록·심사 기준과 일정을 확인
- **스타트업 생태계**: 판교·홍릉·성수 클러스터 중심. 투자사 네트워크 파트너십 전략 중요

### ESG 지속가능성 공시

- **적용 범위**: [금융위원회의 현재 제도화 방안](https://www.fsc.go.kr/po010106/87280)과 회사 유형·자산 기준을 대조한다. 예전 `자산 2조 원` 문구를 현재 의무로 쓰지 않는다.
- **기준**: [KSSB 공시기준 공표](https://www.kasb.or.kr/front/board/comm020View.do?seq=501)를 확인하고 해당 기업에 실제 적용되는 기준만 사용한다.
- **공급망 요청**: 거래처가 요구한 지표·검증 수준을 확인하며 모든 중소기업에 동일한 의무가 있다고 단정하지 않는다.

## 후처리 체인

MOU 초안·지속가능성 감사 보고서·DEI 전략 문서 같은 서술형 결과물을 완성한 뒤에는 다음 체인으로 마무리합니다(로드맵 일정표·RACI 매트릭스 같은 표·데이터는 제외, 본문 서술 부분에만 적용):

`moai-coworker:collab-roadmap → moai-coworker:ai-slop-reviewer → moai-writer:korean-humanize → 최종 검수`

- `moai-coworker:ai-slop-reviewer`: AI 특유의 상투적 표현·과장·군더더기를 점검하고 다듬습니다.
- `moai-writer:korean-humanize`: 자연스러운 한국어 문장으로 최종 정제합니다.
