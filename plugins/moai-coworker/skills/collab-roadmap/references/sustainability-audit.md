# 지속가능성 자료 검토 가이드

환경·사회·거버넌스 자료를 정리하고 미확인 항목을 찾는다. 이 문서만으로 법정 공시나 제3자 검증을 완료하지 않는다.

## 먼저 확인

- 회사 유형, 공시 대상 여부와 적용 기준
- 실제 배출량·에너지·수자원·폐기물 자료의 기간·경계·산정 방식
- 인사·공급망·이사회 자료의 수집 권한과 공개 범위
- 이미 사용 중인 보고 기준과 감사·검증 이력

## 검토 절차

1. [금융위원회 제도화 방안](https://www.fsc.go.kr/po010106/87280)과 [KSSB 공시기준 공표](https://www.kasb.or.kr/front/board/comm020View.do?seq=501)를 회사의 적용 범위와 대조한다.
2. 실제 받은 자료만 출처와 기준 기간을 붙여 표로 정리한다. 자료가 없으면 외부 평균값으로 자사 성과를 대신하지 않는다.
3. Scope 1·2·3 등 산정이 필요한 항목은 조직 경계, 데이터 출처, 산식과 불확실성을 표시한다. 계산하거나 검증하지 않았다면 배출량·감축률을 만들어 내지 않는다.
4. 중요성 판단과 개선 우선순위는 조직의 목표·이해관계자 자료가 있을 때 제시한다.
5. 결과를 `자료 검토 초안`, `미확인 항목`, `전문 검증 필요`로 구분한다. 인증·감사·공시 완료로 표시하지 않는다.
