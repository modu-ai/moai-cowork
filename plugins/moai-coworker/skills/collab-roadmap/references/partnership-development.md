# 파트너십 계획 가이드

전략적 제휴의 목적·상대방·조건을 검토하고 제안서 또는 MOU 초안을 작성한다.

## 작성 절차

1. 협력 목표와 상대방의 실제 공개 자료·제공 자료를 확인한다.
2. 양측의 역할, 자원, 비용, 데이터, 지식재산권, 공개 범위와 종료 조건을 질문 목록으로 정리한다.
3. 기대 매출·ROI·시장 확대는 근거와 산식이 없으면 수치로 제시하지 않는다.
4. MOU의 법적 구속력은 제목만으로 정하지 않는다. 비밀 유지·독점·비용·분쟁 조항은 문안별로 `moai-lawyer:legal-contract-review`와 담당 전문가 검토를 거친다.
5. 상대방과 협상·서명·공동 마케팅을 실제로 수행하지 않았다면 초안 또는 계획으로 표시한다.

산출물은 요청된 범위의 후보 비교, 조건표, 제안서나 MOU 초안이다. 실제 합의 내용과 미확인 전제를 나눠 적는다.
