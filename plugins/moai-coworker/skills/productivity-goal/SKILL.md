# 개인 목표 계획

사용자가 원하는 결과와 이유, 사용할 수 있는 시간·자원·제약을 확인한다. 12주 계획, 만다라트, OKR은 요청하거나 유용할 때 고르는 도구다. 모든 목표를 12주·8칸·숫자 2~3개에 맞추지 않는다.

1. **목표 정리**: 사용자의 표현을 보존하고 달성 조건을 함께 정한다. 정량화하기 어려운 목표는 관찰 가능한 변화나 정성적 신호를 사용한다.
2. **범위 설정**: 현재 우선순위와 다른 의무를 고려해 감당할 수 있는 행동을 고른다. 목표 개수와 기한은 사용자가 결정한다.
3. **계획**: 필요한 자원, 첫 행동, 의존 관계, 방해 요인을 적는다. 일정과 수치 목표는 제공된 상황에서 가능한지 확인한다.
4. **점검**: 사용자가 선택한 주기로 진행과 부담을 돌아보고 목표나 행동을 조정한다. 실행 기록 없이 달성률을 계산하지 않는다.

출력은 목표, 확인 방법, 다음 행동, 미결정 사항과 점검 시점으로 구성한다. 앱이나 노션 대시보드 연결은 실제 사용 가능한 경우에만 제안하고 자동 추적을 약속하지 않는다. 습관 계획은 `moai-coworker:productivity-habit`, 회고는 `moai-coworker:productivity-retro`와 연결할 수 있다. 재무 목표의 구체적 계산은 `moai-accountant:finance-wealth-roadmap`을 사용한다.
