# 사용자 피드백 분석 가이드

분석 대상, 수집 기간, 수집 경로, 응답 수와 제외 기준을 먼저 기록한다. 접근 가능한 원문과 요약 자료의 차이를 밝힌다.

- **주제 분류**: 실제 표현에서 반복되는 문제·요청·칭찬을 분류하고 대표 인용에는 출처를 붙인다. AI 분류를 사용했다면 표본을 사람이 검토하고 애매한 항목을 남긴다.
- **빈도**: 같은 사람이 여러 번 남긴 응답, 채널별 중복, 표본 편향을 고려한다. 빈도가 곧 모든 고객의 비율은 아니다.
- **NPS·CSAT**: 질문과 척도, 응답 수를 확인한다. 결과값만 있으면 계산 검증과 세그먼트 분석은 수행하지 않았다고 적는다.
- **비교**: 기간·모집 방식·질문이 같거나 차이를 설명할 수 있을 때만 추세를 해석한다. 경쟁사 벤치마크는 같은 정의의 자료가 있을 때만 사용한다.
- **권고**: 발견별로 제품에서 확인할 가설과 다음 관찰 방법을 제시한다. 발송, 보상 지급, 고객 접촉은 사용자 승인과 해당 도구 권한이 있을 때만 한다.

출력에는 확인된 수치와 사용자 진술, 해석, 미확인 과제를 나누어 쓴다.
