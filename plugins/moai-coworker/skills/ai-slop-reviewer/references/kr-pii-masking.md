# 개인정보 마스킹 규격 (kr-pii-masking)

> moai-coworker | ai-slop-reviewer 소유 공유 규격
> 이력서·급여대장·고객 문의·계약서 원본처럼 개인정보가 포함된 입력을 처리하는 모든 스킬(career·recruiter·cs·accountant·lawyer 라인)이 이 파일 하나를 참조합니다.
> 근거 법령: [개인정보 보호법 제28조의8](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029331979) 및 개인정보 보호위원회 안내. 표의 자릿수는 이 문서의 출력 예시일 뿐 모든 업무의 법정 마스킹 기준은 아닙니다.

## 0. 대원칙 — 산출물 재출력 금지

1. **외부 공유용 산출물에는 불필요한 개인정보 원본을 재출력하지 않습니다.** 내부 급여·계약처럼 식별자가 필요한 업무는 사용자의 권한과 목적을 확인하고 최소한의 정보만 사용합니다.
2. 업무 수행에 **불필요한 개인정보는 산출물에서 아예 제거**합니다 (마스킹보다 삭제가 우선 — 개인정보 보호법 제3조 최소처리 원칙).
3. 마스킹 전 원문을 예시·인용 형태로도 남기지 않습니다 ("원본: …" 병기 금지).

## 1. 항목별 마스킹 자릿수 규칙

| 항목 | 규칙 | 표기 예 |
|------|------|---------|
| 주민등록번호 | 생년월일 6자리만 표시, **뒤 7자리 전체 마스킹** | `900101-*******` |
| 외국인등록번호 | 주민등록번호와 동일 규칙 | `900101-*******` |
| 계좌번호 | **뒤 4자리만 표시**, 나머지 마스킹 | `***-****-1234` |
| 카드번호 | **뒤 4자리만 표시**, 나머지 마스킹 | `****-****-****-5678` |
| 휴대전화·전화번호 | **중간 자리 마스킹** | `010-****-5678` |
| 이메일 | 로컬부 앞 2~3자만 표시하고 나머지 마스킹 (도메인은 유지 가능) | `ho***@example.com` |
| 주소 | 시·군·구까지만 표시, **상세주소(동·호수·번지) 제거** | `서울시 마포구` |
| 성명 | 문맥상 필요 시 가운데 글자 마스킹 또는 이니셜 | `홍*동`, `H씨` |
| 사업자등록번호 | 법인·사업자 공개 정보이므로 원칙적으로 마스킹 대상 아님. 단, **개인사업자 번호가 개인 식별과 결합되는 문맥**(예: 급여·채용 문서)에서는 뒤 5자리 마스킹 | `123-45-*****` |
| 운전면허·여권번호 | 뒤 4자리만 표시 | `**-**-****56` |

## 2. 처리 절차 (입력 처리 단계)

1. 입력 수신 시 위 표의 항목을 스캔합니다.
2. 산출물 작성 전에 마스킹/삭제를 적용하고, 이후 모든 중간·최종 산출물에서 동일 규칙을 유지합니다.
3. 사용자가 "마스킹 해제"를 명시적으로 요청해도, 산출물이 제3자 공유용(공고문·답변서·보고서)이면 마스킹 유지를 권고하고 이유를 알립니다.

## 3. 국외 이전 근거 확인 (개인정보 보호법 제28조의8)

국내 개인정보처리자가 국외의 제3자에게 제공·처리위탁·보관하는 경우 [제28조의8](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029331979)의 근거를 확인합니다. 별도 동의, 법률·조약, 계약 이행에 필요한 위탁·보관과 처리방침 공개·알림, 인증 또는 적정성 인정 등 법에서 정한 경로가 있습니다. 모든 국외 이전에 별도 동의가 필요한 것은 아닙니다. [개인정보 보호위원회 설명](https://m.pipc.go.kr/np/default/page.do?mCode=D060040000)은 국외 사업자가 정보주체로부터 직접 수집하는 경우를 국내 처리자의 국외 이전과 구분합니다. 실제 처리 흐름과 서비스 약관을 확인합니다.

1. 이전되는 개인정보 항목
2. 이전되는 국가, 시기·방법
3. 이전받는 자의 성명(법인명)과 연락처
4. 이전받는 자의 이용 목적과 보유·이용 기간
5. 이전을 거부하는 방법·절차와 거부 시 불이익

→ 실무에서는 국내 처리자가 타인의 개인정보를 해외 서비스에 전송하는지, 어떤 적법 근거와 고지 방식이 적용되는지 확인합니다. 마스킹된 정보도 다른 자료와 결합해 식별할 수 있으면 개인정보일 수 있으므로 마스킹만으로 법적 요건을 충족했다고 단정하지 않습니다.
