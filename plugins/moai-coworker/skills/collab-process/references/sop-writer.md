# 표준 운영 절차 작성 가이드

현재 절차와 개선안을 구분해 실행 가능한 SOP 초안을 만든다.

## 입력

- 대상 업무, 시작·종료 조건, 적용 범위
- 실제 담당자·승인자와 사용 도구
- 기존 문서·현장 기록과 알려진 예외

## 작성 절차

1. 읽은 자료와 확인하지 못한 현장 관행을 분리한다.
2. 단계마다 실행자, 입력, 행동, 산출물과 완료 확인 기준을 적는다.
3. 예외·오류·에스컬레이션 경로를 명시한다. 실제 승인권자와 연락 경로가 없으면 확인 필요로 남긴다.
4. 개선 제안은 현행 절차와 구분하고 변경 승인 전에는 적용된 절차라고 쓰지 않는다.
5. 담당자가 실제로 수행해 본 결과가 있어야 실행 가능성 검증을 완료로 표시한다.

요청한 문서만 작성하고, 파일 저장이 필요하면 현재 앱의 쓰기 기능과 합의한 위치를 확인한다. 별도 에이전트 실행을 필수로 가정하지 않는다.
