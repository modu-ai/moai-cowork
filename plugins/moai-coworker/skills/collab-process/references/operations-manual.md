# 운영 매뉴얼 작성 가이드

제공된 문서·설정·업무 기록에서 실제 절차를 추출해 운영 매뉴얼 초안을 만든다.

## 입력 확인

- 대상 프로세스와 매뉴얼 독자
- 접근 가능한 기존 문서·코드·위키와 기준 버전
- 절차 담당자, 승인권자, 사용하는 도구
- 오류·예외 처리와 공개 범위

## 작성 절차

1. 실제 읽은 자료를 목록과 출처로 기록한다. 읽지 못한 자료는 미확인으로 표시한다.
2. 자료에 근거한 현재 절차와 개선 제안을 구분한다.
3. 각 단계에 입력, 실행자, 행동, 산출물, 완료 확인 방법을 적는다.
4. 예외 흐름과 문의 대상을 확인한다. 실제 연락처가 없으면 이름이나 번호를 만들지 않는다.
5. FAQ는 자료에서 확인된 질문과 답만 채운다. 교육 자료·그림은 요청과 실제 자료가 있을 때 추가한다.
6. 담당자에게 현장 실행 가능성을 확인받기 전에는 `검증 완료`라고 쓰지 않는다.

파일 저장은 사용자가 요청하고 현재 앱에서 가능한 경우에만 합의한 위치에 한다. 코드 접근이 없을 때는 `[코드 미확인]`으로 표시하고, 일반 템플릿을 실제 절차처럼 제시하지 않는다.
