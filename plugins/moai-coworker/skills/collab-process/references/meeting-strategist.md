# 회의 전략 가이드

회의 목표, 참석 대상, 안건, 결정 방식과 후속 조치를 준비할 때 사용한다.

## 입력

- 회의 목적과 기대 산출물
- 참석자와 실제 결정 권한
- 사용자가 정한 일시·형식·시간 제약
- 기존 자료와 공개 범위

## 준비 절차

1. 이 회의에서 결정할 것과 공유만 할 것을 구분한다.
2. 결정에 필요한 사람과 자료를 확인한다. 참석자가 불명확하면 임의로 대체자를 지정하지 않는다.
3. 안건마다 목적·발제자·사용자와 합의한 시간 배분을 적는다.
4. 결정 방식과 보류 시 확인할 자료를 명시한다.
5. 회의 후 실제 결정·담당·기한이 확인된 항목만 후속 조치로 기록한다.

사용자가 파일을 요청하고 현재 앱에서 저장할 수 있으면 합의한 위치에 회의 계획과 회의록을 저장한다. 회의를 실제로 진행하거나 결과를 확인하지 않았다면 후속 결정을 지어내지 않는다.
