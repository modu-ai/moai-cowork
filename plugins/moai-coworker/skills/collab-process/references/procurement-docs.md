# 구매·조달 문서 작성 가이드

발주자 관점에서 요구사항, 비교 기준, 계약 검토 항목, 수락 기준을 정리한다. 입찰 참가자의 제안서 작성은 `moai-coworker:collab-proposal`을 참고한다.

## 적용 범위 확인

- 구매 주체가 민간 기업, 국가기관, 지방자치단체 또는 공공기관 중 어디인지 확인한다.
- 공공조달이면 해당 기관의 현재 규정과 공고·계약 방식을 담당자가 확인한다. 국가계약법 시행령 제26조를 모든 기관의 수의계약 공통 근거로 쓰지 않는다.
- [국가계약법 시행령 제26조](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1023682371)와 [조달청 업무 절차](https://www.pps.go.kr/kor/content.do?key=00179)는 해당하는 거래에만 참조한다.

## 작성 절차

1. 구매 목적, 예산, 수량, 납품·지원 범위와 기존 계약을 확인한다.
2. 필수 요구사항과 선택 요구사항을 분리하고 각각 수락 방법을 적는다.
3. 공급업체 비교 기준과 가중치는 발주자가 승인한 항목만 사용한다. 후보사 정보가 없으면 가상 평가 점수를 만들지 않는다.
4. 계약 조항의 책임·지식재산권·데이터·해지·손해배상은 초안과 법률 검토 필요 항목으로 구분한다. 법률 검토는 `moai-lawyer:legal-contract-review`와 담당 전문가에게 연결한다.
5. 수락 시험은 요구사항과 연결하고, 실제 시험 전에는 합격·검증 완료라고 쓰지 않는다.

파일 저장과 전자조달 시스템 입력은 각각 사용자의 요청, 현재 앱의 기능, 권한을 확인한 뒤에만 수행한다. 초안을 만들었다고 발주나 계약이 완료된 것으로 표시하지 않는다.
