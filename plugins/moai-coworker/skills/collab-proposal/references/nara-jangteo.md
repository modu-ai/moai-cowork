# 나라장터 입찰 제안 준비 — 공급자 관점

공공조달 공고에 응찰할 때 제안서에 반영할 사항을 확인하는 가이드다. 발주자 측 문서는 `moai-coworker:collab-process`의 `references/procurement-docs.md`를 참고한다.

## 공고별 확인

1. [나라장터](https://www.g2b.go.kr/)에서 해당 공고의 최신 원문·정정 공고·첨부 제안요청서를 연다. 공고번호와 조회일을 기록한다.
2. 발주기관이 국가기관, 지방자치단체, 공공기관 중 어디인지 확인하고 적용 법령과 기관 규정을 구분한다.
3. 참가 자격, 제출 서류, 보증, 평가 기준, 가격 양식, 마감 시각, 제출 방식을 공고문 항목별로 옮긴다. 일반 목록을 모든 공고의 필수 요건으로 간주하지 않는다.
4. 자사 인증·실적·재무·면허 등의 실제 증빙을 요구사항과 대조한다. 미보유 또는 확인 불가 항목은 그대로 표시하고 허위 증빙을 만들지 않는다.
5. 기술 제안은 해당 공고의 평가 항목 순서에 맞추고, 가격·납기·지원 약속은 승인된 조건만 적는다.
6. 실제 전자입찰서 제출과 전자서명은 현재 계정·권한·사용자 승인·나라장터의 최신 절차를 확인한 뒤 진행한다. 제안서 초안을 만들었다고 입찰 참가나 계약 체결이 끝났다고 표시하지 않는다.

## 법령과 도움말

- [국가계약법 시행령 제26조](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1023682371)는 국가기관의 수의계약 사유를 열거한다. 지방자치단체나 다른 기관의 계약에 그대로 적용하지 않는다.
- 보증금 비율·면제·대체 수단은 해당 기관에 적용되는 최신 법령과 **해당 공고**를 확인한다. 일반 수치를 모든 입찰에 고정하지 않는다.
- [조달청 업무 처리 절차](https://www.pps.go.kr/kor/content.do?key=00179)는 조달청의 절차를 설명한다. 화면·인증 방식·제출 방식은 실제 나라장터 안내와 공고를 우선한다.
