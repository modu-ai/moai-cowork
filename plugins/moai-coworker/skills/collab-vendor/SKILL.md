# 공급업체 관리

요청에 맞는 참고 문서만 읽는다. 공급업체 선정 기준과 실제 업체 평가 결과를 구분한다. 견적·계약·납품·품질 자료를 보지 않았다면 점수, 위험 수준, 이행률을 만들지 않는다.

## 진행 방법

1. 구매 품목·서비스, 거래 국가, 후보 업체, 조직의 구매 권한과 실제 자료를 확인한다.
2. 평가 기준과 가중치는 구매 목적과 조직 규정으로 정한다. 조직 기준이 없다면 선택 가능한 항목을 제안하고 가중치는 미정으로 둔다.
3. 업체별 증빙의 출처·일자를 적고 미확인 항목은 평가 보류로 표시한다. 업체의 재무 상태, 인증, 납기 실적을 추정하지 않는다.
4. 위험은 원인·영향·조기 신호·대응·담당자를 연결한다. 발생 확률과 비용 영향은 관련 자료가 있을 때만 수치화한다.
5. 계약·법령·통관 관련 결론은 거래 유형, 당사자 지위, 관할, 최신 원문을 확인한 뒤 해당 전문 스킬이나 담당자의 검토로 넘긴다. 계약 체결·발주·지급·신고는 초안 작성과 별도 작업이다.

결과는 평가 기준표, 업체별 근거표, 미확인 사항, 실행 전 확인 목록으로 정리한다. 법적 계약서 해석은 `moai-lawyer:legal-contract-review`, 회계·지급은 관련 회계 스킬에 연결한다. 문체 후처리를 하더라도 수치와 근거를 보존한다.
