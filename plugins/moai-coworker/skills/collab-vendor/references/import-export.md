# 수출입 거래 검토 가이드

품목 설명·재질·용도, 출발국·도착국, 거래 당사자, 수량·가격, 적용하려는 협정과 계약상의 인도 조건을 먼저 확인한다.

- **품목분류**: HS 코드를 추측으로 확정하지 않는다. 분류가 불명확하면 [관세청 품목분류 사전심사 안내](https://www.customs.go.kr/ftaportalkor/cm/cntnts/cntntsView.do?cntntsId=8441&mi=15087)를 확인하고 필요한 자료와 신청 절차를 정리한다.
- **세율·원산지**: 목적지·적용 시점·품목과 협정문을 확인한다. [관세청 FTA 포털](https://www.customs.go.kr/ftaportalkor/ad/ftaTrtyPsr/psr.do)의 조회값도 참고 자료이며, 실제 적용은 원산지 요건과 증빙을 별도 검토한다.
- **통관 서류**: 운송 방식과 거래 조건에 필요한 송장·포장 명세·운송 서류·인증서를 해당 국가의 최신 요구사항에 맞춰 확인한다.
- **비용·결제**: 견적 통화, 운임, 보험, 세금, 결제 조건을 근거 자료로 비교한다. 환율 전망이나 헤지 효과를 보장하지 않는다.

산출물은 확인한 사실, 공식 출처와 조회일, 미확인 요건, 통관사·관세사·거래 은행에 확인할 질문으로 나눈다. 실제 신고·결제·계약 변경은 별도 권한과 검토가 필요하다.
