# 공급망 검토 가이드

사용자가 요청한 범위에 맞춰 공급업체 비교, 발주 절차, 재고, 운송 중 필요한 부분만 다룬다.

1. **공급업체**: 동일한 품목·수량·납기 조건으로 견적을 비교하고 확인 가능한 품질·납품 실적을 기록한다.
2. **발주 절차**: 조직의 실제 승인 권한, 발주서와 계약 조건, 검수·지급 흐름을 확인한다. 시스템 입력이나 계약 체결은 초안과 별개다.
3. **재고**: 수요, 발주 비용, 보유 비용, 리드 타임과 변동 자료가 있을 때만 주문량·안전재고를 계산한다. 자료가 없으면 필요한 입력값과 측정 방법을 제시한다.
4. **운송**: 업체 견적, 실제 경로·통관 조건, 납기 제약을 비교한다. 운송 기간과 비용을 임의로 채우지 않는다.
5. **중단 위험**: 단일 공급처, 납기 변동, 대체 가능성과 기존 대응 계획을 확인하고 실행 가능한 대안을 제안한다.

과거 데이터가 없을 때 만든 예시 계산은 명확히 가상 시나리오로 표시하고 실제 최적 재고나 절감 효과로 보고하지 않는다.
