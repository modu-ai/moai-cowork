# 운영 현황 보고자 (Status Reporter)

## 개요

사용자가 제공하거나 접근을 허용한 자료에서 KPI와 운영 현황을 정리합니다. 데이터 연결이나 갱신 주기가 확인되지 않으면 실시간 대시보드·이상 탐지·예측 분석이 동작한다고 말하지 않습니다.

## 트리거 키워드

상태 보고, 현황 보고, 진행 현황, 마일스톤, KPI, 대시보드, 주간 보고, 월간 보고, 실적 정리, 성과 요약, OKR, 분기 보고, 경영 보고

## 워크플로우

1. **보고 유형 판별**: 주간/월간/분기/연간 중 선택, 보고 대상(팀/부서/경영진) 확인
2. **KPI 수집**: 사용자가 제공한 자료나 실제 접근 가능한 파일에서 수치·기간·정의를 추출하고 출처를 기록
3. **구조 생성**:
   - 핵심 성과 요약 (Executive Summary)
   - KPI 달성 현황 표 (목표 vs 실적, 달성률)
   - 주요 마일스톤 진행 상황
   - 이슈 및 리스크 목록
   - 다음 기간 액션 아이템
4. **검증**: 목표·실적의 기간과 단위가 같을 때만 달성률을 계산하고, 원인이 확인되지 않은 변동은 가설로 표시
5. **형식 선택**: 요청한 텍스트·마크다운·스프레드시트 형식으로 정리하고 발송이 필요하면 초안을 검토

## 보고 원칙

- 지표마다 정의, 산식, 측정 기간, 데이터 출처와 담당자를 적습니다.
- 목표가 없으면 달성률을 만들지 않고 실제 관찰값만 제시합니다.
- 전기 비교는 같은 집계 기준의 두 기간이 있을 때만 합니다.
- 자동 수집과 정기 발송은 해당 연결·권한·일정이 실제로 설정된 경우에만 수행합니다.

## 보고서 템플릿 구조

### 주간 현황 보고 (Weekly Status Report)

```
[주간 보고] {팀/프로젝트명} — {YYYY}년 {M}월 {N}주차

■ 핵심 요약
- 이번 주 주요 성과: ...
- 완료 마일스톤: ...
- 다음 주 핵심 과제: ...

■ KPI 달성 현황
| 지표 | 목표 | 실적 | 달성률 | 추이 |
|------|------|------|--------|------|
| ... | ... | ... | ...% | ▲/▼/— |

■ 이슈 & 리스크
| 구분 | 내용 | 영향도 | 대응 계획 |
|------|------|--------|-----------|

■ 다음 주 액션 아이템
- [ ] ...
```

### 월간 운영 보고 (Monthly Operations Report)

전월 자료가 비교 가능하다면 변동 폭을 적습니다. 원인은 자료로 확인된 것과 확인할 가설을 나눕니다.

## 산출물

- 마크다운 형식 주간/월간 보고서
- KPI 달성 현황 표 (목표/실적/달성률/전기 대비)
- 마일스톤 진행률 요약
- 이슈 및 리스크 매트릭스
- 다음 기간 액션 아이템 목록
- 경영진/팀별 맞춤 어조 조정 버전

## 관련 스킬 (후처리 체인)

보고서의 **서술형 본문**(핵심 요약, 이슈·리스크 설명, 액션 아이템 등)은 수치·기간·출처와 원인 가설을 대조하고, 과장·모호한 표현을 직접 검수합니다. 현재 앱에 아래 스킬이 노출돼 있으면 추가로 사용합니다.

```
collab-status-report → 자체 근거·문체 검수 → (노출된 경우) ai-slop-reviewer → (별도 설치된 경우) korean-humanize
```

- `moai-coworker:ai-slop-reviewer` — 노출된 경우 서술형 본문의 AI 티 패턴을 추가 검수합니다.
- `moai-writer:korean-humanize` — 별도 설치돼 노출된 경우 한국어 보고체를 추가로 다듬습니다. 수치와 미확인 표시는 보존합니다.

KPI 달성 현황 표, 마일스톤 진행률, 이슈·리스크 매트릭스 등 **수치·표 산출물**은 산문 후처리 대상이 아닙니다. 이 스킬에서 마크다운 표를 완성하고, 사용자가 엑셀 파일이나 대시보드를 요청했고 해당 플러그인이 현재 앱에 노출됐을 때만 `moai-officer:doc-xlsx` 또는 `moai-analyst:data-visualizer`로 연결합니다.

## 참고 사항

- **공공기관 보고**: 해당 기관이 제공한 양식과 지침을 확인한 뒤 적용
- **결재 디지털화**: 결재 문서용 포맷(공문서 스타일)으로 변환 지원
- **ESG 연계**: 요청받은 지속가능성 지표가 있으면 적용 대상·기준과 원자료를 먼저 확인
- **보안 주의**: 재무 데이터, 인사 정보 포함 시 배포 범위 재확인 권장

## 문제 해결

| 상황 | 해결 방법 |
|------|-----------|
| 결재 라인 정보 부족 | 조직도나 결재 단계를 알려주시면 수신자별 맞춤 어조로 작성해 드립니다 |
| KPI 데이터 미제공 | 측정 가능한 지표 목록을 먼저 설계해 드릴 수 있습니다 |
| 보고 양식이 정해져 있음 | 기존 양식이나 템플릿을 공유해 주시면 그 형식에 맞춰 작성합니다 |
| 이전 보고서와 비교 필요 | 이전 보고서 내용을 함께 입력해 주시면 전기 대비 분석을 포함합니다 |
