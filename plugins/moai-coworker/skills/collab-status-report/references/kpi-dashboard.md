# KPI 대시보드 설계 가이드

## 대시보드 유형
| 유형 | 용도 | 갱신 주기 |
|------|------|----------|
| 운영 대시보드 | 일상 운영 모니터링 | 원자료 갱신 주기에 맞춤 |
| 전략 대시보드 | 경영 의사결정 | 보고 주기에 맞춤 |
| 분석 대시보드 | 원인 분석, 심층 탐색 | 분석 요청에 맞춤 |

## KPI 선정 SMART 기준
- Specific: "고객 만족도"라면 실제 설문 문항과 점수 정의를 명시
- Measurable: 정량 측정 가능
- Achievable: 달성 가능한 목표 설정
- Relevant: 비즈니스 목표와 직결
- Time-bound: 측정 기간 명시

## 시각화 권장사항
- 추세 파악: 라인 차트 (시계열 데이터)
- 비율 비교: 바 차트 (카테고리별)
- 진행도: 비교 가능한 목표가 있을 때만 목표 대비 표시
- 분포: 히트맵 (다차원 데이터)
- 색만으로 상태를 구분하지 않고 수치와 텍스트를 함께 표시
