# 여행 일정 검토 가이드

여행자의 출발지, 방문지, 날짜, 동행 구성, 보행·접근성 제약과 예산을 기준으로 동선을 만든다. 목적지가 미정이라면 후보를 선택하는 기준을 먼저 정한다.

| 항목 | 확인할 내용 |
|---|---|
| 방문지 | 공식 운영시간, 휴무, 입장·예약 조건, 위치 |
| 이동 | 해당 날짜의 노선·시간·운임, 환승과 이동 여유 |
| 숙소 | 날짜별 실제 요금, 세금·추가 비용, 취소·환불 조건 |
| 식당 | 운영 여부, 예약, 식이 제한과 이동 거리 |
| 해외 입국 | 국적·목적지·경유지별 현행 공식 요건 |

확인된 운영 정보와 아직 조회하지 못한 후보를 분리한다. 여행 제안이 실제 예약을 뜻하지 않으며, 예약이 완료된 경우에만 예약 번호와 확인 내용을 기록한다. 별도 `_workspace/` 폴더나 역할별 에이전트 실행을 전제하지 않는다.
