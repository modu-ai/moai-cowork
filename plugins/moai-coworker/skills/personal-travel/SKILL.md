# 여행 계획

`references/travel-planner.md`를 읽고 사용자의 출발지·목적지·날짜·인원·예산·관심사·이동 제약에 맞는 계획을 만든다. 숙소·식당·교통·관광지를 추천하면 여행 날짜에 유효한 공식 운영 정보와 예약 조건, 최근 가격을 조회하고 출처·조회일을 적는다. 조회하지 못한 항목은 추천 후보나 예산 확인 과제로 표시한다.

## 진행 순서

1. 사용자 조건과 반드시 지킬 제약을 정리한다. 날짜가 없으면 계절·요일에 따른 운영 차이를 단정하지 않고 예시 동선으로 제시한다.
2. 방문 후보의 위치·운영시간·휴무·예약 필요 여부를 실제 자료로 확인한다. 이동 시간과 환승은 확인 가능한 교통 정보로 잡고 일정에 여유를 둔다.
3. 항공·숙소·교통·식사·활동 비용은 동일 날짜·인원·통화의 견적으로 비교한다. 자료가 없으면 항목별 예산 상한과 조회할 경로를 제시한다. 오래된 평균값이나 고정 비수기 할인율을 현재 가격으로 쓰지 않는다.
4. 해외여행은 국적·목적지·경유지·여행 시점에 맞는 공식 입국·여권·비자·안전 정보를 확인한다. 확인 전에는 입국 가능 여부를 확정하지 않는다.
5. 일정표에 확인한 사실, 예약 전 확인 사항, 비용 출처와 취소 조건을 구분한다. 예약·결제는 사용자의 요청과 실제 연결 도구·권한을 확인한 뒤에만 수행하고 결과를 읽어 확인한다.

최종 출력은 날짜별 동선, 비용표, 예약 우선순위와 대안으로 구성하되 사용자가 원한 범위만 담는다. 문체를 다듬을 때 운영시간·가격·출처를 보존한다. 개인 재무 계획은 `moai-accountant:finance-household-budget`, 웨딩 행사는 `moai-coworker:personal-event`를 사용한다.
