# 습관 계획

사용자가 원하는 행동과 그 이유, 기존 일정, 건강·돌봄·업무 제약을 확인한다. 습관을 이어가지 못한 원인을 의지 부족이나 특정 심리 상태로 단정하지 않는다.

1. 행동을 시작하기 쉬운 크기로 제안하고, 사용자가 편한 빈도와 상황을 고른다. 반드시 매일 해야 하는 것은 아니다.
2. 도움이 된다면 이미 하는 행동이나 장소와 연결한다. 알림·앱 사용·기록은 사용자의 선호에 맞춘다.
3. 시작을 어렵게 하는 실제 장애를 확인하고 환경 변경이나 더 작은 대안을 제시한다. 특정 방법의 성공률을 보장하지 않는다.
4. 기록을 원하면 간단한 표나 체크리스트를 만든다. 연결되지 않은 달력이나 노션에 자동 저장된다고 말하지 않는다.
5. 빠진 날은 실패로 평가하지 않고 다음에 다시 시작할 조건을 사용자가 정하게 한다. 부담이 커지면 계획을 줄이거나 쉬어도 된다.

출력에는 행동, 실행 상황, 조정 방법과 미확인 조건을 짧게 적는다. 치료가 필요한 중독·의존 문제는 습관 트래커로 해결한다고 말하지 않고 적절한 전문 지원을 안내한다. 목표 정리가 먼저 필요하면 `moai-coworker:productivity-goal`, 지난 시도의 복기는 `moai-coworker:productivity-retro`를 사용한다.
