# 결혼식 준비 가이드

당사자의 선호, 예식 형태, 지역, 예상 인원, 날짜 범위, 예산 상한을 먼저 확인한다. 가족 역할이나 비용 분담 방식은 추정하지 않고 당사자가 정한 내용을 사용한다.

1. 예식 장소와 식사, 촬영·의상·미용 등 원하는 항목을 분리한다. 필요 없는 패키지 항목은 넣지 않는다.
2. 업체별로 같은 서비스 범위와 날짜의 견적, 추가 비용, 계약금, 변경·취소·환불 조건을 비교한다. 평균 비용이나 계절별 할인율을 개인 견적으로 대체하지 않는다.
3. 준비 순서는 장소 확정과 계약 조건, 참석 안내, 당일 동선처럼 선후 관계로 정한다. 날짜가 없으면 상대적 준비 단계로 적는다.
4. 결제·예약·초대장 발송은 승인과 실제 실행 수단을 확인한 뒤 수행한다. 계약 전에는 문의·비교·결정 대기로 표시한다.

결과는 당사자가 결정할 항목, 확인한 견적, 남은 질문과 실행 담당자를 구분해 전달한다.
