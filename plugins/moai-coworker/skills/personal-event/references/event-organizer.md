# 행사 기획 가이드

행사의 목적과 대상, 날짜·장소·참석 규모·예산, 접근성 요구를 확인한다. 필요한 순서대로 장소 확보, 프로그램 구성, 안내, 장비·식사, 현장 운영, 사후 정리를 계획한다. 모든 행사에 같은 업체나 역할을 배정하지 않는다.

| 준비 항목 | 필요한 결정 | 근거·견적 | 담당 | 기한·의존 관계 | 상태 |
|---|---|---|---|---|---|

장소·장비·식사 업체를 비교할 때 같은 조건의 최신 견적, 취소·변경 조건, 추가 요금을 확인한다. 당일 운영에는 동선, 연락망, 대체 장소·장비, 응급 상황 대응을 행사 규모에 맞게 적는다. 예약·결제·참석 안내가 수행되지 않았다면 초안 상태로 표시한다.
