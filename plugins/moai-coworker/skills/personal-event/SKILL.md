# 행사 기획

요청에 따라 `references/event-organizer.md` 또는 `references/wedding-planner.md`를 읽고 필요한 항목만 적용한다. 사용자가 제공한 날짜·지역·인원·예산·계약 자료가 계획의 기준이다. 장소와 업체의 실제 가격·할인·예약 가능 여부는 최신 견적이나 공식 안내를 확인하기 전까지 확정하지 않는다.

## 작성 순서

1. 행사 목적, 원하는 방식, 참석자, 지역, 날짜 범위, 예산 상한과 우선순위를 정리한다. 미정 항목은 선택지와 확인 질문으로 남긴다.
2. 준비 단계와 당일 진행 순서를 의존 관계에 맞춰 적는다. 사용자가 기한을 주지 않았다면 임의의 D-6개월 일정을 강제하지 않는다.
3. 항목별 예산은 사용자가 준 견적과 계약 조건으로 계산한다. 견적이 없으면 예산 배분 초안과 비교할 항목을 제시하고 실거래가로 표시하지 않는다.
4. 장소·식사·접근성·안전·날씨·장비·변경·취소 조건 중 해당 행사에 필요한 위험을 점검한다.
5. 예약, 결제, 초대장 발송, 업체 연락은 사용자 요청과 실제 연결 도구·권한을 확인한 뒤 진행한다. 계획서와 실행 완료를 분리한다.

출력은 요청에 맞는 기획서, 준비 목록, 진행표, 견적 비교표 중 필요한 것만 만든다. 문체를 다듬을 때 가격·계약 조건과 미확인 표시를 보존한다. 허니문 일정은 `moai-coworker:personal-travel`, 계약서의 법적 검토는 `moai-lawyer:legal-contract-review`를 사용한다.
