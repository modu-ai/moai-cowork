# 회고 정리

사용자가 돌아보려는 기간과 목적을 확인한다. 실제 경험이나 기록이 없으면 회고 결과를 대신 채우지 않고 질문 또는 빈 양식을 제공한다. 5분 회고, KPT, 키워드 방식은 선택지이며 모두에게 같은 형식을 강제하지 않는다.

## 선택할 수 있는 형식

- **한 줄 회고**: 이번 기간의 중요한 일과 다음에 살펴볼 일을 한두 문장으로 기록한다.
- **KPT**: 유지할 일, 어려웠던 점, 시도할 일을 나눈다. 팀 회고라면 참여자별 의견과 합의된 행동을 구분한다.
- **키워드 회고**: 사용자가 고른 단어에 관련 경험과 근거를 붙인다.

실제 사용자가 말한 사실, 해석, 다음 시도를 분리한다. 다음 행동이 아직 정해지지 않았다면 반드시 하나를 만들어 넣지 않는다. 약속한 행동이나 성과를 자동 추적한다고 말하지 않고, 사용자가 원하는 기록 위치와 점검 주기를 제안한다.

가벼운 개인 회고는 여기서 다루고, 프로젝트 진행 상황을 근거로 보고하는 작업은 `moai-coworker:collab-pm-report`를 사용한다. 정신건강 상태를 진단하거나 업무 실패의 심리적 원인을 단정하지 않는다.
