# 상품 이미지·영상 제작

## 입력 확인

상품의 실제 사진·사양·브랜드 자료, 원하는 산출물, 사용 채널, 필요한 화면 비율을 받습니다. 사진이나 사양이 없으면 확인되지 않은 형태·성능·효과를 이미지와 카피에 넣지 않습니다. 실존 인물·브랜드 캐릭터 사용 권한과 광고 표현의 근거도 확인합니다.

## 제작 경로

1. **이미지**: ChatGPT Work에서 네이티브 이미지 생성 도구가 노출되면 GPT Image 2.5 경로를 사용합니다. 호스트에 해당 도구가 없으면 사용할 수 있는 이미지 도구를 확인해 사용자에게 경로를 밝힙니다. 사용자가 Higgsfield를 지정했다면 공식 Higgsfield MCP에서 현재 노출된 이미지 도구와 모델을 확인합니다. 특정 모델명이나 이미지 입력 기능을 확인 없이 가정하지 않습니다.
2. **영상**: 사용자가 영상을 요청한 경우에만 공식 Higgsfield MCP 등 실제 연결된 영상 도구의 입력·길이·가격·상태를 확인합니다. 도구가 없거나 작업이 실패하면 영상을 완료로 표시하지 않습니다.
3. **채널별 변환**: 대상 채널의 현재 광고·업로드 규격을 확인한 뒤 이미지의 비율·크기·안전 영역을 조정합니다. Pillow 등 사용 가능한 편집 도구로 이미지 변환이 가능해도 영상 길이·자막 편집까지 자동 처리된다고 가정하지 않습니다.
4. **검수**: 상품 외형, 표시 문구, 잘린 로고·가격, 저작권·초상권 자료, 선택한 채널 규격을 확인합니다. AI 생성 표기 의무와 방식은 해당 채널의 현행 규정을 확인합니다.

## 산출물 보고

각 산출물에 파일 경로 또는 접근 가능한 URL, 사용한 도구, 생성·변환 상태, 검수 결과를 기록합니다. 실패한 단계와 미확인 규격은 별도로 표시합니다. 실제 생성하지 않은 이미지·영상, 확인하지 않은 비용, 보장되지 않은 성능 수치는 예시 결과처럼 적지 않습니다.

## 연계

- 상세페이지의 섹션별 합성이 필요하면 `commerce-detail-page-image`를 사용합니다.
- 원본 사진에서 부족한 컷을 찾으려면 `commerce-product-photo-brief`를 사용합니다.
- Higgsfield 지정 작업은 공식 Higgsfield MCP의 현재 도구 설명을 따릅니다.
