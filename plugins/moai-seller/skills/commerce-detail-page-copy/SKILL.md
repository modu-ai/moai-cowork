# 상세페이지 카피

## 입력

상품명, 실제 사양·사진, 판매 가격, 대상 고객, 판매 채널, 근거 자료를 확인합니다. 후기·통계·인증·전문가 인용·보증·재고·마감일은 출처가 있을 때만 사용합니다. 자료가 없으면 해당 문구를 생략하고 필요한 자료를 표시합니다. URL이나 이미지를 열 수 없다면 페이지 진단이 제한됨을 밝힙니다.

## 작업 방식

- **기본**: `references/13-sections.md`를 선택 가능한 구조로 사용해 Hero, Pain, Problem, Story, Solution, How, Proof, Authority, Benefits, Risk, Compare, Filter, CTA 카피를 만듭니다. 상품에 맞지 않거나 근거가 없는 섹션은 억지로 채우지 않습니다.
- **`--mode diagnose`**: 실제로 확인한 페이지 요소만 평가합니다. 점수를 매긴다면 기준과 확인 범위를 함께 기록하고, 보지 못한 항목에는 점수를 주지 않습니다.
- **`--mode copy`**: 사용자가 제공한 고객 조사나 JTBD 자료를 토대로 필요한 만큼 대안을 만듭니다. 페르소나 이름·나이·직업을 임의로 사실처럼 만들지 않습니다. 25/50/25 같은 분량 비율은 참고용이며 상품과 채널에 맞게 조정합니다.

## 검수

1. 제품 특징을 고객에게 어떤 의미가 있는지 풀어 쓰되 확인되지 않은 효과를 약속하지 않습니다.
2. 건강·식품·화장품·의료 관련 표현은 근거와 현재 적용 규정을 확인합니다. `commerce-ad-claim-compliance-kr`의 결과도 법적 승인으로 단정하지 않습니다.
3. 사용 가능한 경우 `moai-coworker:ai-slop-reviewer`와 `moai-writer:korean-humanize`를 통해 문장을 다듬고 원문 사실관계를 다시 대조합니다. 호출하지 못한 검수는 완료로 표시하지 않습니다.
4. 가격·할인·환불·재고·마감, 후기·통계·인용의 출처와 날짜를 최종 카피에 연결합니다. 채널 정책은 게시 전 해당 채널의 현재 공지를 확인합니다.

## 출력

섹션별 카피와 마크다운 미리보기, 근거가 필요한 자리, 확인한 출처, 미검수 항목을 함께 제공합니다. `slop_review` 같은 상태 필드는 실제 검수 결과가 있을 때만 씁니다. 이미지가 필요하면 `commerce-detail-page-image`, HTML 상세페이지가 필요하면 `commerce-product-detail`로 넘깁니다.
