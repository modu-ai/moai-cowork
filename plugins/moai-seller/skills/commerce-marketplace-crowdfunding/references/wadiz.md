# 와디즈 프로젝트 확인 가이드

와디즈에서 펀딩·프리오더·스토어는 운영 방식이 다릅니다. 상품 종류만으로 유형을 정하거나 동일한 수수료·심사·영상 조건을 적용하지 않습니다. [와디즈 공식 서비스 구분](https://helpcenter.wadiz.io/hc/ko/articles/25514036821529-%EC%8A%A4%ED%86%A0%EC%96%B4%EC%99%80-%ED%8E%80%EB%94%A9%EC%9D%98-%EC%B0%A8%EC%9D%B4%EC%A0%90%EC%9D%80-%EB%AC%B4%EC%97%87%EC%9D%B8%EA%B0%80%EC%9A%94)을 먼저 확인합니다.

## 1. 메이커 자격과 유형

- 한국 메이커의 펀딩에는 개인·개인사업자·법인사업자가 가능하다고 [공식 자격 안내](https://helpcenter.wadiz.io/hc/ko/articles/25375740913817-%EB%88%84%EA%B5%AC%EB%82%98-%EB%A9%94%EC%9D%B4%EC%BB%A4%EA%B0%80-%EB%90%A0-%EC%88%98-%EC%9E%88%EB%82%98%EC%9A%94)가 구분합니다. 프리오더·스토어와 해외 메이커에는 다른 조건이 있습니다.
- 실제 신청 계정의 메이커 유형, 정산 정보, 제출 서류를 확인합니다. 사업자등록증이나 신분증을 모든 프로젝트의 필수 서류로 단정하지 않습니다.
- 투자형 문의는 별도 서비스의 현재 자격·계약·규제를 확인합니다. 이 리워드 가이드로 투자 조건을 안내하지 않습니다.

## 2. 프로젝트 준비

| 항목 | 확인할 자료 |
| --- | --- |
| 결과물 | 실제 제작 단계, 샘플·시연 자료, 제공할 리워드 |
| 신뢰와 안전 | 품목별 표시·인증·허가, 이미지·영상 사용 권리 |
| 제작과 배송 | 수량, 원가, 제작·포장·배송 계획과 지연 대응 |
| 후원 조건 | 목표 금액 근거, 리워드별 가격·수량·발송 약속 |

인증이나 샘플이 필요한지는 상품과 프로젝트 유형의 현재 심사 안내에서 확인합니다. 영상 길이·해상도·자막, 대표 이미지와 본문 이미지 규격도 프로젝트 에디터의 현행 조건을 확인합니다. `1080×12720` 같은 작업용 합성 크기를 업로드 성공 규격으로 쓰지 않습니다.

## 3. 비용과 정산

[와디즈 공식 요금제 안내](https://helpcenter.wadiz.io/hc/ko/articles/25375315142169-%EC%99%80%EB%94%94%EC%A6%88-%EC%9A%94%EA%B8%88%EC%A0%9C-%EC%88%98%EC%88%98%EB%A3%8C-%EC%95%88%EB%82%B4)는 프로젝트 유형에 관계없이 적용하는 기본 요금제를 안내하면서, 메이커 지역·제출일·선택형 컨설팅과 계약별 예외를 구분합니다. 고정 수수료율이나 정산 소요일을 모든 계정에 적용하지 않습니다.

1. 현재 계정에 적용되는 계약·요금제·부가세·결제 및 정산 조건을 확인합니다.
2. 리워드별 제작비, 포장비, 배송비, 세금, 광고비와 현재 계약 비용을 같은 기준으로 계산합니다.
3. 조건이 확인되지 않으면 순수익·정산일은 `미확인`으로 표시합니다.

## 4. 스토리와 리워드

- 만든 이유, 결과물, 제작 단계, 실제 시연, 리워드 구성, 일정과 위험 대응을 원자료에 근거해 작성합니다.
- 할인율·한정 수량·정가 비교는 사용자가 제공한 가격표·재고·실제 판매 계획과 대조합니다. 고정 할인 단계나 펀딩 후 가격 규칙을 만들어 내지 않습니다.
- “세계 최초”, 인증 완료, 배송 보장 같은 표현은 증빙 없이 쓰지 않습니다.

## 5. 제출과 운영

- 현재 에디터에서 필수 입력, 심사 상태, 공개 가능 일정과 수정 요청을 확인합니다. 심사 기간이나 담당 PD 제공을 모든 프로젝트에 약속하지 않습니다.
- 오픈·결제·정산은 계정에서 실제 완료 상태를 확인한 뒤 기록합니다.
- 지연·수량 변경이 생기면 프로젝트 약속과 현재 채널 정책에 따라 후원자에게 정확히 안내합니다.
