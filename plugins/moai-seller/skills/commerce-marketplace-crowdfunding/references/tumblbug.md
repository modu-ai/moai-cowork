# 텀블벅 프로젝트 확인 가이드

텀블벅의 펀딩·프리오더·상시판매를 구분하고, 현재 프로젝트 에디터의 조건을 확인합니다. 창작 분야라는 이유만으로 심사가 가볍거나 일정 금액을 모을 것이라고 예측하지 않습니다.

## 1. 창작자 자격

[텀블벅 공식 프로젝트 올리기 안내](https://help.tumblbug.com/ko/categories/%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%98%AC%EB%A6%AC%EA%B8%B0-2aba4029)는 개인과 사업자가 프로젝트를 시작할 수 있다고 안내하면서 계좌·본인 확인과 품목별 심사 자료를 구분합니다.

- 창작자 유형, 정산 계좌, 본인 확인, 해당 품목의 추가 서류를 확인합니다. 개인은 본인 계좌를 쓰고 사업자는 대표자 계좌도 허용한다는 현행 안내를 확인합니다.
- 개인 프로젝트에 사업자등록증을 요구하거나 사업자 프로젝트에 개인 신분증만으로 충분하다고 단정하지 않습니다.
- 식품·디지털 콘텐츠·행사 등 품목별 허가·표시·권리 자료는 실제 프로젝트 유형과 공식 심사 안내를 대조합니다.

## 2. 프로젝트 구성

- 창작자와 제작 동기, 제공할 결과물, 현재 제작 단계, 실제 시연·사진, 후원 선물, 목표 금액 근거, 전달 일정과 위험 대응을 정리합니다.
- 대표 이미지·본문 자료의 비율·형식·용량은 현재 에디터에서 확인합니다. 다른 채널의 이미지 규격을 옮겨 쓰지 않습니다.
- 후원자 후기나 사용자 수, 예상 모금액, 평균 후원액, 영상 기여도를 자료 없이 만들지 않습니다.

## 3. 선물과 가격

- 선물은 실제 제작·배송 가능한 결과물에서 정하고, 가격·수량·발송일을 원가와 확보한 생산 능력에 맞춥니다.
- 소액 후원·번들·한정판은 선택 가능한 구성안입니다. 고정 가격대와 한정 수량을 권장값으로 적용하지 않습니다.
- 이미 공개한 약속과 변경 가능 범위는 프로젝트 에디터와 현재 약관에서 확인합니다.

## 4. 수수료와 정산

[현행 텀블벅 수수료 정책](https://help.tumblbug.com/ko/articles/%EC%88%98%EC%88%98%EB%A3%8C-%EC%A0%95%EC%B1%85-2ee4a118)은 선택 요금제, 플랫폼 이용 수수료, 결제 등 대행수수료와 정산 절차를 구분합니다. 단일 수수료율이나 종료 후 고정 일수를 모든 프로젝트에 적용하지 않습니다.

1. 현재 프로젝트에 선택한 요금제와 결제·정산·세금 조건을 확인합니다.
2. 최종 결제 성공 금액과 명세서가 확인되기 전에는 정산액을 확정하지 않습니다.
3. 지급 보류·환불·취소 조건은 현재 정책과 프로젝트 계약에서 확인합니다.

## 5. 심사와 운영

- 에디터의 필수 입력과 심사 결과를 확인하고, 수정 요청이 있으면 실제 보완 자료를 준비합니다. 심사 기간이나 승인 가능성을 약속하지 않습니다.
- 창작 과정과 배송 진행을 사실에 맞게 알리고, 질문에는 확인된 정보로 답합니다. 일률적인 업데이트 주기나 응답 시한을 필수 정책으로 제시하지 않습니다.
- 공개·결제·정산·배송 상태는 실제 계정 기록으로 확인합니다.
