# 크라우드펀딩 프로젝트 기획

## 목적

와디즈·텀블벅 프로젝트의 초안을 작성하고, 공개 전에 확인해야 할 계정별 조건을 정리합니다.
펀딩·프리오더·스토어는 서로 다른 방식입니다. 와디즈의 [서비스 구분 안내](https://helpcenter.wadiz.io/hc/ko/articles/25514036821529-%EC%8A%A4%ED%86%A0%EC%96%B4%EC%99%80-%ED%8E%80%EB%94%A9%EC%9D%98-%EC%B0%A8%EC%9D%B4%EC%A0%90%EC%9D%80-%EB%AC%B4%EC%97%87%EC%9D%B8%EA%B0%80%EC%9A%94)와 텀블벅의 현재 프로젝트 에디터를 확인합니다.

## 트리거

크라우드펀딩, 와디즈, wadiz, 텀블벅, tumblbug, 펀딩 프로젝트, 리워드 펀딩,
선주문, 사전판매, 메이커, 펀딩 후기, 해피빈 펀딩, 크라우드 펀딩 카피

## 작업 순서

1. **프로젝트 확인** — 상품·창작물의 실제 제작 단계, 제공할 결과물, 대상 국가, 메이커 유형, 확보한 인증·사진·영상, 예상 제작비·배송비·일정을 받습니다. 없는 값은 `미확인`으로 남깁니다.
2. **채널 후보 제시** — 사용자가 원하는 거래 방식과 현재 채널의 프로젝트 유형을 대조합니다. 품목만으로 와디즈·텀블벅을 자동 확정하지 않습니다. 투자형 요청은 리워드 펀딩과 구분해 해당 서비스의 현행 자격·규제를 별도로 확인합니다.
3. **현재 조건 확인** — 선택한 계정의 프로젝트 에디터·계약과 공식 도움말에서 메이커 자격, 프로젝트 유형, 심사·인증 자료, 이미지·영상 조건, 수수료·세금, 결제·정산·취소·환불, 공개 일정을 확인합니다. 계정에 접근할 수 없으면 필요한 확인 목록을 반환하고 초안임을 표시합니다.
4. **스토리와 리워드 설계** — 실제 제작 근거로 목적, 결과물, 제작 단계, 리워드, 목표 금액의 산출 근거, 배송 약속과 위험 대응을 작성합니다. 할인율·한정 수량·성과 전망을 임의로 만들지 않습니다.
5. **비용 점검** — 리워드별 제작·포장·배송·세금·현재 계약의 플랫폼 비용을 같은 기준으로 합산합니다. 비용이나 수수료가 없으면 손익·정산액을 확정하지 않습니다.
6. **검토와 공개** — 상품 표시와 인증, 가격·수량·일정, 이미지·영상 권리, 변경·환불 조건을 사용자 원자료와 대조합니다. 공개 또는 계정 변경은 사용자 승인 후 진행합니다.
7. **운영** — 실제 승인된 일정과 채널 정책에 맞춰 새소식·질문·배송 지연을 관리합니다. 공개·결제·정산이 성공했다고 기록하려면 해당 계정의 결과를 확인합니다.

## 작성 결과

다음 구조로 사실과 미확인 항목을 구분합니다. 가격·예정 날짜는 사용자 자료와 현재 계정 조건으로 확인합니다. 과거 모금액·판매 실적·심사 승인·정산 결과는 계정 기록을 확인하기 전까지 `미검증`으로 표시합니다.

```json
{
  "channel_candidate": "wadiz 또는 tumblbug",
  "project_type": "계정에서 확인한 유형 또는 미확인",
  "eligibility": {"checked": false, "missing": []},
  "story_draft": ["만드는 이유", "결과물과 제작 단계", "리워드", "일정과 위험 대응"],
  "rewards": [],
  "costs": {"source": "현재 계약 또는 미확인", "estimate": null},
  "submission_requirements": [],
  "open_questions": [],
  "publication_status": "초안"
}
```

간단한 카피 요청에는 사용자가 제공한 사실만으로 문안을 작성하고, 등록·가격·정산 실행에 필요한 자료가 없으면 해당 단계만 보류합니다.

## 연결 자료

- `references/wadiz.md` — 와디즈의 현재 계정·프로젝트 유형 확인 항목
- `references/tumblbug.md` — 텀블벅의 현재 계정·품목별 확인 항목

- `moai-coworker:ai-slop-reviewer`·`moai-writer:korean-humanize` — 설치된 경우 선택적으로 표현 검수. 미실행 시 완료로 표시하지 않습니다.

## 주의

- 인증·표시·세금·환불과 후원자 약속은 실제 상품, 계정 계약, 현행 정책과 대조합니다. 확인되지 않은 자격이나 오픈 승인을 단정하지 않습니다.
- 후기·판매 실적·할인율·한정 수량·영상 효과를 만들어 내지 않습니다.
- 투자형 상품의 법적 자격이나 수익을 이 리워드 펀딩 초안으로 판단하지 않습니다.
