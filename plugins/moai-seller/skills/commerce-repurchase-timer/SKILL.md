# 재구매 시점 설계

## 입력

주문별 고객 ID·상품·결제일·수량·취소·반품 상태, 관측 기간, 마케팅 수신 동의와 거부 목록을 확인한다. 고객 자료가 없다면 제품의 일반적인 사용 주기를 실제 구매 간격으로 단정하지 않는다.

## 분석

1. 같은 고객·같은 상품군의 유효 주문을 시간순으로 정렬하고 재구매 간격을 계산한다. 취소·반품·대량 구매·구독 주문은 별도로 검토한다.
2. 중앙값과 분포, 고객별 편차를 확인한다. 평균 하나로 모든 고객에게 같은 날 연락하지 않는다.
3. 첫 구매자와 기존 고객의 코호트를 분리하고 관측 가능한 기간만 비교한다. 아직 재구매 기회가 오지 않은 고객을 이탈자로 분류하지 않는다.
4. 연락 시점은 자료의 분포·재고·배송 기간·채널 수신 동의를 고려해 후보를 만든다. 80%, 110%, 150% 같은 고정 비율이나 화장품 60일 등의 보편값을 기본으로 쓰지 않는다.
5. 메시지의 혜택·긴급성·재고·배송 약속은 실제 조건에 맞춘다. 수신 거부 고객에게 발송하지 않는다.

## 측정

대상 고객 수, 발송·열람·구매 수, 대조군, 증분 이익, 할인 비용, 수신 거부율을 같은 기간으로 확인한다. 재구매율의 분모와 관측 종료일을 명시한다. 고정 리드 점수나 도입 후 성과 상승을 검증 없이 약속하지 않는다.

## 산출물

고객군별 관측 구매 간격, 연락 시점 후보, 근거, 사용할 수 있는 채널, 필요한 동의, 실험·중단 기준을 표로 제공한다. 실제 발송은 연결된 도구와 승인된 대상·문구를 확인한 뒤 진행한다.
