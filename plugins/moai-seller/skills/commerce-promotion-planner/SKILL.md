# 프로모션 기획

## 입력

상품·고객·채널, 행사 목표, 재고와 공급 가능량, 정상가·원가·수수료·배송비, 가용 할인 범위, 고객 발송 동의를 확인한다. 빠진 값은 **미확인**으로 남긴다. 매출 확대, 신규 고객, 재고 정리 중 우선 목표를 정하고 기준선과 측정 지표를 함께 기록한다.

## 유형 선택

| 유형 | 먼저 확인할 것 |
|---|---|
| 사전 예약 | 공급·배송 일정, 취소·환불 조건, 실제 우선 혜택 |
| 기간 한정 | 실제 시작·종료 시각, 재고, 가격 적용 범위 |
| 고객 감사 | 대상 고객 정의, 혜택의 공정성, 발송 동의 |
| 신상품 소개 | 입증 가능한 상품 특징, 기대 수요, 재고 |

한정·마감·남은 수량은 실제 운영 조건과 일치할 때만 쓴다. 기념일, 인증, 임상, 사회적 성과는 증빙이 없으면 캠페인 명목으로 만들지 않는다. 다른 브랜드의 성과는 출처·기간·조건을 확인한 경우에만 참고한다.

## 손익과 운영

정상가·행사가·판매 수수료·상품 원가·배송·쿠폰·사은품 비용을 같은 주문 단위로 계산한다. 고객별 할인 중복, 환불·반품, 품절, 가격 되돌리기와 고객 문의 대응을 확인한다. 행사 전후 매출 비교에는 광고비와 주문 귀속 기간을 맞춘다. 목표 수치나 수익률을 실측 없이 확정하지 않는다.

## 발행 전 확인

- 상품 정보와 혜택 조건이 랜딩 페이지·주문 화면에서 일치하는가
- 기간·수량·대상 고객·취소·환불 조건이 실제 운영과 맞는가
- 할인 후 공헌이익과 배송 능력이 감당 가능한가
- 광고 표현과 발송 동의·수신 거부 요건을 현행 규정으로 확인했는가
- 행사 결과를 측정할 기준선과 데이터 접근 권한이 있는가

문구 검토에는 `commerce-ad-claim-compliance-kr`를, 고객 메시지 발송 요건에는 `commerce-message-compliance-kr`를 사용할 수 있다. 연결되지 않은 도구의 검수를 통과했다고 적지 않는다.

## 출력

행사 목표, 대상, 혜택 조건, 손익 계산과 가정, 운영·문의 처리, 발행 전 확인 결과, 측정 계획을 한 문서에 정리한다. Notion 페이지는 연결된 도구가 있고 사용자가 그곳에 기록해 달라고 요청한 경우에만 만든다. 그 외에는 복사 가능한 초안을 제공한다.
