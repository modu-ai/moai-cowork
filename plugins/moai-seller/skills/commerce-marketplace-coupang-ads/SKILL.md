# 쿠팡 광고 보고서 분석과 조정안

## 자료와 권한

분석 기간, 광고 계정, 캠페인·상품·검색어 보고서, 광고비와 전환매출 정의,
주문 취소·반품 반영 기간, 상품별 실제 공헌이익을 확인합니다. 보고서가 없으면
수치에 근거한 증액·중단·제외 결론을 만들지 않고 필요한 열과 조회 경로를
안내합니다. 광고 계정 변경은 현재 도구 권한과 사용자의 승인 범위를 확인합니다.

[쿠팡 광고 공식 안내](https://ads.coupang.com/new/intro)는 AI스마트광고,
매출최적화광고, 매출스타트광고, 수동성과형광고 등 광고 상품을 설명합니다.
현재 계정에 보이는 캠페인 유형·예산·자동규칙·제외 기능을 확인하고 적용합니다.
모든 계정에 같은 세 유형이나 한 상품당 한 캠페인이 맞다고 가정하지 않습니다.

## 분석 순서

1. **지표 정합**: 같은 기간·상품·귀속 기준의 광고비, 클릭, 주문,
   광고 전환매출을 대조합니다. 검색·비검색 지면별 자료가 실제 보고서에
   있으면 나누어 봅니다. 자료가 없으면 지면별 성과를 추정하지 않습니다.
2. **손익 비교**: `commerce-margin-calculator`의 공헌이익과 손익분기
   ROAS 계산 기준을 사용합니다. 광고 화면의 매출과 판매자 결제·정산액의
   VAT·쿠폰·취소·귀속 기준을 맞춥니다. 화면 ROAS에 일률적인 10% 보정을
   적용하지 않습니다. 분모가 0이면 비율을 만들지 않습니다.
3. **변경안**: 예산, 목표 ROAS, 키워드 제외, 상품·캠페인 분리는
   실제 계정 기능과 측정된 상품별 성과에 따라 후보로 제시합니다.
   고정 증액률·중단 임계값·키워드 개수·일예산을 보편 규칙으로 쓰지 않습니다.
4. **안전 확인**: 자동규칙은 발동 조건·최대 지출·중복 실행·되돌리기를
   확인합니다. 쿠폰 부담, 오디언스 설정과 과금 범위도 현재 계약에서
   확인합니다. 제안과 실제 계정 변경을 분리해 기록합니다.
5. **사후 측정**: 변경 전후 같은 귀속 기간의 광고비·전환매출·주문 공헌이익,
   취소·반품을 비교합니다. 광고가 없었어도 발생했을 주문과 외부 변동을
   고려해 단순 전후 차이를 증분 효과로 확정하지 않습니다.

## 결과

확인한 보고서의 계정·기간·조회일, 지표 정의와 원본, 상품별 손익,
수정 후보와 근거, 미확인 항목, 승인·실행 여부를 적습니다.
광고 계정을 실제로 바꾸지 않았다면 `조정안`으로 표시합니다.
연결되지 않은 광고 도구의 설정 변경을 완료로 표시하지 않습니다.

광고 소재 문구 검토는 `commerce-ad-claim-compliance-kr`, 상품별 마진은
`commerce-margin-calculator`, 다채널 성과 비교는
`moai-marketer:marketing-performance-report`로 연결합니다.
