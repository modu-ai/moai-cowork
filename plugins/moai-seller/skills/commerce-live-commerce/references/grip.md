# 그립 방송 확인 항목

[그립 공식 비즈니스센터](https://business.grip.show/)는 판매자 직접 방송과
그리퍼에게 상품 판매를 맡기는 경로를 모두 안내합니다. 현재 계정의
입점·방송 권한, 교육·지원, 비용과 정산 조건을 확인한 뒤 방식을 고릅니다.

## 직접 방송과 협업 비교

| 방식 | 확인할 것 |
| --- | --- |
| 판매자 직접 방송 | 진행 인력, 상품 시연, 송출 도구, 계정 권한 |
| 그리퍼 협업 | 진행자 선정, 보수, 광고 표시, 원본·클립 사용권 |

상품군과 고객은 실제 주문·시청 자료로 판단합니다. 특정 연령대만 이용한다거나
모든 방송에 인플루언서가 필요하다고 단정하지 않습니다.
플랫폼 비용과 협업 보수는 현재 계약에 따라 각각 계산합니다.

방송 후 시청·주문·반품·비용을 같은 기간으로 비교합니다. 팔로워 대비 시청률이나 전환율을 보편 목표로 제시하지 않습니다.
