# 라이브 진행 스크립트 작성

방송 길이와 상품 수는 사용자 요청, 실제 시연 시간, 질문 대응 인력에 맞춰
정합니다. 아래 순서는 대본의 뼈대이며 모든 방송에 같은 분량을 강제하지 않습니다.

## 대본 뼈대

1. **오프닝** — 방송 목적과 오늘 보여줄 상품을 말합니다. 확인된 혜택이 있으면 적용 대상과 기간을 정확히 알립니다.
2. **시연** — 실제 제품과 검증된 사양을 보여줍니다. 비교·효능·안전성 주장은 출처를 확인하고 범위를 넘지 않습니다.
3. **질문 응대** — 구매자가 묻는 가격·옵션·배송·교환 조건을 현재 판매 정보와 대조합니다. 모르면 즉답을 꾸미지 않고 확인 후 안내합니다.
4. **중간 안내** — 늦게 들어온 시청자가 필요한 상품·혜택·구매 경로를 이해하도록 간단히 반복합니다.
5. **마무리** — 실제 종료 시각, 재고와 혜택 조건을 다시 확인합니다. 제한이 없다면 카운트다운이나 품절 압박을 만들지 않습니다.

## 문구 자리표시자

> 오늘은 [확인된 상품명]의 [실제로 보여줄 기능]을 시연합니다.
> 가격은 [판매자 화면에서 확인한 가격]이고, [확인된 배송·교환 조건]을 적용합니다.
> 궁금한 점은 채팅으로 남겨 주세요. 확인할 수 없는 내용은 방송 후 공식 채널로 안내하겠습니다.

대괄호는 검증된 값으로 교체하거나 해당 문장을 삭제합니다. 정가·할인율·후기·재고·사은품·당첨자·자동 저장 여부를 만들어 넣지 않습니다.

## 송출 전·후

카메라·마이크·네트워크·상품 연결을 현재 채널의 도구에서 시험합니다.
고객 알림이나 이벤트는 실제 설정과 동의를 확인합니다. 방송 후에는
시청·주문·취소·비용 지표의 정의와 기간을 적고 과거 기준선과 비교합니다.
고정 전환율·시청 시간·객단가 목표를 검증 없이 쓰지 않습니다.
