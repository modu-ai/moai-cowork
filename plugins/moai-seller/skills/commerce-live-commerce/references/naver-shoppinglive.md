# 네이버 쇼핑라이브 확인 항목

[스마트스토어 고객센터의 쇼핑라이브 안내](https://help.sell.smartstore.naver.com/faq/content.help?faqId=5441)에서
현재 방송 자격과 송출 방법을 확인합니다. 계정 등급, 상품 유형, 방송 방식에 따라
사용 가능한 기능이 다를 수 있으므로 판매자센터 화면과 함께 확인합니다.

## 방송 전

- 연결할 상품, 실제 판매가·쿠폰·배송 조건, 재고와 방송 시간을 확인합니다.
- 현재 계정에서 방송 등록·송출 도구·알림·다시보기 기능이 열리는지 확인합니다.
- 카메라·마이크·연결 상태를 시험합니다. 특정 화질이나 장비를 모든 판매자의 필수 조건으로 쓰지 않습니다.
- 고객에게 알림을 보내려면 수신 동의, 채널 정책, 실제 발송 권한을 확인합니다.

## 비용과 결과

[네이버의 수수료 안내](https://help.sell.smartstore.naver.com/faq/content.help?faqId=15759)는
쇼핑라이브 유형과 유입 경로 등에 따라 비용 항목이 달라짐을 설명합니다.
현재 계정의 판매수수료·라이브 관련 비용·쿠폰 부담을 구분해 손익에 넣습니다.
고정 수수료율이나 검색 우대를 약속하지 않습니다.

방송 후에는 실제 제공된 시청·주문·취소 자료와 광고비를 같은 기간으로 비교합니다. 시청 시간과 전환율의 보편 목표값을 이 문서에서 만들지 않습니다.
