# 쿠팡 라이브 확인 항목

[쿠팡라이브 공식 시작 안내](https://ads.coupang.com/coupanglive_start/)는
WING 판매자와 서플라이어허브 판매자의 진입 경로와 매뉴얼을 따로 제공합니다.
판매자 유형을 먼저 확인하고 해당 계정에서 현재 라이브 기능의 노출·신청 자격·
상품 연결·송출 방법을 확인합니다. 공개 안내만으로 모든 판매자에게
라이브 기능이 제공된다고 단정하지 않습니다.

## 방송 전

- 계정에 표시되는 라이브 메뉴와 상품·배송 유형별 사용 조건을 확인합니다.
- 실제 재고·판매가·쿠폰·배송 예정일을 상품별로 확인합니다. 로켓배송이나 다음 날 도착을 모든 상품에 약속하지 않습니다.
- 계정에서 제공하는 송출 도구, 알림, 다시보기와 광고 기능을 확인합니다.

## 비용과 결과

판매 수수료, 배송·풀필먼트 비용, 방송 관련 비용과 광고비를 현재 계약으로
구분해 계산합니다. 고정 수수료율, 검색 우대, 특정 고객 연령대나 전환율을
이 문서의 규칙으로 쓰지 않습니다. 방송 뒤 실제 주문·취소·반품을 확인합니다.
