# 라이브 커머스 기획과 진행 스크립트

## 먼저 확인할 자료

요청한 문구나 기획에 필요한 범위에서 상품 사양·가격·재고·배송·교환 조건,
판매 채널, 계정의 방송 권한, 방송 목적과 길이, 진행자·장비·예산,
이전 방송 자료를 확인합니다. 간단한 오프닝 문구에는 방송 장비나 예산을
필수 입력으로 요구하지 않습니다.
없는 숫자나 혜택을 예시 문구에 채워 실제 약속처럼 제시하지 않습니다.

채널별 신청 자격·송출 방식·노출·수수료·정산·다시보기 조건은
현재 판매자 계정 화면과 공식 안내에서 확인합니다. 계약·프로모션·배송 방식에 따라
비용과 노출이 달라지므로 공통 수수료율이나 연령대별 성과를 고정하지 않습니다.
확인한 자료의 날짜와 계정 범위를 적고, 볼 수 없는 조건은 `미확인`으로 둡니다.

| 채널 | 확인할 공식 출발점 | 계정에서 확인할 것 |
| --- | --- | --- |
| 네이버 쇼핑라이브 | [스마트스토어 고객센터](https://help.sell.smartstore.naver.com/faq/content.help?faqId=5441) | 방송 자격·등록·상품 연결·수수료 |
| 카카오 쇼핑라이브 | [카카오 쇼핑라이브](https://shoppinglive.kakao.com/) | 입점·방송 방식·계약·알림 조건 |
| 그립 | [그립 비즈니스센터](https://business.grip.show/) | 직접 방송 또는 그리퍼 협업·비용·정산 |
| 쿠팡 | [쿠팡라이브 시작 안내](https://ads.coupang.com/coupanglive_start/) | 판매자 유형에 맞는 WING·서플라이어허브의 라이브 권한·배송·비용·노출 |

## 진행 순서

1. **채널 비교**: 상품과 고객 자료, 실제 계정 권한, 예상 비용과 운영 인력을
   같은 기준으로 비교합니다. 공식 문서나 계정에서 확인되지 않은 채널은
   신청 가능·노출 우대·수수료를 확정하지 않습니다.
2. **방송 설계**: 사용자가 지정한 길이와 상품 수를 우선합니다. 시연·질문·혜택 설명에
   필요한 시간을 배분하고, 상품별 핵심 사실과 보여줄 장면을 정합니다.
   30분·60분 또는 특정 SKU 수를 보편적 정답으로 강제하지 않습니다.
3. **스크립트**: 오프닝, 상품 시연, 질문 응대, 구매·배송 안내, 마무리를
   실제 자료로 작성합니다. 새 시청자 재안내와 종료 알림은 방송 흐름에 맞춰
   선택합니다. 가격·할인·수량·시간 제한은 확인된 조건만 말합니다.
   상세 표현은 [`references/live-script.md`](references/live-script.md)를 따릅니다.
4. **송출 전 점검**: 현재 채널이 요구하는 장비·화질·상품 연결·알림·이벤트 조건을
   확인합니다. 실제 송출 도구와 계정 권한이 보이지 않으면 방송 준비 완료로
   표시하지 않습니다. 고객 메시지는 수신 동의와 승인된 발송 범위를 확인합니다.
5. **방송 후 측정**: 채널이 실제 제공하는 시청·주문·취소·비용 데이터를
   같은 기간으로 정리합니다. 기준선이 없으면 시청자 수·전환율·객단가 목표를
   만들어 넣지 않습니다. 다시보기·클립 재사용은 채널 기능과 사용 권한을 확인합니다.

## 출력

방송 기획안에는 `확인한 채널 조건과 출처`, `상품·혜택 근거`, `진행 순서와 대본`,
`송출 전 누락 항목`, `비용·권한·승인`, `사후 측정 방법`을 적습니다.
요청한 결과에 꼭 필요한 사실이 빠졌으면 질문 채널이 있는 직접 실행에서만 묻고,
하위 실행이나 질문 채널이 없는 직접 실행에서는 해당 사실과 재개 방법을
blocker로 반환합니다. 필수 사실이 아닌 자료는 `미확인`으로 표시하고
작성할 수 있는 부분을 계속 작성합니다.

상품·광고 표현은 원본 자료와 대조합니다. 경제적 이해관계와 후기·효능 표시는
게시 시점의 규정과 플랫폼 정책을 확인합니다. 유료 광고·고객 메시지 발송·
판매 플랫폼 변경은 사용자의 승인 범위 안에서만 실행합니다.
`moai-coworker:ai-slop-reviewer`와 `moai-writer:korean-humanize`가 설치돼 있으면
표현 검수에 추가할 수 있으며, 실행하지 않은 검수는 완료로 표시하지 않습니다.

## 관련 스킬

- `moai-seller:commerce-detail-page-copy` — 상품 카피
- `moai-seller:commerce-integrated-strategy` — 채널·손익 비교
- `moai-seller:commerce-ad-claim-compliance-kr` — 광고 주장 확인
- `moai-cs:cs-channel-message` — 승인된 채널 메시지 초안
- `moai-marketer:content-sns-content` — 방송 후 SNS용 짧은 글

일반 상품 등록은 해당 마켓플레이스 스킬로 안내합니다. 자체 스트리밍이나
구매 연결이 없는 인스타·유튜브 방송은 해당 채널의 제작 지침을 확인합니다.

사용자가 라이브 후 짧은 영상을 요청하면, 현재 호스트에 인증된
Higgsfield 공식 연결의 영상 도구와 비용이 확인될 때만 유료 생성 절차로 이어갑니다.
