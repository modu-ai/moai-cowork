# 네이버 광고 보고서 분석과 조정안

## 자료와 광고 유형

광고 계정, 캠페인 유형, 기간, 검색어·소재 보고서, 광고비, 전환매출의
추적 설정과 귀속 기간, 상품별 공헌이익을 확인합니다. 보고서가 없으면
숫자를 채운 최적화안을 만들지 않고 필요한 자료와 조회 방법을 안내합니다.

[네이버 광고 공식 도움말](https://ads.naver.com/help)은 검색광고와
성과형 디스플레이 광고의 계정·상품별 운영 정보를 제공합니다.
쇼핑검색광고·파워링크·브랜드검색·성과형 디스플레이 등은 요청과 현재
계정에 보이는 상품에 따라 구분합니다. 모든 판매자에게 네 유형이 필요하거나
쇼핑검색광고가 항상 첫 선택이라고 단정하지 않습니다.

## 분석 순서

1. **측정 기준**: 캠페인·상품·소재·검색어별 노출, 클릭, 비용과
   전환매출을 같은 기간으로 정리합니다. 추적되지 않은 전환을 0매출로
   단정하지 않습니다. 클릭률·전환율의 분모와 귀속 창을 표시합니다.
2. **상품 수익성**: `commerce-margin-calculator`의 공헌이익과 손익분기
   ROAS 기준을 사용합니다. 할인·쿠폰·환불·수수료·VAT와 광고 보고서의
   매출 기준을 맞춘 뒤 비교합니다. 업종 공통 목표 ROAS를 적용하지 않습니다.
3. **검색어·소재 검토**: 실제 검색어 보고서가 제공하는 범위에서
   상품명·카테고리·키워드·랜딩의 관련성을 확인합니다. 제외 키워드,
   입찰 조정, 소재 교체는 계정 기능과 충분한 관측치를 확인한 뒤 후보로
   제시합니다. 사진 후기의 고정 개수나 품질지수 상승을 성과 보장으로
   사용하지 않습니다.
4. **캠페인별 판단**: 브랜드검색과 디스플레이 광고는 현재 상품 자격,
   과금 방식, 대상 고객과 비용을 확인해 별도로 평가합니다.
   검색광고의 지표를 디스플레이 광고의 성과처럼 합치지 않습니다.
5. **변경·측정**: 예산·입찰·제외 설정뿐 아니라 소재 교체·캠페인 구성 등
   모든 광고 계정 변경 전에 사용자 승인과 현재 도구 권한을 확인합니다.
   실행했다면 이전값과 변경값을 기록하고,
   같은 기간·귀속 기준에서 이후 결과를 비교합니다.

## 결과

확인한 자료의 계정·기간·조회일, 지표 정의와 누락, 상품별 손익,
검색어·소재·예산 조정 후보, 승인·실행 여부를 구분해 적습니다.
실제 계정 설정을 바꾸지 않았다면 완료가 아닌 `조정안`으로 표시합니다.

광고 문구는 `commerce-ad-claim-compliance-kr`, 상품 등록은
`commerce-marketplace-naver`, 다채널 성과는
`moai-marketer:marketing-performance-report`로 연결합니다.
