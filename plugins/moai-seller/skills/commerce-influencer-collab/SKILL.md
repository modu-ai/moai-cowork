# 인플루언서·UGC 협업

## 입력

제품과 광고 표현의 제한, 협업 목적, 예산, 채널, 대상 청중, 콘텐츠 사용 기간·범위, 측정 방법을 확인한다. 팔로워 수만으로 전환율이나 비용을 추정하지 않는다. 협업 단가·성과는 실제 제안서와 과거 캠페인 자료로 검증한다.

## 경제적 이해관계 표시

[공정거래위원회의 추천·보증 등에 관한 표시·광고 심사지침 개정 안내](https://www.ftc.go.kr/www/selectBbsNttView.do?bordCd=3&key=12&nttSn=43669&pageIndex=25&pageUnit=10&searchCnd=all)를 확인한다. 금전·제품·할인·제휴 수익·향후 조건부 대가 등 이해관계를 빠짐없이 검토한다. 글·영상·숏폼 등 매체별 최신 표시 방식과 플랫폼 정책을 게시 시점에 확인하고, 소비자가 쉽게 알아볼 수 있는 위치와 표현으로 표시한다. 모든 게시물에 같은 초수·줄 수 규칙을 기계적으로 적용하지 않는다.

## 협업 절차

1. 후보의 청중·콘텐츠 품질·기존 유료 협업과 실제 단가를 확인한다.
2. 산출물, 마감, 수정 횟수, 보수, 광고 표시, 2차 사용권, 사진·초상권, 성과 측정 조건을 문서로 정한다.
3. 제품 효능·가격·비교 주장은 입증 자료와 카테고리별 광고 규정을 대조한다.
4. 브랜드 계정에서 후기·사진을 재게시하거나 광고에 사용할 때는 저작권자와 촬영된 인물의 허락 범위를 확인한다. 허락 범위를 넘는 편집·2차 사용은 하지 않는다.
5. 게시 후 실제 광고 표시와 링크·코드 작동을 확인한다.

## 산출물

후보 비교표, 협업 조건 초안, 게시 전 점검표, 확인된 성과 지표를 제공한다. 특정 과태료 액수나 협업 ROI를 근거 없이 단정하지 않는다.
