# 구독 모델 설계

## 확인할 자료

제품의 실제 소비·교체 주기, 고객별 구매 간격, 배송·포장·반품비, 정기 결제 수수료, 고객이 받는 혜택, 고객 지원 역량을 확인한다. 같은 업종의 구독 사례 수나 고정 가격 범위만으로 적합성을 판정하지 않는다.

## 설계 선택

| 모델 | 고객이 받는 가치 | 검토할 부담 |
|---|---|---|
| 정기 배송 | 필요한 시점에 제품 도착 | 수요 변동·재고·배송비 |
| 큐레이션 | 선택 시간 절약·발견 | 구성품 품질·취향 차이 |
| 멤버십 | 실제로 쓰는 혜택 | 혜택 원가·미사용 고객 |
| 맞춤 | 적절한 추천 | 데이터 사용 동의·추천 정확도 |

모델을 고르기 전에 단품 구매와 비교한 고객의 실질 혜택을 계산한다. 무료 체험·할인·맞춤 추천은 제공할 수 있을 때만 제안한다.

## 유지와 해지

갱신 주기, 결제일, 가격 변경, 일시 정지, 취소·환불 경로를 고객이 이해할 수 있게 설계한다. 해지 장애물을 이탈 방지 수단으로 삼지 않는다. 개인화에 필요한 데이터는 목적과 보유 범위를 확인한다. 메시지는 채널별 수신 동의와 거부 상태를 확인한 뒤 계획한다.

## 검증

코호트별 갱신율·해지율, 월별 공헌이익, 고객 문의와 반품을 같은 기준 기간으로 측정한다. 실험 전에는 목표와 중단 기준을 적는다. 구독 모델이 이익을 낼 것이라는 가정과 실제 관측치를 구분한다.
