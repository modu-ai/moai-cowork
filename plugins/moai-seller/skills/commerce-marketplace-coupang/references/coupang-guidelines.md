# 쿠팡 상품 등록 점검 항목

[쿠팡 공식 상품 등록 안내](https://marketplace.coupang.com/register)는
상품명·카테고리·옵션·대표 이미지·상세설명·상품 주요정보·배송·반품을
등록하는 순서를 설명합니다. 실제 판매자 계정에서 보이는 입력 조건과
계약을 확인합니다.

## 상품과 이미지

- 브랜드·모델·옵션·사양·인증·가격·재고는 원본 자료와 대조합니다.
- 대표·추가 이미지와 상세설명 이미지는 서로 다른 입력란입니다.
  현재 계정에서 각 크기·용량·형식과 카테고리별 제한을 확인합니다.
- 1080×12720 합성본은 작업용입니다. 자동 압축이나 그대로 업로드 가능함을
  가정하지 않고, 필요하면 별도로 변환한 뒤 업로드·미리보기를 확인합니다.
- 식품·화장품·건강기능식품의 효능, 인증, 원산지·유통기한 표현은
  실제 상품 서류와 현재 적용 기준을 확인합니다.

## 검색·혜택·배송

- 상품명과 검색어는 실제 상품에 해당하는 표현만 사용합니다.
  글자 수·태그 수·노출 기준을 공통 고정값으로 제시하지 않습니다.
- 후기·평점·반품률·이미지 장수에 따른 보편적 노출 우대를 약속하지 않습니다.
- 쿠폰·행사·무료배송·당일 또는 익일 배송은 실제 설정과 적용 대상을 확인합니다.
- 판매자배송·로켓그로스·로켓배송의 비용과 책임은 현재 계약·정산 내역으로
  구분합니다. 공통 수수료율이나 모든 상품의 배송 속도를 만들지 않습니다.

등록 전에 상품별 필수 고지와 반품 조건, 이미지 권리, 미리보기 화면을
확인합니다. 계정에서 등록 결과를 보지 못했다면 `미확인`으로 남깁니다.
