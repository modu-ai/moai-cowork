# 쿠팡 상품 등록 검토

## 먼저 확인할 것

판매자 유형과 계정 권한, 상품 카테고리, 브랜드·모델·인증·옵션,
실제 가격·재고·배송·반품 조건, 이미지와 상세설명 원본을 확인합니다.
로켓배송·로켓그로스·판매자배송을 이름만 보고 같은 운영 조건으로 취급하지 않습니다.

[쿠팡 공식 상품 등록 안내](https://marketplace.coupang.com/register)는 상품명,
카테고리, 옵션, 이미지, 상세설명, 고지, 배송·반품 정보를 등록하고 미리보는
순서를 안내합니다. 현재 계정 화면과 계약 조건을 우선해 적용합니다.
계정에 보이지 않는 기능이나 수수료를 공개 안내만으로 확정하지 않습니다.

## 진행 순서

1. **상품 사실 대조**: 원본 자료로 상품명·사양·인증·가격·할인·옵션·재고를
   확인합니다. 검색 결과나 경쟁사의 문구를 사실 근거로 복사하지 않습니다.
2. **등록 조건 확인**: 현재 계정에서 카테고리 권한, 대표·추가 이미지와
   상세설명의 크기·용량·형식, 상품명·검색어 입력 제한을 확인합니다.
   같은 쿠팡 공식 안내 사이에도 이미지 권장값이 다를 수 있으므로
   계정 화면에서 선택한 등록 경로의 값을 사용합니다.
3. **이미지 검토**: `commerce-detail-page-image`의 1080×12720 합성본은
   작업용 원본입니다. 그대로 업로드되거나 자동 압축된다고 약속하지 않습니다.
   규격이 다르면 별도 변환을 안내하고 결과 파일·미리보기를 확인합니다.
4. **배송·비용 검토**: 배송 유형별 실제 계약, 정산 수수료, 물류비,
   출고 가능일과 반품 비용을 구분합니다. 모든 상품의 익일 도착이나
   고정 수수료·검색 우대를 단정하지 않습니다.
5. **등록 전 점검**: 금지 표현·법정 고지·이미지 권리·상품 정보와
   미리보기 화면을 확인합니다. 등록·노출 결과를 보지 않았다면 완료로
   표시하지 않습니다.

세부 항목은 `references/coupang-guidelines.md`를 따릅니다. 문구의 법규 검토는
`commerce-ad-claim-compliance-kr`, 이미지 제작은 `commerce-detail-page-image`,
다른 오픈마켓은 `commerce-marketplace-naver`로 연결합니다.

## 결과

상품과 등록 화면의 대조 결과, 현재 계정에서 확인한 조건·출처·조회일,
누락 자료와 실제 미리보기·업로드 여부를 적습니다. 확인하지 않은 조건은
`미확인`으로 두고, 실행하지 않은 등록이나 법규 검토를 `PASS`로 표시하지 않습니다.
