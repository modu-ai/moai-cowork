# 자사몰 (D2C) 운영 가이드

자사몰은 상품 구성·브랜드 표현·고객 경험을 직접 설계할 수 있습니다. 빌더 요금 외에도 결제, 배송, 도메인, 앱, 광고, 운영 인력의 비용이 발생할 수 있으므로 `수수료 없음` 또는 `통제권 100%`라고 안내하지 않습니다.

## 요청과 자료

자사몰, D2C, 카페24, 아임웹, 메이크샵, 독립몰, 브랜드 쇼핑몰 요청에 사용합니다. 판매 품목·국가, 상품 수, 디자인·개발 인력, 기존 주문량, 결제·배송 방식, 예산, 현재 사업·신고 상태를 확인합니다. 자료가 없는 항목은 `미확인`으로 둡니다. 간단한 비교나 준비 목록은 계정 없이도 작성합니다.

## 작업 순서

1. **필요 기능 정리** — 상품·재고·옵션, 국내·해외 결제, 배송, 콘텐츠 편집, 외부 앱, 데이터 내보내기를 구분합니다.
2. **빌더 비교** — [카페24 공식 소개](https://www.cafe24.com/commerce/start/founder.html), [아임웹 요금제 안내](https://www.imweb.me/qna?mode=faq&q=72127), 메이크샵의 현재 공식 안내를 확인합니다. 브랜드 규모나 미확인 시장 점유율만으로 결론 내리지 않습니다.
3. **비용 계산** — 선택한 빌더 플랜과 PG 계약, 간편결제, 도메인, 디자인, 배송, 유료 앱, 광고의 실제 견적을 같은 주문량 기준으로 비교합니다. 견적이 없고 사용자가 추정을 원하면 가정·산식·미확인 항목을 분리한 예시 계산을 제공합니다. 예시를 실제 계약 비용으로 확정하지 않습니다.
4. **개설 준비** — 도메인·HTTPS, 상품·이미지, 결제 신청, 배송·반품 정책, 개인정보·마케팅 동의, 검색 도구를 실제 계정의 기능에 맞춰 점검합니다. 한 장의 긴 상세 이미지가 모든 빌더에서 그대로 허용된다고 약속하지 않습니다.
5. **신고와 계약 확인** — 사업자·PG 제출 서류와 통신판매업 신고 또는 면제 여부를 현재 기관·서비스 안내에서 확인합니다. [전자상거래법 제12조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027063205)는 일정 기준 이하의 신고 면제를 둡니다. 모든 판매자에게 신고가 필수라고 단정하지 않습니다.
6. **운영 계획** — 실제 마진·고객 획득비·재구매 자료로 채널과 목표를 정합니다. 공통 ROAS·전환율·마켓 대 자사몰 비율을 보편 목표로 제시하지 않습니다.

## 출력

```json
{
  "needs": {"products": "미확인", "payment": [], "shipping": []},
  "candidates": [],
  "verified_terms": [],
  "cost_inputs_missing": [],
  "registration_and_pg_checks": [],
  "setup_checklist": [],
  "recommendation": "조건부 비교"
}
```

사용자가 "아임웹과 카페24 중 뭘 쓸까?"라고 물으면 알려진 기능과 확인할 비용을 먼저 나란히 보여줍니다. 사업자등록 자료가 없어도 사이트 설계 초안은 작성할 수 있습니다. 실제 결제 개통의 요건은 선택한 PG와 판매 형태에서 확인합니다.
