# 자사몰과 마켓 채널 운영

자사몰은 상품 표현과 고객 경험을 직접 설계할 수 있지만, 결제·배송·광고·운영 비용을 부담합니다. 마켓은 검색·방문 흐름을 제공할 수 있지만, 실제 판매 조건은 채널·상품·계약마다 다릅니다. 한쪽의 수수료를 0% 또는 고객 데이터 소유를 100%로 단정하지 않습니다.

## 채널 판단

1. 현재 채널별 매출, 주문, 순이익, 재구매와 고객 획득 비용을 같은 기간에 모읍니다.
2. 마켓의 실제 수수료·광고·배송비와 자사몰의 PG·빌더·앱·광고·운영비를 구분합니다.
3. 상품 발견 경로, 재고·반품 부담, 고객 동의 범위와 데이터를 내보낼 수 있는 기능을 확인합니다.
4. 계정과 계약에서 확인한 값으로 시나리오를 비교합니다. 값이 없으면 목표 비율이나 이전 결론을 확정하지 않습니다.

## 측정과 실험

- 주문 전환율: 주문 수와 측정 가능한 방문 수의 관계를 채널별로 봅니다.
- 기여 이익: 매출에서 원가·결제·배송·광고·반품 등 실제 변동비를 뺍니다.
- 재구매: 같은 고객을 합법적으로 식별할 수 있는 범위와 기간을 명시합니다.
- 광고 성과: ROAS만으로 흑자를 판단하지 않고 마진과 반품을 함께 봅니다.
- 데이터 수집과 메시지 발송은 개인정보 처리 및 광고성 정보 동의 범위에서 설계합니다.

첫 구매 쿠폰, 무료배송, 이메일, 알림톡, 리타겟팅은 선택 가능한 실험입니다. 할인액·발송 간격·광고 수익률을 공통 정답으로 지정하지 않습니다. 사용자의 원가·예산·동의 자료가 없으면 실행 계획은 조건부 초안으로 표시합니다.

## 운영 점검 목록

- [ ] 채널별 실매출·주문·반품 자료
- [ ] 실제 계약상 수수료·정산·배송 조건
- [ ] 상품별 원가와 광고·쿠폰 비용
- [ ] 고객 동의와 데이터 내보내기 가능 범위
- [ ] 도메인·결제·배송·반품 안내
- [ ] 실험의 측정 기간과 중단 기준
