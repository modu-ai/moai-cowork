# 카페24 자사몰 준비

[카페24 공식 신규 창업자 안내](https://www.cafe24.com/commerce/start/founder.html)는 쇼핑몰 솔루션의 월 이용료가 없다고 설명합니다. 결제 서비스·배송업체·추가 서비스·앱에는 비용이 생길 수 있습니다. 이를 판매 전체가 무료라는 뜻으로 읽지 않습니다.

## 개설 순서

1. [공식 쇼핑몰 만들기](https://www.cafe24.com/commerce/start/founder.html)에서 계정과 개설 조건을 확인합니다.
2. 상품 옵션·재고·배송 정책을 정리하고 무료 템플릿 또는 현재 디자인센터의 상품을 선택합니다.
3. 도메인과 HTTPS를 연결하고 실제 모바일 화면을 확인합니다.
4. 계정에서 제공되는 PG·간편결제를 비교합니다. 사업자·통신판매업 관련 제출 서류, 수수료, 정산 일정은 선택한 계약에서 확인합니다.
5. 배송업체·앱·광고 기능은 필요한 것만 골라 현재 가격과 약관을 확인합니다.
6. 상품 이미지 규격과 업로드 제한은 실제 등록 화면에서 확인합니다.

## 비용 비교

| 비용 | 확인 자료 |
| --- | --- |
| 솔루션 | 카페24의 현재 요금 안내 |
| 결제 | 선택한 PG·간편결제 계약 |
| 디자인·앱 | 실제 구매 화면과 구독 계약 |
| 도메인·배송 | 도메인 판매자·배송업체 견적 |
| 광고·운영 | 사용자가 정한 예산과 실제 주문 자료 |

카드 수수료·정산일·무료배송 기준·적합한 매출 규모를 임의의 고정값으로 제시하지 않습니다. 쇼핑몰 개설과 결제 개통은 별개 단계입니다.
