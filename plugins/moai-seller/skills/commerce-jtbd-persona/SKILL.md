# 구매 동기와 고객 유형 분석

## 자료

사용자가 제공한 리뷰, 문의, 인터뷰, 시장조사 결과를 우선한다. 연결된 커머스 도구가 실제로 제공하는 조회 기능과 계정 권한을 확인한 뒤 사용한다. 자료마다 출처·기간·상품·건수를 기록한다. 경쟁 상품의 리뷰를 쓰는 경우에는 별도 집단으로 표시하고, 내 상품 고객의 행동으로 해석하지 않는다. 자료가 없으면 실제 고객 페르소나를 만들지 않고 조사 질문과 필요한 자료를 제안한다.

## 구매 동기

기능적·감정적·사회적 동기를 구분하되, 각 범주를 정해진 개수로 채우지 않는다. 고객의 말과 관찰에서 드러난 문제, 구매 전 상황, 대안, 선택 기준을 기록한다. 추론은 **가설**로 표시하고 근거 문장과 분리한다. 시장 규모·광고 효율·전환 가능성을 리뷰 빈도만으로 순위 매기지 않는다.

| 항목 | 기록할 내용 |
|---|---|
| 상황 | 구매 전 어떤 일이 있었나 |
| 해결할 일 | 고객이 무엇을 이루려 했나 |
| 대안 | 무엇과 비교했나 |
| 선택 기준 | 가격·편의·신뢰 등 실제 언급 |
| 근거 | 자료 출처와 인용 위치 |
| 불확실성 | 자료가 없는 집단과 반대 사례 |

## 고객 유형

자료에 구분되는 행동 패턴이 있으면 유형별 니즈·걱정·구매 기준을 작성한다. 구분이 약하면 하나의 공통 유형만 제시한다. 이름·나이·직업·일상은 자료에 없으면 만들지 않는다. 가상의 예시가 필요하면 **가상 예시**라고 표시한다. 고객 정보를 재식별할 수 있는 세부 내용은 출력에서 제거한다.

브랜드 관계 단계는 실제 접점 기록으로만 분류한다. 광고를 봤다는 사실만으로 구매 의향이나 광고 비용을 추정하지 않는다. 장바구니 이탈의 이유도 가격·신뢰 등으로 단정하지 말고 확인할 질문으로 둔다.

## 출력

1. 자료 목록과 수집 범위
2. 근거가 있는 구매 동기와 반대 사례
3. 확인된 고객 유형 또는 유형을 만들기 어려운 이유
4. 검증할 가설과 다음 조사 질문

문장 검수 스킬이 연결돼 있고 실제 실행했다면 결과를 기록한다. 실행하지 않은 검수 상태를 `passed`로 채우지 않는다. 자료가 부족할 때는 경쟁 상품 리뷰를 정해진 건수만큼 가져와 고객 유형을 자동 생성하지 않는다.
