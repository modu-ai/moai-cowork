# 상세페이지 카피 패턴 (Copy Patterns)

상세페이지 본문·CTA·가격 표시에 쓰이는 카피 패턴 모음. commerce-detail-page-copy 스킬에 위임 시 입력 가이드로 활용.

---

## 1. 저관여 vs 고관여 언어 분기

### 빠른 비교가 필요한 제품

| 원칙 | 적용 |
|---|---|
| **쉬운 문장** | 고객에게 낯선 용어 설명 |
| **짧게** | 한 문장에 한 가지 정보 |
| **우리말** | 외래어 최소 |
| **1EA 가격** | "박스당" 가격 X, "1개당" |
| **빠른 확인** | 가격·규격·배송 등 핵심 정보 앞에 배치 |

예시:
- ❌ "영양 성분이 풍부한 프리미엄 비타민" → ⭕ "하루 1알, 종합 비타민"
- ❌ "탁월한 흡수율과 지속력" → ⭕ "{제품 시험으로 확인된 사용감만 설명}"

### 검토 정보가 많은 제품

| 원칙 | 적용 |
|---|---|
| **신뢰 정보** | 실제 인증·수상·연구 결과만 |
| **타사 비교** | 현재 출처와 동일 비교 조건이 있을 때만 |
| **상세 옵션 설명** | 사이즈·옵션별 차이 |
| **사용 과정** | 실제 사용법과 확인된 변화만 |

예시:
- 해당 제품의 적용 표시와 유효한 자료
- 제품별 시험 자료의 대상·방법·결과
- 실제 전문가 추천 사실과 공개 허락

### "고민 시간" 프레임 (3박자 법칙)

저관여/고관여 둘 다 적용 가능한 프레임:

```
[1] 고객의 고민 명시 — "이런 거 있죠?"
[2] 확인된 문제 맥락 — 원인을 단정하기 전에 자료 확인
[3] 제품이 제공하는 기능 — 성능 수치는 측정 근거가 있을 때만
```

## 2. 가격 표시 아이디어

아래 방식은 실제 판매 조건과 근거가 있을 때만 사용합니다. 기간·수량·정가·혜택을 임의로 만들지 않습니다.

| # | 전략 | 적용 예 | 효과 |
|---|---|---|---|
| 1 | **가격 변경 안내** | 실제 변경일·변경액 | 조건 명확화 |
| 2 | **기간별 환산** | 실제 총액 ÷ 이용 기간 | 총액과 함께 표시 |
| 3 | **할인 비교** | 실제 기준 가격과 현재 가격 | 비교 기준·기간 확인 |
| 4 | **단위 가격** | 실제 수량당·용량당 가격 | 계산 방식 확인 |
| 5 | **할인가 강조** | 실제 할인 가격 | 원가격·기간 확인 |
| 6 | **대안 비교** | 동일 범위의 확인된 대안 | 출처와 조건 표시 |
| 7 | **재고 안내** | 현재 재고 수량 | 갱신 시점 확인 |
| 8 | **행사 종료 안내** | 실제 종료 일시 | 시간대 확인 |
| 9 | **묶음 할인** | 실제 묶음 구성과 가격 | 단품 대비 계산 |
| 10 | **정기구독 할인** | 실제 정기 결제 조건 | 해지·갱신 안내 |
| 11 | **무료배송 기준** | 실제 배송 정책 | 제외 지역·조건 확인 |
| 12 | **사은품 안내** | 실제 제공 품목 | 수량·기간 확인 |
| 13 | **첫 구매 할인** | 실제 쿠폰 조건 | 대상·유효기간 확인 |

조합은 실제 조건을 확인한 항목만 선택합니다. 기간·수량 문구는 갱신할 수 없으면 빼는 편이 정확합니다.

## 3. 카피 변환 공식 (FAB → 사용자 체감)

### 3단계 변환

```
[1] Feature (기능)        → 실제 제품 사양
[2] Advantage (이점)       → 시험 조건을 포함한 확인된 성능
[3] Benefit (사용자 혜택) → 확인된 사용 상황과 연결
```

혜택을 설명하되 사양과 근거를 함께 보여줍니다.

### 어려운 정보 → 일상 표현

| 어려운 (전문) | 일상 (체감) |
|---|---|
| 확인된 성분표 | 성분명과 제품에 허용된 표시 범위 |
| 확인된 배터리 용량 | 실제 충전 조건과 호환 기기 |
| 확인된 화면 사양 | 해상도·패널 종류와 사용 장면 |
| 확인된 제품 치수 | 실제 사용 방법과 주의사항 |

## 4. 뷰티 카피 8유형 (각 10-15 패턴)

뷰티 상세페이지에서 검토할 수 있는 표현 유형. 효능·수치·추천은 제품별 자료를 확인한 경우만 사용합니다.

1. **사용 순서** — 실제 제품 사용법 안내
2. **공감·페인** — "마스크 자국, 이제 안녕"
3. **실측 정보** — 실제 시험 자료의 조건과 결과
4. **비교 정보** — 같은 조건의 확인된 비교
5. **전문가 설명** — 실제 추천·공개 허락이 있는 경우
6. **성분 정보** — 실제 성분표와 확인된 표시 범위
7. **라이프스타일** — "출근 5분 전 메이크업"
8. **시즌·이벤트** — "봄꽃 피기 전 피부 깨우기"

각 유형마다 페르소나·시즌·가격대에 맞춰 변주 가능.

## 5. CTA 카피 패턴

상세페이지 CTA(Call to Action)는 페이지 하단 + 중간 + 상단 3곳에 배치 권장.

### CTA 카피 5유형

| 유형 | 예시 | 적용 시점 |
|---|---|---|
| **즉시형** | "지금 구매하기" | 가장 무난 |
| **혜택 강조형** | "{실제 할인 조건 확인하기}" | 혜택이 있을 때 |
| **결핍 해소형** | "내 피부에 적용하기" | 페인 해결 시 |
| **체험 안내형** | "{실제 체험 시작하기}" | 체험 제공 시 |
| **재고 안내형** | "{현재 재고 확인하기}" | 재고가 갱신될 때 |

CTA 디자인 원칙:
- 색상 대비 (배경 ≠ CTA 색)
- 충분한 여백 (다른 요소와 거리)
- 모바일 thumb-friendly (44px 이상 높이)
- 1페이지 1차 CTA 우선 (혼란 X)

## 6. 본문 카피 톤 매트릭스

```
              | 캐주얼 톤              | 격식 톤
--------------+-----------------------+------------------------
저관여(생활)   | "오늘 저녁 어때요?"    | "일상에 가벼운 도입"
고관여(투자)   | "지금이 그 시점이에요"  | "장기적 가치를 고려해주세요"
```

상세페이지는 보통 **저관여+캐주얼** 또는 **고관여+격식** 조합. 채널이 펀딩이면 캐주얼 우세, 커머스면 격식·중립.

## 활용 — commerce-detail-page-copy로 위임

본 references는 commerce-detail-page-planner의 Brief에서 **카피 톤·가격 전략·CTA 유형**을 결정하는 데 사용. 결정된 항목은 Brief YAML의 다음 필드로 출력:

```yaml
copy_strategy:
  involvement: "{low|high}"
  tone: "{casual|formal}"
  pricing_tactics: []  # 실제 조건·출처 확인 후 선택
  cta_type: null  # 실제 구매·혜택·체험·재고 조건 확인 후 선택
```

확인된 항목을 `moai-seller:commerce-detail-page-copy`의 입력으로 전달하고 실제 산출물에서 반영 여부를 확인합니다.
