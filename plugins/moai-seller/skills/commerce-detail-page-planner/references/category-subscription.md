# 카테고리 분기: 정기구독 (Category — Subscription)

정기구독은 **1회 구매와 근본적으로 다른 비즈니스 모델**. 신규 가입 + 이탈 방지 동시 설계.

대상: 구독 박스, 정기 배송, 멤버십, 스트리밍, 정기 결제 서비스.

---

## 1. 1회 구매 vs 정기구독 차이

| 축 | 1회 구매 | 정기구독 |
|---|---|---|
| 가치 강조 | 제품 자체 | **LTV·반복 경험** |
| 가격 표시 | 절대 가격 | **월·연 + 회당 가격** |
| 페이지 목적 | 구매 결제 | **첫 회 구매 + 약정 동의** |
| 핵심 메트릭 | 전환율·객단가 | **MRR·이탈율** |
| 카피 톤 | 즉시 매력 | **장기 관계·예측 가능성** |

---

## 2. 정기구독 페이지 필수 8 섹션

```
[1] 히어로 — 실제 배송 주기와 가입 CTA
[2] What's in the Box — 매월 받는 내용 시각화 (사진·박스 개봉)
[3] 큐레이션 가치 — "왜 이걸 매월 받아야 하나" (전문가 / AI / 사용자 기반)
[4] 구독 가격 표 — 1개월 / 3개월 / 6개월 / 1년 선택 (장기 할인)
[5] 일시정지·해지 정책 — 실제 가능한 방법·시점·조건
[6] 사회적 증명 — 검증된 후기·집계가 있는 경우
[7] 첫 회 무료 / 할인 — 실제 제공하는 경우
[8] 자주 묻는 질문 (FAQ) — 배송 주기·환불·변경
```

---

## 3. 가격 표시 전략

### 핵심 — "회당 가격" 명시

```
회당 가격 = 실제 총 결제액 ÷ 실제 배송 횟수
월 환산 가격 = 실제 선결제액 ÷ 실제 이용 개월 수
```

배송 주기가 월 1회인지 월 여러 회인지 먼저 확인한 뒤 총 결제액·횟수·회당 가격을 대조합니다.

### Tier 권장

| Tier | 기간 | 할인 |
|---|---|---|
| 월간 | 실제 제공하는 경우 | 실제 판매 가격 |
| 분기 | 실제 제공하는 경우 | 실제 할인 조건 |
| 반기 | 실제 제공하는 경우 | 실제 할인 조건 |
| 연간 | 실제 제공하는 경우 | 실제 할인 조건 |

할인율·약정 기간·자동 갱신 조건은 실제 판매 조건으로 바꿔 표시합니다.

---

## 4. 첫 회 할인·무료

신규 가입 혜택을 실제로 제공할 때만 다음 형식으로 표시합니다.

| 전략 | 적용 |
|---|---|
| **첫 달 무료** | 실제 무료 기간·이후 결제 조건 확인 |
| **첫 회 할인** | 실제 첫 회 가격·이후 가격 확인 |
| **사은품 증정** | 실제 제공 품목·조건 확인 |
| **묶음 할인** | 실제 결제액·기간·할인 기준 확인 |
| **추천 코드** | 실제 적립 조건·유효기간 확인 |

---

## 5. 이탈 방지 메시지

페이지 곳곳에 "불안 해소" 메시지 배치.

| 불안 | 해소 카피 |
|---|---|
| "약정에 묶일까?" | 실제 일시정지·해지 가능 시점과 방법 |
| "마음에 안 들면?" | 실제 청약철회·환불 조건 |
| "다음달 자동 결제?" | 다음 결제일과 실제 사전 알림 여부 |
| "내용 변경?" | 실제 구성 변경 가능 범위 |
| "주기 변경?" | 실제 선택 가능한 배송 주기 |

---

## 6. 큐레이션 가치 어필

정기구독 가입의 핵심 동기는 **"내가 직접 고르지 않아도 되는 편의성"**.

### 큐레이션 방식 4종

| 방식 | 어필 카피 |
|---|---|
| **전문가 큐레이션** | "10년 차 소믈리에가 매월 직접 선정" |
| **AI 추천** | "구독자의 취향 데이터 기반 AI 추천" |
| **신상품 자동 배송** | "매월 출시되는 신상품 자동 도착" |
| **테마 박스** | "이번 달은 봄꽃 테마" |

각각 다른 페르소나 타깃 — 페이지에서 큐레이션 방식 명시 필수.

---

## 7. 사회적 증명 — 회원 수·후기

| 표시 | 효과 |
|---|---|
| **누적 회원 수** | 집계 기준일과 실제 수치가 있을 때만 표시 |
| **누적 발송 박스** | 실제 발송 기록을 확인한 경우만 표시 |
| **평균 구독 기간** | 집계 기간·모수를 확인한 경우만 표시 |
| **재가입률** | 정의·모수·집계 기간을 확인한 경우만 표시 |
| **별점 + 후기** | 실제 리뷰와 사용 권한이 있을 때만 표시 |

---

## 8. 환불·해지 정책 (투명성)

페이지 footer 또는 별도 섹션에 명시. 숨기면 불신.

```
[해지 방법 — 실제 서비스에서 확인]
- 신청 경로와 처리 시점
- 다음 결제 중단 마감 시점
- 고객 지원 경로

[환불 정책 — 실제 약관에서 확인]
- 첫 회와 이후 회차의 청약철회·환불 조건
- 발송·서비스 제공 전후의 처리 기준
- 선결제 기간의 미이용분 정산 기준
```

---

## 9. 본문 톤 매너

- **편안 + 신뢰 + 친근**
- "당신" "여러분"
- 장기 관계 강조 — "1년 후" "10번째 박스"
- 약정·자동결제 부담을 "편리함"으로 재구성

```yaml
      - tier: "{실제 판매 기간}"

      type: "{전문가|AI|신상품|테마}"
      content: "..."

    social_proof:
      member_count: "{집계가 확인된 경우만}"
      total_boxes: "{발송 기록이 확인된 경우만}"
      avg_subscription_months: "{집계 근거가 확인된 경우만}"
      rating: "{실제 플랫폼 수치가 있는 경우만}"

    refund_policy_visible: "{실제 정책 표시 여부를 확인}"
    cancellation_steps: "{실제 해지 절차를 확인}"
```
