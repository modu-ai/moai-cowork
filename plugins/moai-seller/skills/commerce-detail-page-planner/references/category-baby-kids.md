# 카테고리 분기: 베이비/키즈 (Category — Baby / Kids)

유아·아동용품은 **부모가 구매하고 아이가 사용**하는 이중 페르소나. 안전 인증·연령 분기가 핵심.

---

## 1. 이중 페르소나 매핑

| 페르소나 | 관심사 | 카피 어필 |
|---|---|---|
| **구매자 (부모)** | 안전·품질·교육적 가치·가격 | "엄마·아빠 마음 놓이는" |
| **사용자 (아이)** | 재미·시각·인지 발달 | "아이가 좋아하는·놀이 시간" |

상세페이지는 구매 결정을 위한 안전·품질 정보와 아이의 실제 사용 장면을 함께 다룹니다.

---

## 2. 연령 분기 (필수)

연령별로 안전 기준·사용 방식·카피가 완전히 다름.

| 연령 | 핵심 요구 | 본문 강조 |
|---|---|---|
| **0-6개월** | 안전·청결·신생아 적합 | 실제 소재·세척 방법과 사용 가능 연령 |
| **6-12개월** | 제품별 사용 가능 연령 | 실제 사용 방법·보호자 감독 조건 |
| **1-3세** | 제품별 사용 가능 연령 | 실제 크기·소재·세척 방법 |
| **3-6세** | 제품별 사용 가능 연령 | 실제 놀이 방법·구성품 |
| **6-12세** | 제품별 사용 가능 연령 | 실제 기능·관리 방법 |

페이지에 **연령 추천 표** 또는 **연령 필터** 권장.

---

## 3. 안전 인증 (한국 시장 필수)

| 인증 | 의미 | 카테고리 |
|---|---|---|
| **KC 표시** | 국내 제품안전 관리 대상의 해당 절차 | 해당 품목·절차를 확인한 경우 |
| **유럽 CE** | 해당 EU 규정에 따른 적합성 표시 | 적용 대상과 문서를 확인한 경우 |
| **EN 71** | EU 장난감 관련 기준 | 해당 시험 결과를 확인한 경우 |
| **OEKO-TEX 100** | 섬유 관련 인증 | 해당 제품 인증 범위를 확인한 경우 |
| **친환경 표시** | 표시마다 기준이 다름 | 해당 표시의 발급 주체·범위를 확인한 경우 |
| **유기농 표시** | 품목별 기준이 다름 | 해당 제품 인증 범위를 확인한 경우 |

제품안전정보센터에서 품목별 안전인증·안전확인·공급자적합성확인 대상과 표시 방법을 확인합니다. 실제 제품의 표시·증빙이 없으면 로고를 넣지 않습니다. [제품안전정보센터 대상품목](https://www.safetykorea.kr/policy/targetsSafetySupply)

---

## 4. 부모 페인포인트 매핑

베이비/키즈 페이지에서 자주 어필되는 부모 고민 7가지:

| 페인 | 카피 어필 |
|---|---|
| "안전한가?" | 적용 품목의 실제 표시·시험 결과와 소재 정보 |
| "오래 쓰나?" | 실제 내구성 자료·사용 허락을 받은 후기 |
| "발달에 좋나?" | 확인된 사용 방식만 설명; 발달 효능은 근거가 있을 때만 |
| "청소 쉬운가?" | "세탁기·식기세척기 OK" |
| "아이가 좋아할까?" | 사용 허락을 받은 실제 보호자 후기 |
| "환경 친화적인가?" | 친환경 소재·재활용 가능 |
| "가격 대비 가치?" | "1년 사용 시 일당 X원" |

## 5. 베이비/키즈 본문 추가 권장 모듈

| 모듈 | 내용 |
|---|---|
| **연령 추천** | "Best for 6-12개월" 또는 연령 슬라이더 |
| **안전 정보** | 해당 제품의 실제 표시·시험 자료가 있을 때 배치 |
| **성분·소재 표** | 유해 물질 검사 결과 |
| **부모 후기** | 사용 허락을 받은 실제 후기만 표시 |
| **연계 추천** | "함께 사용하면 좋은 제품" |
| **선물 포장** | 실제 제공 여부·비용 확인 |
| **A/S·교환·환불** | 명확히 |

---

## 6. 카피 톤 매너

- **안심 + 신뢰 + 따뜻**
- 의학·발달 전문 용어는 부모가 이해할 수준
- "엄마·아빠" 호명 OK (단, 한부모·조부모 양육도 고려)
- 아이의 미소·웃음 이미지 풍부
- **자극적 표현 금지** ("우리 아이 천재로", "100% 효과" 같은 단정)

---

## 7. 광고 심의 가드

| 금지 | 사유 |
|---|---|
| **"천재"·"영재"·"우등생"** | 발달 단정 |
| **"100% 효과"·"확실히 발달"** | 효능 단정 |
| **"의학적 효과"** | 의약품 효능 (장난감·교육제품) |
| **"안전 100%"** | 사고 가능성 부정 |

대체 문구도 실제 제품 자료로 뒷받침해야 합니다. 사용 연령·소재·사용 방법처럼 확인된 정보를 우선합니다.

```yaml
brief:
  category: "베이비-키즈"
  baby_kids_specific:
    dual_persona:
      buyer: "부모 (30~40대 여성/남성)"
      user: "아이 (연령 분기)"

    age_range:
      min: "6개월"
      max: "12개월"
      use_method: "{실제 사용 방법·보호자 감독 조건}"

    safety_certifications:
      - "{해당 품목에 적용되고 증빙된 표시만}"

    parent_pain_points:
      - "안전한가?"
      - "오래 쓰나?"
      - "발달에 좋나?"
      - "청소 쉬운가?"

    additional_modules:
      - "연령 추천 표"
      - "{증빙된 표시가 있을 때만 안전 정보}"
      - "성분·소재 표"
      - "{실제 후기와 사용 허락이 있을 때만}"
      - "선물 포장"

    compliance:
      forbidden_terms: ["천재", "영재", "100% 효과", "100% 안전"]
      pediatrician_recommendation: false   # 의학적 추천 표현 주의

    photo_priority:
      - "{실제 제품의 적용 표시가 있을 때만 촬영}"
      - "아이 사용 장면 (실사)"
      - "부모와 함께 사용"
      - "청소·세탁 장면"
```
