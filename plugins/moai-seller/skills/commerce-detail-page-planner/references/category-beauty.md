# 카테고리 분기: 뷰티 (Category — Beauty)

뷰티 카테고리 (스킨케어·메이크업·헤어·바디) 상세페이지의 카테고리 특화 가이드.
효능·효과 표현은 해당 제품의 기능성화장품 심사·보고 내용과 광고 근거를 확인해야 합니다.

---

## 1. 뷰티 본문 4단계 (USP 정리 공식)

```
[1] USP 도입 (대표 USP 1~2개)
    → "{실제 성분과 확인된 특징}"

[2] 좋은 제품 특징 2~3개
    → "{실제 사용감과 시험·표시 근거가 있는 특징}"

[3] 신뢰도 정보
    → 실제로 확인된 시험·표시 자료와 사용 허락을 받은 후기

[4] 옵션·용량·가격 정보
    → 실제 용량·구성·가격
```

이 4단계가 뷰티 본문의 표준 뼈대.

## 3. 한국 화장품법·표시광고법 광고 심의

### 효능 표현 검토 예시

| 확인할 표현 | 확인 이유 | 근거가 없을 때 |
|---|---|---|
| **재생·치료·염증 치료** | 의약품으로 오인될 수 있는 효능 | 해당 표현을 빼고 실제 제품 특성만 설명 |
| **주름 개선·자외선 차단** | 기능성화장품 해당 여부와 허용 효능 | 심사·보고 내용 확인 전에는 단정하지 않음 |
| **세포·회복·노화 방지** | 작용 범위와 실증 근거 | 확인된 사용감·제품 사양만 설명 |

### 제품별 근거를 확인할 일반 표현 예시

| 표현 | 카테고리 |
|---|---|
| **보습** | 스킨케어 전반 OK |
| **피부 결 정돈** | OK |
| **피부 톤 케어** | OK |
| **탄력 케어** | OK |
| **수분 공급** | OK |
| **메이크업 베이스** | OK |
| **자외선 차단** | 기능성화장품 심사·보고와 표시 범위 확인 필요 |

### 기능성 화장품 추가 규제

다음 기능을 광고할 때는 해당 제품의 기능성화장품 심사·보고 상태와 허용된 효능·효과를 확인합니다. 모두 동일한 방식의 '인증'을 받는다는 뜻은 아닙니다. [식약처 화장품 정책개요](https://www.mfds.go.kr/wpge/m_639/de050601l001.do)
- 미백
- 주름 개선
- 자외선 차단
- 염모
- 탈모 완화

## 4. 성분과 실제 제품 근거 연결 (뷰티 특화)

성분명만으로 피부 변화·지속 시간·효능을 추론하지 않습니다. 제품의 시험 자료와 허용된 표시 범위를 확인한 뒤 문장을 작성합니다.

| 입력 | 확인할 자료 | 표현 |
|---|---|---|
| 제품의 실제 성분표 | 함량·표시 명칭 | 확인된 성분명만 기재 |
| 사용감 후기 | 실제 원문·사용 허락 | 허락된 원문 범위만 인용 |
| 효능·지속 시간 | 제품별 시험·기능성화장품 자료 | 자료와 허용 범위 안에서만 작성 |

질병 치료로 오인될 표현은 쓰지 않습니다.

## 5. 뷰티 카테고리별 세부 가이드

### 스킨케어

- 핵심 USP: 성분·텍스처·효능
- 필수 모듈: 사용 순서 (토너→세럼→크림), 피부 타입별 추천
- 사진 우선: 제형·발색·흡수·전후

### 메이크업

- 핵심 USP: 발색·지속력·발림성
- 필수 모듈: 컬러 차트, 피부 톤별 매칭
- 사진 우선: 발색 (다양한 피부 톤), 사용 장면

### 헤어

- 핵심 USP: 모발 변화 (윤기·볼륨·진정)
- 필수 모듈: 모발 타입별 (건성·지성·손상모), 사용 빈도
- 사진 우선: 사용 전후 (모발 광택)

### 바디

- 핵심 USP: 향·보습·텍스처
- 필수 모듈: 향 노트, 함께 쓰면 좋은 제품
- 사진 우선: 제형·향 시각화 (꽃잎·과일 컷)

## 6. 뷰티 후기 모듈 (필수)

실제 후기가 있고 사용 권한을 확인했다면 본문에 후기 모듈을 배치합니다.

### 후기 표시 권장

```
[1] 별점 분포 그래프 (5/4/3/2/1)
[2] 평균 별점 (큰 글씨)
[3] 키워드 태그 (자주 언급된 단어 5개)
[4] 사진 후기 (가로 스크롤 갤러리)
[5] 사용 허락을 받은 실제 텍스트 후기
```

⚠️ 후기 조작·과장 금지. 표시광고법 위반.

## 7. 뷰티 가격 표시 전략

| 전략 | 적용 |
|---|---|
| **1ml당 가격** | 같은 카테고리 비교 우위 |
| **정기구독 할인** | 스킨케어 (월 1회 정기 배송) |
| **세트 할인** | 토너+세럼+크림 3종 세트 |
| **샘플 증정** | "본품 구매 시 샘플 5종" |
| **사은품 (파우치·메이크업 도구)** | 객단가 ↑ |
