# 카테고리 분기: 여행/체험 (Category — Travel / Experience)

호텔·투어·액티비티·체험 패키지. **무형 경험 상품** — 사진·후기·기대감이 구매 결정.

---

## 1. 여행 상품의 구매 결정 요인

| 요인 | 비중 | 페이지 반영 |
|---|---|---|
| **사진·동영상** | ★★★★★ | 풍부한 비주얼 (상단·갤러리) |
| **후기·별점** | ★★★★★ | 후기 모듈 별도 |
| **가격 (총 비용)** | ★★★★ | 모든 비용 포함 표시 |
| **위치·접근성** | ★★★★ | 지도·교통 정보 |
| **편의시설·옵션** | ★★★ | 체크리스트 |
| **취소·환불 정책** | ★★★ | 명확 표기 |

---

## 2. 여행 페이지 필수 8 섹션

```
[1] 히어로 — 풍경 사진 + 한 줄 약속 + 예약 CTA
[2] 갤러리 — 객실·식사·풍경·체험 10~20장
[3] 일정 / 코스 — 1일·2일·3일별 흐름
[4] 위치·접근성 — 지도 + 교통 옵션
[5] 포함·불포함 — 명확한 체크리스트
[6] 후기 — 별점 + 사진 후기
[7] 가격 + 취소 정책 — 일자별 가격 + 환불 일정
[8] FAQ — 비자·언어·날씨·짐 등
```

---

## 3. 일정·코스 표시 (필수)

투어·패키지는 **시간 단위 일정** 명시.

### 예시 — 1박 2일 부산 자유여행

```
Day 1 (월요일)
14:00  KTX 부산역 도착 → 호텔 체크인
15:30  광안리 해변 + 일몰
17:30  해운대 시장 저녁
20:00  부산 야경 투어
22:00  호텔 휴식

Day 2 (화요일)
08:00  호텔 조식
09:30  감천문화마을
12:00  자갈치 시장 점심
14:00  KTX 부산역 출발
```

---

## 4. 포함·불포함 (투명성)

후속 추가 비용으로 불만 생기지 않도록 명확.

### 포함·불포함 표기

상품 계약서와 예약 화면에 적힌 교통, 숙박, 식사, 입장료, 가이드 비용을 각각 대조합니다. 예시 일정의 `1박 2일`과 숙박·식사 횟수가 어긋나지 않아야 합니다. 미확인 항목은 포함 또는 불포함으로 단정하지 않습니다.

---

## 5. 계절·시즌 분기

여행은 **시즌별 가격·체험·후기**가 완전히 다름.

| 시즌 | 카피 어필 | 가격 |
|---|---|---|
| **현지 성수기** | 실제 혼잡도·행사·기후 안내 | 예약일별 실제 가격 |
| **현지 준성수기** | 실제 방문 여건 안내 | 예약일별 실제 가격 |
| **현지 비수기** | 실제 운영 범위 안내 | 예약일별 실제 가격 |

페이지에 **시즌별 가격 표** 또는 캘린더 권장.

---

## 6. 후기 모듈 (여행 핵심)

여행 후기는 **사진 + 별점 + 정성** 모두 중요.

### 표시 권장

```
[1] 실제 집계된 별점 (있는 경우)
[2] 별점 분포 그래프 (5/4/3/2/1)
[3] 인기 키워드 태그 — "친절·청결·맛·교통"
[4] 사진 후기 갤러리 (가로 스크롤)
[5] 사용 허락을 받은 실제 후기
[6] 응답률·응답 시간 (호텔·투어 운영자)
```

## 7. 무형 경험 가시화

만질 수 없는 "경험"을 사진·동영상·시나리오로 가시화.

| 요소 | 표현 |
|---|---|
| **감각 경험** | "현지 음식의 알싸한 향" |
| **시간 흐름** | "해질 무렵 5시 30분" |
| **사회적 경험** | "현지 가족이 직접 안내" |
| **개인 변화** | "도시 스트레스 벗어남" |
| **사진 가치** | 촬영 가능한 장소·시간대의 실제 정보 |

---

## 8. 취소·환불 정책 (필수)

여행 취소는 자주 발생 — 명확한 정책 = 신뢰.

### 실제 정책 확인 표

| 확인 항목 | 표시 내용 |
|---|---|
| 취소 신청 시점 | 판매자가 적용하는 기준 시각·시간대 |
| 환불액 | 예약 조건·약관에 따른 실제 금액과 공제 항목 |
| 공급자 취소·기상 악화 | 각각의 처리 기준 |
| 당일 불참 | 실제 노쇼 조건 |

예약처·상품·출발일에 따라 조건이 달라집니다. 임의의 환불률을 표준으로 제시하지 않습니다.

여행 보험 옵션 추천.

## 9. 가격 표시 — 총 비용 투명성

| 항목 | 표시 |
|---|---|
| **1인 기본 가격** | 실제 예약일·인원 기준 가격 |
| **2인 동반 시** | 실제 할인 조건이 있는 경우만 표시 |
| **세금·수수료** | 포함 또는 별도 명시 |
| **추가 옵션** | 선택 시 합산 표시 |
| **할인 코드 적용** | 적용 가능 조건과 최종 금액 확인 |

"총 결제 금액"을 마지막에 한 번 더 표시.

## 활용 — Brief 출력 시

```yaml
brief:
  category: "여행"
  travel_specific:
    type: "{호텔|투어|액티비티|패키지|체험}"
    duration: "{실제 일정}"

    season:
      target: "{성수기|준성수기|비수기}"
      actual_prices: "{예약일별 실제 가격}"

    itinerary:
      - day: 1
        schedule: ["{실제 첫날 일정}"]
      - day: 2
        schedule: ["{실제 둘째 날 일정}"]

    inclusions: ["{실제로 포함된 항목}"]
    exclusions: ["{실제로 제외된 항목}"]

    reviews:
      evidence: "{실제 후기·집계가 있는 경우만}"

    cancellation_policy:
      - "{실제 약관의 기준 시각·조건·환불액}"

    pricing:
      base_price: "{현재 기본 가격}"
      per_person_2: "{실제 동반 가격이 있는 경우만}"
      tax_included: "{세금·수수료 포함 여부}"
      additional_options: ["{실제 추가 옵션}"]
```
