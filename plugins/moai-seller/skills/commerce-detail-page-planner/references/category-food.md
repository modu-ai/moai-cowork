# 카테고리 분기: 푸드 (Category — Food)

푸드 카테고리 (식품·음료·건강기능식품·농수산물) 상세페이지의 카테고리 특화 가이드.

---

## 1. 목적형 vs 탐색형 소비자 분리

푸드는 구매 동기에 따라 두 가지 사용자 타입이 명확히 갈린다.

### 목적형 (특정 제품 찾는 사용자)

| 행태 | 본문 전략 |
|---|---|
| 검색 → 비교 → 즉시 구매 | **최상단에 USP·가격·옵션 배치** |
| 페이지 체류 짧음 | 군더더기 제거 |
| 가격 민감 | 실제 할인·묶음·정기구독 조건 확인 |
| 신뢰 정보 중시 | 해당 제품의 표시·원산지·소비기한 확인 |

### 탐색형 (새로운 식품 발견하는 사용자)

| 행태 | 본문 전략 |
|---|---|
| 인스타·블로그 → 호기심 → 시도 | **스토리·라이프스타일 우선** |
| 페이지 체류 길어도 OK | 인트로 충실 |
| 감성 구매 | 실제 제품 사진·사용 허락을 받은 후기 |
| 새로운 경험 추구 | 차별화·독특함 강조 |

### 채널 매핑

- 채널마다 검색·추천·광고 경로가 달라집니다. 실제 판매 채널의 유입 자료를 보고 정보 순서를 정합니다.

---

## 2. 푸드만의 키워드 — "먹는 경험"

상세페이지에 다음 4개 키워드를 자연스럽게 녹여야 식욕 자극.

| 경험 | 카피 예시 |
|---|---|
| **시각** | "터지는 노른자, 윤기 흐르는 면발" |
| **후각** | "들어서면 풍기는 깊은 된장 향" |
| **촉각** | "한 입 베어물면 바삭, 안은 촉촉" |
| **청각** | "젓가락 들 때 '톡' 갈라지는 소리" |

미각 직접 표현보다 **다른 감각으로 미각 환기**가 효과적.

---

## 3. 농수산물 4가지 스토리텔링

농수산물은 산지·생산자 스토리가 차별화.

### 4가지 스토리 패턴

| # | 패턴 | 적용 |
|---|---|---|
| 1 | **산지 이야기** | 실제 원산지·생산 지역 자료가 있을 때 |
| 2 | **생산자 이야기** | 실제 생산자·공개 허락이 있을 때 |
| 3 | **계절 이야기** | 실제 수확·제조 시기가 확인될 때 |
| 4 | **전통·역사 이야기** | 기록으로 확인된 이력이 있을 때 |

판매자가 확인할 수 있는 이야기만 선택합니다.

---

## 4. 식품 광고 심의 가드

### 효능·원산지 표현 검토

| 확인할 표현 | 검토 기준 |
|---|---|
| 질병 예방·치료 | 식품을 의약품처럼 보이게 하는 주장인지 검토 |
| 면역·체중 관련 기능 | 제품 유형과 인정·허용된 표시 범위 확인 |
| 자연·무첨가·원산지 | 실제 원재료·제조 자료와 표시 기준 확인 |

### 건강기능식품 별도 규제

- 건강기능식품과 일반 식품을 구분하고, 실제 제품의 인정·표시·광고 심의 자료를 확인합니다.
- 일반 식품도 일정 요건 아래 기능성 표시가 가능한 경우가 있으므로 문구만 보고 일률적으로 허용·금지하지 않습니다.
- 질병 예방·치료, 의약품 오인, 건기식 오인, 허위·과장 광고는 식품표시광고법 제8조의 금지 대상입니다. [국가법령정보센터 제8조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029094685) · [일반식품 기능성 표시 규정](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000210547&chrClsCd=010201)

### 안전 표현 가이드

- 맛·향·신선도도 실제 제품 상태와 자료를 확인한 뒤 표현합니다.
- 기능·건강 관련 표현은 제품 유형, 허용 범위, 근거 자료를 확인합니다.

## 5. 푸드 본문 추가 권장 모듈

| 모듈 | 내용 |
|---|---|
| **영양 성분표** | 1회 제공량 + 100g당 |
| **알레르기 정보** | 현재 제품에 적용되는 표시 대상·원재료 확인 |
| **소비기한·보관법** | 실제 포장 표시와 일치 |
| **조리·섭취 방법** | 5단계 이내 |
| **함께 먹으면 좋은 음식** | 활용도 어필 |
| **원산지** | 해당 상품에 적용되는 원산지 표시 기준과 실제 자료 |

## 6. 푸드 사진 우선순위 (photo-checklist 보강)

기본 5종 (단면·원물·조리예·식탁·박스)에 추가:

| 추가 사진 | 이유 |
|---|---|
| **김 모락 살아있는 한 컷** | 즉시 식욕 |
| **소스·국물 흐르는 장면** | 질감 |
| **첫 한 입 갈라지는 단면** | 식감 |
| **포장 안 정렬** | 청결·정성 |

## 7. 가격 표시 — 푸드 특화

| 표시 방식 | 적용 |
|---|---|
| **1팩당 / 1인분당** | 단위 가격 명확 |
| **g당 가격** | 비교 우위 (경쟁 제품과) |
| **묶음 할인** | 실제 구성·기준 가격·현재 가격 |
| **정기 배송** | 실제 결제·배송·해지 조건 |
