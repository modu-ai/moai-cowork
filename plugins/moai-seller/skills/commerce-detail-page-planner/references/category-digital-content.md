# 카테고리 분기: 디지털 콘텐츠 (Category — Digital Content)

강의·e북·뉴스레터·소프트웨어 등 **무형 디지털 상품**. 물리 상품과 근본적으로 다른 카피·구조.

---

## 1. 무형 상품의 핵심 어려움

| 어려움 | 해결책 |
|---|---|
| 만질 수 없음 | **미리보기·체험판** 제공 |
| 효과 가시화 어려움 | **실제 학습 과제·확인된 결과** |
| 가치 가늠 어려움 | **구성·이용 기간·실제 제공 범위** |
| 환불 부담 | **실제 청약철회·환불 조건** |
| 신뢰 어려움 | **검증된 경력·사용 허락을 받은 후기** |

---

## 2. 디지털 콘텐츠 페이지 필수 8 섹션

```
[1] 히어로 — 확인된 핵심 내용 + 실제 구매 또는 체험 CTA
[2] 강사·저자 소개 — 경력·실적·신뢰
[3] 커리큘럼 / 목차 — 전체 흐름 + 각 챕터 소요 시간
[4] 미리보기 / 샘플 — 실제 제공하는 부분만 공개
[5] 학습 결과 — 커리큘럼으로 뒷받침되는 과제
[6] 수강생 후기 — 실제 후기와 사용 허락을 확인한 경우
[7] 가격 + 환불 조건 — 이용 기간과 실제 정책
[8] FAQ — 수강 환경·기간·자료·자격증
```

---

## 3. 학습 결과 어필 (Outcome 중심)

기능 나열 X, **수강 후 무엇을 할 수 있는가** 명시.

### 결과 카피 공식

```
"이 강의를 마치면, ___을 ___할 수 있어요."
                ↑              ↑
            확인 가능한 결과   실제 과제·수준
```

예시:
- ❌ "파이썬 기초를 배웁니다"
- ⭕ "예제 데이터로 정렬·필터링 코드를 작성해 볼 수 있어요"

- ❌ "디자인 강의"
- ⭕ "실습에 따라 모바일 화면을 직접 설계해 볼 수 있어요"

학습 기간·처리 속도·취업 또는 수입 결과는 실제 자료로 확인될 때만 약속합니다.

---

## 4. 강사·저자 신뢰 모듈

디지털 콘텐츠는 **강사 신뢰 = 구매 결정**. 별도 섹션 필수.

### 표시 요소

```
[1] 강사 사진 (전문 촬영)
[2] 확인된 직함·전문 분야
[3] 실제 공개 가능한 경력
[4] 자료가 있는 활동·성과
[5] 확인된 매체 노출
[6] 판매자가 제공한 현재 채널 정보
```

---

## 5. 커리큘럼 표시 — 시간 + 가치

| 챕터 | 소요 시간 | 학습 결과 |
|---|---|---|
| 1. 환경 설정 | 30분 | 개발 환경 갖춤 |
| 2. 기초 문법 | 2시간 | 기본 코드 작성 |
| 3. 데이터 처리 | 3시간 | 100건 데이터 정리 |
| ... | ... | ... |

각 챕터에 **결과 명시** — 단순 제목 X.

---

## 6. 미리보기·체험판 — 진입 장벽 해소

| 유형 | 적용 |
|---|---|
| **실제 공개하는 무료 챕터** | 강의·e북 |
| **실제 제공하는 무료 체험** | SaaS·구독 |
| **샘플 PDF** | e북 |
| **데모 영상** | 모든 콘텐츠 |
| **무료 워크북** | 강의 |

무료 제공이 없는 상품에는 체험 CTA를 만들지 않습니다. 실제 구매·미리보기 행동을 안내합니다.

---

## 7. 청약철회·환불 조건 (필수 확인)

디지털 콘텐츠는 환불 부담이 가입 장벽. 명확한 환불 정책으로 해소.

### 표시 위치

- 페이지 하단 별도 섹션
- CTA 버튼 옆 조건 요약 (실제 정책이 있을 때)
- FAQ에 상세

결제 전 실제 약관에서 청약철회 기간, 콘텐츠 제공 시작 여부, 미리보기 제공, 이용분 정산, 환불 신청 방법을 확인합니다. 전자상거래법 제17조는 일반적인 청약철회 기간과 디지털콘텐츠 제공 개시 때의 예외를 함께 규정합니다. 법정 권리를 일률적인 `결제 후 7일 100% 환불`로 바꾸거나, 판매자가 약속하지 않은 보장을 만들지 않습니다. [국가법령정보센터 제17조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1024961473)

## 8. 수강생 후기 — 정량·정성

| 표시 | 효과 |
|---|---|
| **완강률·재구매율** | 집계 기간·모수·산식을 확인한 경우만 표시 |
| **별점 분포** | 실제 플랫폼의 집계값을 출처와 함께 표시 |
| **정량 후기** | 원문·사용 허락·측정 근거를 확인한 경우만 표시 |
| **정성 후기** | 실제 수강생 원문과 사용 허락을 확인한 경우만 표시 |

---

## 9. 가격 표시 — 가치 환산

가격과 제공 범위를 먼저 명확히 표시합니다. 비교가 필요하면 같은 조건의 확인 가능한 상품만 비교합니다.

| 환산 방식 | 예시 |
|---|---|
| **구성 안내** | 포함된 강의·자료·이용 기간을 실제 조건대로 표시 |
| **대안 비교** | 비교 대상·범위·가격의 현재 출처를 확보한 경우만 사용 |
| **기간별 가격** | 실제 결제액과 이용 기간으로 계산하고 자동 갱신 조건을 함께 표시 |

## 10. 디지털 콘텐츠 카피 톤

- **명확 + 친근 + 전문**
- 학습 의지·발전 욕구 자극
- 막연한 "재미" X, 구체 "변화"
