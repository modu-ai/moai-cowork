# 카테고리 분기: 명품/럭셔리 (Category — Luxury)

명품·하이엔드 브랜드의 상세페이지는 **격식·여백·간결**이 핵심. 일반 이커머스와 완전히 다른 톤 매너.

---

## 1. 럭셔리 카피 톤의 4 원칙

| 원칙 | 설명 |
|---|---|
| **격식 (Formal)** | 친근체·이모지·신조어 금지 |
| **여백 (White Space)** | 시각 노이즈 최소 |
| **간결 (Brevity)** | 한 문장 = 한 메시지 |
| **정통성 (Heritage)** | 브랜드 역사·장인 정신 |

---

## 2. 럭셔리 vs 매스 비교

| 축 | 매스 시장 | 럭셔리 |
|---|---|---|
| 가격 강조 | 상품별 판매 방식 | 실제 판매 가격 또는 문의 방식 |
| CTA | "지금 구매" | "스토어 방문" "VIP 컨설팅 예약" |
| 페이지 길이 | 길게 | **짧게·압축적** |
| 색상 | 다채 | 모노톤·골드·검정 |
| 폰트 | 산세리프 | **세리프** (전통) |
| 톤 | 친근·감성 | **격식·세련** |
| 이미지 | 풍부·다양 | **고화질·소수정예** |
| 사회적 증명 | 실제 후기·자료 | 사용 허락을 받은 매체·기관 자료 |

---

## 3. 럭셔리 페이지 필수 6 섹션

```
[1] 히어로 — 제품 한 컷 + 짧은 헤드라인
[2] 브랜드 이야기 — 확인된 창립·제작 정보가 있을 때
[3] 제품 디테일 — 소재·생산·디자이너 (간결한 텍스트 + 고화질 사진)
[4] 컬렉션 / 세트 — 함께 어울리는 다른 제품
[5] 서비스 — 실제 제공하는 관리·수리·멤버십
[6] CTA — 스토어 위치·문의·예약
```

---

## 4. 브랜드 헤리티지 (필수)

럭셔리는 **이야기 = 가치**.

### 표시 요소

- **창립 연도** (공식 브랜드 자료로 확인한 경우)
- **국가·도시** (실제 설립·제작 장소를 구분)
- **창립자·장인 이야기**
- **시그니처 패턴·디자인 유산**
- **역사적 사용자** (사용 사실과 공개 권한이 확인된 경우)
- **수상·인증** (수상·인증 범위와 유효성을 확인한 경우)

---

## 5. 가격 표시 — 실제 판매 방식에 맞추기

가격 공개 방식과 구매 경로는 브랜드의 실제 판매 정책을 확인합니다. 결제 전에 고객이 총 결제액과 조건을 확인할 수 있어야 합니다.

| 방식 | 적용 |
|---|---|
| **온라인 구매** | 실제 판매 가격·옵션·배송 조건 표시 |
| **문의 판매** | 실제 문의 경로와 견적 절차 안내 |
| **오프라인 구매** | 실제 매장 정보와 가격 확인 방법 안내 |

할인이나 가격 비교는 실제 판매 조건과 브랜드 지침에 맞춰 결정합니다.

---

## 6. CTA — 실제 구매 경로

| CTA | 적용 |
|---|---|
| **"구매하기"** | 온라인 결제가 실제 가능한 경우 |
| **"부티크 방문 예약"** | 실제 예약 가능한 매장이 있는 경우 |
| **"상담 예약"** | 실제 상담 서비스를 제공하는 경우 |
| **"카탈로그 요청"** | 실제 요청·발송 절차가 있는 경우 |
| **"문의하기"** | 실제 고객 지원 경로가 있는 경우 |

---

## 7. 럭셔리 사진 (photo-checklist 보강)

| 추가 사진 | 이유 |
|---|---|
| 고화질 클로즈업 (소재·바느질) | 장인 정신 |
| 제품 단독 (배경 모노톤) | 시각 노이즈 X |
| 모델 컷 (셀러브리티 또는 무명) | 라이프스타일 |
| 박스·포장 (언박싱) | 럭셔리 경험 |
| 브랜드 부티크·작업실 | 헤리티지 |

원본 사진의 해상도·초점·색 정확도를 확인합니다. 촬영 장비 종류만으로 사진의 적합성을 판단하지 않습니다.

---

## 8. 사회적 증명 — 매체·기관

매체·기관 자료가 실제로 있고 인용 권한이 있을 때만 활용합니다. 실제 고객 후기 역시 출처와 사용 권한을 확인하면 사용할 수 있습니다.

### 표시 우선순위

```
[1] 인용 허락을 받은 실제 매체 소개
[2] 계약·자료가 있는 실제 협찬 노출
[3] 기록으로 확인된 실제 전시
[4] 초상·상표 사용 허락을 받은 실제 착장
[5] 확인 가능한 실제 수상 기록
```

| 모듈 | 내용 |
|---|---|

| **컬렉션** | 함께 어울리는 제품 |
| **케어 가이드** | 제품 관리·세탁·보관 |
| **수리·리퍼브** | 실제 제공 범위·기간·비용 |
| **VIP 서비스** | 실제 멤버십·맞춤 제작 조건 |

---

## 10. 카피 톤 매너

- **격식 + 세련 + 절제**
- "당신"보다 "Madame·Monsieur"·"고객님"
- 감탄사·이모지·신조어 X
- 한 문단 = 한 메시지
- 영어·프랑스어·이탈리아어 단어 자연 혼용 OK ("Maison" "Atelier" "Savoir-faire")
