# 카테고리 분기: B2B / SaaS (Category — B2B / SaaS)

B2B 솔루션·SaaS 제품은 구매 방식과 의사결정자를 확인해 페이지를 구성합니다.

---

## 1. B2C vs B2B/SaaS 차이

| 축 | B2C | B2B/SaaS |
|---|---|---|
| 의사결정자 | 1명 (구매자=사용자) | **다수** (사용자·관리자·경영진·법무) |
| 검토 시간 | 상품·조직에 따라 다름 | **도입 절차에 따라 다름** |
| 가격 민감도 | 절대 가격 | **ROI·TCO** (총소유비용) |
| 페이지 목적 | 실제 구매 경로 | **셀프서비스 구매 또는 데모·문의** (실제 판매 방식 확인) |
| 본문 길이 | 짧게·즉시 | **길게·상세** (기술 스펙·보안·SLA) |
| 톤 | 캐주얼·감성 OK | **격식·전문** |

---

## 2. SaaS 상세페이지 섹션 예시

```
[1] 히어로 — 핵심 USP 한 문장 + 실제 구매·체험·데모 CTA와 사용 화면
[2] 사회적 증명 — 공개 허락을 받은 고객 로고·집계가 있는 경우
[3] 핵심 기능 3~6개 — UI 캡처 + benefit 카피
[4] 비교 / 차별화 — 경쟁 SaaS와 매트릭스 비교 (기능 ✓/✗)
[5] 가격 페이지 (별도) — Free / Pro / Enterprise tier 표
[6] 보안·인증 — 실제 감사·인증·법적 의무와 이행 범위
[7] 고객 후기 / 사례 — 고객 사용 허락과 측정 근거가 있는 경우
[8] CTA — 실제 제공하는 체험·데모·문의 경로
```

---

## 3. 가격 페이지 — Tier 매트릭스

SaaS 가격은 별도 페이지 또는 상세페이지 하위 섹션에 표시할 수 있습니다. 실제 제공하는 요금제만 적습니다.

| Tier | 타깃 | 가격 모델 | 핵심 차이 |
|---|---|---|---|
| **Free / Trial** | 개인·신규 | 무료 | 기능 제한·사용량 제한 |
| **Pro** | 팀·스타트업 | 월 $X / 사용자 | 핵심 기능 모두 |
| **Enterprise** | 대기업 | "문의" | 보안·SLA·전담 지원·커스텀 |

가격 표시 원칙:
- **연간 결제 할인** (실제 제공하는 경우, 비교 기준과 함께)
- **사용자당 가격** vs **고정 가격** 명확
- **추가 비용** (스토리지·API 호출) 투명 공개
- **Enterprise 가격 비공개**인 경우 실제 문의 경로와 확인된 응답 정책 안내

---

## 4. 복수 의사결정자 매핑

B2B는 한 페이지에 **여러 페르소나용 콘텐츠** 동시 배치.

| 페르소나 | 관심사 | 페이지 배치 |
|---|---|---|
| **사용자** | 사용성·생산성 | 히어로·기능 섹션 |
| **관리자 / IT** | 보안·통합·관리 도구 | 보안 섹션·관리 화면 |
| **경영진** | ROI·도입 효과·비즈니스 가치 | 케이스 스터디·도입 효과 |
| **법무·구매** | 약관·계약·청구 | FAQ·약관 링크 |

각 섹션마다 페르소나 표기 권장: "[관리자용]·[CTO용]" 등.

---

## 5. CTA 전략 — 리드 수집 우선

B2B라도 셀프서비스 구매가 가능하면 실제 구매 경로를 안내합니다. 영업 상담이 필요한 상품은 리드 수집 경로를 확인합니다.

### CTA 유형 5종

| 유형 | 적용 |
|---|---|
| **무료 체험 시작** | Self-service 가능 SaaS |
| **데모 신청** | 영업 주도 SaaS |
| **영업팀 문의** | Enterprise tier |
| **가격 확인 (문의)** | 비공개 가격 |
| **백서 다운로드** | 리드 자석 (이메일 수집) |

### Form 설계

- 최소 필드 우선 (이메일만)
- 점진적 프로파일링 (다음 단계에서 회사·역할 수집)
- 처리 시간은 실제 측정하거나 운영 정책으로 보장하는 경우만 표시

---

## 6. ROI / TCO 강조

B2B 구매 의사결정의 핵심은 **ROI 계산**. 페이지에 다음 도구 권장:

- **ROI 계산기** (검증 가능한 입력·가정·계산식을 제시할 수 있는 경우)
- **TCO 비교 표** (현재 도구 비용 vs 우리 도구)
- **도입 효과 정량 사례** (측정 기간·모수·고객 공개 허락이 있는 경우)

---

## 7. 보안·컴플라이언스 (해당하는 경우)

| 항목 | 확인할 자료 |
|---|---|
| **SOC 2 Type II** | 실제 감사 보고서의 대상 법인·시스템·기간 확인 |
| **ISO/IEC 27001** | 인증서의 대상 법인·범위·유효기간 확인 |
| **GDPR** | 적용 여부와 실제 이행 자료 확인 |
| **개인정보보호법 (한국)** | 적용 의무와 실제 처리 방침·운영 자료 확인 |
| **HIPAA** | 적용 대상인지 먼저 확인하고 이행 자료 확인 |

SOC 2는 감사 보고서, ISO/IEC 27001은 인증서로 확인합니다. 실제 자료가 있고 로고 사용 권한을 확인한 경우에만 보안 페이지에 표시합니다. 법률 준수는 인증 로고로 표현하지 않습니다. [AICPA SOC 2 안내](https://www.aicpa-cima.com/topic/audit-assurance/audit-and-assurance-greater-than-soc-2) · [ISO/IEC 27001 안내](https://www.iso.org/standard/27001) · [ISO 로고 사용 안내](https://www.iso.org/certification.html)

---

## 8. 사회적 증명 — 로고 + 숫자

B2B는 "다른 누가 쓰는가"가 결정적.

### 표시 우선순위

```
[1] 공개 허락을 받은 도입 기업 로고
[2] 집계 기준이 확인된 사용자·기업 수
[3] 공개 허락과 측정 근거가 있는 사례
[4] 인용 허락을 받은 후기·직책·회사명
[5] 실제 플랫폼에서 확인한 별점
```

## 9. 본문 톤 매너

- **격식 + 전문 + 직접**
- "당신·우리" 대신 "팀·조직"
- 감정 표현 최소
- 데이터·수치 풍부
- 비교 우위 명확
