# 카테고리 분기: 펫 (Category — Pet)

반려동물 사료·간식·용품·서비스. **보호자가 구매하고 반려동물이 사용**하는 이중 페르소나.

대상: 강아지·고양이 / 기타 (햄스터·새·물고기 등).

---

## 1. 이중 페르소나 매핑

| 페르소나 | 관심사 | 카피 어필 |
|---|---|---|
| **구매자 (보호자)** | 안전·성분·반응·신뢰 | 실제 성분표와 적용 표시 |
| **사용자 (반려동물)** | 기호성·급여 방식 | 실제 급여량과 사용 허락을 받은 반응 후기 |

상세페이지는 보호자가 확인할 사양·급여 정보와 실제 반려동물 사용 장면을 함께 다룹니다.

---

## 2. 반려동물 종류·연령 분기

| 종류 | 단계 | 페이지에서 확인할 정보 |
|---|---|---|
| **강아지** | 제품의 실제 성장 단계 표시 | 급여 가능 대상·알갱이 크기 |
| **고양이** | 제품의 실제 성장 단계 표시 | 급여 가능 대상·형태 |
| **소형/대형견** | 제품의 실제 체중·크기 권장 | 알갱이 크기·급여량 |

페이지에 **연령·크기 추천 표** 또는 필터 권장.

---

## 3. 사료 성분 표시 (가장 중요)

| 항목 | 표시 |
|---|---|
| **단백질 함량** | 실제 제품 성분표의 수치 |
| **주재료 원산지** | 실제 원산지 표시와 증빙 |
| **첨가 비타민·미네랄** | 실제 성분표에 기재된 항목 |
| **함유하지 않은 물질** | 시험·제조 자료로 확인한 경우만 |
| **알레르기 정보** | 닭·소·옥수수 등 알레르기원 |
| **유통기한** | 명확히 |

성분표는 **이미지 + 텍스트** 동시 표시.

---

## 4. 보호자 페인포인트 매핑

| 페인 | 어필 |
|---|---|
| "안전한 성분인가?" | 실제 성분표·적용 표시·원산지 |
| "우리 아이가 잘 먹을까?" | 사용 허락을 받은 실제 보호자 후기 |
| "변 상태 좋아질까?" | 효능 약속 대신 실제 급여 방법 안내 |
| "알레르기 있을까?" | 알레르기 원인 표시 |
| "가격 부담?" | 1kg당 가격·정기 배송 할인 |
| "수의사 추천?" | 실제 추천과 공개 허락이 있는 경우에만 표시 |

---

## 5. 펫 본문 추가 권장 모듈

| 모듈 | 내용 |
|---|---|
| **종류·연령 추천** | 강아지/고양이/소형/대형 + 연령 |
| **성분표 시각화** | 표 + 이미지 + 함유 X |
| **수의사 추천** | 실제 추천 사실·자격·공개 허락을 확인한 경우만 |
| **급여 가이드** | 체중별 1일 급여량 표 |
| **반응 후기** | 실제 원문·사진 사용 허락을 확인한 경우만 |
| **정기 배송 할인** | 실제 제공하는 배송·할인 조건만 |

---

## 6. 광고 심의 가드

| 금지 | 사유 |
|---|---|
| **"100% 자연·100% 안전"** | 단정 표현 |
| **"질병 치료·예방"** | 의약품 효능 (사료에 사용 X) |
| **"수명 연장"** | 단정 표현 |
| **수의사 직책 사칭** | 실제 수의사 인증 필요 |

대체 문구도 효능을 주장할 수 있으므로 성분표·급여 방법·실제 시험 자료의 범위 안에서 작성합니다.

## 7. 펫 사진 (photo-checklist 보강)

| 추가 사진 | 이유 |
|---|---|

```yaml
    size: "{소형|중형|대형}"

      - "안전한 성분?"

    compliance:
      forbidden_terms: ["100% 안전", "질병 치료", "수명 연장"]
      vet_recommendation_verified: null  # 확인 전 미확인
```
