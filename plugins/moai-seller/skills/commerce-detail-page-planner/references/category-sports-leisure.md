## 2. 활동 시나리오 시각화

스포츠는 **사용 장면 = 구매 동기**. 시나리오 사진 풍부.

### 시나리오 분류

| 종목 | 시나리오 예시 |
|---|---|
| 캠핑 | 새벽 텐트 안·모닥불 옆·비 오는 타프 아래 |
| 러닝 | 새벽 트레일·도시 야경·마라톤 코스 |
| 자전거 | 시골 도로·산악 트레일·도시 출퇴근 |
| 골프 | 페어웨이·그린·러프·날씨별 |
| 등산 | 능선·바위·강풍·일출 |

각 시나리오마다 제품이 어떻게 도움 되는지 명시.

## 3. 기능 사양 표 (정량)

사양 숫자는 제품 자료와 측정 조건이 확인될 때 신뢰를 줍니다.

### 입력 항목 예시 — 트레일 러닝화

| 사양 | 값 |
|---|---|
| 중량 (표기 사이즈) | 실제 제품 사양 |
| 드롭 | 실제 제품 사양 |
| 미드솔 | 실제 소재 표시 |
| 아웃솔 | 실제 부품·상표 사용 권한 |
| 방수 | 실제 시험 조건·적용 소재 |
| 핏 | 실제 실측·착용 정보 |
| 적합 거리 | 제조사 자료가 있는 경우만 |
| 적합 지형 | 실제 사용 조건·주의사항 |

---

## 4. 사이즈·핏 가이드

사이즈·핏은 선택에 도움이 되는 정보입니다. 맞는 사이즈가 부상을 예방한다고 보장하지 않습니다.

### 표시 권장

- 발 길이 / 발폭 측정법 (사진 + 다이어그램)
- 다른 브랜드와 사이즈 비교는 양쪽 실측 자료가 있을 때만
- 시즌·양말 두께에 따른 권장 사이즈
- 후기 기반 통계는 집계 기준·표본이 확인될 때만

## 5. 호환성 표시

기존 장비와 함께 쓰는 경우 — 호환 명시 필수.

| 카테고리 | 호환 정보 |
|---|---|
| **자전거 부품** | 프레임 크기·크랭크·드레일러 호환 |
| **카메라 액세서리** | 마운트·전기 접점 |
| **골프 그립** | 샤프트 굵기·기존 그립 제거 방법 |
| **러닝화 인솔** | 발 모양·아치 높이 |

---

## 6. 운동선수·전문가 추천 (신뢰)

스포츠는 **신뢰 = 전문가 사용**.

### 표시 우선순위

```
[1] 사용 사실과 초상·이름 공개 허락이 있는 선수 사례
[2] 협찬 관계와 사용 허락을 확인한 추천
[3] 실제 입점 자료
[4] 인용 허락을 받은 실제 매체 리뷰
[5] 사용 허락과 집계 근거가 있는 고객 후기
```
