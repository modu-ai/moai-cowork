# 카테고리별 사진 체크리스트 (Photo Checklist)

상세페이지에 필요한 사진은 **카테고리 × 거리(가까운/먼)**로 나누어 검토합니다. 제품에 해당하지 않는 컷은 촬영 목록에서 뺍니다.

---

## 카테고리별 가까운/먼 사진 아이디어

아래 표의 사진은 필수 요건이 아닙니다. 실제 제품·장소·인물의 사진과 사용 권한을 먼저 확인합니다. 인증·효능·추천을 보여주는 사진은 해당 자료가 있을 때만 고릅니다.

### 패션 (의류·잡화)

| 거리 | 사진 아이디어 | 비고 |
|---|---|---|
| 가까운 | 원단 클로즈업 (텍스처·짜임) | 손가락이나 자 함께 — 두께·재질 가늠 |
| 가까운 | 부자재 (단추·지퍼·라벨) | 마감 품질 증명 |
| 가까운 | 디자인 디테일 (자수·프린트·스티치) | 사진으론 안 보이는 차별화 |
| 먼 | 전신 착장 (정면·측면·후면) | 핏 가늠 |
| 먼 | 코디 룩 (3-5 코디) | 활용도 어필 |

## 사진 없이 상세페이지 기획 5단계 (사진 촬영 전)

촬영 전에 기획을 마쳐야 사진을 효율적으로 찍을 수 있다.

```
[1] 원 메시지 결정
    → 모듈 1 (One Message) 산출
    → 사진의 미적 방향 확정

[2] 특징 3~5개 추출
    → USP 1~3개 + 좋은 제품 특징 2~3개

[3] 각 특징별 사진 종류 결정
    → 가까운 vs 먼
    → 사진 vs 디자인 이미지 (보이는 특징 vs 안 보이는 특징)

[4] 사진 vs 짧은 영상 결정
    → 정적 사진 (텍스처·발색·디테일)
    → 짧은 영상 (실제 작동·움직임)

[5] 흐름 짜기 (사용 가능한 문서·슬라이드·디자인 도구)
    → 슬라이드별 캡션 + 사진 자리만 표시
    → 후속 촬영 가이드 도출
```

## 사진 vs 짧은 영상 선택 기준

| 사진(정적) | 짧은 영상(동적) |
|---|---|
| 텍스처·재질·색·디테일 | 작동·움직임·접힘·펼침 |
| 정확한 가늠이 중요 | 시간 흐름이 중요 |
| 인쇄·SNS 다른 채널 재활용 | 모바일 상세 전용 |
| 파일 크기 확인 | 게시 채널의 현재 형식·용량 제한 확인 |

## 레퍼런스 찾기 5단계

1. **실제 제품 사진** — 보유 자산과 사용 권한 확인
2. **유료 광고 단어 추출** — 카테고리 검색 → 광고 이미지에 쓰인 단어·구도 메모
3. **참고 이미지** — 라이선스와 사용 범위를 확인해 분위기만 참고
4. **경쟁사 상세페이지** — 공개 화면의 흐름·구도만 참고하고 이미지·문구는 복제하지 않음
5. **자체 무드보드** — 실제 촬영 목록을 한 페이지에 정리

## 촬영 당일 체크리스트

- [ ] 해당 상품에 필요한 사진만 골랐는가?
- [ ] 각 사진이 실제 특징을 확인하게 돕는가?
- [ ] 움직임을 보여줘야 하는 기능은 실제 작동 영상으로 촬영했는가?
- [ ] 사이즈 가늠 사진 (자·손·사람 옆) 찍었는가?
- [ ] 패키지 박스 개봉 시퀀스 찍었는가?
- [ ] 인물·고객 후기·타사 상표의 촬영 및 사용 권한을 확인했는가?

## 이미지 편집 도구 선택

- 사용 가능한 편집 도구에서 밝기·대비·선명도를 확인합니다.
- 배경을 제거하거나 이미지를 합성했다면 제품 형태·색·표시가 바뀌지 않았는지 원본과 대조합니다.
- 실제 판매 채널의 이미지 비율·파일 크기·형식 제한을 공식 판매자 문서에서 확인합니다.
- ChatGPT 기본 이미지 생성은 `media-codex-image`, 사용자가 Higgsfield를 지정한 경우는 `media-higgsfield-image`로 연결합니다. 생성 이미지는 실제 상품·인증·후기 사진의 증빙으로 쓰지 않습니다.
