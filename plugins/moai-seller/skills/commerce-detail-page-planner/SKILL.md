# 상세페이지 기획

## 입력

상품의 실제 사양·사진·가격·판매 채널·고객 질문과 검증 가능한 장점을 확인합니다. 구매 후기·성능 수치·인증·안전성·효과는 자료가 없으면 브리프에서 미확인으로 표시합니다.

## 기획

1. 고객이 알아야 할 핵심 메시지를 한 문장으로 정합니다. 제품의 성능·안전 약속은 근거 자료의 범위를 넘지 않습니다.
2. 상품 특징, 사용법, 옵션·규격, 가격·배송·교환·반품, 실제 근거, 구매 행동을 이해하기 쉬운 순서로 배치합니다. 13섹션 구조는 선택 가능한 틀이며 모든 섹션을 채울 필요는 없습니다.
3. 기존 상품 사진을 섹션과 연결하고 부족한 컷의 촬영 브리프를 만듭니다. 인물·고객 후기·인증서는 실제 자료와 사용 권한이 있을 때만 씁니다.
4. 채널별로 현재 등록 규격과 광고·표시 정책을 공식 판매자 문서에서 확인합니다. `references/category-*.md`와 `photo-checklist.md`는 아이디어 목록이며 수치·법적 표현은 최신 자료로 다시 검증합니다.

## 산출물

핵심 메시지, 대상 고객의 확인된 요구, 페이지 정보 순서, 사용할 원본 사진, 추가 촬영 컷, 채널별 규격·정책 확인 결과, 누락된 근거를 짧은 브리프로 정리합니다. 실제 카피는 `commerce-detail-page-copy`, 이미지 합성은 `commerce-detail-page-image`, HTML은 `commerce-product-detail`로 이어갑니다. 자동 호출이나 완료 상태를 확인 없이 주장하지 않습니다.
