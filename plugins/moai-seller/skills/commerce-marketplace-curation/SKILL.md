# 큐레이션 채널 입점 제안

## 목적

사용자가 제공한 브랜드와 상품 자료로 카카오 메이커스·무신사·29CM의 입점 제안 초안을 작성합니다. 채널이 입점·노출·매출을 보장한다고 말하지 않습니다. 신청 경로와 계약 조건은 현재 공식 파트너 화면에서 확인합니다.

## 트리거

큐레이션 커머스, 카카오 메이커스, 메이커스, 무신사, 무신사스토어, 29CM, 라이프스타일 셀렉션,
주문생산, 한정 발매, 셀렉션, 입점 제안, 큐레이션 입점, MD 제안

## 작업 순서

1. **자료 받기** — 브랜드 정체성, 실제 판매 상품과 인증, 사진 사용 권리, 생산·배송 방식, 가격·원가, 현재 유통 이력과 신청 국가를 확인합니다. 매출·후기·팔로워 수는 원자료가 없으면 `미확인`으로 둡니다.
2. **채널 후보 고르기** — 현재 취급 품목과 사용자가 원하는 주문·배송 방식, 공개된 입점 안내를 대조합니다. 특정 연령대·카테고리만으로 승인 가능성을 점수화하지 않습니다.
3. **공식 신청 경로 확인** — 무신사는 [공식 파트너 입점 페이지](https://partner.musinsa.com/entry/login), 29CM는 [공식 파트너 안내의 입점 신청 링크](https://partner-stage.one.musinsa.com/musinsa-store)에서 시작합니다. 29CM 링크는 문의 화면으로 연결되므로 실제 제출 가능 여부와 심사 조건은 화면·담당자에게 확인합니다. 카카오 메이커스의 현재 접수 경로는 공식 사이트에서 확인하고, 찾지 못하면 담당자에게 묻습니다.
4. **제안 자료 작성** — 실제 브랜드 소개, 상품 카탈로그, 사진·표시 자료, 공급 가능 수량과 배송 계획을 정리합니다. 채널이 요구하지 않은 PDF 분량·상품 개수·팔로워 기준을 필수라고 쓰지 않습니다.
5. **조건 검토** — 현재 제안서와 계약에서 수수료, 재고 소유·보관, 반품·정산, 광고·콘텐츠 협업, 독점·재신청 제한을 확인합니다. 확인 전에는 비용·노출·심사 기간을 확정하지 않습니다.
6. **제출과 운영** — 입점 신청·계약·광고 구매는 사용자 승인 후 실행합니다. 제출·승인·노출·매출은 실제 계정 결과를 확인한 뒤 기록합니다.

간단한 입점 소개 문구 요청에는 확보한 브랜드 사실로 초안을 작성합니다. 계정 접근이나 계약 자료가 없어도 초안은 제공하고, 제출·비용 계산 단계의 누락 자료만 표시합니다.

## 주의

- 확인되지 않은 입점 수수료, 심사 기간, 통과율, 재신청 제한, 광고 효과를 사실처럼 쓰지 않습니다.
- 브랜드 인지도나 SNS 팔로워가 적다는 이유만으로 신청 불가라고 단정하지 않습니다.
- 한국어 문안은 원본 상품 정보·가격·혜택과 대조하고, 사용 권리가 없는 후기·이미지·성과를 넣지 않습니다.
