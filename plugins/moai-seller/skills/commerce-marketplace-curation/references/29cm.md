# 29CM 입점 제안 자료

[무신사 공식 파트너 안내](https://partner-stage.one.musinsa.com/musinsa-store)의 `29CM 입점 신청`은 [29CM 문의 화면](https://www.29cm.co.kr/customer/contact-us)으로 연결됩니다. 이 링크에서 시작하되, 실제 제출 가능 여부·담당 부서·심사 자격은 현재 화면이나 담당자 답변으로 확인합니다. [29CM 쇼핑몰](https://www.29cm.co.kr/)은 상품과 브랜드를 살펴보는 곳이며 입점 신청서로 단정하지 않습니다.

## 브랜드 자료

- 브랜드 정체성과 상품의 차별점, 실제 판매·제작 단계
- 상품 사진과 설명의 사용 권리, 가격·재고·배송 계획
- 품목별 표시·인증 자료와 기존 유통 실적의 원자료
- 채널 제안에 필요한 협업 아이디어와 공급 가능 범위

기존 매출이나 후기·팔로워 수가 없으면 `미확인`으로 두고, 합격 기준이나 통과율을 만들어 내지 않습니다. 공개된 카테고리 구성이나 특정 고객 연령을 전체 이용자의 고정 비율로 제시하지 않습니다.

## 계약과 운영

수수료, 재고 소유·보관, 정산 주기, 반품, 독점 여부와 콘텐츠 협업은 브랜드별 현재 계약에서 확인합니다. 29CM가 모든 상품을 위탁 보관하거나 모든 브랜드에 매거진 노출을 제공한다고 약속하지 않습니다. 이미지 규격은 해당 파트너 상품 등록 화면에서 확인합니다.

브랜드 제안 문안은 실제 사진·상품 사실로 작성합니다. 제출·승인·노출·매출은 파트너 계정이나 담당자 기록을 확인한 뒤 표시합니다.
