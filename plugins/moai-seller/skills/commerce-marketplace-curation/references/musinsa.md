# 무신사 입점 자료

무신사 입점은 [공식 파트너 페이지](https://partner.musinsa.com/entry/login)와 [입점 신청서](https://partner.musinsa.com/entry/apply)에서 현재 경로를 확인합니다. 기존 문서의 `my.musinsa.com` 쇼핑 계정 주소를 입점 접수처로 사용하지 않습니다.

## 신청 전 확인

- 신청 브랜드와 상품의 실제 소유·유통 권리
- 현재 [공식 입점 문의](https://www.musinsa.com/app/company/partner)에 적힌 취급 상품 조건
- 브랜드 소개, 실제 상품 사진, 가격과 공급 가능 수량
- 사업자·정산 자료 등 현재 신청 화면이 요구하는 서류
- 품목별 표시·인증 및 상표·사진 사용 권리

SNS 팔로워 수, 사업 기간, 매출 규모를 공개된 필수 기준처럼 적용하지 않습니다. 공식 신청서에 없는 PDF 분량이나 제품 수를 필수 서류라고 안내하지 않습니다.

## 계약과 상품 등록

입점 제안이 승인되면 실제 계약에서 수수료, 재고 보관·소유, 공급·배송·반품, 정산, 광고·콘텐츠 협업 조건을 확인합니다. 모든 브랜드가 위탁 재고를 무신사 물류센터에 맡긴다고 단정하지 않습니다. 이미지 크기·형식은 현재 파트너 상품 등록 화면에서 확인합니다.

## 진행 상태

신청 후 진행 현황은 공식 파트너 페이지의 계정 기록으로 확인합니다. 서류 심사·미팅·승인에 걸리는 기간과 재신청 제한은 현행 화면이나 담당자 답변이 없으면 `미확인`으로 둡니다. 매거진·광고 노출은 별도 제안·계약을 확인합니다.
