# 카카오 메이커스 제안 자료

[카카오의 공식 서비스 소개](https://www.kakaocorp.com/page/service/service/KakaoMakers)는 공동주문·주문제작과 수요 불확실성을 줄이는 취지를 설명합니다. 이 설명만으로 모든 상품이 주문생산이거나 카카오톡의 특정 지면에 노출된다고 약속할 수 없습니다.

## 먼저 확인할 것

- 현재 파트너 제안·입점 접수 경로와 신청 자격
- 상품 품목, 실제 생산 방식, 최소 생산 수량과 배송 가능 시점
- 판매 기간과 주문 취소·반품 조건
- 수수료·결제비용·정산·재고 소유에 관한 개별 계약
- 사진·영상·상표 사용 권리와 품목별 표시·인증 자료

[공식 메이커스 화면](https://makers.kakao.com/)에서 현재 서비스와 접수 안내를 확인합니다. 공개 화면에서 파트너 신청 경로가 보이지 않으면 담당자 확인 항목으로 남깁니다. 쇼핑몰 첫 화면을 신청서라고 안내하지 않습니다.

## 제안서 초안

1. 브랜드와 상품이 실제로 해결하는 문제를 원자료로 설명합니다.
2. 공동주문·주문제작이 적합하다면 생산·검수·배송 계획을 구체화합니다. 이미 만든 재고가 있다면 그 사실을 그대로 적습니다.
3. 가격·수량·한정 기간은 사용자가 확인한 판매 계획으로만 채웁니다.
4. 예상 노출·판매량이나 입점 확률은 근거 없이 수치화하지 않습니다.

## 제출과 운영

계약·입점·광고 구매는 사용자의 승인 후 진행합니다. 실제 신청 상태와 주문 결과를 계정에서 확인하기 전에는 성공으로 표시하지 않습니다. 배송 지연이 생기면 확인한 변경 일정과 해당 채널 정책을 기준으로 안내합니다.
