# 네이버 스마트스토어 상품 등록 점검

[스마트스토어 고객센터](https://help.sell.smartstore.naver.com/)와 현재 판매자 계정의
상품 등록 화면을 함께 확인합니다. [상품 등록 FAQ](https://help.sell.smartstore.naver.com/faq/content.help?faqId=15745)는
카테고리와 대표 이미지 등 등록 기준을 안내합니다. 공개 FAQ만으로 계정의
등록 권한이나 실제 입력 한도를 확정하지 않습니다.

## 이미지와 상세설명

- 대표·추가·상세 이미지의 크기, 파일 용량·형식, 카테고리별 조건을 각각 확인합니다.
- 작업용 1080×12720 상세 합성본을 그대로 업로드할 수 있다고 가정하지 않습니다.
  필요하면 현재 제한에 맞게 별도 변환하고 업로드·미리보기 결과를 확인합니다.
- 이미지에 넣은 사양·인증·후기·가격·혜택 문구를 상품 원본과 대조합니다.

## 상품 정보와 고객 응대

- 실제 상품과 맞는 카테고리, 브랜드·모델·옵션, 가격·재고·배송·반품 조건을 확인합니다.
- 상품명·태그의 입력 제한과 노출 정책은 현재 계정 화면에서 확인합니다.
  후기 건수·평점·톡톡 응답 시간에 대한 보편적 검색 우대 수치를 만들지 않습니다.
- 리뷰 혜택이나 톡톡 자동응답은 현재 정책·계정 설정·고객 동의를 확인합니다.
  보상과 무관하게 특정 평점을 강요하거나 허위 후기를 유도하지 않습니다.

등록 후에는 실제 상품 페이지를 열어 이미지·옵션·고지·구매 경로를 확인합니다.
확인 전에는 검색 노출과 등록 성공을 약속하지 않습니다.
