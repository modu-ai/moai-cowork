# 네이버 스마트스토어와 오픈마켓 등록 검토

## 시작 자료

판매 채널과 계정 유형, 상품의 실제 사양·카테고리·가격·옵션·재고·배송·반품 조건,
대표 이미지와 상세 이미지, 등록하려는 문구를 확인합니다. 자료가 없으면
해당 항목을 `미확인`으로 두고 확인 경로를 제시합니다.

채널의 이미지 크기·용량·형식, 상품명·검색어·태그의 입력 제한,
금지 표현과 노출 조건은 현재 판매자 계정 화면과 공식 안내에서 확인합니다.
시점·카테고리·상품 유형에 따라 다를 수 있는 숫자를 공통 규칙으로 쓰지 않습니다.

| 채널 | 공식 출발점 | 확인할 계정 화면 |
| --- | --- | --- |
| 네이버 스마트스토어 | [스마트스토어 고객센터](https://help.sell.smartstore.naver.com/) | 상품 등록·카테고리·이미지·검색설정 |
| 11번가 | [셀러오피스](https://soffice.11st.co.kr/) | 상품 등록·이미지·검색어·정산 |
| G마켓·옥션 | [ESM PLUS](https://www.esmplus.com/) | 각 마켓의 상품 등록·이미지·정산 |

## 진행 순서

1. **상품 사실 대조**: 브랜드·모델·인증·옵션·가격·배송 약속을 원본 자료와
   대조합니다. 경쟁 판매자의 문구와 카테고리를 그대로 복사하지 않습니다.
2. **채널별 등록 조건**: 현재 계정에서 카테고리 권한, 이미지 입력값,
   상세설명 방식, 상품명·검색어 제한을 확인합니다. 확인되지 않은 검색 우대나
   고정 순위 기준을 제시하지 않습니다.
3. **이미지 검토**: `commerce-detail-page-image`의 1080×12720 합성본은 작업용
   원본입니다. 그대로 업로드 가능하다고 가정하지 않고 현재 채널 규격과
   실제 업로드 결과를 확인합니다. 규격이 다르면 별도 변환을 안내합니다.
4. **고객 안내**: 톡톡·후기·쿠폰·메시지는 현재 계정 기능, 동의와 플랫폼 정책을
   확인합니다. 후기 작성 대가나 평점을 조건으로 한 보상은 승인된 정책 범위에서만
   제안하며 허위 후기를 만들지 않습니다.
5. **등록 전 확인**: 미리보기, 옵션·가격·재고, 고지 항목, 이미지와 금지 표현을
   확인합니다. 실제 저장·노출을 확인하지 않았다면 등록 완료로 표시하지 않습니다.

채널별 세부 점검 항목은 `references/naver-smartstore.md`와
`references/openmarket-common.md`를 따릅니다. 광고 문구의 법규 검토는
`commerce-ad-claim-compliance-kr`, 이미지 제작은 `commerce-detail-page-image`로
이어갑니다. 쿠팡 등록은 `commerce-marketplace-coupang`을 사용합니다.

## 결과

채널별로 확인한 조건·출처·조회일, 상품과 이미지의 검토 결과,
수정할 문구, 누락 자료, 업로드·미리보기의 실행 여부를 적습니다.
실행하지 않은 채널 정책 확인이나 표현 검수를 `PASS`로 표시하지 않습니다.
