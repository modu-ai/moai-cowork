# 매장 운영 브리핑

## 범위

주문 요약인지 운영 전체 브리핑인지, 대상 매장·채널·조회 날짜·시간대·상태 기준을 정한다. '오늘'과 '어제'는 매장 시간대로 계산한다. 연결되지 않은 매장 또는 광고 계정을 읽은 것으로 표시하지 않는다.

## 자료 수집

1. 현재 호스트에서 실제 연결된 스마트스토어·카페24·아임웹 등 커머스 도구의 조회 기능을 확인한다. 없으면 사용자가 제공한 내보내기 파일·스크린샷·텍스트를 사용한다.
2. 주문 건수는 주문 ID, 채널, 상태, 결제 시각 기준을 명시한다. 같은 주문의 복수 상품행·채널 동기화 중복·취소·환불을 확인하고 합계를 계산한다.
3. 문의는 미답변 상태와 조회 시각을 확인한다. 광고 ROAS는 광고비·귀속 매출·기간·귀속 방식을 같은 기준으로 확인한다.
4. 검색 트렌드는 별도 출처가 있을 때만 넣는다. 주문 데이터에서 트렌드가 확인된 것처럼 쓰지 않는다.

## 출력 예시

| 항목 | 값 | 범위·기준 |
|---|---:|---|
| 신규 주문 | 확인된 건수 | 채널·상태·기간 |
| 순매출 | 확인된 금액 | 취소·환불 반영 기준 |
| 미답변 문의 | 확인된 건수 | 조회 시각 |
| 광고 성과 | 확인된 수치 | 계정·기간·귀속 기준 |

빠진 채널은 0으로 합산하지 않고 미조회로 표시한다. 실제로 확인한 채널만 합계에 포함하고, 제외된 채널을 함께 적는다. 소스별 조회 시각이 다르면 그 차이를 표시한다.

## 검수와 저장

합계·전일 대비의 분모를 다시 계산하고 원본 자료와 대조한다. 결과 파일 저장은 사용자의 작업 폴더와 현재 호스트의 쓰기 기능을 확인한 경우에만 수행한다. 저장하지 않았으면 파일을 만들었다고 쓰지 않는다. 조회 불가·자료 부족·미검증 수치는 그대로 보고한다.
