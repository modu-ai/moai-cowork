## 마켓별 확인 절차

1. 계정의 상품 유형과 카테고리 권한을 확인합니다.
2. 대표·추가 이미지와 상세 이미지의 입력란을 구분하고 각각의 크기,
   파일 용량·형식·장수·사용 권한을 확인합니다.
3. 상세설명 에디터가 이미지, 텍스트, HTML을 어떻게 받는지 확인합니다.
   외부 CSS·JavaScript·iframe을 지원한다고 가정하지 않습니다.
4. 상품명·검색어·태그의 입력 제한과 고지 항목을 현재 화면에서 확인합니다.
   후기·평점·배송 유형의 검색 순위 가중치를 만들지 않습니다.
5. 등록 전 실제 미리보기에서 이미지·문구·가격·옵션·배송·반품 정보를
   확인합니다. 저장·노출은 별도의 결과로 기록합니다.

규격이 다르면 필요한 변환 도구와 절차를 정하고 변환 결과를 확인합니다.
이미지 생성 스킬의 인라인 코드는 채널별 변환·업로드를 수행하지 않습니다.

기존 프로젝트의 프레임워크·디자인 토큰·컴포넌트·이미지 처리 방식을 따릅니다.
반응형 크기와 이미지 최적화는 실제 레이아웃과 기기에서 확인합니다.

코드만 생성한 경우 결제·주문·배포가 작동한다고 보고하지 않습니다.
