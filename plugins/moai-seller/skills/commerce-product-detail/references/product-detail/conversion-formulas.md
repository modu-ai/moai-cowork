# 상품 상세페이지의 전환 점검

전환율은 상품·유입·가격·배송·측정 방식에 따라 달라집니다.
업계 평균이나 CTA 색상의 개선폭을 근거 없이 대입하지 않습니다.
상품의 실제 자료와 같은 기간의 방문·주문 기록으로 가설을 세웁니다.

## 정보 순서

다음은 선택 가능한 구성입니다. 고객 질문에 답하지 않는 섹션은 생략합니다.

1. **처음 보는 정보** — 실제 상품명, 대표 사진, 가격·옵션, 핵심 사양을 분명히 보여줍니다.
2. **선택 이유** — 제품의 확인된 기능과 사용 조건을 설명합니다. 성능·효능·안전성은 시험·표시 자료의 범위에서만 씁니다.
3. **비교 자료** — 타사·이전 제품과 비교할 때 같은 조건의 현재 자료와 사용 권한을 확인합니다.
4. **신뢰 자료** — 후기·평점·인증·전문가 추천은 원본, 집계 기준, 공개 허락이 있을 때만 사용합니다.
5. **구매 조건** — 총 결제액, 배송, 교환·반품, 실제 재고·행사 조건을 보여줍니다.
6. **행동** — 현재 채널에 실제로 존재하는 구매·문의·체험 경로로 안내합니다.

한정 수량이나 마감 시간을 꾸며 긴급성을 만들지 않습니다. 판매 채널이 표시하는 정보와 페이지 문구가 일치해야 합니다.

## 특징을 고객 정보로 바꾸기

| 자료 | 설명할 수 있는 것 | 보류할 것 |
| --- | --- | --- |
| 실제 제품 사양 | 용량·크기·소재·구성품 | 시험하지 않은 성능·절감액 |
| 시험 보고서 | 대상·조건·측정값·한계 | 다른 조건에서의 동일한 결과 |
| 제품 사용법 | 실제 단계·주의사항 | 모든 사용자에게 같은 효과 |
| 판매 기록 | 출처·기간이 있는 주문·후기 | 출처 없는 판매량·별점 |
| 계약·운영 기록 | 현재 배송·반품·보증 조건 | 제공하지 않는 무료배송·환불 보증 |

예를 들어 4.5L 용량은 확인된 사양일 수 있습니다.
10시간 작동, 피부 개선, 월 전기료 절감에는 각각 별도 측정과 적용 조건이 필요합니다.
화장품 효능이나 질병 관련 표현은 해당 제품의 심사·표시·실증 자료를 먼저 확인합니다.

## 전환 지표

- 측정 도구에서 같은 기간·같은 채널의 방문 또는 세션 정의와 주문 정의를 확인합니다.
- 전환율은 측정된 주문 수를 같은 범위의 방문 또는 세션 수로 나눠 계산하고 분모 정의를 함께 적습니다.
- 방문부터 상품 조회·옵션 선택·장바구니·결제까지 어디에서 이탈하는지 실제 이벤트 기록을 확인합니다.
- 주문 수가 적거나 측정 방식이 바뀌었으면 한 번의 비율 차이를 성과로 확정하지 않습니다.
- 목표는 제품 마진·유입 비용·재고·반품률을 고려해 판매자가 정합니다.

## 개선 실험

1. 문제를 하나 정합니다. 예: 모바일에서 배송비를 결제 직전에만 확인할 수 있는가?
2. 같은 상품·대상·기간에서 바꿀 요소와 성공 지표를 정합니다.
3. 실험 도구의 분할 방식과 표본·기간을 현재 트래픽에 맞춰 계산합니다. 모든 실험에 같은 표본 수나 기간을 적용하지 않습니다.
4. 결과에는 모수, 기간, 차이와 불확실성을 함께 기록합니다. 검증하지 않은 개선폭을 평균 효과로 제시하지 않습니다.
5. 법정 표시·접근성·고객의 결제 조건은 실험 때문에 숨기지 않습니다.

CTA의 색보다 읽을 수 있는 대비와 실제 구매 경로가 우선입니다.
이미지 형식·폭·용량은 [판매 채널별 확인 항목](platform-specs.md)과 실제 등록 화면에서 확인합니다.
웹사이트라면 사용 중인 이미지 처리 방식과 모바일 성능을 측정합니다.
첫 화면의 핵심 이미지를 무조건 지연 로딩하지 않습니다.

## 결과 기록

상품 사양과 효능 근거, 후기 사용 권한, 채널의 이미지·에디터 규격,
방문·주문 정의와 기간, 실험 가설·결과를 구분해 기록합니다.
실제 실험을 하지 않았다면 결과는 NOT-RUN으로 표시합니다.

자료가 없는 상품에도 정보 순서와 필요한 자료 목록은 제안할 수 있습니다.
전환율, 절감액, 효능, 배송 속도, 할인·재고·환불 보증은
실제 자료가 확인되기 전에는 판매 문구로 만들지 않습니다.
