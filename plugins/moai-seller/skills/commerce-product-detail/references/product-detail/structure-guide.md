# 상품 상세 콘텐츠 구조 가이드

[상위 스킬](../../SKILL.md)의 입력·산출물 경계를 따릅니다.
판매 채널이 마켓인지 자사몰인지 먼저 확인합니다.
마켓 에디터에 HTML·CSS·JavaScript를 그대로 올릴 수 있다고 가정하지 않습니다.
등록 규격은 [채널별 확인 항목](platform-specs.md)과 현재 판매자 계정에서 확인합니다.

## 정보 순서

다음은 선택 가능한 블록입니다. 실제 상품 정보가 없는 블록은 생략하거나 미확인으로 남깁니다.

| 블록 | 필요한 자료 | 확인할 점 |
| --- | --- | --- |
| 대표 정보 | 실제 상품명·이미지·옵션·판매가 | 현재 채널의 입력란과 이미지 권한 |
| 선택 이유 | 제품별 사양·시험·사용법 | 효능·안전성의 표현 근거 |
| 상세 사양 | 규격·구성품·주의사항 | 포장·제조사 자료와 일치 |
| 배송·반품 | 현재 판매 정책·약관 | 가격과 결제 전 고지 |
| 후기·평점 | 실제 집계·원문·사용 허락 | 모수·기간·인용 범위 |
| 질문과 답변 | 실제 고객 질문과 확인된 답 | 보증·호환성 단정 금지 |
| 구매 행동 | 계정에 존재하는 구매·문의 경로 | 옵션·재고·가격 연결 |

후기, 할인율, 남은 재고, 무료배송, 내일 도착, 환불 보증은
실제 자료가 있을 때만 표시합니다.
관련 상품도 실제 판매 상품과 현재 가격이 확인된 경우에만 추천합니다.
법정·채널별 상품 정보 고시는 품목과 판매 국가에 따라 확인합니다.

## 화면 설계

- 현재 브랜드의 색·폰트·컴포넌트와 기존 웹사이트의 디자인 시스템을 우선 사용합니다.
- 작은 화면에서 상품명·가격·옵션·배송·구매 행동을 읽고 조작할 수 있는지 확인합니다.
- 이미지의 비율·형식·용량·장수는 채널의 실제 등록 화면에서 확인합니다.
- 고정 하단 버튼·탭·아코디언은 콘텐츠와 구매 흐름에 필요할 때만 사용합니다.
- 움직임과 자동 재생을 넣는 경우 사용자의 설정, 성능, 접근성을 확인합니다.
- 색 대비, 키보드 조작, 초점 표시, 이미지 대체 텍스트, 상태 안내를 렌더링한 화면에서 점검합니다.
- 성능 점수와 로딩 지표는 대상 페이지와 실제 기기에서 측정한 결과만 기록합니다.

특정 화면 폭, 이미지 장수, 글자 수, 폰트, CTA 색상, 성능 점수를 모든 상품의 고정 규칙으로 쓰지 않습니다.

## 마켓과 자사몰의 산출물

### 마켓

현재 에디터가 받는 텍스트·이미지·HTML 범위를 확인합니다.
외부 CSS, JavaScript, iframe, React 코드가 허용된다고 가정하지 않습니다.
입력 제약을 확인할 수 없으면 카피·이미지 배치안과 등록 시 점검표를 제공합니다.
이미지 업로드·미리보기·저장·노출을 각각 다른 결과로 기록합니다.

### 자사몰·독립 웹사이트

사용자가 지정한 기술 스택이나 기존 프로젝트를 따릅니다.
HTML 또는 React 코드를 작성할 수 있지만 특정 프레임워크나 설치 버전을 강제하지 않습니다.
가격·옵션·장바구니·주문은 실제 데이터와 연결된 상태에서 검증합니다.
정적 미리보기만 만들었다면 결제나 주문이 동작한다고 보고하지 않습니다.

구조화 데이터와 공유 미리보기 정보는 실제 페이지에 존재하는
제품·가격·재고·후기만 사용합니다.
없는 평점과 리뷰 수를 예시 숫자로 그대로 내보내지 않습니다.

## 결과 보고

- 확인한 상품 자료, 판매 채널과 조회일
- 산출물 형식과 실제 생성 파일 또는 편집 지침
- 현재 계정에서 확인한 이미지·에디터·고지 조건
- 렌더링·계정 미리보기에서 실행한 점검과 출력
- 미확인 자료와 NOT-RUN 항목

파일 작성, 마켓 등록, 공개 노출, 주문·결제 동작을 서로 다른 단계로 표시합니다.
