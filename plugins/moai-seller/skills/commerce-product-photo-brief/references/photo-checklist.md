# 13섹션 컷 체크리스트

13섹션 상세페이지 템플릿을 쓸 때 참고하는 촬영 컷 체크리스트.
실제 페이지 구성에 없는 섹션은 생략하고, 이미 확보한 컷에 맞춰 조정합니다.
사진 크기·형식·용량은 게시할 판매 채널의 현재 상품 등록 화면에서 확인합니다.
이 체크리스트는 업로드 규격이나 등록 성공을 보장하지 않습니다.

## 섹션별 필수/권장 컷

### 1. Hero — 필수

**필요 컷**: 시그니처 뷰티샷 (3/4 각도, 풀블리드 가능한 고해상도)

체크:
- [ ] 상품이 화면의 60% 이상 차지
- [ ] 드라마틱 라이팅 (림라이트 권장)
- [ ] 깔끔한 그라디언트 또는 단색 배경
- [ ] 상품 시그니처 디테일이 보임

### 2. Pain — 무관

**상품 노출 금지**. 대신:
- 답답한 상황 라이프스타일 (운동 중, 통근 중)
- 어두운 톤 메타포 사진
- 또는 일러스트로 대체

### 3. Problem — 선택

**옵션 1**: 일러스트/인포그래픽 (촬영 불필요)
**옵션 2**: 단면도 또는 분해 컷

### 4. Story — 권장

**필요 컷**: Before/After 페어
- Before: 무드 다운, 답답함
- After: 밝고 활기

**대안**: 라이프스타일 사진 1장 + Story 섹션은 카피 위주로

### 5. Solution — 필수

**필요 컷**: 스튜디오 뷰티샷 (Hero와 다른 각도)
- 깔끔한 단색 배경
- 정면 또는 정면 근접
- 상품 디테일 부각

### 6. How — 선택

**옵션 1**: 일러스트 3단계 (촬영 불필요)
**옵션 2**: 사용 단계 컷 3장 (1·2·3단계)

### 7. Proof — 필수

**필요 컷**:
- 사용 허락을 받은 실제 리뷰어 사용 컷 (확보한 경우)
- 또는 실제 인물 포트레이트 + 허락받은 후기 인용

### 8. Authority — 권장

**필요 컷**: 창업자/전문가 포트레이트
- 3/4 크롭
- 표정 자신감 + 따뜻함
- 디새튜레이트 배경

**대안**: 인증서·수상·자격증 이미지

### 9. Benefits — 선택

**필요 컷**:
- 메인 라이프스타일 컷 1장
- 또는 아이콘 그리드 (촬영 불필요)

### 10. Risk — 무관

문서·인증서 이미지로 대체 가능 (촬영 불필요).

### 11. Compare — 권장

**필요 컷**: Without/With 페어
- Without: 답답함
- With: 만족

(Story 섹션과 통합 가능)

### 12. Filter — 무관

체크리스트 텍스트 위주. 사진 불필요.

### 13. CTA — 필수

Hero 컷 재사용 가능. 또는:
- Hero 다른 각도
- 패키지 박스 컷
- 한정 수량 어필 컷

## 촬영 후보와 우선순위

선택한 섹션에 필요한 컷과 이미 확보한 사진을 대조해 부족한 컷만 적습니다.
아래 순서는 템플릿 예시이며 모든 상품에 같은 촬영 수량을 요구하지 않습니다.

### 먼저 확인할 후보
- Hero를 쓸 때: 사용할 수 있는 상품 대표 컷
- Solution을 쓸 때: 설명에 필요한 상품 컷
- CTA를 쓸 때: 기존 Hero 컷 재사용 가능 여부

### 자료가 있을 때 검토할 후보
- Story·Compare를 쓸 때: 사실에 맞는 비교 컷
- Proof를 쓸 때: 사용 허락을 받은 실제 리뷰어 컷
- Authority를 쓸 때: 실제 창업자나 전문가의 촬영 동의가 있는 컷

### 표현을 보강할 후보
- Benefits를 쓸 때: 라이프스타일 컷
- 상품 설명에 필요할 때: 디테일 클로즈업
- CTA를 쓸 때: 패키지 컷

## 카테고리별 촬영 후보

### electronics
- 정면, 사선, 후면 (포트·버튼)
- 사용 손 컷
- 패키지 박스

### fashion
- 정면 + 후면 + 디테일 (패브릭)
- 모델 착용 (있으면 좋음)
- 사이즈 비교 (예: 손/발 옆)

### food
- 패키지 정면
- 내용물 노출 컷
- 사용/조리 컷
- 식감 클로즈업 (해당 시)

### beauty
- 패키지 + 펌프/입구
- 텍스처 컷 (제형이 보이는)
- 손등 시연
- 모델 사용 (있으면 좋음)

### home
- 단독 컷 (스튜디오)
- 인테리어 배치 컷 (실생활)
- 소재·결 클로즈업

### handmade
- 작가의 손 + 도구
- 제작 과정 컷
- 완성품 다양한 각도
- 한정·시리얼 넘버

## AI 이미지 보완 옵션

부족한 컷은 현재 앱의 이미지 도구 또는 호스트에 맞게 인증된 Higgsfield 공식 연결의 도구가 있을 때 보완할 수 있습니다. Images 2.5 요청은 노출된 모델을 확인하고, Flare·Sunburst API 모델 ID 지정 요청은 별도 API 경로가 있을 때만 진행합니다. Higgsfield에서 상품 사진을 참조로 쓰려면 채팅 첨부와 별도로 업로드 완료를 확인합니다:
- 라이프스타일 컷 (모델·배경 합성)
- 인포그래픽
- 일러스트 단계 시퀀스
- 인증서·문서는 실제 발급 자료만 사용

창업자 포트레이트와 실제 후기 컷을 가짜 인물·후기 이미지로 대체하지 않습니다.
