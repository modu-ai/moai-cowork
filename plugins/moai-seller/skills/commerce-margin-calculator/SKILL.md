# 상품 마진과 손익분기 광고수익률

## 입력

판매가와 고객 결제액, 판매자 부담 할인·적립금, 과세 유형, 매입원가, 플랫폼·결제 수수료의 실제 금액 또는 계약 요율과 과금 기준, 포장·배송·반품 비용을 확인한다. 채널 이름만으로 수수료율을 채우지 않는다. 수수료는 유입 경로·카테고리·결제수단·판매 방식·프로모션에 따라 달라질 수 있다. [네이버 스마트스토어 정산 안내](https://help.sell.smartstore.naver.com/faq/content.help?faqId=3558)와 [쿠팡 로켓그로스 비용 안내](https://sell.coupang.com/ko-kr/fee-page)는 실제 판매자 정산 내역 확인에 참고한다.

세금 포함 가격과 세금 제외 원가를 섞지 않는다. 과세·면세·간이과세 여부, 매입세액 공제, 수수료에 붙는 세금 처리는 실제 사업자 자료를 확인한다. 확인되지 않으면 세전·세후 시나리오로 구분하고 확정 순이익처럼 표현하지 않는다.

## 계산

같은 기준의 한 주문 또는 한 상품에 대해 다음을 분리해 보여준다.

```text
고객 결제액
- 판매자가 부담한 할인·환불
- 실제 정산 수수료
- 상품 매입원가
- 판매자 부담 배송·포장·변동 운영비
= 광고비 전 주문 공헌이익
```

광고비 전 공헌이익이 0 이하이면 해당 주문만으로 광고비를 회수할 수 없다. 양수이면 같은 매출·귀속 기준에서 주문당 허용 광고비의 단순 상한으로 사용할 수 있다. 손익분기 ROAS는 해당 매출 기준액을 허용 광고비로 나눈 값이다. 실제 캠페인 ROAS와 비교할 때 광고 플랫폼의 귀속 매출, VAT 포함 여부, 취소·반품 반영 기간을 맞춘다. 자세한 계산 경계는 `references/end-roas.md`를 따른다.

## 결과

입력값, 수수료 과금 기준, 세금 처리, 각 비용 항목, 계산식, 누락된 항목과 민감도 시나리오를 함께 제시한다. 광고 목표 ROAS를 임의의 배수로 정하거나 플랫폼 쿠폰을 판매자 부담 0원이라고 가정하지 않는다. 주문 공헌이익은 임대료·인건비 등 고정비나 장기 고객 가치를 모두 반영한 순이익이 아니다.
