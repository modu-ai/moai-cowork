# 프로모션 기획 검토

행사 후보는 상품의 수요 주기와 고객 자료를 기준으로 고릅니다. 설·추석처럼 매년 날짜가 바뀌는 행사는 해당 연도의 실제 날짜를 확인합니다.

1. 행사 기간, 대상 상품, 할인·쿠폰·적립 조건, 재고 상한, 배송 가능량을 정합니다.
2. 예상 매출보다 할인 후 기여이익과 반품·CS 부담을 먼저 계산합니다.
3. 광고 예산은 기존 캠페인 성과와 실험 범위에 맞춰 잡습니다. 고정 배수나 ROAS 달성을 약속하지 않습니다.
4. 종료 조건, 고객 안내, 결과 비교 기간을 기록합니다.

"오늘만", "선착순", "재고 부족" 등의 표현은 실제 운영 조건과 일치할 때만 사용합니다. 채널별 광고·프로모션 정책은 게시 전에 현재 공식 안내로 확인합니다.
