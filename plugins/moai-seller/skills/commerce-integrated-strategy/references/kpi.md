# 이커머스 지표 설계

| 지표 | 계산·확인 사항 |
|---|---|
| 매출 | 취소·반품·세금·배송비 포함 여부와 기준일 |
| 객단가 | 같은 기간 순매출 ÷ 주문 수 |
| 전환율 | 구매 고객 또는 주문 수 ÷ 방문 세션; 분모를 명시 |
| ROAS | 광고 귀속 매출 ÷ 광고비; 귀속 기간과 채널 중복 표시 |
| 기여이익 | 순매출 − 상품 원가 − 결제·채널 수수료 − 배송·포장 − 광고 등 변동비 |
| 재구매율 | 정의한 고객 집단 중 기간 내 재구매 고객 비율 |
| LTV | 관측 기간, 신규·기존 고객 분리, 반품·비용 포함 여부 표시 |

목표값은 계정의 과거 기준선과 상품 손익에 따라 정합니다. 외부 평균이나 업종별 보편 목표를 출처 없이 채우지 않습니다. 대시보드가 없는 지표는 `미측정`으로 표시합니다.
