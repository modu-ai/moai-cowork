# 재구매·고객 관리 검토

재구매 전략은 상품의 실제 소모 주기, 구매 기록, 고객 동의, 메시지 수신 채널을 바탕으로 설계합니다. CAC와 LTV는 비용 범위·고객 기간·반품을 명시해 계산합니다.

- 주문·배송 안내는 실제 주문 상태에 맞게 보냅니다.
- 후기 요청, 쿠폰, 추천 메시지는 수신 동의와 각 채널의 현행 발송 규칙을 확인합니다.
- 등급·적립·정기배송 조건은 실제 판매자 설정과 약관에 맞춰 씁니다.
- 실험은 대상군, 대조군, 비용, 재구매·해지 결과를 기록합니다.

고정 발송 일정, 할인율, 재구매율 목표, 후기 점수가 모든 상점에 적용된다고 가정하지 않습니다. 자동 발송은 사용자의 채널 연결과 승인 후에만 설정합니다.
