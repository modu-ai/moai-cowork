# 가격 전략 검토

가격은 실제 원가, 플랫폼 수수료, 결제 수수료, 배송·포장비, 반품 비용, 광고비, 세금 처리 기준을 합쳐 계산합니다. 상품·채널별 손익분기 가격과 할인 후 기여이익을 표시합니다.

- 정가·할인가·기간 한정 가격은 실제 판매 이력과 판매 채널의 현재 표시 규칙을 확인합니다.
- 할인율은 목표가 아니라 계산 결과입니다. 경쟁 가격과 상품 차이를 같은 조건으로 비교합니다.
- 회원 혜택·쿠폰·적립금·배송비의 중복 적용을 반영합니다.
- 가격 변경 전 적용 날짜, 재고, 이미 구매한 고객에 대한 안내를 확인합니다.

특정 할인율, 비용 비율, 채널 간 허용 가격차를 보편적 안전 기준이나 법적 의무로 단정하지 않습니다. 법령·플랫폼 정책이 필요한 문구는 공식 최신 자료와 실제 계정 설정으로 검증합니다.
