# 전자상거래 런칭 점검 순서

1. **상품**: 판매 자격, 사양·원산지·인증·재고와 근거 자료를 확인합니다.
2. **상품 페이지**: 가격·배송·반품·고객 문의 정보와 검증 가능한 상품 설명을 작성합니다. 후기·인증을 임의로 만들지 않습니다.
3. **가격**: 원가와 수수료·배송·반품·광고 비용을 포함해 손익을 계산합니다.
4. **채널·마케팅**: 현재 입점 조건, 광고 계정 권한, 예산과 검증 지표를 확인합니다.
5. **고객 지원**: 실제 운영 가능한 답변 시간, 배송·반품 처리 절차를 정합니다.

필요한 자료가 없으면 가정과 미완료 항목을 구분해 보고합니다. 역할별 작업은 연결된 호스트의 기능과 사용자의 범위에 맞춰 순서대로 수행할 수 있습니다. 파일 생성, 광고 실행, 가격 변경, 고객 메시지 발송은 각 요청과 권한을 확인한 뒤 별도 단계로 진행합니다.
