# 이커머스 통합 전략

## 입력

사용자가 제공한 상품·마진·재고·채널 매출·광고 비용·전환 자료와 기존 조사 결과를 확인합니다. 연결된 커머스 MCP가 있으면 현재 계정 권한과 도구의 실제 응답을 확인하고, 없으면 사용자가 제공한 자료로 범위를 한정합니다. 데이터의 기간·통화·세금 포함 여부와 채널별 중복 집계 여부를 기록합니다.

## 분석

1. 매출, 기여이익, 광고비, 반품, 재구매 지표를 **같은 기간**으로 맞춥니다. 분모나 비용 항목이 없으면 ROAS·LTV·마진을 확정하지 않습니다.
2. `references/channel-mix.md`, `pricing.md`, `promotion.md`, `retention.md`, `kpi.md`는 검토 항목의 참고 자료로 사용합니다. 문서 안의 비율·일정·수수료·법적 표현은 현재 계정과 공식 채널 안내로 확인하기 전에는 실행 기준으로 사용하지 않습니다.
3. 사업 단계·자원·상품 특성에 맞는 대안을 비교합니다. 채널 비중, 할인율, 광고비, CRM 발송 시점은 사용자 데이터가 뒷받침할 때만 숫자로 제안합니다. 고객 메시지 발송·광고 설정·가격 변경은 별도 실행과 확인이 필요한 외부 작업입니다.
4. 실행 항목마다 근거, 예상 효과를 검증할 지표, 담당자, 중단 조건을 적습니다. 기존 자료만으로 판단할 수 없는 항목은 조사 과제로 남깁니다.

## 출력

- 현재 확인한 숫자와 기준 기간
- 우선순위별 실행 제안과 그 근거
- 필요한 권한·자료·승인
- 미확인 가정과 검증 방법

가능하면 `moai-coworker:ai-slop-reviewer`와 `moai-writer:korean-humanize`로 문체를 검토합니다. 실제로 실행하지 않은 검수는 완료로 표시하지 않습니다. 운영 자동화 세부 설계는 `commerce-automation-audit`를 사용합니다.
