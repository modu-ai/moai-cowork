# 한국 광고성 메시지 발송 전 점검

이 스킬은 메시지 초안과 발송 기록을 확인해 **검토 결과**를 작성합니다. 법적 적합성이나 실제 발송 허가를 자동 보증하지 않습니다. 수신자별 동의·거부 기록, 채널 심사, 발송 설정을 확인하지 못하면 `PASS`를 내지 않습니다.

## 요청 자료

- 메시지 원문, 제목·이미지·버튼·연결 화면
- 문자·이메일·앱 알림·카카오 메시지 등 실제 전송 매체
- 발송 주체, 수신 대상, 발송 일시와 수신자의 지역
- 수신자별 광고 동의·철회·거부 기록과 수집 문구
- 야간 별도 동의 기록, 거래관계 예외를 주장하는 경우 거래·연락처 수집 증거
- 전송자 명칭·연락처, 광고 표시, 수신거부 경로와 비용
- 카카오 등 채널의 현재 템플릿·심사·발송 설정

간단한 문구 검토 요청에는 자료가 있는 범위에서 문제 후보와 확인할 자료를 반환합니다. 계정 기록이 없다는 이유로 문구 검토 자체를 거절하지 않습니다.

## 판정 순서

1. **광고성 여부** — [정보통신망법 제50조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025127785)와 [KISA 안내서](https://spam.kisa.or.kr/spam/na/ntt/selectNttInfo.do?bbsId=1002&mi=1020&nttSn=3001)를 기준으로 메시지 전체와 연결 화면의 영리 목적을 확인합니다. 주문·배송 등 필수 안내에 혜택·재구매 유도가 섞이면 광고성 여부를 다시 검토합니다. 쿠폰·마일리지·적립금을 일방적으로 제공한 뒤 발급·소멸을 알리는 경우, 단순 거래 고지라고 단정하지 않습니다.
2. **동의·거부** — 광고라면 수신자별 명시적 사전 동의 또는 제50조 제1항의 구체적 예외 증거를 확인합니다. 동의가 있어도 수신거부·철회 후에는 광고를 보내지 않습니다. 거래관계 예외는 같은 종류의 재화, 직접 수집한 연락처, [시행령 제61조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0061&lsiSeq=288033&urlMode=lsScJoRltInfoR)의 기간 조건을 확인합니다.
3. **야간** — 오후 9시부터 다음 날 오전 8시까지 광고를 보내려면 별도 사전 동의를 확인합니다. 시행령 제61조 제2항의 전자우편 예외는 야간 **별도 동의**에 관한 것으로, 일반 광고 동의·거부 규칙까지 면제하지 않습니다. 발송 예약 시간과 수신자 시간대를 확인합니다.
4. **표시와 수신거부** — 매체별 [시행령 별표 6 원문](https://law.go.kr/flDownload.do?flSeq=42827884)에 맞는 광고 표시, 전송자 정보, 쉬운 수신거부·동의 철회 방법을 확인합니다. 이메일은 제목 시작 부분의 `(광고)`와 본문의 전송자 명칭·이메일 주소·전화번호·주소 및 한글·영문 거부 안내·간편한 철회 방법을 각각 확인합니다. 문자 등 비음성 전송매체는 광고 시작 부분과 끝 부분의 표시 사항을 각각 확인합니다. 수신자가 전화요금 등 금전적 비용을 부담하지 않도록 해야 합니다. 앱 알림 수신거부에 로그인 등 복잡한 절차를 강요하지 않습니다.
5. **채널 정책** — [카카오 알림톡 심사 가이드](https://kakaobusiness.gitbook.io/main/ad/infotalk/audit)는 메시지 일부라도 광고성 내용이 포함되면 알림톡 발송을 허용하지 않습니다. 광고가 섞인 알림톡은 `BLOCK`으로 둡니다. 카카오의 사전 협의 가능성은 광고가 없는 정보성 메시지에 한정해 현재 가이드·승인 화면에서 확인합니다. 친구톡·문자·이메일의 길이·버튼 규격도 각 발송 서비스의 현재 안내를 확인합니다.
6. **결과** — 확보한 자료로 확인된 항목과 미확인 항목을 분리합니다. 실제 발송 전에는 발송 서비스의 설정·테스트 수신·수신자 목록을 다시 확인합니다.

## 결과 상태

| 상태 | 뜻 |
| --- | --- |
| `BLOCK` | 확인된 법령·채널 조건과 충돌하거나 수신거부 기록이 확인됨 |
| `REVIEW` | 문구는 검토했지만 동의·예외·템플릿·설정 자료가 없어 발송 판단 불가 |
| `READY_FOR_SEND_CHECK` | 제출된 기록에서 점검 항목을 충족함. 실제 발송 설정과 수신 목록은 별도 확인 필요 |

`READY_FOR_SEND_CHECK`를 법적 면책이나 전송 성공의 뜻으로 쓰지 않습니다. 과태료와 형사처벌을 메시지 한 건의 고정 손실로 환산하지 않습니다. 제재 여부·금액은 위반 유형과 적용 조항, 절차에 따라 판단됩니다.

## 출력 예시

```json
{
  "status": "REVIEW",
  "message_category": "광고성 가능",
  "channel": "SMS",
  "verified": ["할인 문구가 포함됨"],
  "missing_evidence": ["수신자별 광고 동의", "발송 시각", "무료 수신거부 경로"],
  "required_edits": ["매체별 광고 표시 위치와 전송자 정보를 확인"],
  "send_decision": "미확정"
}
```

주문 확인 메시지의 정보성 초안은 동의 기록 없이도 검토할 수 있습니다. 광고 문구로 바뀌면 다시 판정합니다. 광고 표현 자체의 적법성은 `commerce-ad-claim-compliance-kr`, 메시지 카피 작성은 `cs-channel-message`를 사용합니다.
