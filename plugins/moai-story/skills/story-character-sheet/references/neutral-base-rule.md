# 중립 기본형 · 실루엣 극단 차별 · 색 반복 · 참조 재생성

> `story-character-sheet` Step 4에서 로드한다. 캐릭터 참조(Soul ID 시드)의 품질과 재사용성을 지키는 4개 원칙. AI 작화에서 캐릭터가 컷마다 흔들리는 실제 빈발 실패를 막는다.

## 1. 중립 기본형 원칙 (재사용성)

캐릭터 참조는 **중립 기본형으로만** 뽑는다.

- **넣는 것:** 고정 외형 + 기본 의상 + 중립 포즈 + 기본 표정 1~2개.
- **다른 컷에서 바뀔 요소:** 손에 든 물건, 특정 동작, 특정 감정 연기, 장면 소품. 반복 사용하려는 참조에는 넣지 않는 편이 좋다.
- **이유:** 참조의 소품·포즈가 이후 컷에 반복될 수 있다. 장면별 소품·상황 포즈는 컷 프롬프트(`story-webtoon-art`)에서 지정하고 생성 결과를 확인한다.
- **각도:** 정면·측면·반측면 + 표정 변화. (비표준어 "반쯔렴"이 아니라 **반측면**.)

## 2. 실루엣 극단 차별 (인물 혼동 방지)

비슷한 두 인물은 독자·AI 모두 헷갈린다.

- 실루엣·체형·헤어·복장 중 독자가 구별할 수 있는 요소를 다르게 설계한다.
- 프롬프트를 고쳐도 생성 결과가 혼동된다면, 기존 캐릭터 설정을 임의로 바꾸지 말고 사용자와 앵커 변경을 정한 뒤 참조를 다시 만든다.

## 3. 색 반복 명시 (색 표류 방지)

머리색·의상색은 모델과 참조에 따라 컷마다 흔들릴 수 있다.

- 고정해야 할 머리색·의상색은 일관성 앵커와 참조 이미지에 적는다. 컷 프롬프트에서 필요한 요소를 명시하고 실제 결과를 확인한다(예: "갈색 단발, 베이지 셔츠").
- 없는 요소가 반복해서 생기면 "안경 없음"처럼 부정형도 시도하고 실제 결과를 확인한다.

## 4. 참조 재생성 에스컬레이션 (사다리)

일관성이 계속 깨지면 프롬프트 손질에 매달리지 말고 단계를 올린다.

```
1단계: 컷 프롬프트에 고정 외형·색을 반복 명시
2단계: 참조와 컷 프롬프트의 앵커가 일치하는지 확인
3단계: 사용자가 캐릭터 설정 변경을 승인하면 참조 이미지를 다시 만든다
```

> 참조를 다시 만든 뒤에도 캐릭터가 일치하는지는 결과 컷을 대조해 판단한다.
