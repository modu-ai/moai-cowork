# 미디어 제작 경로 선택

1. 요청의 산출물, 사용처, 형식, 필수 제약을 확인한다. 보호되는 캐릭터·로고·실존 인물의 식별 가능한 재현을 요청하면 생성 전에 원본 자료, 요청한 사용 범위, 사용 허락 근거를 확인한다. 허락을 확인할 수 없으면 해당 재현은 생성하지 않고 독창적인 대안을 제안한다. 이름이 언급됐다는 사실만으로 침해를 단정하지 않는다. 실제 실행에 필요한 입력이 빠졌으면 현재 런타임의 질문 채널로 묻는다. 직접 실행·하위 실행 모두 질문 채널이 없으면 필요한 입력을 blocker로 반환한다.
2. 현재 세션의 도구 목록을 확인한다. 일반 ChatGPT 이미지 요청은 `media-codex-image`의 기본 이미지 생성 경로로 보낸다. Gemini 모델을 지정한 이미지 생성 요청은 현재 앱에 해당 Gemini 모델의 생성 연결이 실제 있는지 확인한다. 없으면 Gemini 생성은 미완료로 보고하고 `media-gemini-3-image-prompt`의 완성된 프롬프트를 제공한다. Midjourney를 지정한 이미지 생성 요청은 현재 앱에 실제 Midjourney 생성 연결이 있는지 확인한다. 없으면 Midjourney 생성은 미완료로 보고하고 `media-midjourney-v8-prompt`의 완성된 프롬프트를 제공한다. 사용자가 Higgsfield 또는 그 계정의 모델을 지정하면 `media-higgsfield-core`의 연결 프로필을 확인하고 이미지·영상·제품 등 해당 스킬로 보낸다. ElevenLabs 오디오는 `media-audio-gen`으로 보낸다. 프롬프트만 요청했으면 생성 도구를 호출하지 않는다.
3. 유료 크레딧, 업로드, 보이스 복제 같은 외부 작업은 해당 스킬의 견적·동의·승인 절차를 따른다. 지정한 연결이 없으면 그 상태를 알리고, 제공자를 조용히 바꾸지 않는다.
4. 반환된 산출물을 실제로 열어 요청한 형식·크기·문구·길이 등을 확인한다. 확인하지 못한 속성은 미검증으로 기록한다. 상업용·브랜드 핵심 자산의 추가 검수가 필요하면 `media-brand-audit`를 사용한다. 같은 주체의 자기 검수는 독립 감사라고 부르지 않는다.
5. 결과에는 실제 사용한 생성 경로, 산출물 위치, 확인한 조건, 크레딧과 남은 확인 사항을 적는다.

Claude의 `media-producer` 에이전트 파일은 에이전트 실행 환경에서 사용할 수 있다. ChatGPT 플러그인에서는 이 스킬이 같은 라우팅의 발견 가능한 진입점이다.
