# Higgsfield 제품 촬영 (media-higgsfield-product)

> `moai-media` | 브랜드·제품 비주얼 10모드 판정과 생성 (코어: `media-higgsfield-core`)

## 개요

"제품 사진 만들어줘"는 한 종류의 요청이 아니다. 스튜디오 컷과 핀터레스트 핀과 광고 팩은 구도·비율·장수·프롬프트 구조가 전부 다르다. 이 스킬은 요청을 **10개 모드 중 하나로 먼저 판정하고**, 그 모드의 프롬프트 구조로 조립한다.

호출 계약·비용 프리플라이트는 코어를 따른다:
- 호출 계약: `../media-higgsfield-core/references/call-schema.md`
- 잡·비용·리드백: `../media-higgsfield-core/references/job-lifecycle.md`

## ⚠️ 알려진 한계 (먼저 읽는다)

Higgsfield 공식 CLI에는 `product-photoshoot` 전용 **백엔드 프롬프트 강화기**가 있다. 모드별 사진 용어와 구조 템플릿을 서버가 들고 있다가 프롬프트를 조립해 준다.

**현재 연결에 전용 강화·촬영 기능이 실제 노출됐는지 먼저 확인한다.** 과거 MCP 앱 목록에서는 전용 기능을 찾지 못했지만, 그 부정 관측만으로 모든 앱·시점의 부재를 단정하지 않는다. 전용 경로가 없으면 **모드별 프롬프트 구조를 직접 조립해 현재 연결의 이미지 모델에 넘긴다.** 직접 조립은 공식 강화기와 같은 결과를 보장하지 않는다.

결과적으로:

| 항목 | 현재 연결의 직접 생성 경로 | 공식 전용 촬영 경로 |
|---|---|---|
| 모드 판정 | 공식 모드 정의를 참조 | 공식 모드 정의 |
| 인터뷰 흐름 | 공식 질문 유형을 참조 | 공식 질문 유형 |
| 프롬프트 조립 | 스킬이 직접 | 서버 강화기 |
| 충실도 | **보장 못 함** | 공식 최적화 |
| 접근 | 현재 연결의 모델·도구를 사용 | 연결에 전용 기능이 노출된 경우에만 사용 |

공식 CLI 스킬은 강화기를 우회해 이미지 모델을 직접 호출하면 결과 품질이 떨어진다고 경고한다. **촬영 모드의 정확한 재현이 필요한 요청**은 전용 기능의 현재 앱 노출 여부를 확인하고, 없으면 직접 조립 경로의 한계를 알려 사용자가 결정하게 한다.

이 한계를 사용자에게 숨기지 않는다.

## 트리거 키워드

제품 사진, 제품컷, 스튜디오 컷, 누끼 배경, 라이프스타일 컷, 연출컷, 핀터레스트 핀, 히어로 배너, 상단 배너, 캐러셀, 슬라이드 광고, 광고 소재, 메타 광고, 가상 피팅, 착용컷, 룩북, 컨셉추얼, 부유하는 제품, 스플래시, 리스타일, 시즌 버전

## 10개 모드

| 모드 | 언제 |
|---|---|
| `product_shot` | 중립·스튜디오·카탈로그 배경 위 제품 |
| `lifestyle_scene` | 실제 환경, 손, 동작, 분위기 |
| `closeup_product_with_person` | 손·얼굴 일부가 들어간 타이트 크롭 — 뷰티 시연, 사용 장면 |
| `moodboard_pin` | 세로 2:3 핀터레스트 무드보드 |
| `hero_banner` | 웹사이트·이메일·캠페인 가로 헤더 |
| `social_carousel` | IG·링크드인·페이스북 연결형 3~10장 |
| `ad_creative_pack` | 메타·틱톡·핀터레스트·구글 정적 광고 변형 묶음 |
| `virtual_model_tryout` | AI 모델이 착용·사용 |

판정 규칙·동점 처리는 `references/modes.md`. 사전 인터뷰 유형(A~F)은 `references/interview.md`.

## 워크플로우

### 1단계 — 모드 판정

표면 키워드가 아니라 **의도**로 고른다. 둘 다 걸리면 더 구체적인 쪽이 이긴다. 상세는 `references/modes.md`.

### 2단계 — 인터뷰 (최대 4문항)

사용자 상황을 A~F 유형으로 분류하고 그 유형의 질문만 묻는다. **한 메시지에 4문항을 넘기지 않는다.** 맥락에서 이미 답이 나온 질문은 건너뛴다. 선택지를 붙여 묻고 열린 질문을 하지 않는다.

직접 실행에 현재 앱의 질문 채널이 있으면 필요한 항목을 확인한다. 하위 에이전트는 질문 도구가 보여도 필요한 슬롯·선택지·재개 방법을 blocker로 상위에 반환한다. 직접 실행에 채널이 없어도 같은 blocker를 반환한다.

### 3단계 — 현재 연결의 촬영 경로 선택

전용 product-photoshoot 기능이 현재 연결에 실제 노출되고 선택한 모드를 지원하면 **그 기능으로 분기**한다. 전용 도구의 입력 스키마를 확인하고 공식 경로처럼 짧은 사용자 의도·모드·참조 이미지·장수를 전달한다. 전용 경로에서는 이미지 모델용 프롬프트를 직접 조립하지 않는다. 전용 기능이 없거나 선택 모드를 지원하지 않을 때만 `references/modes.md`의 구성 요소로 프롬프트를 직접 조립한다. 어떤 경로인지 승인 전에 알린다.

### 4단계 — 라이브 조회·비용 프리플라이트

전용 촬영 경로라면 그 도구의 실제 입력 스키마와 **그 경로의 비용 견적 수단**을 확인한다. 견적이 불가능하면 비용을 추측해 제출하지 않는다. 직접 조립 경로라면 MCP는 `models_explore(action:'get')`와 `get_cost: true`, ChatGPT 공식 플러그인은 `models_get({model_id})`와 `estimate_image_cost({params})`로 대상 모델의 제약과 청구 크레딧을 확인한다. HTTPS 참조의 계정 업로드가 필요하면 견적 전에 허용을 받는다. 비율은 모드 기본값을 쓰되 사용자가 명시하면 따른다.

### 5단계 — 승인 게이트

크레딧이 나가기 전에 멈춘다 — 코어 §유료 생성 승인 게이트를 그대로 따른다. 직접 조립 경로라면 강화기 없이 만든 프롬프트가 사용자 의도와 맞는지 특히 확인한다. 전용 경로도 실제 제출 인자와 견적을 확인한다.

- **[HARD] 승인 화면에는 실제 제출할 내용을 보여준다.** 직접 조립 경로라면 프롬프트 전문을, 전용 경로라면 모드·짧은 사용자 의도·참조 이미지·장수·확정 옵션을 보여준다. 아래 §주의사항의 "프롬프트 전문을 되돌려주지 않는다"는 **결과 보고**에 관한 규칙이다.
- 다중 변형(`social_carousel`·`ad_creative_pack` 포함)은 **장수 × 단가 = 최대 총 크레딧**을 함께 보여주고 배치 단위로 한 번에 승인받는다.

### 6단계 — 생성·전달

승인된 경로와 값으로만 호출한다. 전용 기능이 확인됐으면 그 도구를 호출하고, 없을 때만 직접 조립한 프롬프트를 이미지 모델에 제출한다. MCP는 참조 `media_id` 또는 `job_id`를 사용하고, ChatGPT 공식 플러그인의 HTTPS 참조는 외부 전송 허용 뒤에만 사용한다. 결과는 이미지 URL 목록으로 짧게 전달한다.

## 다중 변형

직접 조립 경로에서 여러 장을 요청하면 프리셋·조명·앵글·팔레트를 서로 다르게 계획한다 — 같은 프롬프트의 재구성이 되지 않게 한다. 전용 촬영 경로에서는 연결이 지원하는 변형 옵션과 실제 결과를 확인한다.

`social_carousel`과 `ad_creative_pack`은 장수가 곧 슬라이드/변형 수다. 이 두 모드는 **전 슬라이드의 시각 시스템을 고정**해야 하므로, 변형을 주더라도 팔레트·타이포·구도 문법은 공유한다.

## 출력 형식

```
## Higgsfield 제품 비주얼 결과
- 판정 모드: [mode] — 근거: [걸린 신호]
- 사용 모델: [라이브 모델 도구로 확인한 실제 id]
- 비율·장수: [aspect] · [count]
- 비용: [연결별 견적 도구가 반환한 credits]
- 결과:
  - [URL]
  - [URL]
- 서버 조정(adjustments): [있으면 그대로 보고]
```

**결과 보고에서는** 조립한 프롬프트 전문을 되돌려주지 않는다 — 원하는 것은 결과물이다. 단 **5단계 승인 화면은 예외이며, 거기서는 전문을 보여준다**(크레딧이 나가기 전이므로).

## 주의사항

- **한계를 먼저 알린다.** 전용 강화 기능이 현재 연결에 없으면 직접 조립한 프롬프트의 충실도는 보장하지 않는다.
- 인터뷰 4문항 한도를 넘기지 않는다.
- 모드를 잘못 고르면 나머지가 전부 어긋난다 — 판정이 첫 번째 품질 관문이다.
- 10개 모드 밖의 이름을 만들어 쓰지 않는다.
- 제품 사진 없이 텍스트만으로 만들면 충실도가 크게 떨어진다. 사진 업로드를 먼저 권한다.
- 경쟁사 상표·타인 저작물을 합성하지 않는다.
- 실제 제품과 다른 성능·효능을 암시하는 연출은 표시광고법 위반 소지가 있다 — 커머스 맥락이면 `moai-seller:commerce-ad-claim-compliance-kr`로 넘긴다.
