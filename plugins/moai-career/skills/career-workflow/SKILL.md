# 구직자 커리어 작업 경로

1. 지원자의 실제 경력, 목표 직무·회사, 필요한 산출물과 기준을 확인한다. 이력서·채용공고·프로젝트 이력 등 필수 자료가 없으면 현재 런타임의 질문 채널로 묻는다. 질문할 수 없는 하위 실행에서는 누락 자료를 blocker로 반환한다.
2. 이력서·자기소개서는 `career-resume`, 포트폴리오는 `career-portfolio`, 면접은 `career-interview`, 이직 계획은 `career-transition`, 첫 직장 적응은 `career-junior-onboarding`의 지침을 따른다.
3. 지원자가 실제로 한 일과 수치만 쓴다. 채용공고에 맞춘 표현 변경은 가능하지만 경력·자격·성과를 만들어 넣지 않는다. 숫자가 없으면 지원자에게 확인할 항목으로 남긴다.
4. 채용시장 수치와 급여 범위는 현재 출처를 확인하고 기준 시점을 표시한다. 민감한 개인정보는 요청된 산출물에 필요한 범위만 보존하고 제3자 이름은 기본적으로 가린다.
5. 최종 산출물의 주장과 날짜는 `career-claim-audit` 기준으로 대조한다. 최종 이력서·자기소개서, 포트폴리오 프로젝트 설명, 채용 관행·급여 주장처럼 결과에 영향이 큰 산출물은 현재 런타임에서 별도 검수자를 실행할 수 있으면 산출물과 원자료를 전달해 독립 검수를 요청한다. 별도 검수자를 실행할 수 없으면 직접 대조한 범위와 독립 검수 미실시를 분리해 보고한다. 확인하지 못한 주장은 확인 필요로 표시한다.

Claude의 `career-coach` 에이전트와 목적이 겹친다. ChatGPT 플러그인에서는 이 스킬이 발견 가능한 진입점이다.
