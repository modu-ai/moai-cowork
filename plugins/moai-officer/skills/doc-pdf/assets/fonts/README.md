# PDF 폰트 안내

이 디렉터리에는 Noto Sans CJK 폰트 파일이 포함돼 있지 않습니다. `LICENSE.txt`는 SIL Open Font License 1.1 전문이며, 실제 폰트 바이너리의 번들·자동 다운로드를 뜻하지 않습니다. 이 플러그인에는 폰트 다운로드 스크립트도 없습니다.

PDF 출력 전 현재 호스트에서 사용 가능한 한글·일본어·중국어 폰트를 확인합니다. 사용하는 렌더러가 대체 폰트를 선택했다면 결과 PDF에서 실제 글리프와 줄바꿈을 눈으로 확인합니다. 외부 폰트를 사용하거나 배포하려면 해당 파일의 출처와 라이선스 조건을 확인합니다.

- [Noto CJK 원본 저장소](https://github.com/notofonts/noto-cjk)
- [SIL OFL 1.1 전문](https://openfontlicense.org/open-font-license-official-text/)
