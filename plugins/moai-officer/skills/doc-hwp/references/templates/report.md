# HWPX 보고서 서식 참고 (report)

보고서의 내용을 설계할 때 쓰는 안내다. 실행 가능한 템플릿이나 자동 목차 생성 기능을 제공하지 않는다. 조직 양식 또는 제출처 규정이 있으면 그것을 따른다.

## 필요한 정보

| 항목 | 확인할 내용 |
|---|---|
| 제목·기간 | 실제 보고 대상과 집계 기간 |
| 작성 주체·날짜 | 조직명, 담당자, 작성일 |
| 목적·범위 | 다루는 질문과 제외 범위 |
| 자료·방법 | 숫자와 주장에 대한 출처·계산 방법 |
| 보안등급·결재 | 조직에서 지정한 경우에만 표시 |

## 내용 구성 예시

1. 표지: 제목, 작성 주체, 날짜
2. 요약: 핵심 사실, 결론, 남은 판단 사항
3. 본문: 배경, 분석, 표·그림, 근거
4. 결론: 권고 사항, 담당자와 후속 일정(확인된 경우)
5. 출처·부록: 근거 자료와 상세 계산

목차가 필요한 길이라면 실제 생성 도구의 지원 여부를 확인한 뒤 넣고 페이지 번호를 다시 검사한다. 자동 생성했다고 가정하지 않는다. 수치·인용·도표의 원본을 대조하고, 보안등급이나 승인자를 임의로 채우지 않는다.

## 출력 검수

제목 체계, 표·그림 위치, 페이지 번호, 출처, 누락된 항목을 검토한다. HWPX 생성·다시 열기와 화면 배치 검증은 `doc-hwp/SKILL.md`를 따른다.
