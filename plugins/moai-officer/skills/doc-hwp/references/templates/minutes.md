# HWPX 회의록 서식 참고 (minutes)

회의의 실제 기록을 문서로 정리할 때 쓰는 내용 안내다. 이 파일은 실행 가능한 생성 스크립트나 고정된 법정 서식이 아니다. 조직 양식이 있으면 그 양식을 따른다.

## 필요한 정보

| 항목 | 작성 기준 |
|---|---|
| 회의명·일시·장소 | 회의 공지나 기록으로 확인된 값 |
| 참석자·역할 | 실제 참석자와 기록·진행 담당자를 구분 |
| 안건 | 논의한 순서대로 제목과 핵심 발언을 기록 |
| 결정 사항 | 합의된 내용과 미결 사항을 구분 |
| 후속 조치 | 담당자, 기한, 완료 기준이 확인된 항목만 기재 |
| 승인·서명 | 조직에서 요구한 경우에만 추가 |

## 본문 구성

1. 회의 기본 정보
2. 안건별 논의 요약
3. 결정 사항과 이견 또는 미결 사항
4. 후속 조치 표: `조치 / 담당 / 기한 / 상태`
5. 다음 회의 일정 또는 첨부 자료(있는 경우)

후속 조치 행 수는 실제 건수에 맞춘다. 빈 행이나 서명란을 임의의 기본값으로 넣지 않는다. 발언을 요약했다면 원문 기록과 비교하고, 기록에 없는 결론을 만들지 않는다.

## 출력 검수

인명·기한·결정 사항을 입력 자료와 대조한다. HWPX 생성·다시 열기와 화면 배치 검증은 `doc-hwp/SKILL.md`를 따른다.
