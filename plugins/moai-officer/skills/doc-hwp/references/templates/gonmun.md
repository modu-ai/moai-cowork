# HWPX 공문·시행문 서식 참고 (gonmun)

공문을 작성할 때 필요한 입력과 확인 항목이다. 법정 서식의 정본은 [현행 「행정업무의 운영 및 혁신에 관한 규정」](https://www.law.go.kr/lsInfoP.do?lsiSeq=286187)과 시행규칙, 제출처가 제공한 양식이다. 기관 양식의 결재선·발신명의·공개구분을 이 문서로 대체하지 않는다.

## 작성 전 확인

| 항목 | 확인할 내용 |
|---|---|
| 문서 종류 | 내부 기안문인지, 대외 시행문인지 |
| 수신·경유 | 실제 수신 기관·부서와 경유 여부 |
| 발신명의 | 기관의 권한 있는 발신자 표기 |
| 문서번호·시행일 | 기관에서 부여한 값; 임의 번호를 만들지 않음 |
| 공개구분·결재 | 기관의 결정과 결재 규정 |
| 붙임·연락처 | 실제 첨부 파일, 담당자 정보 |

## 내용 구성 예시

1. 수신 및 경유: 제출처 양식의 위치와 문구를 따른다.
2. 제목: 요청 또는 안내의 대상을 분명히 쓴다.
3. 본문: 관련 문서, 요청 내용, 기한, 회신 방법을 필요한 범위에서 적는다.
4. 붙임: 실제 첨부 파일명과 수량을 대조한다.
5. 결문: 발신명의와 시행 정보는 확인된 값만 넣는다.

숫자·날짜·항목 부호·끝 표시 등은 `../kr-official-forms.md`를 참고하되 현행 별지 서식과 제출처 지침을 우선한다. 직인 이미지가 없으면 임의로 그리지 않는다. 공개구분을 `공개`로 미리 채우지 않는다.

## 출력 검수

수신자, 문서번호, 발신명의, 붙임, 결재 상태와 실제 파일을 원본 자료에 대조한다. HWPX 생성·열림·인쇄 결과는 `doc-hwp/SKILL.md`의 검증 절차에 따른다.
