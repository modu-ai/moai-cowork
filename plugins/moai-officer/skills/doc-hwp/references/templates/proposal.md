# HWPX 제안서 서식 참고 (proposal)

제안서를 구성할 때 쓰는 입력·검수 안내다. 실행 가능한 HWPX 템플릿이나 견적 생성기는 포함하지 않는다. 발주처의 제안요청서와 제출 양식이 있으면 그 요구사항이 우선한다.

## 작성 전 확인

| 항목 | 확인할 내용 |
|---|---|
| 제안 대상·목적 | 수신처와 해결할 문제 |
| 범위·산출물 | 제공하는 작업, 제외 범위, 인수 기준 |
| 일정 | 실제 착수 조건과 단계별 기한 |
| 비용 | 통화, 단가, 수량, 합계, 세금 포함 여부 |
| 유효기간·기밀 표시 | 계약 조건이나 사용자 지시가 있는 경우에만 표시 |
| 연락처 | 승인된 담당자 정보 |

## 내용 구성 예시

1. 표지: 제목, 제안사, 수신처, 제출일
2. 요약: 문제, 제안 내용, 기대 효과의 근거
3. 수행 범위: 작업과 산출물, 역할 분담
4. 일정: 단계, 의존 조건, 검토 시점
5. 비용: 항목별 계산 근거와 세금 처리 기준
6. 조건: 검수·변경·유효기간 등 확인된 사항

일정의 최대 기간이나 부가가치세율을 서식에서 고정하지 않는다. 기대 효과를 확정 성과처럼 쓰지 않고 근거와 전제를 밝힌다. `CONFIDENTIAL` 등의 표시도 사용자나 계약의 근거 없이 넣지 않는다.

## 출력 검수

산술 합계, 세금 포함 여부, 일정, 발주처 요구항목, 제안 내용의 출처를 확인한다. HWPX 생성·열림·배치 검증은 `doc-hwp/SKILL.md`를 따른다.
