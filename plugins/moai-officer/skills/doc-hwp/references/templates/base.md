# HWPX 공통 서식 참고 (base)

이 파일은 문서 작성 시 확인할 항목을 정리한 참고 자료다. 실행 가능한 템플릿이나 HWPX 생성기가 아니다. 실제 출력에는 `doc-hwp/SKILL.md`에서 확인한 호스트 기능 또는 설치된 HWPX 도구를 사용한다.

## 문서 설정

- 용지 크기·방향·여백은 제출처 양식이나 사용자가 제공한 원본을 따른다. 지정이 없으면 작성 목적과 인쇄 환경을 확인한 뒤 정한다.
- 제목·본문·표·각주가 많은 문서는 일관된 문단 스타일을 사용한다. 글꼴, 크기, 줄 간격, 들여쓰기 값은 실제 문서에서 확인한다.
- 특정 운영체제에만 기본 설치된 서체를 필수값으로 두지 않는다. 수신 환경의 글꼴 대체와 줄바꿈을 출력물에서 확인한다.
- 머리글·바닥글·페이지 번호는 필요할 때만 넣고, 문서 제목이나 작성일을 임의로 채우지 않는다.

## 입력 항목

| 항목 | 확인할 내용 |
|---|---|
| 제목 | 사용자가 정한 정확한 문서명 |
| 작성 주체 | 실제 기관·부서·담당자 표기 |
| 날짜 | 작성일과 시행일 중 필요한 항목 |
| 공개 범위 | 사용자가 지정한 경우에만 표시 |
| 서명·직인 | 권한과 원본 이미지가 확인된 경우에만 삽입 |

## HWPX 검증

한컴의 [HWPX 구조 설명](https://tech.hancom.com/hwpxformat/)에 따르면 문서는 ZIP 패키지이며 `mimetype`, `version.xml`, `Contents/content.hpf`, `Contents/header.xml`, `Contents/section0.xml` 등으로 구성된다. 이 목록은 생성 지침의 전부가 아니다. 실제 파일을 생성한 뒤 ZIP 무결성, XML 파싱, 도구에서의 다시 열기, 가능할 경우 한컴오피스의 화면·인쇄 결과를 각각 확인한다.

플레이스홀더가 남아 있거나 서식이 깨지면 결과물로 전달하지 않는다. 한컴오피스를 실행하지 못했다면 호환성 검증은 `미실행`으로 보고한다.
