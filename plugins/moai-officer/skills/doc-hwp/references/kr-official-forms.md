# 한국형 공식 문서 서식 참고

공문·기안문·품의서를 작성할 때 확인할 항목이다. 공공기관의 법정 서식은 [현행 「행정업무의 운영 및 혁신에 관한 규정」](https://www.law.go.kr/lsInfoP.do?lsiSeq=286187), [시행규칙](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=252189), 제출처가 제공한 양식을 직접 확인한다. 이 문서는 법령 정본이나 기관 양식을 대신하지 않는다. 민간 기업의 품의서에는 해당 조직의 내부 규정을 적용한다.

## 공문·시행문

작성 전에 다음 값을 원본 자료 또는 담당 기관에 확인한다.

| 항목 | 확인할 내용 |
|---|---|
| 수신·경유 | 정확한 기관명, 담당 부서, 경유 여부 |
| 제목·본문 | 요청이나 통지의 목적, 근거, 기한, 회신 방법 |
| 문서번호·시행일 | 기관에서 실제 부여한 번호와 날짜 |
| 발신명의·직인 | 발신 권한과 사용 승인된 명의·이미지 |
| 공개구분 | 기관의 결정과 적용 기준 |
| 붙임·연락처 | 실제 첨부 파일, 담당자 정보 |

두문·본문·결문의 위치, 항목 부호, 날짜, `끝.` 표시와 결재란은 사용하는 현행 별지 서식에서 확인한다. 임의의 문서번호·직인·결재 상태·공개구분을 채우지 않는다. 구체적인 작성 항목은 `templates/gonmun.md`도 참고한다.

## 기안문

내부 의사결정 문서에는 기안 목적, 근거, 제안 내용, 예산·일정, 관련 부서 협의, 실제 결재선이 필요할 수 있다. 조직의 결재 규정과 전자결재 시스템 양식을 먼저 확인한다. 전결·대결 표시는 권한 규정을 확인한 뒤에만 쓴다. 공문 발송 전에는 기안 상태와 대외 시행 상태를 구분한다.

## 품의서

품의서는 기업·기관별 내부 양식을 우선한다. 품목, 수량, 단가, 총액, 세금 포함 여부, 거래처, 집행 예정일, 예산 과목, 승인 권한을 확인한다. 견적서가 있다면 금액과 조건을 원본에 대조한다. 승인자와 전결 한도는 추정하지 않는다.

## 출력 검수

- [ ] 제출처 또는 조직이 요구한 서식과 필수 항목을 확인했는가
- [ ] 수신자·발신명의·문서번호·날짜·연락처를 원본과 대조했는가
- [ ] 붙임 목록과 실제 첨부 파일이 일치하는가
- [ ] 결재·공개구분·직인에 확인되지 않은 값을 넣지 않았는가
- [ ] HWPX 파일을 다시 열고, 가능하면 한컴오피스에서 화면·인쇄 결과를 확인했는가

마지막 항목을 실행하지 못했다면 호환성은 `미실행`으로 보고한다.
