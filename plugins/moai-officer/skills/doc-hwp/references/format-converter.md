# 문서 형식 선택과 변환

HWPX·DOCX·PPTX·XLSX는 각각 구조와 편집 기능이 다릅니다. 요청한 출력 형식을 확인하고 현재 호스트에서 실제로 가능한 경로만 사용합니다.

## 작업 전 확인

1. 입력 파일의 형식과 내용을 확인합니다. 확장자만 믿지 말고, 원본을 보존합니다.
2. 변환 목적을 확인합니다: 텍스트 재구성, 편집 가능한 문서, 기존 레이아웃 보존 중 무엇이 필요한지 구분합니다.
3. 호스트의 문서 도구 또는 이미 설치된 변환 기능이 해당 입력·출력을 지원하는지 확인합니다. `pandoc`이나 Python 라이브러리가 사용자 환경에 있다고 가정하지 않습니다.
4. 경로가 없으면 다른 형식으로 만든 파일을 요청 형식인 것처럼 전달하지 않습니다.

## 형식별 경계

| 출력 | 사용할 경로 | 확인할 결과 |
|---|---|---|
| HWPX | 이 플러그인의 `kordoc` MCP `generate_document`·`fill_form`·`patch_document`, 호스트 출력 기능 또는 설치된 HWPX 라이브러리 | 재개봉, OWPML 구조, 내용·서식 |
| DOCX | 호스트 문서 기능 또는 설치된 DOCX 도구 | Word/LibreOffice 열림, 내용·서식 |
| PPTX | 호스트 프레젠테이션 기능 또는 설치된 PPTX 도구 | 슬라이드 수, 글자·도형 배치, 편집 가능성 |
| XLSX | 호스트 스프레드시트 기능 또는 설치된 XLSX 도구 | 값·수식·시트 구조 |

바이너리 HWP→HWPX 변환에는 별도 변환 기능이 필요합니다. HWPX 생성 라이브러리가 HWP도 읽는다고 전제하지 않습니다. DOCX에서 HWPX로 재구성하면 원본 레이아웃이 바뀔 수 있으므로 원본과 결과를 비교합니다.

## 검증과 보고

- 출력 파일을 다시 열고 실제 데이터·텍스트·페이지 또는 슬라이드 구조를 대조합니다.
- 원본 보존, 누락된 그림·표·수식, 대체된 서체, 변환하지 못한 기능을 명시합니다.
- 사용한 호스트에서 시각 검증이 불가능하면 그 결과를 `미실행`으로 남깁니다.
- 대량 변환은 파일별 성공·실패를 기록합니다. 일부 성공을 전체 완료로 표시하지 않습니다.
