# 발표자료용 서체 조합 예시

## 1. Modern (Pretendard + Inter) — 설치 상태 확인

일반 비즈니스 발표에 사용할 수 있는 예시다. 발표 환경에서 두 서체의 설치 여부와 대체 글꼴을 확인한다.

| 위계 | 한국 | 영문 | 사이즈 | weight |
|---|---|---|---|---|
| 표지 제목 | Pretendard | Inter | 56pt | Bold |
| H1 | Pretendard | Inter | 36pt | Bold |
| H2 | Pretendard | Inter | 24pt | SemiBold |
| H3 | Pretendard | Inter | 18pt | SemiBold |
| 본문 | Pretendard | Inter | 16-18pt | Regular |
| 캡션 | Pretendard | Inter | 12pt | Regular |
| Stat 숫자 | Pretendard | Inter | 80pt | Bold |
| CTA 버튼 | Pretendard | Inter | 24pt | SemiBold |

**적합**: B2B 일반·임원 보고·고객 발표·내부 회의
**라이선스**: Pretendard 오픈소스(SIL OFL) · Inter 오픈소스(SIL OFL)

## 2. Editorial (Pretendard + Lora Italic) — 매거진·인용 강조

Lora Italic이 인용·발췌에 적합.

| 위계 | 한국 | 영문 | 사이즈 | weight |
|---|---|---|---|---|
| 표지 제목 | Pretendard | Lora | 56pt | Bold |
| H1 | Pretendard | Lora | 36pt | Bold |
| H2 | Pretendard | Lora | 24pt | SemiBold |
| 본문 | Pretendard | Inter | 16-18pt | Regular |
| **Pull Quote** | Pretendard | **Lora Italic** | 32pt | Regular Italic |
| 캡션 | Pretendard | Inter | 12pt | Regular |

**적합**: 매거진 톤·인용 중심·키노트·창의 분야
**라이선스**: 실제 사용 파일의 라이선스 확인

**라이선스**: 실제 사용 파일의 라이선스 확인

## 폰트 사용 규칙

### 한 슬라이드 폰트 수

- **3개 이내 권장** (Heading·Body·Mono)
- 장식보다 읽기 쉬운 일관성을 우선

### 한국·영문 페어링 원칙

- 한국 본문에 영문 Serif (Lora) 단독 사용 금지 — 한국 폰트와 페어
- 한국 본문에 영문 Mono 단독 사용 금지 — Heading은 한국 폰트
- 한국·영문 사이즈 약간 다르게 — 한국 폰트가 영문보다 1-2pt 작게 보임 (사이즈 보정)

### 사이즈 위계 예시

아래 크기는 예시다. 실제 발표 거리·화면 크기·내용에 맞춰 조정하고 결과를 눈으로 확인한다.

- 표지 제목 ≥ 56pt
- H1 ≥ 36pt
- H2 ≥ 24pt
- 본문 ≥ 18pt (32-40 ft 거리 가독성)
- 캡션 ≥ 12pt

### Weight 위계

- ExtraBold: 표지·강조 헤딩 (Bold Heading 페어링에만)
- Bold: 일반 헤딩
- SemiBold: 소제목
- Regular: 본문

### 줄 간격

- 표지 제목 1.0-1.1
- H1·H2 1.2-1.3
- 본문 1.4-1.6
- Pull Quote 1.5-1.6

### 자간 (Letter Spacing)

- 큰 헤딩: -0.02em ~ -0.05em (살짝 좁힘)
- 본문: 0em (기본)
- 모노: 0em (기본)
