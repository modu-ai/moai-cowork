# 발표 슬라이드 구성 예시

아래 유형은 내용을 배열하는 참고 틀이다. 발표마다 모두 넣거나 정해진 순서·장수로 만들 필요는 없다. 원본 자료가 없는 수치·팀 경력·고객 사례를 채우지 않는다.

| 유형 | 핵심 질문 | 확인할 자료 |
|---|---|---|
| 표지 | 무엇에 관한 발표인가 | 제목·발표자·날짜·승인된 로고 |
| 목차 | 어떤 흐름으로 설명할까 | 실제 섹션 제목 |
| 문제 | 어떤 문제가 확인됐나 | 관측 자료·대상·기간 |
| 해법 | 무엇을 제안하나 | 범위·구현 근거·제약 |
| 기능 | 어떤 기능이 실제로 있나 | 제품 설명·시연 자료 |
| 수치 | 어떤 변화가 있었나 | 값·분모·기간·단위·출처 |
| 팀 | 누가 참여하나 | 공개 승인된 이름·직책·사진 |
| 행동 요청 | 청중에게 무엇을 요청하나 | 가능한 다음 단계·연락처 |
| 마무리 | 무엇을 기억해야 하나 | 핵심 결론·질의응답 정보 |

## 배치 원칙

- 제목과 본문, 근거·출처를 같은 위계로 읽을 수 있게 둔다.
- 한 장에 내용이 많으면 표·그림을 나누고, 나눴을 때 단위·범례·출처를 반복한다.
- 색상과 아이콘만으로 상태를 구분하지 않는다.
- 차트·인용·사진은 원본 또는 사용 허가를 확인한다.
- 시퀀스는 발표 목적과 실제 자료에 맞춰 정한다. 정해진 5·12·25장 예시는 요구사항이 아니다.

결과 슬라이드는 대상 앱에서 미리 보며 글자 크기·잘림·대비·대체 서체를 확인한다.
