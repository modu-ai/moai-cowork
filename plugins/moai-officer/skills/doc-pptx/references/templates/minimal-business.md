# 간결한 비즈니스 슬라이드 예시

이 문서는 브랜드가 없는 경우 검토할 레이아웃 제안이다. 법정·기업 표준이나 실제 PPTX 파일은 아니다. 사용자 조직의 색·로고·서체가 있으면 그것을 따른다.

## 색과 글자

- 배경과 글자색을 함께 정해 대비를 확인한다. 네이비 배경에는 밝은 글자, 흰 배경에는 짙은 글자를 쓸 수 있다.
- 강조색은 데이터 의미와 조직 브랜드에 맞춘다. 성공·경고를 색만으로 구분하지 않는다.
- 한글·영문 서체는 발표 PC에 설치된 것을 확인한다. 미설치 서체는 대체돼 줄바꿈이 바뀔 수 있다.

## 레이아웃

| 유형 | 필요한 내용 |
|---|---|
| 표지 | 확인된 제목·발표자·날짜 |
| 비교 | 같은 단위의 두 대상과 비교 기준 |
| 콘텐츠와 이미지 | 근거 있는 문장과 사용 권한이 있는 이미지 |
| 수치 | 원본 값·단위·기간·출처 |
| 인용 | 원문·발언자·출처 |
| 마무리 | 청중에게 필요한 다음 행동 |

슬라이드 수·텍스트 줄 수·이미지 해상도·여백을 고정하지 않는다. 실제 화면 비율과 내용 밀도에 맞춰 조정한다. PptxGenJS의 위치·크기는 픽셀 좌표가 아니므로 사용 중인 레이아웃 단위로 계산한다.

## 검수

대상 발표 앱에서 화면과 인쇄 결과를 확인한다. 표·차트 수치, 출처, 읽기 쉬운 글자 크기, 잘림·겹침, 대체 폰트를 확인하지 못했으면 PASS라고 쓰지 않는다.
