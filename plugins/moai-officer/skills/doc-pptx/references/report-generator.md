# 보고서형 발표자료 구성

보고서 내용을 슬라이드로 옮길 때 쓰는 참고 절차다. 별도의 에이전트 팀이나 자동 보고서 생성기는 포함하지 않는다.

1. 보고 목적, 청중, 범위, 제출 형식과 원본 자료를 확인한다.
2. 핵심 주장마다 숫자·인용·그림의 출처를 붙인다. 확인되지 않은 자료는 결론의 근거로 쓰지 않는다.
3. 요약, 근거, 분석, 판단이 필요한 사항을 발표 흐름에 맞춰 고른다. 긴 원문 표는 가독성에 맞게 나누고 수치·단위를 보존한다.
4. 사용자 브랜드와 발표 환경에 맞춰 슬라이드를 만든다. 생성 경로는 doc-pptx 스킬을 따른다.
5. 결과 PPTX를 다시 열어 내용·표·차트·페이지·대체 서체를 확인한다. 시각 검수를 못 했다면 미실행으로 보고한다.

기존 작업 파일을 덮어쓰거나 확인되지 않은 협업 에이전트·작업 디렉터리를 자동 생성하지 않는다.
