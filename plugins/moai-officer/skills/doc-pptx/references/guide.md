# PPTX 디자인 시스템 설계 참고

이 파일은 브랜드를 반영한 발표자료를 설계할 때 확인할 항목을 정리한다. 자동 생성기나 마스터 파일은 포함하지 않는다.

## 입력

- 조직의 공식 색·로고·서체·브랜드 사용 규정
- 발표 목적, 청중, 화면 비율, 발표 앱
- 원고·숫자·이미지와 사용 권한
- 필요한 슬라이드 유형과 편집 가능 범위

## 설계

1. 글자색과 배경색을 함께 정하고 실제 화면에서 대비를 확인한다.
2. 발표 PC에 서체가 있는지 확인한다. 서체 이름만 지정해도 폰트가 PPTX에 포함되는 것은 아니다.
3. 표지·본문·비교·통계·인용·마무리 중 필요한 레이아웃만 고른다. 정해진 12개 레이아웃을 모두 만드는 규칙은 없다.
4. 같은 역할의 제목·본문·출처에 일관된 크기와 위치를 적용한다. 실제 내용의 길이와 화면을 보고 조정한다.
5. 로고·연락처·인용은 확인된 자료만 사용한다. 가상 회사나 임의 성과를 채우지 않는다.

## 출력

사용 가능한 PPTX 생성 경로를 확인한 뒤 실제 파일을 저장한다. 원본 데이터·본문과 다시 대조하고 대상 발표 앱에서 전체 슬라이드를 확인한다. 디자인 가이드나 PDF는 요청받았고 생성 경로가 있을 때만 별도 산출한다.
