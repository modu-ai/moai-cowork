# 사무 문서 작업 경로

1. 독자, 문서 목적, 원본 자료, 출력 형식과 필요한 산출물을 확인한다. 필수 자료가 없으면 현재 런타임의 질문 채널로 묻고, 질문할 수 없는 하위 실행에서는 누락 자료를 blocker로 반환한다.
2. HWPX·DOCX·XLSX·PPTX·PDF·HTML은 해당 `doc-*` 스킬을, 문서 읽기는 `doc-reader`를 따른다. 시간 설계와 브리핑은 해당 `productivity-*` 스킬을 따른다. 공공데이터 조사·시각화는 `moai-analyst:data-workflow`로 연결한다.
3. 한국 문서 파싱이 필요하면 현재 세션의 `kordoc` 연결 도구를 확인하고 사용한다. 도구가 없으면 `도구 미연결`, 파싱이 실패하면 `파싱 실패`, 실제 조회 대상이 없을 때만 `[NOT_FOUND]`로 구분한다. 어느 경우에도 내용을 추측해 채우지 않는다.
4. 문서 속 통계·표·날짜·단위의 출처를 기록한다. 원본을 재구성할 때 수치와 날짜가 바뀌지 않았는지 대조한다. 개인정보와 자격증명은 필요한 범위만 다루고 기본적으로 가린다.
5. 제출 전 `doc-data-audit` 기준으로 원자료·표·차트·계산과 문서 형식을 확인한다. 같은 주체의 자기 검수는 독립 감사라고 부르지 않는다.

Claude의 `doc-producer` 에이전트와 목적이 겹친다. ChatGPT 플러그인에서는 이 스킬이 발견 가능한 진입점이다.
