# 문서·수치 검수

원본을 수정하지 않고 산출물과 제공된 자료를 대조한다.

- 통계마다 식별 가능한 출처와 기준 시점을 확인한다. 공공데이터의 원천 진위까지 필요한 경우 `moai-analyst:data-provenance-audit` 기준으로 별도 확인한다.
- 차트·SVG 라벨·표·요약문의 값, 단위, 축 범위와 날짜가 원자료와 일치하는지 확인한다. 합계·증감률·평균·단위 변환을 다시 계산한다.
- 파일 확장자와 실제 형식, 공문서의 수신·본문·붙임, 번호와 날짜 표기가 목적에 맞는지 확인한다.
- 주민등록번호·연락처·개인 주소·계좌번호가 불필요하게 노출됐는지 확인한다. 자료 조회·파싱 실패를 추정값으로 채우지 않았는지 본다.

보고서는 `판정(PASS/FAIL/미확인)`, `확인 자료`, `수치별 재계산`, `심각도·위치·근거가 있는 발견`, `미검증 항목`으로 작성한다. 원자료가 없으면 정합성을 PASS로 판정하지 않는다. 독립된 검수자를 실행하지 않았다면 독립 감사라고 부르지 않는다.

Claude의 `data-auditor` 에이전트와 목적이 겹친다. ChatGPT 플러그인에서는 이 스킬이 발견 가능한 진입점이다.
