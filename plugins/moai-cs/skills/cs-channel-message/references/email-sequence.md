# 이메일·알림톡 시퀀스 카피

아래는 발송 초안의 구조 예시다. 예시의 상품·가격·쿠폰·적립금·배송일·재고·환불 조건은 실제 값이 아니다. 셀러가 확인한 값만 채우고, 광고 수신 동의·발신자 정보·수신거부 방법을 발송 채널에 맞게 점검한다. **알림톡은 정보성 승인 템플릿에만 사용한다.** 후기 보상, 재구매 권유, 카트 회복, 시즌 행사처럼 광고가 섞인 메시지는 알림톡으로 보내지 않는다. 근거: [카카오 알림톡 심사 가이드](https://kakaobusiness.gitbook.io/main/ad/infotalk/audit.md), [카카오톡 채널 가이드](https://business.kakao.com/guide.html).

## 5. 알림톡 vs 이메일 선택 가이드

| 상황 | 권장 채널 |
|------|---------|
| 거래 알림 (주문·배송) | 알림톡 (즉시성) |
| 마케팅 (광고 동의 회원) | 이메일 또는 현재 지원되는 카카오 광고 메시지 |
| 짧은 후크·CTA | 광고 동의가 확인된 푸시·광고 메시지 |
| 스토리·신상 소개 | 이메일 |
| 시즌 캠페인 시작 | 이메일 (사전) + 푸시 (당일) |
| 카트 이탈 | 광고 동의가 확인된 이메일·푸시·광고 메시지 |
| 후기 요청 | 보상·구매 권유 여부를 확인한 뒤 적합한 광고 채널 선택 |

## 6. 이메일 디자인 팁

- 모바일 화면에서 읽기 쉽게 작성
- 한 줄 폭 600px
- 이미지가 표시되지 않아도 핵심 내용이 텍스트로 전달되게 작성
- CTA 버튼 큼직 + 명확
- 발신자 이름은 [브랜드명] (회사명 X)
- 발신자 이메일은 noreply@ 보다 hello@·marketing@ (개인 같은 톤)

## 7. 자동화 도구

- **자사몰 자체**: 카페24·아임웹 기본 자동화 (제한적)
- **외부 마케팅 자동화**: MAILY, Stibee, Mailchimp (이메일)
- **알림톡**: 알리고, 굿스플로, 카카오 비즈메시지
- **통합 CRM**: Braze, OneSignal (대형), 채널톡 (중소)
