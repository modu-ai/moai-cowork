# 푸시 알림 카피 가이드

아래 문안은 형식 예시다. 가격·할인·재고·배송 예정일·환불 조건·쿠폰 지급 여부는 실제 상품·주문·셀러 정책에서 확인된 값으로만 채운다. 확인되지 않으면 혜택을 빼거나 `[셀러 확인 필요]`로 남긴다. 광고성 푸시는 수신 동의와 발송 시간 요건을 확인한 뒤 담당자가 발송한다.

## 1. 푸시 알림 형식

| 부분 | 길이 | 비고 |
|------|------|------|
| 제목 | 30자 (모바일 잘림 한계) | 핵심 후크 |
| 본문 | 120자 (확장 시) | 추가 정보 |
| 액션 버튼 | 10자 | "보러 가기", "쿠폰 받기" |

## 2. 카테고리별 카피 패턴

### 신상품 출시
```
제목: 🎉 [브랜드명] 신상품 단독 발매!
본문: [검증된 제품 정보] — [승인된 회원 혜택]
버튼: 지금 보러 가기
```

### 프로모션 시작
```
제목: ⏰ 24시간 한정 -30% 시작
본문: X200 무선이어폰, [확정된 정상가] → [확정된 행사가]. [확정된 배송 혜택]
버튼: 지금 사러 가기
```

### 프로모션 종료 임박
```
제목: ⌛ 6시간 남았어요 -30%
본문: [확인된 종료 시각] 종료. X200 무선이어폰 [확정된 행사가]. [실제 재고 정보]
버튼: 마지막 기회
```

### 카트 회복
```
제목: 🛒 장바구니 살펴보고 가셨나요?
본문: X200 무선이어폰 + 케이스 — [실제 발급된 쿠폰과 유효기간]
버튼: 결제하기
```

### 재구매 유도 (60일 미구매)
```
제목: 💝 [고객님 이름]님, 오랜만이에요!
본문: 10% 재구매 쿠폰 + 무료배송. 즐겨찾기 상품 X200, 새 색상 출시했어요.
버튼: 둘러보기
```

### 후기 요청
```
제목: ✍️ 후기 한 줄 부탁드려요
본문: 받으신 X200 어떠셨나요? 후기 작성 시 5,000원 적립 — 다음 구매에 사용 가능.
버튼: 후기 쓰기
```

### 배송 안내
```
제목: 📦 X200 출고됐어요
본문: 김OO님, 주문하신 X200 무선이어폰의 [확인된 배송 상태]. 예상 도착일 [택배사 확인값]. 운송장 [번호]
버튼: 배송 조회
```

## 3. 푸시 카피 톤

### Do
- 짧고 강하게
- 첫 단어가 중요 (이모지 1개 OK)
- 숫자·구체성 (시간·할인율·재고)
- 호칭 (가능하면 이름)
- 액션 버튼 명확

### Don't
- "안녕하세요" 같은 인사 (낭비)
- 모호한 표현 ("좋은 소식 있어요" — 뭔지 알 수 없음)
- 이모지 3개 이상
- 긴 문장 (모바일 잘림)
- 전체 발송 (개인화 부재)

## 4. 발송 빈도 가이드

| 빈도 | 권장 |
|------|------|
| 매일 | NO (피로도 누적, 차단율 ↑) |
| 주 2-3회 | OK (활성 회원) |
| 주 1회 | OK (안전, 일반 회원) |
| 월 1-2회 | OK (비활성 회원 회복) |
| 시즌·이벤트 한정 | 추가 OK |

## 5. 발송 시점

### 좋은 시점
- 평일 오전 9-10시 (출근길 폰 확인)
- 평일 점심 12-13시 (점심 시간)
- 평일 저녁 19-21시 (퇴근·여가)
- 주말 오전 10-11시 / 오후 15-17시

### 나쁜 시점
- 21:00~다음 날 08:00 광고 발송 — 별도 사전 동의 여부를 확인해야 함
- 평일 출근 직전 (08:00-08:30) — 무시당함
- 주말 새벽 (00:00-09:00) — 휴식 방해

## 6. 한국 정통망법 (영리목적 광고성 정보)

- 야간(21:00~다음 날 08:00) 영리목적 광고성 정보 발송에는 일반 광고 수신 동의와 별도의 사전 동의가 필요하다. 법령상 매체 예외도 확인한다. [정보통신망법 제50조 제3항](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030434421)
- 거래·배송·CS 알림은 시간 무관
- 마케팅 푸시는 동의 받은 회원에게만

## 7. 세그먼트별 푸시 전략

| 세그먼트 | 메시지 톤 |
|---------|---------|
| 신규 회원 (가입 7일 내) | 환영·할인 적립금 안내 |
| 첫 구매 후 30일 내 | 사용법·후기·재구매 |
| 충성 고객 (3회+ 구매) | 신상 우선 안내·VIP 혜택 |
| 비활성 회원 (60일+ 미구매) | 회복 쿠폰·조심스러운 톤 |
| 카트 이탈 | 즉각 회복 (1시간-24시간 내) |
| 시즌 캠페인 | 광고 수신 동의 대상만 발송 검토 |

## 8. A/B 테스트

- 제목 변형 2-3개
- 발송 시점 변형 (오전 vs 저녁)
- 이모지 유무
- 호칭 유무 (이름 vs 일반)

오픈율·클릭율로 측정 후 우승안 적용.

## 9. 자사몰 빌더별 푸시 도구

- **카페24**: 모바일 앱 푸시 (앱 사용자만), 알림톡 (카카오)
- **아임웹**: 알림톡 + 이메일
- **외부**: Braze, OneSignal (앱 푸시 전문), 채널톡 (채팅·푸시)

## 10. 흔한 실수

- 모든 회원에게 동일 메시지 (개인화 부재)
- 빈도 과다 (주 5회+ → 차단율 ↑)
- 야간 광고 발송 시 별도 사전 동의 누락
- 모호한 제목 ("좋은 소식")
- 액션 버튼 없음 (어디 클릭?)
