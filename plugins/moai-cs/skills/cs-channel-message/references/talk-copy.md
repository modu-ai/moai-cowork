# 톡톡·CS 응답 카피 가이드

**초안 규칙:** 아래 `[확인값]`은 실제 주문·배송·셀러 정책에서 확인한 뒤에만 고객 문안에 넣는다. 환불·교환·적립금·보상·도착일을 확인 없이 약속하지 않는다. 법적 판단이 필요한 환불 거부나 비용 부담은 담당자에게 넘긴다.

## 1. 자동응답 메시지 (스마트스토어 톡톡 / 채널톡)

### 영업시간 외
```
안녕하세요, [브랜드명] 고객센터입니다.

지금은 영업시간(평일 10:00 ~ 18:00) 외 시간이라 즉시 답변이 어렵습니다.
영업시간에 순서대로 확인해 답변드리겠습니다.

급하시다면 자주 묻는 질문도 함께 살펴봐 주세요:
- 배송: [확인된 배송 안내 링크]
- 환불·교환: [셀러의 현행 정책 안내 링크]

감사합니다.
```

### 새 고객 환영
```
[브랜드명]을 만나주셔서 감사해요!

처음이신가요? 이용 방법은 [서비스 안내 링크]에서 확인하실 수 있어요.

상품 문의는 언제든 톡톡으로 보내주세요. 평일 10~18시에 답변 드립니다.
```

### FAQ 자동 안내
```
자주 묻는 질문 중 답이 있나요?

배송: [확인된 배송 정책 링크]
환불·교환: [확인된 청약철회·비용 안내 링크]
적립: [확인된 적립 정책 링크]

원하는 답이 없으면 메시지 보내주세요. 영업시간에 순서대로 답변드리겠습니다.
```

## 2. 상품 문의 응답

### 사이즈 문의
```
안녕하세요. [브랜드명] 입니다.

[상품명] 사이즈 추천드릴게요:
- 평소 키 168cm + 55사이즈 입으시면 → S 추천
- 키 173cm 이상 + 66사이즈 → M 추천
- 박시핏 선호하시면 한 단계 큰 사이즈 추천드려요

상품페이지 [사이즈 가이드]에 모델 착용샷이 있으니 참고 부탁드려요.
추가 문의는 편하게 보내주세요.
```

### 재입고 문의
```
[상품명] 관심 가져주셔서 감사해요.

해당 상품은 현재 품절 상태이며, 재입고 일정은 [날짜] 예정입니다.
재입고 알림 신청해주시면 입고 즉시 알림톡으로 안내 드릴게요.

📲 [재입고 알림 신청] 링크: [URL]
```

## 3. 클레임 응답 (1점 후기 등)

### 후기 평점 1-2점 응답
```
안녕하세요, [브랜드명]입니다. 먼저 불편을 드려 진심으로 죄송합니다.

[고객님이 언급한 문제]에 대해 정확히 파악하고 빠르게 해결해드리고 싶어요.
번거로우시겠지만 [톡톡 또는 1:1문의]로 주문번호와 함께 메시지 주시겠어요?
가능한 해결 방법을 주문 상태와 정책에 따라 확인해 안내드리겠습니다.

이번 일을 발판으로 더 나은 제품과 서비스로 보답하겠습니다. 다시 한 번 죄송합니다.
```

**핵심**: 사과 + 책임 인정 + 해결 옵션 제시 + 개선 약속.
**금지**: 변명, 책임 회피, 고객 잘못 지적, 형식적 사과.

### 환불 요청
```
안녕하세요. 환불 요청 내용을 확인하겠습니다.

주문번호 [확인된 번호]의 수령일과 상품 상태를 확인한 뒤 청약철회 가능 기간·배송비 부담·환불 절차를 안내드리겠습니다.
상품에 문제가 있다면 관련 사진을 보내주시면 담당자가 확인하겠습니다.
불편 드려 죄송합니다.
```

### 배송 지연 사과
```
[고객님 성함] 고객님, 배송 지연으로 불편을 드려 죄송합니다.

확인해보니 [택배사 사정 / 재고 부족 / 명절 물량] 사유로 평소보다 1~2일 지연되었습니다.
현재 확인된 배송 상태는 [택배사 조회 결과]입니다. 도착 예정일이 확인되면 안내드리겠습니다.

보상 여부는 담당자가 확인한 뒤 안내드리겠습니다.
다시 한 번 죄송합니다.
```

## 4. 톡톡 톤 가이드

### Do
- "고객님" 호칭
- 존댓말 + 약간의 친근함
- 이모지 1-2개 (과하지 않게)
- 구체적 답변 (모호한 안내는 신뢰 ↓)
- 24시간 이내 응답

### Don't
- 반말
- 기계적 자동응답만
- "저희" 자주 (주체 모호) → "[브랜드명]" 명시
- 책임 회피·변명
- 길게 늘어지는 답변 (모바일 시청)

## 5. 알림톡 vs 카카오 광고 메시지

| 구분 | 알림톡 | 현재 지원되는 카카오 광고 메시지 |
|------|-------|-------|
| 발송 조건 | 거래 등 정보성·승인된 템플릿 | 해당 광고 채널의 동의·발송 요건 확인 |
| 비용 | 계약·대행사 요금 확인 | 계약·대행사 요금 확인 |
| 광고성 | 광고 내용 혼합 불가 | 광고 요건 충족 시 가능 |
| 광고 동의 | 정보성 요건 확인 | 광고 수신 동의 확인 |

### 알림톡 카피 (거래)
```
[주문 확인]
김OO 고객님, 주문이 완료되었습니다.
주문번호: 20260501-1234
상품: X200 무선이어폰 1개
결제: 89,000원
배송: [확인된 출고·배송 정보]

📦 배송조회: [URL]
```

### 광고 메시지 카피 (동의 및 채널 심사 필요)
```
(광고) [확정된 행사] X200 무선이어폰

[확정된 가격·혜택]
[실제 재고와 종료 시각]

▶ 지금 보러 가기: [URL]

수신거부: [현재 채널에서 실제 동작하는 방법]
```

## 6. 자동응답 운영 팁

- 카페24·아임웹·채널톡 모두 시간대별 자동응답 설정 가능
- 영업시간 + 점심시간 + 휴일 분리
- FAQ 키워드 매칭 (사이즈·환불·배송 자동 분기)
- 봇 답변 후 "사람과 대화" 옵션 항상 제공

카카오 메시지에서는 정보성 내용에 할인·행사 안내가 섞여도 광고성으로 취급될 수 있다. 알림톡은 정보성 승인 템플릿만 사용하고, 광고 메시지는 현재 채널의 표시·발신자 정보·수신거부 요건을 확인한다. 근거: [카카오톡 채널 가이드](https://business.kakao.com/guide.html), [알림톡 심사 가이드](https://kakaobusiness.gitbook.io/main/ad/infotalk/audit.md).
