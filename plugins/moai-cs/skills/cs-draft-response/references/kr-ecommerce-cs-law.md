# 한국 이커머스 CS 법정 기준 요약 (kr-ecommerce-cs-law)

CS 응답 초안의 "해결책" 단계에서 환불·교환·반품 관련 안내를 작성할 때 참조하는 법정 기준 요약입니다. 개별 거래와 상품 유형에 따라 적용 요건이 달라지므로, 기간과 비용을 고객에게 확정 안내하기 전에 현행 조문과 주문 사실관계를 확인합니다.

> ⚠️ 본 문서는 법률 자문이 아닌 응대 참고 자료입니다. 분쟁이 임박한 건은 법무 검토(`moai-lawyer`)로 에스컬레이션하십시오. 법령·고시는 개정될 수 있으므로 응답에 기준일을 명시하고, 최신 조문은 국가법령정보센터에서 확인합니다.

## 1. 청약철회 (단순 변심 반품) — 전자상거래법 제17조

| 항목 | 기준 | 근거 |
|------|------|------|
| 기본 기간 | 계약내용에 관한 서면을 받은 날부터 7일. 재화등의 공급이 그보다 늦으면 재화등을 공급받거나 공급이 시작된 날부터 7일. 거래 당사자가 더 긴 기간을 약정했는지도 확인 | 전상법 제17조 제1항 제1호 |
| 서면 미교부·판매자 주소 미기재 등으로 통상 기간에 철회할 수 없는 경우 | 판매자 주소를 안 날 또는 알 수 있었던 날부터 7일. 해당 사유 충족 여부를 확인 | 전상법 제17조 제1항 |
| "환불 불가" 일괄 고지 | 무효 — 법정 철회권은 약관·고지로 배제 불가 | 전상법 제17조·제35조(소비자에게 불리한 약정 무효) |

**청약철회 제한 사유** (전상법 제17조 제2항 — 각 호의 요건과 제6항의 적용 범위를 따로 확인):
- 소비자 책임으로 재화가 멸실·훼손된 경우 (확인용 포장 훼손 제외)
- 사용·일부 소비로 가치가 현저히 감소한 경우
- 시간 경과로 재판매가 곤란할 정도로 가치가 감소한 경우 (신선식품 등)
- 복제 가능한 재화의 포장을 훼손한 경우 (음반·소프트웨어 등)
- 용역 또는 디지털콘텐츠의 제공이 개시된 경우. 가분적인 계약에서 아직 제공이 시작되지 않은 부분은 별도 확인
- 개별 주문 제작 등으로 철회를 인정하면 판매자에게 회복할 수 없는 중대한 피해가 예상되고, 거래별 사전 고지와 소비자의 서면·전자문서 동의가 있는 경우 (시행령 제21조)

제17조 제6항의 명확한 표시·시험 사용 등 조치는 제2항 제2호부터 제5호의 제한에 적용된다. 제1호와 주문 제작에 관한 제6호까지 같은 요건이 일률적으로 적용된다고 안내하지 않는다. 디지털콘텐츠는 제6항 단서의 추가 요건도 확인한다.

## 2. 하자·표시광고 상이 시 청약철회 — 전자상거래법 제17조 제3항

- 재화의 내용이 **표시·광고 내용과 다르거나 계약 내용과 다르게 이행된 경우**: 공급받은 날로부터 **3개월 이내이면서**, 그 사실을 안 날 또는 알 수 있었던 날로부터 **30일 이내**여야 한다. 어느 한 기간이 지나면 이 조항에 따른 철회 기간을 충족하지 못한다는 [법제처 해석례](https://law.go.kr/LSW/expcInfoP.do?expcSeq=314906)를 확인했다.
- 이 경우 제17조 제3항의 별도 요건을 적용한다. 포장 개봉·사용 여부만으로 모든 사안의 결론을 단정하지 않는다.

## 3. 반품 배송비 부담 — 전자상거래법 제18조

| 사유 | 반품비 부담 | 비고 |
|------|------------|------|
| 단순 변심 | 원칙적으로 소비자 부담 | 전상법 제18조 제9항. 실제 배송비와 거래 조건 확인 |
| 하자·오배송·표시광고 상이 | **판매자 부담** | 전상법 제18조 제10항 |
| 환급 기한 | 재화를 공급한 경우 반환받은 날부터 **3영업일 이내**. 용역·디지털콘텐츠·미공급 거래는 법정 기산점이 다름 | 전상법 제18조 제2항 |

## 4. 소비자분쟁해결기준 — 품목별 대표 조항

공정거래위원회 고시 「소비자분쟁해결기준」을 적용할 때는 현재 품목과 분쟁 유형에 맞는 별표 원문을 확인한다. 품목별 보증기간·수리·교환·환급 순서를 이 요약만으로 확정하지 않는다. 판매자의 계약 조건과 법정 청약철회권도 함께 검토한다.

## 5. CS 응답 작성 시 적용 원칙

1. **법정 기준 미달 안내 금지**: "교환·환불 불가", "수령 후 24시간 내에만 반품" 등은 법정 기준(7일)보다 불리 → 사용 금지.
2. **사유 먼저 분류**: 단순 변심 vs 하자·오배송을 먼저 확인한 뒤 반품비 부담 주체·기한을 안내.
3. **기한은 거래 사실과 조문으로**: 제17조 제1항의 서면 수령일·재화 공급일, 제3항의 두 기간, 제18조 제2항의 재화 반환일 또는 다른 거래 유형의 기산점을 각각 확인한다. 고객에게 단일 기산점을 일괄 적용하지 않는다.
4. **근거 병기**: 고객 안내문에는 조문 번호까지 쓰지 않아도 되지만, 내부 초안 메모에는 근거 조문을 남깁니다.
