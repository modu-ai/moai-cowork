# 응답 초안 작성 (Draft Response)

## 개요

고객 문의에 대한 응답 초안을 한국어 경어로 작성합니다. 이메일, 카카오채팅, 앱 내 메시지, 공식 답변서 등 채널별 어조와 형식에 맞춰 초안을 생성합니다. 문의 원문과 셀러의 실제 정책을 확인하고 공감·확인된 사실·다음 단계를 구분합니다. 초안을 고객에게 발송한 것으로 표현하지 않습니다.

## 트리거 키워드

응답 초안, 답변 작성, 이메일 답장, 고객 응대, 메시지 초안, 공식 답변, CS 답변, 답변 템플릿, 문의 답변

## 워크플로우

1. **문의 유형 파악**: cs-ticket-triage 스킬 연동 또는 직접 입력된 문의 내용 분석
2. **채널 선택**: 이메일 / 카카오채널 / 앱 내 채팅 / 공식 서한 / SNS DM
3. **어조 설정**: 
   - 공식: 공문서·법적 답변, 높임말 최고 수준
   - 표준: 이메일·헬프데스크, 정중한 비즈니스 어조
   - 친근: 채팅·SNS, 부드러운 고객 접점 어조
4. **초안 생성**: 공감 → 상황 확인 → 해결책 → 다음 단계 구조로 작성
5. **품질 체크**: 경어 일관성, 개인정보 마스킹, 부정적 표현 검토

## 응답 구조 원칙

```
1. 공감 인사: "고객님, 불편을 드려 진심으로 죄송합니다."
2. 상황 확인: 실제 주문·문의 기록을 조회한 경우에만 "확인하였습니다"라고 쓴다. 조회하지 못했다면 "확인하겠습니다"로 표시
3. 해결책: 승인된 처리 방안만 제시. 처리 방법이나 일정이 미확정이면 담당자 결정 항목으로 남김
   — 환불·교환·반품 문의는 `references/kr-ecommerce-cs-law.md`(청약철회 7일·하자 기한·반품비 부담·소비자분쟁해결기준)를 확인해 법정 기준보다 불리한 안내를 하지 않도록 합니다
4. 다음 단계: 고객이 해야 할 행동 또는 실제로 확인된 다음 안내 시점
5. 마무리: 지속적인 지원 의사 표명
```

## 채널별 어조 가이드

| 채널 | 어조 | 길이 | 특징 |
|------|------|------|------|
| 이메일 | 정중·공식 | 200-400자 | 제목 포함, 서명 필수 |
| 카카오채널 | 친근·간결 | 100-200자 | 이모지 선택적, 빠른 응답 |
| 앱 내 채팅 | 표준·신속 | 50-150자 | 실시간성 강조 |
| 공식 서한 | 격식·법적 | 500자+ | 날짜·수신인·발신인 필수 |
| SNS DM | 친근·공개 | 100자 이내 | 공개 가능성 고려 |

## 응답 핵심 원칙

- **반복 설명 방지**: 접근 권한이 있는 이전 대화에서 확인한 사실을 반영하되, 보지 못한 기록을 본 것처럼 쓰지 않는다.
- **응답 시점**: 셀러의 실제 응답 기준을 확인한다. 즉시 답변할 수 없으면 접수 확인 초안을 별도로 작성한다.
- **AI 사용 고지**: 셀러의 운영 정책과 채널 요건을 확인해 필요한 고지 문구를 넣는다.
- **불만 응대**: 불편을 인정하되 원인·책임·보상은 확인 전 단정하지 않는다.

## 산출물

- 채널별 맞춤 응답 초안 (한국어 경어)
- 대안 어조 버전 (공식/표준/친근 3종)
- 후속 조치 안내문
- 자동 접수 확인 메시지 (즉시 응답용)

## 참고 사항

- **경어 레벨**: "합니다/습니다" 체 사용 필수. "해요" 체는 채팅 채널에만 선택적 허용
- **부정 표현 지양**: "안 됩니다", "불가능합니다" 대신 "처리해 드릴 수 있는 방법은..." 형식 사용
- **약속 주의**: 기한 미확인 시 임의의 범위도 제시하지 않는다. 환불·보상·배송일·정책 예외는 셀러가 확인하거나 승인한 경우에만 확정 표현을 쓴다.
- **개인정보**: 응답에 고객 주민번호, 카드번호, 계좌번호 직접 기재 금지

## 문제 해결

| 상황 | 해결 방법 |
|------|-----------|
| 티켓 원문 접근 불가 | 문의 내용을 요약해서 입력해 주시면 그에 맞는 초안을 작성합니다 |
| 고객 정보 부족 | "고객님" 형식의 일반 호칭으로 작성 후 나중에 맞춤화할 수 있습니다 |
| 사내 답변 가이드라인 존재 | 가이드라인 핵심 원칙을 알려주시면 그에 맞춰 조정합니다 |
| 법적 분쟁 가능성 있는 문의 | 법적 주의사항을 포함한 신중한 어조로 작성하며 법무팀 검토를 권장합니다 |

## 관련 스킬 (후처리 체인)

응답 초안을 작성한 뒤에는 같은 스킬 안에서 먼저 사실·약속·개인정보·경어를 검수합니다. `moai-coworker`와 `moai-writer`가 현재 설치돼 사용 가능하면 아래 순서로 표현을 추가 점검합니다. 다른 플러그인이 없어도 초안을 마무리할 수 있습니다.

```
cs-draft-response → moai-coworker:ai-slop-reviewer → moai-writer:korean-humanize → 최종 검수
```

- `moai-coworker:ai-slop-reviewer` — AI 티 나는 표현·과잉 수식·기계적 문장 패턴을 검수·수정
- `moai-writer:korean-humanize` — 한국어 경어 자연스러움과 사람이 쓴 듯한 어조로 다듬기

채널별 어조 기준 및 금지 표현 목록: `references/tone-guide.md`

- 고객 문의 원문에 개인정보가 있으면 업무에 불필요한 값은 삭제하고, 필요한 값도 주민등록번호 뒤 7자리·연락처 중간 자리·계좌와 카드번호 앞자리를 가립니다. 주소는 시·군·구까지만 남깁니다. 주문번호는 고객 공개 초안에서 삭제하거나 식별에 필요한 뒤 4자리만 남깁니다. 중간 메모와 답변 초안에 원본을 다시 쓰지 않고, 제출 전 원문과 대조합니다. 공유 규격 `moai-coworker:ai-slop-reviewer/references/kr-pii-masking.md`를 이용할 수 있으면 함께 확인합니다.
- 다른 플러그인이 없어도 고객 응답은 일관된 존댓말로 쓰고, 확인되지 않은 처리 결과·기한을 단정하지 않습니다. `moai-coworker:collab-report-speak`가 설치돼 있으면 `references/kr-honorific-tone.md`도 참고합니다.
