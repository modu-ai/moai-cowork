# 티켓 분류 (Ticket Triage)

## 개요

고객 지원 티켓을 분류하고 우선순위를 배정합니다. 응답·해결 목표는 셀러의 실제 운영 시간과 승인된 SLA를 확인해 제시합니다. 복잡하거나 법적 판단이 필요한 문의는 담당자에게 이관합니다.

## 트리거 키워드

티켓 분류, 문의 분류, CS 우선순위, 고객 문의, 지원 요청, 티켓 배정, 인바운드 CS, 문의 처리, 헬프데스크

## 워크플로우

1. **티켓 수신 분석**: 문의 내용, 채널(이메일/채팅/전화/SNS), 고객 등급 확인
2. **유형 분류** (아래 분류 체계 적용):
   - 기술 문제 / 결제·환불 / 배송 조회 / 일반 문의 / 불만·컴플레인 / VIP 요청
3. **긴급도 판정**:
   - P1 긴급: 안전·보안 위험, 광범위한 서비스 장애, 결제 중복 등 피해 확대 가능성 → 즉시 담당자에게 알림
   - P2 높음: 환불 분쟁, 반복 결제 오류 등 개별 고객의 중대한 피해 가능성 → 담당자 우선 검토
   - P3 보통: 일반 문의, 사용법 안내 → 통상 처리 순서
   - P4 낮음: 제안, 피드백 → 정기 검토
   - VIP 여부나 강한 감정만으로 P1을 확정하지 않는다. 법정 시한·안전 위험·피해 규모를 먼저 확인하고, 각 등급의 실제 응답 목표는 셀러의 SLA에서 가져온다.
4. **담당자 배정**: 유형별 전문 팀 또는 FAQ 자동 응답 연결
5. **에스컬레이션 판단**: 감정적 민원, 반복 문의, VIP는 human-in-the-loop 전환

## 고객 기대 조사와 운영 목표의 구분

[Zendesk 2026 CX 트렌드](https://cxtrends.zendesk.com/kr/)는 여러 국가 소비자 조사다. 아래 수치는 한국 셀러의 법정 응답 시한이나 개별 사업자의 SLA가 아니다.

| 기준 | 수치 |
|------|------|
| AI로 인해 고객지원이 24시간 내내 이용 가능하길 기대 | 소비자 74% |
| 1년 전보다 빠른 응답을 기대 | 소비자 88% |
| 담당자가 바뀔 때 같은 설명을 반복하는 데 불만 | 소비자 74% |
| 텍스트·이미지·동영상을 같은 대화에서 보낼 수 있는 기업을 선택하겠다는 응답 | 소비자 76% |
| AI가 내린 결정의 설명을 기대 | 소비자 95% |

## 분류 출력 형식

```
[티켓 분류 결과]

티켓 ID: #XXXXX
접수 채널: 이메일 / 카카오채널 / 앱 내 문의
분류: 결제·환불
긴급도: P2 (높음)
응답 목표: [셀러의 승인된 SLA 확인 필요]
권장 담당팀: 결제팀
에스컬레이션 필요: 아니오

요약: 고객이 3일 전 주문 취소 후 환불이 미완료됨을 문의
권장 초안: cs-draft-response 스킬 호출
```

## 산출물

- 분류 레이블 및 긴급도 등급 (P1~P4)
- 담당 팀/담당자 배정 권고
- 확인된 운영 정책에 따른 응답 목표 표시 (미확인 시 공란)
- 에스컬레이션 필요 여부 판단
- 관련 KB 아티클 링크 제안 (cs-kb-article 스킬 연동)

## 참고 사항

- **경어 필수**: 고객 응대 시 존댓말 사용은 필수이며, "고객님" 호칭을 기본으로 사용
- **감정 분석**: 불만의 강한 어조는 담당자 검토 신호로 표시하되, 긴급도는 실제 피해와 정책 기준으로 판정
- **개인정보**: 주민등록번호, 카드번호 등 민감 정보 포함 시 마스킹 처리 후 분류
- **멀티모달**: 이미지·영상 첨부 티켓은 내용 요약 후 담당자에게 원본 전달

## 문제 해결

| 상황 | 해결 방법 |
|------|-----------|
| 티켓 원문 접근 불가 | 문의 내용 요약 또는 핵심 키워드만 입력하셔도 분류 기준을 안내해 드립니다 |
| 고객 정보 부족 | 고객 등급 없이도 문의 내용 기반으로 긴급도와 유형을 판단합니다 |
| 분류 기준 내부 규정과 충돌 | 내부 분류 체계를 공유해 주시면 그에 맞춰 조정합니다 |
| 멀티채널 통합 필요 | 채널별 우선순위 매핑표를 함께 설계해 드립니다 |

> 티켓 분류는 분류·우선순위 판정 작업으로, 별도 서술형 산출물을 생성하지 않습니다. 분류 결과를 바탕으로 **고객 응답 초안**을 작성할 때는 `moai-cs:cs-draft-response`를 사용합니다. 다른 플러그인의 표현 검수 스킬은 설치돼 있을 때만 추가로 사용합니다.

## 이 스킬을 사용하지 말아야 할 때

- **고객 응답 초안 작성** → moai-cs:cs-draft-response 스킬이 더 적합합니다
- **에스컬레이션 처리 및 VIP 대응** → moai-cs:cs-escalation 스킬을 사용하세요
- **지식베이스 문서 작성** → moai-cs:cs-kb-article 스킬을 사용하세요
- **실제 티켓 시스템(Zendesk, Freshdesk) 조작** → 해당 시스템에 직접 접속해야 합니다
