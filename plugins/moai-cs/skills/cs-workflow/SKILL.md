# 고객지원 작업 경로

1. 실제 고객 메시지, 주문 상황, 채널, 셀러의 정책과 어조 지침, 필요한 산출물을 확인한다. 필수 자료가 없으면 현재 런타임의 질문 채널로 묻고, 질문할 수 없는 하위 실행에서는 누락 자료를 blocker로 반환한다.
2. 문의 분류는 `cs-ticket-triage`, 답변 초안은 `cs-draft-response`, 담당자 이관은 `cs-escalation`, FAQ는 `cs-kb-article`, 리뷰와 VOC는 `cs-voc-triage`, 채널 문구는 `cs-channel-message` 지침을 따른다.
3. 환불·보상·배송일·정책 예외를 셀러의 승인 없이 약속하지 않는다. 미확정 사항은 셀러 결정 항목으로 표시한다. 고객에게 보낸 적 없는 초안을 발송 완료로 표현하지 않는다.
4. 저장되는 산출물에는 필요한 개인정보만 남기고 주문번호·연락처·주소·결제정보는 기본적으로 가린다. 불만 답변은 문제를 먼저 인정하고 비난을 피한다. 법적 판단이 필요한 사안은 담당자 검토 대상으로 표시한다.
5. VOC 수치와 감정 분류는 실제 데이터와 연결한다. 제출 전 `cs-quality-audit` 기준으로 약속·개인정보·근거를 확인한다. 같은 주체의 자기 검수는 독립 감사라고 부르지 않는다.

Claude의 `cs-responder` 에이전트와 목적이 겹친다. ChatGPT 플러그인에서는 이 스킬이 발견 가능한 진입점이다.
