# 픽셀 그림 출처와 본문 대조

기존 시안에서 확정한 프로젝트·폴더 그림과 순차·병렬 분업 그림은 `www/design-system/eink-proposal/assets/`에서 원본 그대로 복사했다. 생성 프롬프트는 `reports/20261006-kindle-pixel-design/image-prompts.md`에 있다.

반복 업무 그림은 `www/content/learn/06-review-reuse.md`와 `www/content/workflows/reuse.md`를 읽고 생성했다. 본문의 입력·검토·지침 보완·새 자료·예약 등록과 첫 실행 확인을 시각화한다. 도구는 내장 `image_gen.imagegen`을 사용했다.

첫 생성 요청은 1536×1024, 킨들 색, 문서·돋보기·연필·서랍·달력의 픽셀 그림, 이번 자료 → 초안 작성 → 원문 비교 → 기준 보완 → 다음 업무 적용의 순환이었다. 서랍에는 유지할 기준인 “출고와 도착 구분”을 넣고, 검증 후 예약 등록과 첫 실행 확인으로 이어지는 점선을 요청했다. 단순 문장 카드와 개념 설명 푸터는 제외하도록 요청했다.

첫 결과에 요청하지 않은 “한국어 개념 설명” 푸터와 “운송장 기준으로 확인” 문장이 있었음을 눈으로 확인했다. 이미지 편집 도구에 그 두 부분만 제거하고 원래 그림과 화살표·나머지 문구를 유지하도록 요청했다. 수정본에서 두 부분이 제거되고 한글 라벨과 순환 방향이 유지되는 것을 확인한 뒤 사용했다.
