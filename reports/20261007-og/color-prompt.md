# 컬러 OG 이미지 생성 요청

내장 image_gen을 사용했다. 기존 모아이 석상·바다 OG 그림을 구도 참조로, 사용자가 첨부한 모두의AI 로고를 삽입 참조로 제공했다.

가로형 공유 카드. 황금빛·주황색 일출, 파랑·청록 바다, 녹색 해안과 갈색 석상을 16비트 콘솔 풍의 컬러 픽셀 아트로 표현한다. 오른쪽 큰 모아이와 해안선을 따라 작아지는 석상을 유지한다. 제목은 `MoAI-Cowork`, 다음 줄은 `for ChatGPT, Claude`로 정확히 표기한다. 좌측 하단의 어두운 바다 위에 제공된 모두의AI 흰색 로고를 온전하게 배치한다. 후속 요청으로 로고 아래 작은 영문 문구만 제거한다. 이전 중복 간판·헤드폰·추가 문구·반짝임은 제외한다. 글자와 로고에 안전 여백을 둔다.

생성 결과는 추가 이미지 가공 없이 사이트에 복사했다. 최종 적용 경로는 `www/static/moai-cowork-og-color-pixel-20261007.png`다.

후속 편집: 왼쪽 아래 로고의 영문 부제만 제거하고 해당 영역을 주변 바다 픽셀로 채운다. 모두의AI 로고·제목·풍경·색상·구도는 유지한다. 내장 image_gen으로 편집했다.
