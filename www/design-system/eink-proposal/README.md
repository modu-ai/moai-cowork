# MoAI-Cowork 킨들·픽셀 시안

사용자의 최신 요청에 따른 **검토용 시안**이다. 킨들 리더를 연상시키는 회백색 바탕에 Pretendard 한글·영문과 픽셀 관계·프로세스 그림을 결합했다. 2026-10-06에 이 스타일을 전체 온라인 문서에 적용했다. 이 폴더는 확정 전 시안과 그 측정 기록을 보존하며 현재 운영 기준은 상위 README에서 설명한다.

## 글꼴

기본 한글·영문과 제목·표·버튼·입력·코드·Mermaid는 모두 **Pretendard Variable 1.3.9**이다. 공식 배포 파일을 시안 폴더에 보관하고 OFL 라이선스를 함께 포함했다. 본문·보조 글자 16px, 절 제목 32px, 큰 제목 48px이며 작은 화면의 큰 제목은 32px이다. 본문은 일반 굵기, 제목은 700 굵기다.

공식 [Pretendard 저장소](https://github.com/orioncactus/pretendard)를 기준으로 한다. 사용자의 최신 요청에 따라 픽셀 폰트를 Pretendard로 교체했다. 픽셀 PNG에 그려진 글자와 그림은 이미지 스타일로 유지한다. Noto CJK는 미지원 글자의 시스템 대체 후보이며, 이번 시안에서는 Google Fonts 로딩과 중문·일문 조판을 검사하지 않았다.

## 그림의 역할

- `assets/parallel-pixel-ko.png`: 분석 후 FAQ·안내문으로 나뉘고 다시 합쳐 검토하는 과정. 수정 요청이 작성 단계로 돌아간다.
- `assets/context-pixel-ko.png`: 프로젝트의 목표·지침·참고 자료와 현재 작업, 허용된 폴더의 원본·결과 파일을 연결한다.
- 질문 분기·담당자 인계·반복 업무는 편집 가능한 Mermaid 3개로도 보여 준다. Pretendard 글꼴·각진 노드·직각 연결선을 적용했다.
- 수치 비교는 실제 원자료 표와 막대·해칭 차트로 표현한다.

두 PNG는 내장 이미지 생성 도구로 새로 제작했다. 한국어 라벨과 연결 방향을 육안으로 확인했다. 생성 프롬프트와 파일 출처는 `reports/20261006-kindle-pixel-design/image-prompts.md`에 기록한다. 짧은 비교·상태·실습 요청은 HTML로 유지한다. 불필요한 개념 설명 머리말과 요약 푸터는 넣지 않는다.

## 폭과 접근성

모바일에서는 본문을 한 열로 배치한다. 픽셀 그림은 작은 화면에 억지로 축소하지 않고 그림 영역 안에서 가로로 이동한다. `그림 크게 보기` 링크, 자세한 대체 텍스트, 순서 설명도 제공한다. 표와 Mermaid 역시 각 영역 안에서 이동하며 페이지 전체는 넘치지 않는다.

Mermaid 글꼴을 바꾸면 도식을 다시 렌더링한다. 로컬 렌더링 도우미는 저장소 번들의 시작 부분에 글꼴 대기만 추가하며, 원본 번들을 수정하지 않는다. 실제 SVG와 원본·설정·글꼴·도우미 해시를 저장하고 빌드에서 일치 여부를 검사한다.

## 다시 만들기

```bash
python3 www/design-system/eink-proposal/build.py
python3 -m http.server 1314 --bind 127.0.0.1 --directory www/design-system/eink-proposal
```

Mermaid 원본·설정·글꼴을 바꿨다면 `build.py --prepare-render`로 준비한 `_render.html`을 실제 브라우저에서 렌더링한 뒤 SVG와 `render-provenance.json`을 갱신한다. 준비용 `_render-js/`는 최종 시안에 포함하지 않는다.

검증 기록과 실제 화면 캡처는 `reports/20261006-kindle-pretendard-design/`에 있다. 실제 Kindle 기기의 화면·잔상 성능을 시험한 결과는 아니다. 전체 문서 반영과 공개 배포는 이번 시안 작업의 범위에 포함하지 않는다.
