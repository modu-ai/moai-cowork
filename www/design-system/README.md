# 문서 사이트 디자인 기준

2026-10-06에 확정한 킨들 스타일을 전체 문서에 적용합니다. 현재 기준은 `eink-proposal/tokens.json`과 `eink-proposal/mermaid.config.json`입니다. `handoff/`는 이전 디자인의 기록입니다.

## 현재 기준

- 배경 `#e9e9e5`, 표면 `#f4f4ef`, 본문 `#202020`, 보조 글자 `#555555`.
- 한글·영문은 Pretendard Variable 1.3.9. 글꼴 파일과 라이선스를 함께 제공하며 도식 크기를 계산하기 전에 글꼴을 불러옵니다.
- 일본어는 Google Noto Sans JP, 중국어 간체는 SC, 번체는 TC를 사용합니다.
- 본문과 그림 설명은 16px 이상, 본문 줄 간격 2, 본문 최대 폭 800px.
- 본문 컴포넌트에는 모서리·그림자·모션을 사용하지 않습니다. 상태는 색 대신 문구·선·검토 근거로 구분합니다.
- 코드 창은 기존 macOS 형태를 사용합니다. 어두운 본문·제목 표시줄, 둥근 창 모서리, 빨강·노랑·초록 창 표시, 언어 이름과 복사 버튼을 표시합니다. 한글·영문 Pretendard와 16px 본문, 긴 줄의 가로 스크롤을 유지하며 인쇄에서는 밝은 배경으로 표시합니다.
- 본문의 원리를 보여 주는 픽셀 그림과 Mermaid 도식을 사용합니다. 넓은 그림은 그림 영역 안에서 이동하며 전체 페이지를 밀어내지 않습니다.
- 단순 정의와 비교는 본문의 표·목록으로 설명합니다. 실제 앱 촬영 화면은 원본을 보존합니다.

## 구성과 재생성

`python3 www/design-system/build-kindle.py`는 확정 토큰, 로컬 글꼴, Mermaid 초기화 번들을 생성합니다. 원래 테마의 Mermaid 엔진과 청크는 수정하지 않습니다. 엔진의 시작 코드가 바뀌면 생성 단계가 중단되므로 재검토해야 합니다. 출처 해시는 `kindle-provenance.json`에 기록합니다.

- `www/static/moai-kindle-tokens.css`: 생성된 색·글꼴·컴포넌트 변수.
- `www/static/moai-kindle.css`: 문서·검색·표·코드·모바일·인쇄 스타일.
- `www/assets/diagrams/`: 본문을 근거로 작성한 도식 원본.
- `www/data/concepts.json`: 그림 읽는 방법, 구체적인 예와 원리 설명.
- `concept-diagram` shortcode: 도식 또는 픽셀 그림과 설명을 함께 표시.
- `rate-chart` shortcode: 완료 건수와 문의 건수의 비율을 공통 눈금으로 표시.

## 인포그래픽 작성 기준

본문의 목표·입력·담당 역할·분기 조건·결과를 먼저 읽습니다. 독자가 헷갈리는 관계를 그림으로 만들고 실제 예를 설명합니다. 화살표가 전달, 시작 조건, 수정 의견 중 무엇을 뜻하는지 분명히 합니다. 원문에 없는 사실·기능·수치를 그림에 추가하지 않습니다. 생성한 이미지의 한글, 화살표 방향, 불필요한 푸터와 본문 일치 여부를 직접 확인합니다. 바뀌는 자료와 유지할 지침, 설정과 실제 실행을 구분합니다.

확정 전 독립 시안은 `eink-proposal/index.html`에 보관합니다. 전체 반영 검증 기록은 `reports/20261006-kindle-rollout/`에 있습니다.
