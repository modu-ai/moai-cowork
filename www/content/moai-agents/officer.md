**이 역할은 검토 가능한 문서 파일을 준비할 때 살펴보세요.** 먼저 내용 초안·양식·파일 형식을 제공합니다. 아래 기능 목록은 패키지 원본에서 생성하며, 실제 사용할 수 있는 기능은 현재 앱에서 확인합니다.


<!--more-->


## 첫 요청

```text
이 초안을 지정한 문서 형식으로 만들어 줘. 파일을 저장하고 열 수 있는지도 확인해 줘.
부족한 맥락은 질문하고, 사용한 자료와 아직 확인하지 못한 항목을 남겨 줘.
```

## 준비할 자료와 결과

| 준비물 | 결과 | 확인 기준 |
|---|---|---|
| 내용 초안·양식·파일 형식 | 검토 가능한 문서 파일 | 제공 자료와 일치하고 미정 항목을 구분 |

외부 연결 없이 제공 자료로 초안을 만들 수 있습니다. 실시간 조회·생성·게시가 필요할 때는 현재 도구와 연결 계정을 확인합니다. 실제 실행이 없으면 초안·제작안 단계로 표시합니다.

## 가상 예제로 더 이해하기

아래 자료와 모범 설명은 수업을 위해 작성했습니다. 실제 회사·고객의 실적이나 앱 실행 결과가 아닙니다. 먼저 제공 자료로 작은 결과를 만든 뒤 자신의 자료로 바꿔 보세요.

```text
가상 지출표: 교재 12,000원, 인쇄 8,000원, 소모품 5,000원. 날짜와 결제자는 미정.
```

### 먼저 확인할 질문

원하는 파일 형식은 무엇인가요? 날짜와 결제자는 채울 자료가 있나요? 답을 모르면 해당 항목을 미정으로 남기고, 그 정보 없이 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

세 항목 합계는 25,000원입니다. 금액 열은 숫자로 처리하고 날짜와 결제자는 미정으로 남깁니다. 파일을 만들면 직접 열어 표와 합계를 확인합니다. 문장과 서식은 달라도 이 기준을 충족하는지 직접 비교합니다. 원문 위치·출처·상태가 결과에 함께 남으면 다음 검토자에게 넘기기 쉽습니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 교재 | 12,000원 | 금액 입력값 |
| 인쇄 | 8,000원 | 금액 입력값 |
| 소모품 | 5,000원 | 금액 입력값 |
| 합계 | 25,000원 | 12,000 + 8,000 + 5,000 |
| 날짜·결제자 | 미정 | 빈칸을 추정으로 채우지 않음 |

### 흔한 실수와 수정 요청

원화 기호가 붙은 값을 문자로만 저장하거나 빈 날짜를 오늘 날짜로 채웁니다. 이때는 결과 전체를 다시 만들어 달라는 말보다, 틀린 기준과 고칠 위치를 구체적으로 알려 주세요.

```text
금액은 계산 가능한 숫자로 저장해 줘. 날짜와 결제자는 미정으로 표시하고 합계를 다시 확인해 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

파일 링크를 받았다는 것만으로 문서 제작이 끝났을까요?

<details><summary>답안과 해설 보기</summary>

파일을 내려받아 열어 보고 합계와 서식이 제대로 표시되는지 확인해야 합니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.
