**이 역할은 채용 문서 초안을 준비할 때 살펴보세요.** 먼저 직무 요구사항·공고 기준을 제공합니다. 아래 기능 목록은 패키지 원본에서 생성하며, 실제 사용할 수 있는 기능은 현재 앱에서 확인합니다.


<!--more-->


## 첫 요청

```text
직무 요구사항으로 채용 공고 초안을 만들어 줘. 빠진 조건은 질문해 줘.
부족한 맥락은 질문하고, 사용한 자료와 아직 확인하지 못한 항목을 남겨 줘.
```

## 준비할 자료와 결과

| 준비물 | 결과 | 확인 기준 |
|---|---|---|
| 직무 요구사항·공고 기준 | 채용 문서 초안 | 제공 자료와 일치하고 미정 항목을 구분 |

외부 연결 없이 제공 자료로 초안을 만들 수 있습니다. 실시간 조회·생성·게시가 필요할 때는 현재 도구와 연결 계정을 확인합니다. 실제 실행이 없으면 초안·제작안 단계로 표시합니다.

## 가상 예제로 더 이해하기

아래 자료와 모범 설명은 수업을 위해 작성했습니다. 실제 회사·고객의 실적이나 앱 실행 결과가 아닙니다. 먼저 제공 자료로 작은 결과를 만든 뒤 자신의 자료로 바꿔 보세요.

```text
가상 직무: 고객 문의 정리와 주간보고 작성. 요구 능력은 표 작성, 정책 근거 확인, 팀 문서 인계. 지원자 자료는 없음.
```

### 먼저 확인할 질문

실제 업무와 평가 기준은 무엇인가요? 근무 조건은 확정됐나요? 답을 모르면 해당 항목을 미정으로 남기고, 그 정보 없이 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

업무와 관련된 공고 문구, 표 작성 과제, 정책 검토 질문을 만듭니다. 미정 근무 조건은 확인 필요로 표시하며 지원자 평가 결과는 만들지 않습니다. 문장과 서식은 달라도 이 기준을 충족하는지 직접 비교합니다. 원문 위치·출처·상태가 결과에 함께 남으면 다음 검토자에게 넘기기 쉽습니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 공고 업무 | 고객 문의 정리와 주간보고 작성 | 직무 자료 기반 초안 |
| 과제 후보 | 문의 표를 만들고 원문 정책과 대조 | 검토용 평가 설계 |
| 평가 기준 | 표 정확성 · 근거 위치 · 인계 명료성 | 같은 기준으로 검토 |
| 지원자 평가 | 실제 지원자 자료 없음 | 평가 미실시 |

### 흔한 실수와 수정 요청

지원자 자료 없이 합격자를 정하거나 직무와 관계없는 개인 특성으로 평가 기준을 만듭니다. 이때는 결과 전체를 다시 만들어 달라는 말보다, 틀린 기준과 고칠 위치를 구체적으로 알려 주세요.

```text
실제 업무에 필요한 역량과 관찰 가능한 평가 기준만 정리해 줘. 합격 결정과 미정 조건은 따로 남겨 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

채용 문서를 만들었다는 것이 지원자를 평가했다는 뜻일까요?

<details><summary>답안과 해설 보기</summary>

문서 작성과 개별 지원자의 평가·결정은 다른 단계입니다. 실제 평가 자료와 책임자의 확인이 필요합니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.
