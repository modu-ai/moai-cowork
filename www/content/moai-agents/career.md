**이 역할은 이력서 수정안과 준비 목록을 준비할 때 살펴보세요.** 먼저 경력·희망 직무·기존 이력서를 제공합니다. 아래 기능 목록은 패키지 원본에서 생성하며, 실제 사용할 수 있는 기능은 현재 앱에서 확인합니다.


<!--more-->


## 첫 요청

```text
경력 자료로 이력서를 다듬어 줘. 없는 성과나 수치를 만들지 마.
부족한 맥락은 질문하고, 사용한 자료와 아직 확인하지 못한 항목을 남겨 줘.
```

## 준비할 자료와 결과

| 준비물 | 결과 | 확인 기준 |
|---|---|---|
| 경력·희망 직무·기존 이력서 | 이력서 수정안과 준비 목록 | 제공 자료와 일치하고 미정 항목을 구분 |

외부 연결 없이 제공 자료로 초안을 만들 수 있습니다. 실시간 조회·생성·게시가 필요할 때는 현재 도구와 연결 계정을 확인합니다. 실제 실행이 없으면 초안·제작안 단계로 표시합니다.

## 가상 예제로 더 이해하기

아래 자료와 모범 설명은 수업을 위해 작성했습니다. 실제 회사·고객의 실적이나 앱 실행 결과가 아닙니다. 먼저 제공 자료로 작은 결과를 만든 뒤 자신의 자료로 바꿔 보세요.

```text
가상 경력: 문의 처리 1년, FAQ 초안 4개 작성, 스프레드시트로 문의 목록 정리. 지원 희망은 고객지원 운영. 매출 기여 수치는 없음.
```

### 먼저 확인할 질문

어떤 직무 요건에 맞추나요? 실제 수행 범위와 수치를 증명할 자료가 있나요? 답을 모르면 해당 항목을 미정으로 남기고, 그 정보 없이 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

문의 처리, FAQ 작성, 자료 정리 경험을 희망 직무와 연결합니다. 실제 경험과 학습 계획을 구분하고 매출 성과는 만들지 않습니다. 문장과 서식은 달라도 이 기준을 충족하는지 직접 비교합니다. 원문 위치·출처·상태가 결과에 함께 남으면 다음 검토자에게 넘기기 쉽습니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 직무와 연결할 경험 | 문의 처리 1년 | 가상 경력 자료에서 확인 |
| 자료 정리 역량 | 스프레드시트 문의 목록 정리 | 작업 예시 첨부 후보 |
| 문서 작성 경험 | FAQ 초안 4개 | 최종 배포 실적 아님 |
| 기재하지 않은 성과 | 매출 기여·고객 만족도 수치 | 근거 없음 |

### 흔한 실수와 수정 요청

경력을 과장하거나 팀 전체 성과를 본인 실적으로 바꿉니다. 이때는 결과 전체를 다시 만들어 달라는 말보다, 틀린 기준과 고칠 위치를 구체적으로 알려 주세요.

```text
내가 실제 한 일만 적어 줘. 확인되지 않은 매출 성과와 책임 범위는 삭제하고 직무와 연결되는 경험을 강조해 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

수치가 없으면 그럴듯한 성과 비율을 추정해 넣어도 될까요?

<details><summary>답안과 해설 보기</summary>

넣지 않습니다. 실제 수행 내용과 결과물을 설명하고 확인 가능한 수치가 있는지 질문합니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.
