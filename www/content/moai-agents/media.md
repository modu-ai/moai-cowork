**이 역할은 이미지·영상 제작안 또는 지원되는 생성 결과를 준비할 때 살펴보세요.** 먼저 제작 목적·장면·형식·참고 자료를 제공합니다. 아래 기능 목록은 패키지 원본에서 생성하며, 실제 사용할 수 있는 기능은 현재 앱에서 확인합니다.


<!--more-->


## 첫 요청

```text
이 자료로 이미지 제작안을 만들어 줘. 실제 생성 도구와 비용 조건은 먼저 확인해 줘.
부족한 맥락은 질문하고, 사용한 자료와 아직 확인하지 못한 항목을 남겨 줘.
```

## 준비할 자료와 결과

| 준비물 | 결과 | 확인 기준 |
|---|---|---|
| 제작 목적·장면·형식·참고 자료 | 이미지·영상 제작안 또는 지원되는 생성 결과 | 제공 자료와 일치하고 미정 항목을 구분 |

외부 연결 없이 제공 자료로 초안을 만들 수 있습니다. 실시간 조회·생성·게시가 필요할 때는 현재 도구와 연결 계정을 확인합니다. 실제 실행이 없으면 초안·제작안 단계로 표시합니다.

## 가상 예제로 더 이해하기

아래 자료와 모범 설명은 수업을 위해 작성했습니다. 실제 회사·고객의 실적이나 앱 실행 결과가 아닙니다. 먼저 제공 자료로 작은 결과를 만든 뒤 자신의 자료로 바꿔 보세요.

```text
가상 이미지 요청: 고객 문의 업무를 설명하는 한국어 개념 그림. 실제 앱 화면을 흉내 내지 않으며 제목과 흐름이 읽혀야 함.
```

### 먼저 확인할 질문

개념 그림인가요, 실제 화면 캡처인가요? 사용할 생성 기능과 결과 크기는 무엇인가요? 답을 모르면 해당 항목을 미정으로 남기고, 그 정보 없이 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

개념도에는 목표·자료·질문·검토를 배치합니다. 실제 UI 안내는 직접 촬영한 화면을 사용하며 글자와 화살표를 검토합니다. 문장과 서식은 달라도 이 기준을 충족하는지 직접 비교합니다. 원문 위치·출처·상태가 결과에 함께 남으면 다음 검토자에게 넘기기 쉽습니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 제작 범위 | 목표·자료·질문·검토의 연결을 설명하는 그림 | 개념 설명용 |
| 그림 구성 | 문의 메모 → 질문 → 보고서 초안 → 원문 검토 | 화살표의 의미를 본문에서 설명 |
| 한국어 검토 | 제목·화살표·미정 상태의 글자 | 출력 후 가독성 확인 |
| 실제 화면 안내 | 현재 앱을 직접 촬영 | 생성 UI를 캡처로 표시하지 않음 |
| 실행 상태 | 이미지 제작안 | 생성·비용·게시 미확인 |

### 흔한 실수와 수정 요청

생성한 화면을 실제 앱 스크린샷으로 표시하거나 한국어 오타가 있는 이미지를 바로 사용합니다. 이때는 결과 전체를 다시 만들어 달라는 말보다, 틀린 기준과 고칠 위치를 구체적으로 알려 주세요.

```text
이 이미지는 개념도라고 표시해 줘. 한국어 글자와 순서를 확인하고 실제 앱 화면은 직접 촬영한 자료로 구분해 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

생성 이미지로 앱 메뉴의 현재 존재를 증명할 수 있을까요?

<details><summary>답안과 해설 보기</summary>

할 수 없습니다. 기능과 메뉴는 실제 앱 화면 또는 현재 공식 안내로 확인합니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.
