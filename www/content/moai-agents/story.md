**이 역할은 이야기 기획안을 준비할 때 살펴보세요.** 먼저 세계관·캐릭터·줄거리 메모를 제공합니다. 아래 기능 목록은 패키지 원본에서 생성하며, 실제 사용할 수 있는 기능은 현재 앱에서 확인합니다.


<!--more-->


## 첫 요청

```text
이 설정으로 이야기 기획안을 만들고 비어 있는 설정을 물어봐 줘.
부족한 맥락은 질문하고, 사용한 자료와 아직 확인하지 못한 항목을 남겨 줘.
```

## 준비할 자료와 결과

| 준비물 | 결과 | 확인 기준 |
|---|---|---|
| 세계관·캐릭터·줄거리 메모 | 이야기 기획안 | 제공 자료와 일치하고 미정 항목을 구분 |

외부 연결 없이 제공 자료로 초안을 만들 수 있습니다. 실시간 조회·생성·게시가 필요할 때는 현재 도구와 연결 계정을 확인합니다. 실제 실행이 없으면 초안·제작안 단계로 표시합니다.

## 가상 예제로 더 이해하기

아래 자료와 모범 설명은 수업을 위해 작성했습니다. 실제 회사·고객의 실적이나 앱 실행 결과가 아닙니다. 먼저 제공 자료로 작은 결과를 만든 뒤 자신의 자료로 바꿔 보세요.

```text
가상 설정: 기록을 잃은 도시에서 지도 제작자 민이 오래된 지도를 찾는다. 지도는 과거의 길만 보여 주며 미래는 보여 주지 못한다.
```

### 먼저 확인할 질문

장르와 독자는 누구인가요? 인물의 목적과 바꾸면 안 되는 설정은 무엇인가요? 답을 모르면 해당 항목을 미정으로 남기고, 그 정보 없이 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

민의 목표와 장애물을 정하고 첫 장면을 씁니다. 지도가 미래를 알려 주는 장면은 넣지 않고 설정 검토 목록을 남깁니다. 문장과 서식은 달라도 이 기준을 충족하는지 직접 비교합니다. 원문 위치·출처·상태가 결과에 함께 남으면 다음 검토자에게 넘기기 쉽습니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 고정 설정 | 지도는 과거의 길만 보여 줌 | 미래 예측 장면 제외 |
| 인물 목표 후보 | 도시의 잃어버린 기록을 찾는다 | 집필을 위한 제안 |
| 첫 장면 예시 | 민은 지워진 길의 흔적을 지도에서 찾았다. | 수업용 창작 초안 |
| 표지 구도 후보 | 현재의 도시와 오래된 지도 대조 | 이미지 생성·게시 미실시 |
| 연재 조건 | 플랫폼·분량·계약 조건 | 미정·현재 공식 조건 확인 필요 |

### 흔한 실수와 수정 요청

회차가 바뀌며 지도의 능력을 임의로 확장하거나 인물의 목표가 사라집니다. 이때는 결과 전체를 다시 만들어 달라는 말보다, 틀린 기준과 고칠 위치를 구체적으로 알려 주세요.

```text
지도는 과거의 길만 보여 준다는 설정을 유지해 줘. 민의 목적이 드러나도록 장면을 고쳐 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 내 업무로 바꿔 보기
