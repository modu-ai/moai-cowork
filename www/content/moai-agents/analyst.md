**이 역할은 분석표와 해석을 준비할 때 살펴보세요.** 먼저 표·데이터·기간·단위를 제공합니다. 아래 기능 목록은 패키지 원본에서 생성하며, 실제 사용할 수 있는 기능은 현재 앱에서 확인합니다.


<!--more-->


## 첫 요청

```text
데이터 구조와 누락을 확인한 뒤 분석해 줘. 수치의 기간과 단위를 표시해 줘.
부족한 맥락은 질문하고, 사용한 자료와 아직 확인하지 못한 항목을 남겨 줘.
```

## 준비할 자료와 결과

| 준비물 | 결과 | 확인 기준 |
|---|---|---|
| 표·데이터·기간·단위 | 분석표와 해석 | 제공 자료와 일치하고 미정 항목을 구분 |

외부 연결 없이 제공 자료로 초안을 만들 수 있습니다. 실시간 조회·생성·게시가 필요할 때는 현재 도구와 연결 계정을 확인합니다. 실제 실행이 없으면 초안·제작안 단계로 표시합니다.

## 가상 예제로 더 이해하기

아래 자료와 모범 설명은 수업을 위해 작성했습니다. 실제 회사·고객의 실적이나 앱 실행 결과가 아닙니다. 먼저 제공 자료로 작은 결과를 만든 뒤 자신의 자료로 바꿔 보세요.

```text
가상 자료: A지역 문의 30건, 응답 완료 24건. B지역 문의 20건, 응답 완료 10건. 두 값의 기간은 같은 주이며 단위는 건.
```

### 먼저 확인할 질문

완료율의 분모는 전체 문의인가요? 누락이나 중복 문의가 있나요? 답을 모르면 해당 항목을 미정으로 남기고, 그 정보 없이 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

{{< rate-chart >}}

전체 문의 50건, 완료 34건, 전체 완료율 68%입니다. A는 80%, B는 50%입니다. 지역별 건수와 비율을 함께 표시합니다. 문장과 서식은 달라도 이 기준을 충족하는지 직접 비교합니다. 원문 위치·출처·상태가 결과에 함께 남으면 다음 검토자에게 넘기기 쉽습니다.

### 흔한 실수와 수정 요청

80%와 50%를 단순 평균해 전체 완료율을 65%로 씁니다. 이때는 결과 전체를 다시 만들어 달라는 말보다, 틀린 기준과 고칠 위치를 구체적으로 알려 주세요.

```text
전체 완료율은 완료 건수 합을 문의 건수 합으로 나눠 줘. 지역별 비율의 단순 평균과 구분해 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

전체 완료율을 지역별 비율의 평균으로 계산하면 왜 달라질까요?

<details><summary>답안과 해설 보기</summary>

지역별 문의 수가 다르기 때문입니다. 전체 자료의 비율은 34÷50×100=68%로 계산합니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.
