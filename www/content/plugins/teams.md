**작은 업무는 한 역할로 시작하세요.** 조사·분석·문서 제작이 모두 필요한 경우에만 역할을 추가합니다.

| 결과물 | 역할 구성 예 | 진행 순서 |
|---|---|---|
| 주간보고 | 코워커 + 사무관 | 원문 확인 → 보고서 초안 → 파일 제작 |
| 시장 분석 | 컨설턴트 + 애널리스트 | 질문 정의 → 자료 수집·분석 → 근거 검토 |
| 브랜드 콘텐츠 | 마케터 + 디자이너 | 대상·메시지 → 콘텐츠 → 시안 → 검토 |
| FAQ | CS + 코워커 | 문의 분류 → 답변 초안 → 기준 확인 |

이는 조합 예시입니다. 실제 설치·노출된 스킬을 확인하고 현재 앱의 기능에 맞춰 실행합니다. 미설치 기능은 추천 상태로 남깁니다.


<!--more-->


## 인계할 때 전달할 내용

목표, 사용 자료, 앞 단계 결과, 미정 항목, 결과 형식, 완료 기준을 함께 전달합니다. 같은 자료에서 얻은 숫자라도 기간과 단위가 다르면 바로 합치지 않습니다.

여러 역할을 반복해서 쓴다면 [PM으로 프로젝트 구성](/workflows/first-project/)을 시작하세요. [순차·병렬 분업](/workflows/experts/)에서 진행 방식을 정합니다.
