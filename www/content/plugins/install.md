**첫 업무에 필요한 플러그인 한 개부터 추가하세요.** 앱이 없다면 [데스크톱 설치](/getting-started/install/)부터 진행합니다. 패키지 공개, 내 계정의 설치, 외부 서비스 인증, 실제 업무 실행은 각각 확인합니다.

## 무엇을 추가할지 먼저 고르세요

| 이번 업무 | 먼저 살펴볼 MoAI 패키지 | 첫 확인 결과 |
|---|---|---|
| 가상 문의를 FAQ로 정리 | `moai-cs` | 원문과 정책을 연결한 FAQ 초안 |
| 메모를 보고서로 정리 | `moai-coworker` | 완료·초안·미정을 구분한 보고서 |
| 업무 지침과 역할 구성 | `moai-pm` | 입력·출력·검토 기준이 있는 프로젝트 지침 |

이름은 [저장소](https://github.com/modu-ai/moai-cowork)와 [카탈로그](/plugins/)에서 확인합니다. 붙여넣은 가상 문의를 쓰는 실습에는 CRM·메일 연결이 필요 없습니다.

## ChatGPT Work · 목록에서 추가

### 1 · 플러그인 목록 열기

**맞춤 설정(Customize) → 플러그인(Plugins)** 또는 표시되는 바로가기를 엽니다. 검색창에서 필요한 기능을 찾습니다. [공식 플러그인 안내](https://learn.chatgpt.com/docs/plugins).

![ChatGPT 웹의 실제 플러그인 목록과 추가 메뉴](/screenshots/20261006/chatgpt-plugin-add.jpg)

2026년 10월 6일 촬영한 **ChatGPT 웹**입니다. **공개·개인용**은 탐색 범위를 바꿉니다. 오른쪽 **추가**는 제작·압축 파일 업로드 경로를 열며, 개별 공개 플러그인의 **+ 버튼**과 역할이 다릅니다.

### 2 · 상세 설명과 포함 기능 확인

항목을 열고 제작자, 포함 기능과 필요한 연결을 확인합니다. 목록의 **+** 또는 상세 화면의 설치 버튼을 사용합니다. 메뉴 이름은 계정·앱 버전에 따라 다를 수 있습니다.

![ChatGPT 웹에서 Outlook Email의 상세 설명과 설치 버튼을 확인한 실제 화면](/screenshots/20261006/chatgpt-plugin-detail.jpg)

위 사진은 **설치 전 화면을 읽는 방법**을 보여 주는 Outlook 예시입니다. MoAI 설치나 인증 완료 화면이 아닙니다. 촬영에서는 Outlook을 설치하거나 이메일 계정을 연결하지 않았습니다.

### 3 · 필요한 연결만 완료하고 새 Work 작업 열기

외부 서비스 인증은 설치 때 또는 첫 사용 때 요구될 수 있습니다. 사용할 계정·대상 자료·권한을 확인한 뒤 연결합니다. 설치 후 **새 작업**을 시작하고 기능이 제공되는지 확인합니다. 요청에서 직접 지정하려면 화면의 `@` 선택 메뉴를 사용합니다. [공식 Work 안내](https://learn.chatgpt.com/docs/get-started-with-work).

## ChatGPT Work · MoAI가 공개 목록에 없을 때

촬영한 계정의 **추가 → 플러그인 압축 파일 업로드**는 사용자 지정 패키지 경로입니다. 이 메뉴가 있다면 신뢰할 수 있는 배포자가 만든 설치용 패키지를 선택하고 앱의 검사·설치 절차를 따릅니다. 저장소 전체 소스 ZIP과 플러그인 설치용 ZIP을 혼동하지 마세요. [패키지 안내](/advanced/plugins/).

공개 저장소라고 공용 목록에 자동 등록되는 것은 아닙니다. 메뉴가 없거나 조직 패키지를 써야 한다면 관리자 배포 경로를 확인합니다. 캡처는 **업로드 메뉴 존재**를 확인한 것으로 MoAI ZIP 업로드·실행 완료 기록은 아닙니다.

## Claude Cowork · 목록에서 추가

### 1 · 사용자 지정 → 플러그인 → 탐색

**사용자 지정(Customize) → 플러그인 → 탐색(Discover)** 메뉴로 이동합니다. 이전 화면은 Cowork를 먼저 선택하고 통합 화면은 그대로 사용자 지정으로 이동합니다.

![macOS Claude Desktop에서 촬영한 사용자 지정·플러그인·탐색 화면](/screenshots/20261006/claude-desktop-plugins.png)

**2026년 10월 6일 실제 Claude Desktop**입니다. ‘내 항목’은 내 계정의 항목, ‘탐색’은 추가할 항목을 찾는 위치입니다. 플러그인을 열어 기능을 읽고 필요한 것에 **추가(Add)** 버튼을 누릅니다. [공식 설치 절차](https://support.claude.com/en/articles/13837440-use-plugins-in-claude).

### 2 · MoAI 저장소 추가 경로

현재 제공된다면 **추가 → 마켓플레이스 추가 → 저장소에서 추가**로 이동합니다.

![Claude 웹에서 마켓플레이스 추가·플러그인 업로드 메뉴를 펼친 실제 화면](/screenshots/20261006/claude-plugin-add.jpg)

이 사진과 다음 사진은 **Claude 웹**입니다. Desktop 추가 버튼은 확인했지만 촬영 도구가 해당 창의 입력을 처리하지 못해 세부 과정은 웹에서 촬영했습니다.

### 3 · 저장소 URL 입력과 동기화

‘URL’의 저장소 선택을 열고 아래 주소를 입력합니다. 주소를 사용하는 항목이 나오면 선택합니다. 촬영한 화면에는 **자동으로 동기화**도 있습니다. 저장소 변경을 따라 업데이트하는 방식이므로 필요한 업데이트 정책을 확인합니다.

```text
https://github.com/modu-ai/moai-cowork
```

![Claude 웹의 추가 창에서 공개 MoAI 저장소 주소를 선택한 실제 화면](/screenshots/20261006/claude-marketplace-url.jpg)

주소·출처·업데이트 방식을 확인한 뒤 **동기화**하고 목록에서 필요한 패키지를 선택해 추가합니다. 촬영은 **주소 선택까지** 진행하고 취소했으며 동기화·설치 성공 사진은 아닙니다.

### 4 · 내 항목과 새 작업 확인

‘내 항목’에서 패키지를 확인하고 새 업무를 시작합니다. `/` 또는 `+`에서 제공되는 스킬을 고르거나 자연어로 목표를 설명합니다. 스킬·하위 에이전트·훅·로컬 MCP의 실행 범위는 다릅니다. 웹에 스킬이 보인다고 컴퓨터의 서버가 실행되었다고 판단하지 않습니다. [실행 범위 안내](https://support.claude.com/en/articles/13837440-use-plugins-in-claude).

## 설치 확인

새 작업에서 작은 결과를 확인합니다.

```text
현재 작업에서 사용할 수 있는 CS 관련 MoAI 스킬과 도구를 확인해 줘.
추천 후보와 실제 노출된 기능을 구분해 줘.
외부 서비스는 연결하거나 변경하지 말고 가상 정책으로 FAQ 하나를 만들어 줘.
질문: 주문은 언제 출고되나요?
정책: 영업일 2일 이내 출고. 도착 날짜는 자료에 없음.
실제 적용한 스킬이 있으면 이름을 알려 주고 없으면 일반 초안이라고 밝혀 줘.
```

| 확인 결과 | 통과 기준 |
|---|---|
| 스킬 제공 | 현재 제공된 이름과 추천 후보를 구분 |
| FAQ 내용 | 출고 기준을 유지하고 도착 날짜를 만들지 않음 |
| 외부 실행 | CRM 조회·메일 발송을 안 했다면 했다고 보고하지 않음 |

답변에서 이름을 말하는 것만으로 실행 증거가 되지는 않습니다. 앱의 도구·스킬 표시 또는 작업 기록과 결과를 함께 확인합니다. 안 보이면 설치 계정·활성화·새 작업 여부부터 확인합니다. [연결 문제 해결](/plugins/mcp/troubleshooting/).

## 업데이트와 제거

관리 메뉴에서 버전·업데이트 상태를 확인하고 같은 가상 예제로 다시 비교합니다. 사용자 지침·결과 파일을 보존하고 비활성화·제거합니다. 앱 구독과 외부 API·생성 서비스 비용은 패키지 비용과 따로 확인합니다.
