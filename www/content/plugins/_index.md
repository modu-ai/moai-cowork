**플러그인은 업무 방법과 도구를 설치하는 묶음입니다.** 모두의 코워크에는 {{< catalog-count "plugins" >}}개 역할의 플러그인이 있습니다. 모든 기능을 한 번에 익히기보다 지금 만들 결과물에 맞춰 선택하세요.

| 하고 싶은 일 | 먼저 살펴볼 역할 |
|---|---|
| 보고·기획·회의 정리 | [코워커](/moai-agents/coworker/) |
| Word·Excel·발표 파일 | [사무관](/moai-agents/officer/) |
| 글쓰기·윤문 | [작가](/moai-agents/writer/) |
| 콘텐츠·캠페인 | [마케터](/moai-agents/marketer/) |
| 자료 분석 | [애널리스트](/moai-agents/analyst/) |
| 여러 분야를 묶는 프로젝트 | [PM](/moai-agents/pm/) |

다른 분야는 [역할별 전체 목록](/moai-agents/)에서 찾을 수 있습니다. 이름은 업무 역할을 나타내며 결과의 정확성이나 전문가 자격을 보장하는 뜻은 아닙니다.
