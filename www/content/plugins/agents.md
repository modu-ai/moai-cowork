**스킬은 업무 방법, 에이전트는 업무를 수행하는 역할입니다.** 스킬을 쓴다고 항상 하위 에이전트가 실행되는 것은 아닙니다.


<!--more-->


## 요청하는 방법

자연어로 결과물을 설명하고, 필요하면 현재 앱의 선택 메뉴에서 스킬을 지정합니다. ChatGPT의 `@`, Codex의 `$`, Claude의 `/`와 `+` 등 실제 화면에 노출된 경로를 사용하세요. 특정 이름을 말했더라도 실제 스킬 선택이나 별도 실행 여부를 확인합니다.

## 작성과 검토를 나누기

작성자는 초안을 만들고 검토자는 근거·누락·형식을 확인합니다. 다수 MoAI 패키지는 이 역할을 나누도록 설계되어 있습니다. 권한과 독립 실행이 실제 제공되는지는 현재 호스트에서 확인해야 합니다.

| 확인 항목 | 의미 |
|---|---|
| 스킬 사용 | 해당 업무 지침을 읽고 적용 |
| 별도 에이전트 실행 | 독립 실행으로 담당 역할 수행 |
| 읽기 전용 검토 | 실제 권한 제한을 확인한 검토 |
| 자기 점검 | 같은 실행이 자신의 결과를 재검토 |

지원되지 않는 형식의 에이전트 파일을 만들거나 “반드시 호출됐다”고 보고하지 않습니다. 기능이 없다면 역할별 단계를 순차 실행하고 한계를 알립니다.

[전문가 분업](/workflows/experts/)에서 역할·입력·출력·합류 조건을 구성하고, 각 패키지의 포함 목록은 [AI 코워커](/moai-agents/)에서 확인하세요.
