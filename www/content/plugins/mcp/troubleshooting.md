**연결이 안 되면 실패한 단계를 먼저 찾습니다.** 설치된 패키지가 보이는 것과 실제 자료를 조회하는 것은 다릅니다.

| 증상 | 먼저 확인할 것 | 다음 행동 |
|---|---|---|
| 스킬이 없음 | 설치·활성화·현재 작업 반영 | 새 작업에서 목록 확인 |
| 도구가 없음 | 로컬·원격 서버 지원과 실행 도구 | 서버 오류·시작 상태 확인 |
| 인증 오류 | 실제 계정·키 이름·권한·만료 | 해당 서비스 설정 확인 |
| 결과가 비어 있음 | 검색 조건·기간·계정 | 빈 결과와 호출 실패 구분 |
| 다른 계정 자료 | 연결 사용자·프로젝트 설정 | 계정별 설정 분리 |
| 저장 실패 | 결과 경로·파일 권한 | 원본 보존 후 별도 위치 저장 |

## 오류를 설명할 때

앱·OS, 플러그인 버전, 실행 환경, 시도한 조회, 비밀정보를 제거한 오류 메시지를 기록합니다. 키·토큰·개인 자료는 지원 요청에 붙이지 않습니다.

```text
실패한 단계가 설치, 서버 실행, 인증, 조회 중 어디인지 확인해 줘.
실제 관측한 오류와 아직 확인하지 못한 부분을 구분해 줘.
연결 없이 가능한 초안 작성은 계속 진행해 줘.
```

필요한 설정은 [MCP 설치](/plugins/mcp/install/)와 [계정·API 키](/plugins/mcp/credentials/)에서 확인하세요.
