**파일을 정리하거나 초안을 만드는 일은 외부 연결 없이 시작할 수 있습니다.** 스마트스토어 주문이나 외부 업무 기록을 직접 조회할 때 연결 기능이 필요해집니다.

MCP는 AI가 서버가 제공하는 도구를 사용하는 규격입니다. 어떤 정보를 읽거나 어떤 작업을 할 수 있는지는 실제 서버와 계정 권한이 결정합니다.

## 연결 상태는 세 가지로 확인합니다

| 상태 | 확인할 내용 |
|---|---|
| 패키지 설정 | 필요한 서버가 포함돼 있음 |
| 도구 노출 | 현재 작업에 조회·변경 도구가 표시됨 |
| 실제 사용 | 인증된 계정의 자료를 정상 조회함 |

## 로컬과 원격 연결

로컬 서버는 실행 환경에 필요한 프로그램이 있어야 합니다. 원격 연결은 접속 가능한 서버와 인증이 필요합니다. 웹·클라우드 작업이 컴퓨터의 로컬 서버를 자동으로 사용할 수 있다고 가정하지 않습니다. Claude의 원격 커넥터와 로컬 MCP 서버도 서로 다른 실행 경로입니다.

## 처음 연결한다면

[설치와 설정](/plugins/mcp/install/)에서 현재 호스트와 서버 방식을 확인하고, [자격증명](/plugins/mcp/credentials/)을 준비합니다. 첫 작업은 읽기 전용 조회로 진행하고 계정과 결과를 확인하세요.

계정 연결이 없는 동안은 사용할 자료를 직접 제공하고 초안·체크리스트를 만들 수 있습니다. 연결 작업을 실행했다고 보고해서는 안 됩니다.
