## 이번 수업에서 배울 내용

지금 할 업무를 기준으로 플러그인 한 개와 스킬 후보를 선택합니다. “목록에 있음”, “설치됨”, “현재 작업에서 사용 가능”, “실제 실행됨”을 구분할 수 있어야 합니다.

## 패키지 이름보다 필요한 업무를 먼저 정하세요

고객 문의의 FAQ 초안이 필요하다면 CS 기능을 살펴봅니다. 문서 파일 제작이 필요하면 사무관 기능을, 데이터의 수치를 확인하려면 분석 기능을 추가로 검토합니다. 처음부터 모든 패키지를 설치하는 대신 업무를 먼저 적고 필요한 기능만 선택하면, 연결해야 할 외부 서비스와 확인할 권한도 명확해집니다.

MoAI는 {{< catalog-count "plugins" >}}개 플러그인과 {{< catalog-count >}}개 스킬을 제공합니다. 숫자는 이 문서의 카탈로그 데이터에서 계산하며, 내 계정에 전부 설치되어 있다는 뜻은 아닙니다. [카탈로그](/plugins/)에서 분야별 구성을 확인하세요.

| 하고 싶은 일 | 스킬 후보 | 결과를 확인할 기준 |
|---|---|---|
| 문의를 유형별로 분류 | `moai-cs:cs-voc-triage` | 원문 ID와 유형이 연결됨 |
| 정책 기반 답변 초안 | `moai-cs:cs-draft-response` | 없는 정책을 만들지 않음 |
| FAQ 문서 만들기 | `moai-cs:cs-kb-article` | 질문·답변·정책 근거가 있음 |
| FAQ 품질 검토 | `moai-cs:cs-quality-audit` | 빠진 근거와 수정 항목이 구분됨 |

이 표는 선택 후보입니다. 앱에서 해당 패키지를 설치하고 현재 작업에 스킬이 제공되는지 확인한 뒤 사용합니다. 자연어로 요청할 수도 있고, 앱이 지원하는 스킬 선택 메뉴나 호출 표기를 사용할 수도 있습니다. ChatGPT와 Codex의 표기가 같은 것은 아니므로 현재 앱의 안내를 따르세요. [OpenAI 스킬·플러그인 안내](https://learn.chatgpt.com/docs/skills-and-plugins).

## 설치 화면을 읽는 방법

[직접 촬영한 플러그인 화면](/learn/screens/)에서 앱별 위치를 확인합니다. ChatGPT에서는 플러그인 목록과 설치 가능한 경로를 확인하고, Claude에서는 사용자 지정의 플러그인 화면을 확인합니다. 공용 목록에 MoAI가 없더라도 저장소 자체가 사라진 것은 아닙니다. 사용자 지정 마켓플레이스·조직 배포 등 현재 계정이 지원하는 설치 경로를 확인합니다. [설치 단계](/plugins/install/).

## 실습 · 실제 사용 가능 여부 묻기

```text
이번 업무는 가상 고객 문의를 FAQ 초안으로 정리하는 일이야.
현재 사용할 수 있는 CS 관련 스킬과 도구를 확인해 줘.
추천 후보와 실제 사용할 수 있는 기능을 구분해 줘.
연결되지 않은 외부 서비스는 사용했다고 말하지 말아 줘.
스킬이 없으면 붙여 넣은 예제 자료로 기본 초안을 만들어 줘.
```

### 예상 결과와 해석

스킬이 보이면 이름과 역할을 확인하고 작은 예제로 사용합니다. 스킬이 보이지 않으면 설치·활성화·현재 작업 반영을 확인합니다. 외부 도구가 없다면 초안 작성은 제공 자료로 진행할 수 있지만, 고객지원 시스템의 실제 문의를 조회했다고 말해서는 안 됩니다.

| 화면이나 답변에서 확인한 상태 | 알 수 있는 것 | 아직 알 수 없는 것 |
|---|---|---|
| 카탈로그에 패키지가 있음 | 공개된 기능 구성 | 내 계정의 설치 여부 |
| 설치됨 표시 | 해당 앱의 설치 상태 | 현재 작업에서 사용 가능한지 |
| 도구 목록에 조회 도구가 있음 | 호출할 수 있는 도구가 노출됨 | 인증 성공·자료 조회 성공 |
| 실제 조회 결과가 반환됨 | 그 조회가 실행됨 | 전체 업무의 완료 여부 |

## MCP는 언제 추가할까요?

붙여 넣은 예제 문의로 FAQ를 쓰는 실습에는 외부 연결이 필요 없습니다. 실제 고객지원 시스템의 문의를 가져오려면 연결 도구와 인증이 필요할 수 있습니다. 먼저 조회 범위를 정하고 읽기부터 확인합니다. 공개 게시·메일 발송은 조회와 다른 작업이므로 별도로 확인합니다. [MCP 안내](/plugins/mcp/)에서 연결 방식과 계정별 제한을 읽어 보세요.
