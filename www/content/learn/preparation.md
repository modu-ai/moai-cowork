## 이번 수업에서 배울 내용

앱을 실행하고 로그인한 뒤 업무 입력창을 찾습니다. 필요한 플러그인 한 개를 추가하고 새 작업에서 사용할 수 있는지 확인합니다. 앱 설치·플러그인 설치·외부 서비스 인증을 서로 구분합니다.

## 직접 따라 할 순서

| 순서 | 읽을 안내 | 직접 확인할 결과 |
|---|---|---|
| 1 | [앱 설치와 로그인](/getting-started/install/) | 내 컴퓨터에서 앱이 실행되고 업무 요청을 입력할 수 있음 |
| 2 | [실제 화면](/learn/screens/) | 사진의 제품·환경·촬영일을 확인하고 내 화면의 같은 메뉴를 찾음 |
| 3 | [플러그인 추가](/plugins/install/) | 필요한 패키지 하나를 설치하고 새 작업에서 기능 확인 |
| 4 | [첫 예제](/getting-started/first-task/) | 원문 12건·4개·미확인 상태가 결과에 유지됨 |

**플러그인을 설치하지 못해도 예제 메모로 기본 초안을 만드는 연습은 가능합니다.** 스킬 사용 실습은 설치 상태를 해결한 뒤 다시 진행하고, 실제 적용하지 않은 기능은 적용했다고 보고하지 않습니다.

## 수업 전에 적어 두세요

```text
내 환경: ChatGPT Work 또는 Claude / 웹 또는 데스크톱 / 운영체제
계정 종류: 개인 또는 조직
입력창: 사용 가능 또는 막힌 위치
선택한 패키지: 이름과 설치 상태
새 작업에서 제공된 기능: 확인한 이름 또는 미확인
가상 자료 결과: 숫자·초안 상태·미확인 항목 비교
```

비밀번호·API 키는 이 기록에 넣지 않습니다. 메뉴를 못 찾으면 [막힌 위치별 안내](/getting-started/install/#막힌-위치별-해결)에서 먼저 해결할 항목을 찾습니다.

## 확인 문제

앱에서 로그인했고 보고서 초안도 받았습니다. MoAI 플러그인을 설치했다고 말할 수 있을까요?

<details><summary>답안과 해설 보기</summary>

앱에서 초안을 받을 수 있다는 사실은 앱 준비를 확인합니다. MoAI 설치는 관리 화면의 패키지 상태와 새 작업의 제공 기능을 따로 확인해야 합니다. 스킬이 없어도 일반 초안은 만들 수 있습니다.

</details>
