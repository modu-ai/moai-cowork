**이 강의는 ChatGPT Work와 Claude Cowork로 실제 업무를 맡기고 결과를 확인하는 연습입니다.** 화면을 보며 설명을 읽고, 가상 자료로 실습한 뒤, 자신의 업무에 적용합니다. 앱이 질문하면 답하고, 결과가 원문과 맞는지 직접 비교하는 것까지가 실습입니다.

처음이라면 순서대로 읽습니다. 이미 앱을 사용 중이라면 3강부터 실습하고, 헷갈리는 용어는 1·2강으로 돌아가도 됩니다. [업무별 실습](/cookbook/)에서 자기 업무와 비슷한 예제를 찾을 수 있습니다.

## 준비물과 수업 방법

- ChatGPT Work 또는 Claude Cowork를 사용할 수 있는 계정. 두 앱을 모두 구독할 필요는 없습니다.
- 앱의 입력창에 글을 붙여 넣을 수 있는 상태. [실제 화면 안내](/learn/screens/)에서 시작 위치를 확인합니다.
- 가상 실습 자료. [예제 파일](/downloads/classroom/)을 내려받거나 각 수업의 글을 복사합니다.
- 원문과 결과를 나란히 볼 화면. 예제 수치는 화면을 보며 직접 비교합니다.

각 수업은 **배울 내용 → 그림과 설명 → 예제 → 실습 요청 → 예상 결과 → 흔한 실수 → 확인 문제**로 구성했습니다. 접힌 답안을 펼치기 전에 자신의 말로 답해 보세요. 이미지에 담긴 주요 내용은 본문에도 설명하므로 그림을 확대하기 어렵더라도 학습할 수 있습니다.

예상 결과는 수업을 위해 작성한 모범 예시입니다. 앱에서 실제로 실행한 결과라고 표시하지 않습니다. 문장과 표의 모양은 달라도 사실과 완료 기준이 맞으면 됩니다. 화면 사진은 실제 접속 화면이며 [촬영 기록](/learn/screens/#촬영-범위와-해석)을 함께 제공합니다.
