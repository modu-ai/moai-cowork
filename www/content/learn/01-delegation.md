## 이번 수업에서 배울 내용

수업을 마치면 자신이 맡길 일을 한 문장으로 말하고, 결과에 어떤 내용이 들어가야 하는지 설명할 수 있습니다. “AI를 잘 쓰고 싶다”를 “고객 문의 메모로 팀장용 보고서 초안을 만들겠다”로 바꾸는 연습입니다.

## 질문을 업무 요청으로 바꾸기

“주간보고가 뭐야?”라고 물으면 개념 설명이 필요합니다. “아래 메모로 주간보고를 만들어 줘”라고 하면 자료를 읽고 결과를 만들어야 합니다. 이때 AI에게 필요한 것은 멋진 표현보다 **쓸 자료, 결과의 독자, 형식, 확인 기준**입니다. ChatGPT의 Work는 여러 단계를 거쳐 검토할 결과물을 만드는 작업에 쓰며, Claude Cowork도 결과물 중심의 업무에 활용할 수 있습니다. 사용 가능한 도구와 실행 환경은 앱에서 따로 확인합니다. [ChatGPT 공식 안내](https://learn.chatgpt.com/docs/get-started-with-work), [Claude 공식 안내](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork).

## 그림에 나온 여섯 가지 개념

| 개념 | 쉬운 뜻 | 고객 문의 업무에서의 예 |
|---|---|---|
| 프로젝트 | 한 목표를 위해 자료와 기준을 모아 두는 공간 | 고객 문의 개선 프로젝트 |
| 지침 | 반복해서 지킬 업무 기준 | 정책에 없는 환불 기한은 만들지 않기 |
| 스킬 | 특정 일을 하는 방법과 참고 자료 | 문의 유형 분류, FAQ 작성 방법 |
| 에이전트 | 맡은 역할과 도구로 작업하는 담당자 | 분석 담당, 작성 담당, 검토 담당 |
| 플러그인 | 스킬·도구 등을 묶어 설치하는 패키지 | CS 관련 기능을 묶은 패키지 |
| MCP | AI와 외부 도구·자료를 연결하는 규격 | 허용된 고객지원 시스템의 자료 조회 |

프로젝트에는 목표와 자료를 담고, 지침으로 기준을 정합니다. 필요한 업무 방법은 스킬에서 가져오며, 실행 환경이 지원하면 에이전트에게 역할을 나눕니다. 플러그인은 이런 기능을 배포하는 묶음입니다. 외부 계정의 자료가 필요할 때는 MCP 같은 연결 기능을 추가합니다. 모든 작업에 MCP나 여러 에이전트가 필요한 것은 아닙니다.

## 좋지 않은 요청을 고쳐 보기

| 처음 쓴 요청 | 왜 답하기 어려울까? | 고친 요청 |
|---|---|---|
| 보고서 잘 만들어 줘 | 자료와 독자가 없음 | 아래 문의 메모로 팀장용 보고서 초안을 만들어 줘 |
| 알아서 완벽하게 해 줘 | 완료 기준이 없음 | 성과·문제·다음 행동을 표로 정리하고 숫자는 원문과 대조해 줘 |
| 자료는 너가 찾아 | 내부 자료에 접근할 수 있는지 모름 | 내가 올린 파일부터 확인하고, 없는 자료는 목록으로 알려 줘 |

## 실습 · 업무 요청 다섯 칸 채우기

자기 업무 하나를 골라 아래 빈칸을 채웁니다. 아직 정하지 못한 칸은 “미정”으로 쓰세요.

```text
목표: [무엇을 만들거나 정리할지]
독자: [누가 읽거나 사용할지]
자료: [지금 제공할 수 있는 파일이나 글]
결과 형식: [표, 문서, 슬라이드 등]
완료 기준: [직접 확인할 수 있는 조건]

부족한 정보는 질문해 줘. 없는 사실은 만들지 말아 줘.
우선 검토용 초안을 보여 줘.
```

### 모범 예시

“고객 문의 12건의 처리 내용을 팀장에게 보고한다. 메모를 자료로 쓰고 한 장짜리 표를 만든다. 문의 수 12건과 FAQ 초안 4개가 원문과 맞아야 하며, 배송 지연 원인은 확인 필요로 표시한다.” 이것이면 첫 업무를 시작할 수 있습니다.

## 흔한 실수

결과가 길수록 좋은 것으로 생각하기 쉽습니다. 그러나 읽는 사람이 다음 행동을 찾을 수 있어야 합니다. “한 장 안에 성과와 문제가 구분되고, 미정 사항이 보인다”처럼 직접 볼 수 있는 기준을 정하세요. AI가 질문을 많이 한다면 목적에 꼭 필요한 질문부터 답하고 선택 사항은 나중에 정해도 됩니다.
