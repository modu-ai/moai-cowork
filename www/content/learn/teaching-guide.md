## 수업의 목표

수강생이 자기 업무의 목표와 자료를 설명하고, 질문에 답하며, 만든 결과를 원문과 비교하는 것까지 수행하도록 합니다. 도구 이름을 외우는 것보다 “내가 무엇을 맡겼고 무엇을 확인했는가”를 말할 수 있어야 합니다.

## 수업 전에 점검하세요

1. [준비 수업](/learn/preparation/)의 확인표로 앱 설치·로그인·플러그인 추가·새 작업에서의 노출을 구분해 확인합니다. 화면이 없는 단계는 강사가 실제 계정에서 시연하고, 수행하지 못한 단계는 미완료로 기록합니다.
2. 사용할 계정에서 Work 또는 Cowork 입력창을 확인합니다. 메뉴가 다른 수강생은 같은 기능의 현재 위치를 함께 찾습니다.
3. [가상 실습 자료](/downloads/classroom/)와 원문 수치를 미리 확인합니다. 실제 고객 자료는 기본 실습에 사용하지 않습니다.
4. 강의 화면에서 그림과 표가 읽히는지 확인합니다. 그림 파일을 열면 더 크게 볼 수 있습니다.
5. 앱 장애가 있을 때는 문서의 모범 결과로 검토 연습을 진행하고, 실제 실행을 하지 못한 상태를 기록합니다.

## 수업 흐름

| 순서 | 강사의 시연 | 수강생이 하는 일 | 확인할 질문 |
|---|---|---|---|
| 개념 | 1강의 여섯 개 개념을 고객 문의 사례로 설명 | 자기 업무의 다섯 칸 작성 | 결과를 누가 읽나요? |
| 맥락 | 2강의 지침과 자료를 나누어 보여 주기 | 프로젝트 기준과 원본 구분 | 어떤 자료를 실제로 읽었나요? |
| 첫 결과 | 3강 요청을 앱에 입력하고 질문에 답하기 | 같은 메모로 보고서 만들기 | FAQ 4개는 어떤 상태인가요? |
| 기능 선택 | 4강 설치·노출·실행의 차이 설명 | 필요한 스킬 후보 하나 선택 | 추천과 실제 사용을 구분했나요? |
| 협업 | 5강 그림에서 의존하는 화살표 짚기 | 역할별 입력과 출력 작성 | 검토는 언제 시작하나요? |
| 검토 | 6강의 출고·도착 표현 오류 찾기 | 결과 비교와 수정 기록 | 확인되지 않은 약속이 있나요? |

## 앱이 다른 수강생을 함께 지도하기

같은 자료와 완료 기준을 사용합니다. ChatGPT Work 수강생은 Work 입력창, Claude Cowork 수강생은 Cowork 또는 통합 작업 입력창에서 시작합니다. 화면 위치는 다를 수 있지만, 목표·자료·질문·검토라는 업무 순서는 함께 비교할 수 있습니다. 실제 에이전트 기능을 지원하지 않는 계정에서는 역할별 작업을 순서대로 진행합니다.

## 설명을 충분히 이해했는지 확인하기

“이해했나요?” 대신 구체적인 선택을 묻습니다. “배송 정책이 없으면 FAQ를 어떻게 쓸까요?”, “초안이 없을 때 무엇을 검토할 수 있나요?”처럼 답에 이유가 들어가게 합니다. 접힌 해설은 수강생이 먼저 답한 뒤 펼칩니다.

## 평가 기준

| 기준 | 충족 예시 | 보완이 필요한 예시 |
|---|---|---|
| 목표 | 독자와 결과 형식을 말함 | 잘 만들어 달라고만 요청 |
| 자료 | 원본과 결과를 나누고 읽기 여부 확인 | 파일 이름만 보고 접근했다고 판단 |
| 맥락 | 미정 항목을 질문하거나 표시 | 빈칸을 AI의 추측으로 확정 |
| 업무 순서 | 독립 작업과 후속 검토를 구분 | 모든 작업을 무조건 병렬 지정 |
| 결과 검토 | 원문 수치·정책·파일을 직접 비교 | 문장이 자연스러워서 그대로 사용 |
| 완료 보고 | 실제 수행과 미확인 항목을 구분 | 설치만 하고 전체 성공으로 보고 |

점수를 매길 경우 각 항목의 충족 여부와 보완할 행동을 함께 남깁니다. 모델마다 문장이나 표가 달라지는 것은 오류로 처리하지 않으며, 근거와 기준의 일치를 봅니다. 실제 학습 효과와 수강생 수행률은 이 문서만으로 측정되었다고 볼 수 없습니다.

## 수업 후 과제

자신의 반복 업무 하나를 골라 프로젝트 지침과 결과 검토표를 제출합니다. 원본을 첨부하기 어렵다면 공개 가능한 가상 자료로 바꾸고 그 사실을 표시합니다. 다음 수업에서는 수정 전·후 결과를 비교하며 기준이 어떻게 좋아졌는지 설명합니다.
