## 자료가 안 읽힐 때 확인하는 순서

1. 현재 작업에 파일을 올렸거나 폴더 접근을 제공했는지 확인합니다.
2. 읽을 파일 이름을 지정합니다. 폴더가 보인다고 모든 파일이 읽힌 것은 아닙니다.
3. 웹 프로젝트라면 업로드·연결 자료와 컴퓨터 폴더를 구분합니다.
4. 로컬·클라우드 실행이 바뀌었다면 접근 가능한 자료를 다시 확인합니다.

## 외부 서비스 연결 전

연결할 서비스, 사용할 계정·조직, 조회 범위와 변경 범위를 확인합니다. 플러그인 설치는 계정 인증과 다릅니다. 첫 확인은 조회 작업으로 진행하고 반환된 계정·기간·자료가 맞는지 확인하세요.

API 키는 채팅·프로젝트 지침·공유 자료에 넣지 않습니다. 지원되는 비밀정보 입력란이나 로컬 서버의 자격증명 설정을 사용합니다. [자격증명 안내](/plugins/mcp/credentials/)를 참고하세요.

## 결과물 저장 확인

```text
입력 자료는 변경하지 말고 결과물을 별도 위치에 저장해 줘.
저장한 파일의 이름과 위치를 알려 주고 실제로 열 수 있는지 확인해 줘.
외부 게시나 발송은 초안 검토가 끝난 뒤 별도 범위로 진행할게.
```

임시 초안, 저장된 파일, 외부에 게시된 결과는 서로 다릅니다. 완료 보고에서 각 상태를 확인합니다.
