**moai-pm은 프로젝트를 시작할 때 업무 기준과 진행 순서를 정리하는 역할입니다.** 실제 사용 가능한 플러그인을 확인하고 필요한 전문가 스킬을 연결합니다. 추천 목록에 있는 기능이 이미 설치되었다고 간주하지 않습니다.


<!--more-->

## 프로젝트 지침은 첫 실행으로 확인합니다

{{< concept-diagram pm-setup >}}

## 준비물

`moai-pm` 설치·활성화와 현재 작업의 스킬 노출을 확인하세요. 프로젝트 자료와 결과를 저장할 위치를 준비합니다. 처음에는 가상 자료로 시험해도 됩니다.

## 첫 요청

```text
고객지원팀의 주간보고 프로젝트를 시작해 줘.
업무 메모와 지난 보고서 양식을 사용할 거야.
현재 앱에서 쓸 수 있는 스킬과 도구부터 확인하고,
부족한 맥락은 질문해 줘.
보고서 작성과 검토 역할, 진행 순서, 완료 기준을 정리해서
이 프로젝트에 맞는 지침을 만들어 줘.
지침 파일 생성과 앱 Projects 적용 여부를 따로 알려 줘.
```

앱에 `/project` 명령이 표시되는 경우에는 사용할 수 있습니다. 표시되지 않으면 자연어로 요청하거나 스킬 선택 메뉴에서 project를 선택합니다.

## 진행 중 확인할 것

| 단계 | 확인할 내용 |
|---|---|
| 맥락 | 목표·독자·자료·형식·제약, 답변과 미정 항목 |
| 기능 | 설치·활성화·현재 노출·계정 인증 상태 |
| 설계 | 담당 역할·사용 스킬·입력과 출력·완료 기준 |
| 지침 | 실제 앱 또는 로컬 환경에 맞는 저장 위치 |
| 첫 실행 | 자료 읽기, 초안 생성, 검토, 결과 파일 열기 |

스킬 이름을 모두 외울 필요는 없습니다. PM이 어떤 기능을 선택했고 왜 필요한지 설명하도록 요청하세요. 새 연결이 필요한 작업은 연결 없이 가능한 초안과 구분합니다.

## 완료 기준

프로젝트 지침을 저장하고 새 작업에서 실제 참조하는지 확인했습니다. 대표 업무를 한 번 실행했으며 결과물·미정 항목·사람의 확인 사항이 남았습니다.
