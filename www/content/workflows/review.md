**완료했다는 문장보다 결과물을 확인하세요.** 초안이 보기 좋더라도 원문·숫자·출처가 맞는지 확인해야 합니다.

| 확인 영역 | 확인 방법 |
|---|---|
| 사실 | 원문과 비교하고 출처 링크 열기 |
| 숫자 | 기간·단위·합계·가정 확인 |
| 문서 | 다운로드해 열고 표·글꼴·페이지 확인 |
| 연결 작업 | 실제 서비스의 조회·변경 결과 확인 |
| 검토 | 검토 기준과 발견된 문제, 미확인 항목 확인 |


<!--more-->


## 고쳐 달라고 요청하기

```text
본문 2절의 수치는 원문과 달라. 첨부 표의 값으로 고쳐 줘.
전체 문서를 새로 쓰지 말고 해당 문단과 연결된 요약만 수정해 줘.
어떤 근거를 사용했는지와 아직 확인하지 못한 항목도 알려 줘.
```

문장 다듬기, 수치 검증, 법률·재무 판단은 서로 다른 검토입니다. “AI 티를 줄였음”이 사실 확인을 대신하지 않습니다.

## 별도 검토자와 자기 점검

지원되는 환경에서는 작성과 검토를 별도 담당자로 나눌 수 있습니다. 실제 별도 실행·권한 제한이 확인된 경우에만 독립 검토라고 기록합니다. 같은 AI가 다시 읽은 경우에는 자기 점검으로 구분합니다.

외부 공개 전에는 업무 책임자가 근거·권리·민감정보·결정 사항을 확인하세요. [반복 업무와 개선](/workflows/reuse/)으로 성공한 결과를 재사용할 수 있습니다.
