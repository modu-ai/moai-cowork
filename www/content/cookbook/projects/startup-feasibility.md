**이 실습의 결과는 타당성 검토표입니다.** ChatGPT Work와 Claude Cowork 모두 목표와 자료를 제공하는 방식으로 시작합니다. 실제 서비스 연결과 지원 도구는 현재 앱에서 확인하세요.


<!--more-->


## 준비물

창업 아이디어·입지·고객·비용 자료를 준비합니다. 실습에서는 가상 자료나 공개 가능한 자료를 사용할 수 있습니다. [관련 역할](/moai-agents/consultant/)의 스킬을 추가하려면 [설치 안내](/plugins/install/)를 확인합니다.

## 첫 요청

```text
제공한 자료로 타당성 검토표을 만들어 줘.
목표·독자·결과 형식을 먼저 확인하고 부족한 정보는 질문해 줘.
고객 문제, 시장 자료, 운영 비용, 미검증 가정을 나눠 분석해 줘.
자료 없는 사실과 수치는 만들지 말고 미정 항목을 표시해 줘.
외부 게시·발송·계정 변경 없이 검토용 결과부터 보여 줘.
```

## 진행 순서

1. **자료 확인:** 창업 아이디어·입지·고객·비용 자료 중 읽을 수 있는 것과 없는 것을 구분합니다.
2. **맥락 확인:** 독자·형식·범위를 질문에 답해 정합니다.
3. **초안 작성:** 고객 문제, 시장 자료, 운영 비용, 미검증 가정을 나눠 분석합니다.
4. **검토:** 시장 근거·비용 가정·검증이 필요한 조건을 확인합니다.
5. **수정·저장:** 변경할 부분을 지정하고 결과를 별도 위치에 저장합니다.

독립적인 조사만 병렬로 진행하고, 앞 결과가 필요한 작성·변환은 순차로 진행합니다. [전문가 분업](/workflows/experts/)의 역할·입출력 계약을 사용할 수 있습니다.

## 가상 예제로 더 이해하기

아래 자료와 결과는 수업용 가상 예시입니다. 실제 업무 실적·공고·법률 판단·앱 실행 결과가 아닙니다.

```text
가상 후보지 A: 월 임대료 1,000,000원. 후보지 B: 월 임대료 1,500,000원. 업종은 책방. 유동인구·구매 전환율·객단가·관리비·인건비·면적은 미확인. 주소와 조사 시점은 없음.
```

### 먼저 확인할 질문

두 후보지의 면적과 조사 시점이 같나요? 출처가 있는 유동인구 자료와 업종별 비용이 있나요? 임대료 외 고정비는 무엇인가요? 답을 모르면 미정으로 남기고 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

임대료만 비교하면 B가 A보다 월 500,000원 높습니다. 매출과 이익은 계산할 자료가 없습니다. 주소·기간·면적을 맞춘 시장 자료와 비용 견적을 다음 확인 항목으로 남깁니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 후보지 A 임대료 | 월 1,000,000원 | 가상 제공 값 |
| 후보지 B 임대료 | 월 1,500,000원 | 가상 제공 값 |
| 임대료 차이 | B가 월 500,000원 높음 | 1,500,000 − 1,000,000 |
| 조건 비교 | 주소·시점·면적 | 미확인 |
| 창업 판단 | 매출·이익·추천 순위 | 근거 부족·판단 유보 |

### 흔한 실수와 수정 요청

임대료가 낮다는 이유만으로 창업에 적합하다고 판정하거나, 유동인구를 실제 구매 고객 수로 바꿉니다.

```text
임대료 차이만 계산해 줘. 두 후보지의 조건이 비교 가능한지 먼저 확인하고, 매출·이익·추천 순위는 미검증으로 남겨 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

A의 임대료가 더 낮으면 A가 더 좋은 상권인가요?

<details><summary>답안과 해설 보기</summary>

임대료만으로 판단할 수 없습니다. 고객·매출·면적·운영 비용 등 필요한 비교 근거가 빠져 있습니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.

## 사용할 수 있는 스킬 후보

아래는 이 업무에 참고할 수 있는 패키지 기능입니다. 실제 설치·노출 상태를 먼저 확인하며 이 순서로 반드시 자동 실행된다는 뜻은 아닙니다.

- `moai-accountant:finance-financial-statements`
- `moai-accountant:finance-tax-helper`
- `moai-consultant:consult-market`
- `moai-consultant:consult-sbiz365`

## 완료 기준

결과물에 사용 자료와 미확인 항목이 표시되어 있습니다. 시장 근거·비용 가정·검증이 필요한 조건을 직접 확인했습니다. 파일을 요청한 경우 저장된 파일을 열어 확인합니다. 실제 게시·발송·예약 작업은 별도의 실행 결과로 확인합니다.

## 막혔을 때

자료나 연결이 없으면 제공 자료로 가능한 초안과 다음 준비 목록을 요청합니다. 원문·수치가 다르면 해당 위치와 근거를 지정해 고칩니다. 전문 판단이 필요한 부분은 근거와 쟁점을 정리하고 해당 업무 책임자가 확인합니다.
