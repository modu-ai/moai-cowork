**이 실습의 결과는 브랜드 기준과 랜딩 페이지 초안입니다.** ChatGPT Work와 Claude Cowork 모두 목표와 자료를 제공하는 방식으로 시작합니다. 실제 서비스 연결과 지원 도구는 현재 앱에서 확인하세요.


<!--more-->


## 준비물

브랜드·고객·제품·기존 자료를 준비합니다. 실습에서는 가상 자료나 공개 가능한 자료를 사용할 수 있습니다. [관련 역할](/moai-agents/designer/)의 스킬을 추가하려면 [설치 안내](/plugins/install/)를 확인합니다.

## 첫 요청

```text
제공한 자료로 브랜드 기준과 랜딩 페이지 초안을 만들어 줘.
목표·독자·결과 형식을 먼저 확인하고 부족한 정보는 질문해 줘.
브랜드 기준, 콘텐츠, 시안, 접근성 검토를 순서대로 진행해 줘.
자료 없는 사실과 수치는 만들지 말고 미정 항목을 표시해 줘.
외부 게시·발송·계정 변경 없이 검토용 결과부터 보여 줘.
```

## 진행 순서

1. **자료 확인:** 브랜드·고객·제품·기존 자료 중 읽을 수 있는 것과 없는 것을 구분합니다.
2. **맥락 확인:** 독자·형식·범위를 질문에 답해 정합니다.
3. **초안 작성:** 브랜드 기준, 콘텐츠, 시안, 접근성 검토를 순서대로 진행합니다.
4. **검토:** 주장 근거·행동 버튼·모바일 가독성을 확인합니다.
5. **수정·저장:** 변경할 부분을 지정하고 결과를 별도 위치에 저장합니다.

독립적인 조사만 병렬로 진행하고, 앞 결과가 필요한 작성·변환은 순차로 진행합니다. [전문가 분업](/workflows/experts/)의 역할·입출력 계약을 사용할 수 있습니다.

## 가상 예제로 더 이해하기

아래 자료와 결과는 수업용 가상 예시입니다. 실제 업무 실적·공고·법률 판단·앱 실행 결과가 아닙니다.

```text
가상 브랜드 작은책상: 책상용 USB-C 충전 스탠드. 높이 28cm, 밝기 3단계. 독자는 책상 공간을 정리하려는 사용자. 페이지 목표는 제품 문의. 가격·사용 시간·인증·문의 URL은 미정.
```

### 먼저 확인할 질문

브랜드가 꼭 지켜야 할 말투와 피해야 할 표현은 무엇인가요? 문의 버튼의 실제 주소와 사진 사용 권한이 있나요? 답을 모르면 미정으로 남기고 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

브랜드 기준을 먼저 정한 뒤 같은 기준으로 페이지를 작성합니다. 위에서 아래로 제품 특징, 사용 상황, 사양, 문의 순서를 잡습니다. 문의 주소가 없으면 버튼은 연결 전으로 표시합니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 브랜드 기준 후보 | 쉽고 담백한 말투 · 확인된 사양으로 설명 | 검토용 제안 |
| 첫 화면 제목 | 책상에 두는 USB-C 충전 스탠드 | 제품 자료 기반 초안 |
| 특징·사양 영역 | 밝기 3단계 · 높이 28cm | 확정 사양 |
| 문의 버튼 | 제품 문의하기 | URL 미정·연결 전 |
| 모바일 검토 | 제목 줄바꿈·버튼 크기·사양 읽기 | 실제 시안에서 확인할 항목 |

### 흔한 실수와 수정 요청

제공하지 않은 사용 시간을 광고 문구에 넣거나, 문의 버튼을 만들었다는 이유로 실제 게시와 연결까지 완료했다고 보고합니다.

```text
USB-C 충전·밝기 3단계·높이 28cm만 확정 사양으로 써 줘. 문의 URL은 미정으로 남겨 줘. 모바일에서 제목과 버튼이 읽히는지도 검토해 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

문의 버튼 시안이 있으면 실제 문의를 받을 수 있나요?

<details><summary>답안과 해설 보기</summary>

시안만으로는 확인할 수 없습니다. 실제 주소와 연결, 입력·전송 결과를 별도로 확인해야 합니다. 이 실습은 검토용 페이지 초안입니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.

## 사용할 수 있는 스킬 후보

아래는 이 업무에 참고할 수 있는 패키지 기능입니다. 실제 설치·노출 상태를 먼저 확인하며 이 순서로 반드시 자동 실행된다는 뜻은 아닙니다.

- `moai-coworker:collab-brand-identity`
- `moai-designer:design-brand-system`
- `moai-designer:design-brief`
- `moai-designer:design-landing-motion`
- `moai-designer:design-slop-check`

## 완료 기준

결과물에 사용 자료와 미확인 항목이 표시되어 있습니다. 주장 근거·행동 버튼·모바일 가독성을 직접 확인했습니다. 파일을 요청한 경우 저장된 파일을 열어 확인합니다. 실제 게시·발송·예약 작업은 별도의 실행 결과로 확인합니다.

## 막혔을 때

자료나 연결이 없으면 제공 자료로 가능한 초안과 다음 준비 목록을 요청합니다. 원문·수치가 다르면 해당 위치와 근거를 지정해 고칩니다. 전문 판단이 필요한 부분은 근거와 쟁점을 정리하고 해당 업무 책임자가 확인합니다.
