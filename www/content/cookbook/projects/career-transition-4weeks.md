**이 실습의 결과는 이직 준비 목록과 지원 자료입니다.** ChatGPT Work와 Claude Cowork 모두 목표와 자료를 제공하는 방식으로 시작합니다. 실제 서비스 연결과 지원 도구는 현재 앱에서 확인하세요.


<!--more-->


## 준비물

경력·희망 직무·이력서·활동 가능 범위를 준비합니다. 실습에서는 가상 자료나 공개 가능한 자료를 사용할 수 있습니다. [관련 역할](/moai-agents/career/)의 스킬을 추가하려면 [설치 안내](/plugins/install/)를 확인합니다.

## 첫 요청

```text
제공한 자료로 이직 준비 목록과 지원 자료을 만들어 줘.
목표·독자·결과 형식을 먼저 확인하고 부족한 정보는 질문해 줘.
직무 요구를 확인하고 경력 정리, 이력서 수정, 면접 준비로 진행해 줘.
자료 없는 사실과 수치는 만들지 말고 미정 항목을 표시해 줘.
외부 게시·발송·계정 변경 없이 검토용 결과부터 보여 줘.
```

## 진행 순서

1. **자료 확인:** 경력·희망 직무·이력서·활동 가능 범위 중 읽을 수 있는 것과 없는 것을 구분합니다.
2. **맥락 확인:** 독자·형식·범위를 질문에 답해 정합니다.
3. **초안 작성:** 직무 요구를 확인하고 경력 정리, 이력서 수정, 면접 준비로 진행합니다.
4. **검토:** 실제 경력·수치·지원 요건·미정 일정을 확인합니다.
5. **수정·저장:** 변경할 부분을 지정하고 결과를 별도 위치에 저장합니다.

독립적인 조사만 병렬로 진행하고, 앞 결과가 필요한 작성·변환은 순차로 진행합니다. [전문가 분업](/workflows/experts/)의 역할·입출력 계약을 사용할 수 있습니다.

## 가상 예제로 더 이해하기

아래 자료와 모범 설명은 수업을 위해 작성했습니다. 실제 회사·고객의 실적이나 앱 실행 결과가 아닙니다. 먼저 제공 자료로 작은 결과를 만든 뒤 자신의 자료로 바꿔 보세요.

```text
가상 경력: 문의 처리 1년, FAQ 초안 4개 작성, 스프레드시트로 문의 목록 정리. 지원 희망은 고객지원 운영. 매출 기여 수치는 없음.
```

### 먼저 확인할 질문

어떤 직무 요건에 맞추나요? 실제 수행 범위와 수치를 증명할 자료가 있나요? 답을 모르면 해당 항목을 미정으로 남기고, 그 정보 없이 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

문의 처리, FAQ 작성, 자료 정리 경험을 희망 직무와 연결합니다. 실제 경험과 학습 계획을 구분하고 매출 성과는 만들지 않습니다. 문장과 서식은 달라도 이 기준을 충족하는지 직접 비교합니다. 원문 위치·출처·상태가 결과에 함께 남으면 다음 검토자에게 넘기기 쉽습니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 직무와 연결할 경험 | 문의 처리 1년 | 가상 경력 자료에서 확인 |
| 자료 정리 역량 | 스프레드시트 문의 목록 정리 | 작업 예시 첨부 후보 |
| 문서 작성 경험 | FAQ 초안 4개 | 최종 배포 실적 아님 |
| 기재하지 않은 성과 | 매출 기여·고객 만족도 수치 | 근거 없음 |

### 흔한 실수와 수정 요청

경력을 과장하거나 팀 전체 성과를 본인 실적으로 바꿉니다. 이때는 결과 전체를 다시 만들어 달라는 말보다, 틀린 기준과 고칠 위치를 구체적으로 알려 주세요.

```text
내가 실제 한 일만 적어 줘. 확인되지 않은 매출 성과와 책임 범위는 삭제하고 직무와 연결되는 경험을 강조해 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

수치가 없으면 그럴듯한 성과 비율을 추정해 넣어도 될까요?

<details><summary>답안과 해설 보기</summary>

넣지 않습니다. 실제 수행 내용과 결과물을 설명하고 확인 가능한 수치가 있는지 질문합니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.

## 사용할 수 있는 스킬 후보

아래는 이 업무에 참고할 수 있는 패키지 기능입니다. 실제 설치·노출 상태를 먼저 확인하며 이 순서로 반드시 자동 실행된다는 뜻은 아닙니다.

- `moai-coworker:collab-negotiation`
- `moai-career:career-interview`
- `moai-career:career-junior-onboarding`
- `moai-career:career-portfolio`
- `moai-career:career-resume`

## 완료 기준

결과물에 사용 자료와 미확인 항목이 표시되어 있습니다. 실제 경력·수치·지원 요건·미정 일정을 직접 확인했습니다. 파일을 요청한 경우 저장된 파일을 열어 확인합니다. 실제 게시·발송·예약 작업은 별도의 실행 결과로 확인합니다.

## 막혔을 때

자료나 연결이 없으면 제공 자료로 가능한 초안과 다음 준비 목록을 요청합니다. 원문·수치가 다르면 해당 위치와 근거를 지정해 고칩니다. 전문 판단이 필요한 부분은 근거와 쟁점을 정리하고 해당 업무 책임자가 확인합니다.
