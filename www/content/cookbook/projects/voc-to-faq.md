**이 실습의 결과는 문의 분류와 FAQ 초안입니다.** ChatGPT Work와 Claude Cowork 모두 목표와 자료를 제공하는 방식으로 시작합니다. 실제 서비스 연결과 지원 도구는 현재 앱에서 확인하세요.


<!--more-->


## 준비물

고객 문의·기존 정책·FAQ를 준비합니다. 실습에서는 가상 자료나 공개 가능한 자료를 사용할 수 있습니다. [관련 역할](/moai-agents/cs/)의 스킬을 추가하려면 [설치 안내](/plugins/install/)를 확인합니다.

## 첫 요청

```text
제공한 자료로 문의 분류와 FAQ 초안을 만들어 줘.
목표·독자·결과 형식을 먼저 확인하고 부족한 정보는 질문해 줘.
문의 유형을 분류하고 정책과 대조한 뒤 FAQ 초안을 검토해 줘.
자료 없는 사실과 수치는 만들지 말고 미정 항목을 표시해 줘.
외부 게시·발송·계정 변경 없이 검토용 결과부터 보여 줘.
```

## 진행 순서

1. **자료 확인:** 고객 문의·기존 정책·FAQ 중 읽을 수 있는 것과 없는 것을 구분합니다.
2. **맥락 확인:** 독자·형식·범위를 질문에 답해 정합니다.
3. **초안 작성:** 문의 유형을 분류하고 정책과 대조한 뒤 FAQ 초안을 검토합니다.
4. **검토:** 정책 근거·개인정보 제거·반복 질문의 대표성을 확인합니다.
5. **수정·저장:** 변경할 부분을 지정하고 결과를 별도 위치에 저장합니다.

독립적인 조사만 병렬로 진행하고, 앞 결과가 필요한 작성·변환은 순차로 진행합니다. [전문가 분업](/workflows/experts/)의 역할·입출력 계약을 사용할 수 있습니다.

## 가상 예제로 더 이해하기

아래 자료와 모범 설명은 수업을 위해 작성했습니다. 실제 회사·고객의 실적이나 앱 실행 결과가 아닙니다. 먼저 제공 자료로 작은 결과를 만든 뒤 자신의 자료로 바꿔 보세요.

```text
수업용 문의 6건: 배송 3건, 반품 2건, 결제 1건. 정책은 영업일 2일 이내 출고, 고객지원 창구로 반품 신청. 배송 완료 시점·반품 비용·결제 승인 기준은 없음.
```

### 먼저 확인할 질문

현재 정책 버전과 답변 공개 범위는 무엇인가요? 반품 비용과 결제 담당 절차가 있나요? 답을 모르면 해당 항목을 미정으로 남기고, 그 정보 없이 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

유형 합계 6건을 표시하고 출고 기준과 도착 시점을 구분합니다. 반품 비용과 결제 정책은 확인 필요로 남깁니다. 원문 ID를 FAQ 근거에 연결합니다. 문장과 서식은 달라도 이 기준을 충족하는지 직접 비교합니다. 원문 위치·출처·상태가 결과에 함께 남으면 다음 검토자에게 넘기기 쉽습니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 배송 FAQ | 영업일 2일 이내 출고 | 정책 원문·배송 문의 3건 |
| 반품 FAQ | 고객지원 창구로 신청 | 정책 원문·반품 문의 2건 |
| 미확인 정책 | 배송 도착 시점·반품 비용·결제 승인 | 정책 자료 없음 |
| 검토할 초안 | 결제 문의 1건에 대한 정책 요청 | 원문 확인 필요 |

### 흔한 실수와 수정 요청

2일 이내 출고를 2일 이내 도착으로 바꾸거나 반품이 항상 무료라고 씁니다. 이때는 결과 전체를 다시 만들어 달라는 말보다, 틀린 기준과 고칠 위치를 구체적으로 알려 주세요.

```text
출고와 도착을 구분해 줘. 반품 비용과 결제 기준은 자료에 없으니 확인 필요로 남겨 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

정책이 빠진 유형 때문에 모든 FAQ 작성을 멈춰야 할까요?

<details><summary>답안과 해설 보기</summary>

근거가 있는 배송·반품 절차는 작성하고, 근거가 없는 비용·결제 항목만 보류해 필요한 질문을 모읍니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.

## 사용할 수 있는 스킬 후보

아래는 이 업무에 참고할 수 있는 패키지 기능입니다. 실제 설치·노출 상태를 먼저 확인하며 이 순서로 반드시 자동 실행된다는 뜻은 아닙니다.

- `moai-cs:cs-draft-response`
- `moai-cs:cs-quality-audit`
- `moai-cs:cs-kb-article`
- `moai-cs:cs-voc-triage`

## 완료 기준

결과물에 사용 자료와 미확인 항목이 표시되어 있습니다. 정책 근거·개인정보 제거·반복 질문의 대표성을 직접 확인했습니다. 파일을 요청한 경우 저장된 파일을 열어 확인합니다. 실제 게시·발송·예약 작업은 별도의 실행 결과로 확인합니다.

## 막혔을 때

자료나 연결이 없으면 제공 자료로 가능한 초안과 다음 준비 목록을 요청합니다. 원문·수치가 다르면 해당 위치와 근거를 지정해 고칩니다. 전문 판단이 필요한 부분은 근거와 쟁점을 정리하고 해당 업무 책임자가 확인합니다.
