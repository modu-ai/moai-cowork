**이 실습의 결과는 지원사업 신청서 초안입니다.** ChatGPT Work와 Claude Cowork 모두 목표와 자료를 제공하는 방식으로 시작합니다. 실제 서비스 연결과 지원 도구는 현재 앱에서 확인하세요.


<!--more-->


## 준비물

공고문·사업 자료·자격 요건을 준비합니다. 실습에서는 가상 자료나 공개 가능한 자료를 사용할 수 있습니다. [관련 역할](/moai-agents/consultant/)의 스킬을 추가하려면 [설치 안내](/plugins/install/)를 확인합니다.

## 첫 요청

```text
제공한 자료로 지원사업 신청서 초안을 만들어 줘.
목표·독자·결과 형식을 먼저 확인하고 부족한 정보는 질문해 줘.
공고의 필수 조건을 먼저 확인하고 그 목차에 맞춰 작성해 줘.
자료 없는 사실과 수치는 만들지 말고 미정 항목을 표시해 줘.
외부 게시·발송·계정 변경 없이 검토용 결과부터 보여 줘.
```

## 진행 순서

1. **자료 확인:** 공고문·사업 자료·자격 요건 중 읽을 수 있는 것과 없는 것을 구분합니다.
2. **맥락 확인:** 독자·형식·범위를 질문에 답해 정합니다.
3. **초안 작성:** 공고의 필수 조건을 먼저 확인하고 그 목차에 맞춰 작성합니다.
4. **검토:** 공고 버전·신청 자격·필수 서류·제출 기한을 확인합니다.
5. **수정·저장:** 변경할 부분을 지정하고 결과를 별도 위치에 저장합니다.

독립적인 조사만 병렬로 진행하고, 앞 결과가 필요한 작성·변환은 순차로 진행합니다. [전문가 분업](/workflows/experts/)의 역할·입출력 계약을 사용할 수 있습니다.

## 가상 예제로 더 이해하기

아래 자료와 결과는 수업용 가상 예시입니다. 실제 업무 실적·공고·법률 판단·앱 실행 결과가 아닙니다.

```text
가상 공고 G1: 신청일 기준 창업 3년 이내, 사업계획서와 예산표 제출. 가상 신청자 A1: 창업일 확인 자료 없음, 교육 서비스 준비 중. 월 이용료 후보 20,000원. 예산 근거와 실제 공고 URL은 없음. 실제 지원사업의 요건이 아니다.
```

### 먼저 확인할 질문

실제 공고의 원문·공고일·개정본이 있나요? 창업일과 신청 자격을 증명할 수 있나요? 예산 항목별 견적이 있나요? 답을 모르면 미정으로 남기고 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

공고 요건과 신청자 자료를 같은 행에 놓고, 충족·미확인·누락을 구분합니다. 신청 자격과 예산 근거가 없으면 선정 가능성을 판단하지 않습니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 창업 3년 이내 | A1의 창업일 증빙 없음 | 자격 미확인 |
| 사업계획서 | 교육 서비스 구상만 제공 | 제출 양식에 맞춘 작성 필요 |
| 예산표 | 항목별 견적 없음 | 금액·근거 확보 필요 |
| 실제 신청 | 수업용 가상 공고만 제공 | 신청·선정 미실시 |

### 흔한 실수와 수정 요청

창업일을 추정해 신청 자격을 충족으로 쓰거나, 가상 공고 조건을 실제 사업의 현재 요건처럼 사용합니다.

```text
공고 G1과 신청자 A1을 항목별로 대조해 줘. 창업일과 견적은 미확인으로 표시하고 필요한 증빙을 적어 줘. 제출·선정 여부는 주장하지 마.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

사업계획서 초안이 있으면 신청 자격도 확인된 걸까요?

<details><summary>답안과 해설 보기</summary>

아닙니다. 공고 요건과 증빙을 따로 확인합니다. 수업용 G1의 조건은 실제 지원사업에 적용하지 않습니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.

## 사용할 수 있는 스킬 후보

아래는 이 업무에 참고할 수 있는 패키지 기능입니다. 실제 설치·노출 상태를 먼저 확인하며 이 순서로 반드시 자동 실행된다는 뜻은 아닙니다.

- `moai-coworker:collab-proposal`

## 완료 기준

결과물에 사용 자료와 미확인 항목이 표시되어 있습니다. 공고 버전·신청 자격·필수 서류·제출 기한을 직접 확인했습니다. 파일을 요청한 경우 저장된 파일을 열어 확인합니다. 실제 게시·발송·예약 작업은 별도의 실행 결과로 확인합니다.

## 막혔을 때

자료나 연결이 없으면 제공 자료로 가능한 초안과 다음 준비 목록을 요청합니다. 원문·수치가 다르면 해당 위치와 근거를 지정해 고칩니다. 전문 판단이 필요한 부분은 근거와 쟁점을 정리하고 해당 업무 책임자가 확인합니다.
