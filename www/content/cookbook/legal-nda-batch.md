**이 실습의 결과는 문서별 검토표와 종합 쟁점입니다.** ChatGPT Work와 Claude Cowork 모두 목표와 자료를 제공하는 방식으로 시작합니다. 실제 서비스 연결과 지원 도구는 현재 앱에서 확인하세요.


<!--more-->


## 준비물

NDA 문서 묶음·검토 기준·관할을 준비합니다. 실습에서는 가상 자료나 공개 가능한 자료를 사용할 수 있습니다. [관련 역할](/moai-agents/lawyer/)의 스킬을 추가하려면 [설치 안내](/plugins/install/)를 확인합니다.

## 첫 요청

```text
제공한 자료로 문서별 검토표와 종합 쟁점을 만들어 줘.
목표·독자·결과 형식을 먼저 확인하고 부족한 정보는 질문해 줘.
문서별 결과를 별도 파일로 작성하고 같은 기준으로 모아 비교해 줘.
자료 없는 사실과 수치는 만들지 말고 미정 항목을 표시해 줘.
외부 게시·발송·계정 변경 없이 검토용 결과부터 보여 줘.
```

## 진행 순서

1. **자료 확인:** NDA 문서 묶음·검토 기준·관할 중 읽을 수 있는 것과 없는 것을 구분합니다.
2. **맥락 확인:** 독자·형식·범위를 질문에 답해 정합니다.
3. **초안 작성:** 문서별 결과를 별도 파일로 작성하고 같은 기준으로 모아 비교합니다.
4. **검토:** 문서별 누락·조항 인용·공통 기준·원본 보존을 확인합니다.
5. **수정·저장:** 변경할 부분을 지정하고 결과를 별도 위치에 저장합니다.

독립적인 조사만 병렬로 진행하고, 앞 결과가 필요한 작성·변환은 순차로 진행합니다. [전문가 분업](/workflows/experts/)의 역할·입출력 계약을 사용할 수 있습니다.

## 가상 예제로 더 이해하기

아래 자료와 결과는 수업용 가상 예시입니다. 실제 업무 실적·공고·법률 판단·앱 실행 결과가 아닙니다.

```text
가상 NDA A 제2조: 도면을 비밀정보로 지정. 제5조: 계약 종료 후 비밀유지 기간 공란. NDA B 제2조: 비밀정보 범위 공란. 제5조: 종료 후 2년. 두 문서 모두 관할과 예외 조항은 제공되지 않음.
```

### 먼저 확인할 질문

두 문서의 전체 원문과 버전이 있나요? 비밀정보 범위·예외·반환 의무·관할에 대해 합의된 기준이 있나요? 답을 모르면 미정으로 남기고 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

문서 A와 B의 조항 번호를 각각 남깁니다. 비밀정보 범위와 기간을 같은 기준으로 비교하고, 제공되지 않은 조항은 존재 여부 미확인으로 적습니다. 법적 효력이나 적정 기간을 확정하지 않습니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| A · 제2조 | 도면을 비밀정보로 지정 | 제공 조항 확인 |
| A · 제5조 | 종료 후 유지 기간 공란 | 합의 정보 필요 |
| B · 제2조 | 비밀정보 범위 공란 | 범위 합의 필요 |
| B · 제5조 | 종료 후 2년 | 제공 값·적정성 판정 아님 |
| 공통 미확인 | 관할·예외 조항 | 전체 원문 확인 필요 |

### 흔한 실수와 수정 요청

문서 B의 2년을 문서 A에 옮기거나, 일부 조항만 읽고 전체 계약을 문제없다고 판정합니다.

```text
문서 ID와 조항 번호를 분리해 줘. A의 기간과 B의 정보 범위는 공란 그대로 표시하고, 관할·예외는 원문 미제공으로 남겨 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

문서 B에 기간이 있으면 문서 A의 공란도 자동으로 채워도 될까요?

<details><summary>답안과 해설 보기</summary>

채우지 않습니다. 문서별 합의 내용을 따로 확인해야 합니다. 같은 검토 기준을 적용하는 것과 같은 문구로 고치는 것은 다릅니다.

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.

아래는 이 업무에 참고할 수 있는 패키지 기능입니다. 실제 설치·노출 상태를 먼저 확인하며 이 순서로 반드시 자동 실행된다는 뜻은 아닙니다.

## 완료 기준

결과물에 사용 자료와 미확인 항목이 표시되어 있습니다. 문서별 누락·조항 인용·공통 기준·원본 보존을 직접 확인했습니다. 파일을 요청한 경우 저장된 파일을 열어 확인합니다. 실제 게시·발송·예약 작업은 별도의 실행 결과로 확인합니다.

## 막혔을 때

자료나 연결이 없으면 제공 자료로 가능한 초안과 다음 준비 목록을 요청합니다. 원문·수치가 다르면 해당 위치와 근거를 지정해 고칩니다. 전문 판단이 필요한 부분은 근거와 쟁점을 정리하고 해당 업무 책임자가 확인합니다.
