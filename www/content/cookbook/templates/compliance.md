**이 실습의 결과는 준수 여부 확인 목록입니다.** ChatGPT Work와 Claude Cowork 모두 목표와 자료를 제공하는 방식으로 시작합니다. 실제 서비스 연결과 지원 도구는 현재 앱에서 확인하세요.


<!--more-->


## 준비물

사업·관할·처리 정보·관련 정책을 준비합니다. 실습에서는 가상 자료나 공개 가능한 자료를 사용할 수 있습니다. [관련 역할](/moai-agents/lawyer/)의 스킬을 추가하려면 [설치 안내](/plugins/install/)를 확인합니다.

## 첫 요청

```text
제공한 자료로 준수 여부 확인 목록을 만들어 줘.
목표·독자·결과 형식을 먼저 확인하고 부족한 정보는 질문해 줘.
적용 가능성을 확인할 질문과 관련 정책을 함께 정리해 줘.
자료 없는 사실과 수치는 만들지 말고 미정 항목을 표시해 줘.
외부 게시·발송·계정 변경 없이 검토용 결과부터 보여 줘.
```

## 진행 순서

1. **자료 확인:** 사업·관할·처리 정보·관련 정책 중 읽을 수 있는 것과 없는 것을 구분합니다.
2. **맥락 확인:** 독자·형식·범위를 질문에 답해 정합니다.
3. **초안 작성:** 적용 가능성을 확인할 질문과 관련 정책을 함께 정리합니다.
4. **검토:** 공식 근거·적용 범위·검토 책임·미확인 항목을 확인합니다.
5. **수정·저장:** 변경할 부분을 지정하고 결과를 별도 위치에 저장합니다.

독립적인 조사만 병렬로 진행하고, 앞 결과가 필요한 작성·변환은 순차로 진행합니다. [전문가 분업](/workflows/experts/)의 역할·입출력 계약을 사용할 수 있습니다.

## 가상 예제로 더 이해하기

아래 자료와 결과는 수업용 가상 예시입니다. 실제 업무 실적·공고·법률 판단·앱 실행 결과가 아닙니다.

```text
가상 서비스 정책 P1: 고객 메일은 문의 답변에만 사용. 처리 메모 D1: 이름·메일 주소 저장, 광고 발송 여부·보관 기간·접근 권한은 미확인. 사업 지역과 적용 법률 자료는 없음.
```

### 먼저 확인할 질문

실제 처리 목적과 저장 위치는 무엇인가요? 누가 접근하고 언제 삭제하나요? 검토할 관할과 최신 공식 근거를 제공할 수 있나요? 답을 모르면 미정으로 남기고 가능한 범위를 정합니다.

### 모범 결과를 읽는 방법

정책 P1과 실제 처리 메모 D1을 비교합니다. 목적·접근·보관 항목별 근거를 남기고, 자료가 없는 항목은 미확인으로 표시합니다. 준법 여부를 확정하는 대신 책임자가 확인할 질문을 정리합니다.

### 직접 비교할 모범 결과

| 항목 | 결과 예시 | 근거·상태 |
|---|---|---|
| 사용 목적 | 문의 답변에만 사용 | 정책 P1의 기준 |
| 저장 정보 | 이름·메일 주소 | 처리 메모 D1 |
| 목적 일치 | 실제 광고 발송 여부 | 미확인 |
| 보관·접근 | 기간·접근 권한 | 미확인 |
| 적용 근거 | 사업 지역·최신 법률 자료 | 검토 책임자가 확인 |

### 흔한 실수와 수정 요청

정책 문서에 적혀 있다는 이유로 실제 처리도 같다고 판단하거나, 적용 법률을 확인하지 않고 준법 판정을 내립니다.

```text
정책과 실제 처리 증거를 나눠 줘. 보관 기간·권한·광고 발송 상태는 미확인으로 표시하고, 담당자가 확인할 항목을 정리해 줘.
수정한 부분과 아직 확인할 항목을 따로 알려 줘.
```

### 확인 문제

정책이 작성되어 있으면 실제 준수도 입증된 걸까요?

<details><summary>답안과 해설 보기</summary>

아닙니다. 실제 처리 기록과 적용 근거를 별도로 확인해야 합니다. 이 예제는 확인 목록 작성 연습입니다.

</details>

### 내 업무로 바꿔 보기

예제의 자료를 자신의 공개 가능한 자료로 바꾸고, 결과의 독자와 형식을 다시 정합니다. 변하지 않는 검토 기준은 프로젝트 지침에 저장하고, 이번 작업의 수치와 미정 조건은 새 자료로 제공합니다. [프로젝트와 자료 수업](/learn/02-project-context/)에서 구분 방법을 확인합니다.

## 사용할 수 있는 스킬 후보

아래는 이 업무에 참고할 수 있는 패키지 기능입니다. 실제 설치·노출 상태를 먼저 확인하며 이 순서로 반드시 자동 실행된다는 뜻은 아닙니다.

- `moai-lawyer:legal-compliance-check`

## 완료 기준

결과물에 사용 자료와 미확인 항목이 표시되어 있습니다. 공식 근거·적용 범위·검토 책임·미확인 항목을 직접 확인했습니다. 파일을 요청한 경우 저장된 파일을 열어 확인합니다. 실제 게시·발송·예약 작업은 별도의 실행 결과로 확인합니다.

## 막혔을 때

자료나 연결이 없으면 제공 자료로 가능한 초안과 다음 준비 목록을 요청합니다. 원문·수치가 다르면 해당 위치와 근거를 지정해 고칩니다. 전문 판단이 필요한 부분은 근거와 쟁점을 정리하고 해당 업무 책임자가 확인합니다.
