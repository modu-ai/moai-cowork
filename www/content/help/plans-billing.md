**MoAI 플러그인 패키지 비용과 앱·외부 서비스 비용은 구분하세요.** 플러그인 소스가 무료로 공개되어 있어도 AI 앱의 이용 범위와 유료 API·이미지·영상 생성 서비스는 별도 조건을 따릅니다.


<!--more-->


## 확인할 비용

| 구분 | 확인할 곳 |
|---|---|
| ChatGPT Work·Claude 이용 | 본인 계정의 현재 요금제와 기능 범위 |
| 조직 관리 기능 | 워크스페이스·조직 관리자 설정 |
| 외부 조회·이미지·영상 생성 | 해당 서비스의 요금·크레딧·사용량 |
| API 사용 | 해당 API 계정의 청구·한도 |

가격과 제공 기능은 바뀔 수 있으므로 본 문서에 특정 가격을 고정하지 않습니다. 첫 실습은 [가상 텍스트 자료](/getting-started/first-task/)로 시작하고, 유료 작업을 추가할 때 필요한 도구와 예상 사용 범위를 확인하세요.
