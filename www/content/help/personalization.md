**내 말투 취향과 프로젝트의 업무 규칙은 저장할 위치가 다릅니다.** 모든 업무에 적용할 개인 취향은 지원되는 개인 설정, 특정 업무의 기준은 프로젝트 지침에 남깁니다.

| 기준 | 예 | 저장할 위치 |
|---|---|---|
| 개인 취향 | 설명은 쉬운 한국어로 | 지원되는 개인화 설정 |
| 프로젝트 규칙 | 보고서는 한 장, 수치 추측 금지 | 프로젝트 지침 |
| 반복 업무 방법 | 자료 확인 → 초안 → 검토 | 스킬·업무 절차 |
| 이번 결과의 수정 | 이 문단만 짧게 | 현재 작업 |

## 적용 확인

설정 저장 후 새 작업에서 어떤 기준을 적용하는지 확인합니다. 중요한 결정은 메모리에만 맡기지 말고 확인할 수 있는 지침에도 기록하세요. 모델과 추론 설정은 현재 화면의 선택 범위를 확인하고, 답변 품질이 필요한 기준을 충족하는지 예제 업무로 비교합니다.
