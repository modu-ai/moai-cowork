**보고서의 출처는 검토자가 근거를 다시 확인할 수 있도록 남깁니다.** 코드 라이선스, 생성 결과 정책, 입력 자료 권리는 각각 확인합니다.

| 사용한 것 | 남길 정보 |
|---|---|
| 웹 자료 | 제목·원문 링크·확인일 |
| 통계·표 | 기관·자료명·기준 기간·단위 |
| 내부 파일 | 허용된 문서명·버전·기준일 |
| 사진·글·브랜드 자료 | 권리·이용 조건·필요한 표기 |
| 플러그인 소스 | 원문 라이선스·저작권 고지·변경 사항 |


<!--more-->


## 결과물에 넣을 예

```text
자료: 제공한 업무 메모와 보고서 양식
기준: 이번 주 업무 기록
확인 필요: 배송 지연 원인, 담당자, 조치 기한
작성 범위: 초안 작성과 검토용 정리, 실제 발송 없음
```

AI를 사용했다고만 적는 것으로 자료 출처와 권리 확인이 끝나지는 않습니다. 공식 원문 링크를 열고 실제로 뒷받침하는 내용을 확인하세요. [라이선스 원문](/plugins/license/)과 [결과 검토](/workflows/review/)를 함께 참고합니다.
