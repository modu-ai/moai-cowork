**결과물 하나마다 작업을 나누면 자료와 수정 기록을 찾기 쉽습니다.** 보고서 작성, 이미지 시안, 데이터 분석처럼 서로 다른 목표는 별도 작업으로 진행할 수 있습니다.

## 이어서 작업할 때

같은 결과를 수정할 때는 해당 작업에서 수정할 위치와 기준을 말합니다. 새 작업으로 넘어갈 때는 최종 결과, 결정 사항, 남은 질문을 프로젝트 자료나 지침에 남깁니다. 새 대화가 다른 대화의 모든 내용을 자동으로 읽는다고 가정하지 않습니다.

## 이름과 공유 범위

“주간보고 — 초안 검토”, “제품 소개 — 문구 수정”처럼 결과 중심 이름을 붙입니다. 공유 전에는 원본 자료·민감정보·편집 권한과 공유 링크의 접근 범위를 확인합니다. 앱의 보관과 삭제는 서로 다른 동작이므로 선택한 기능을 확인하세요.
