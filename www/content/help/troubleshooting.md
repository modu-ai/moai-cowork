**현재 실패한 단계부터 확인하세요.** 전체 재설치나 작업 재시작 전에 실제 관측한 상태와 오류를 남깁니다.

| 증상 | 확인할 것 | 안내 |
|---|---|---|
| Work·Cowork가 없음 | 계정 범위·조직 정책·통합 화면 | [환경 선택](/getting-started/choose-app/) |
| 스킬이 없음 | 설치·활성화·현재 작업 노출 | [설치 확인](/plugins/install/#설치-확인) |
| 파일을 못 읽음 | 업로드·폴더 접근·실행 위치 | [파일과 권한](/workflows/permissions/) |
| 같은 질문이 반복됨 | 받은 답변과 미정 상태 | [질문과 맥락](/getting-started/questions/) |
| 결과가 틀림 | 원문·기간·단위·출처 | [결과 검토](/workflows/review/) |
| 계정 연결 실패 | 실제 계정·인증·도구 노출 | [MCP 문제 해결](/plugins/mcp/troubleshooting/) |
| 예약이 안 돌음 | 등록 목록·실행 결과·자료 접근 | [반복 업무](/workflows/reuse/) |

## 지원 요청에 남길 내용

앱·OS, 작업 환경, 플러그인 버전, 시도한 동작, 비밀정보를 제거한 오류, 완료된 단계와 남은 단계를 정리합니다. 키·토큰·개인 자료는 함께 보내지 않습니다.

작업이 멈춘 동안 독립적으로 가능한 초안이나 자료 정리는 진행할 수 있습니다. 실행하지 못한 조회·발송·파일 생성은 완료로 표시하지 않도록 요청하세요.
