## 작업을 작게 나누는 방법

1. 목표와 결과물을 하나씩 정합니다.
2. 필요한 자료만 제공하고 원본의 위치와 기준일을 남깁니다.
3. 긴 문서는 범위·목차를 먼저 확인한 뒤 필요한 부분을 읽습니다.
4. 수정할 때 전체 재작성보다 수정 위치를 지정합니다.
5. 같은 기준을 반복 설명하지 않도록 프로젝트 지침에 저장합니다.

많은 플러그인을 설치했다고 모든 본문이 매번 동일하게 로드되는 것은 아닙니다. 실제 사용 방식은 앱과 스킬 발견·로딩 규칙을 따릅니다. 한도에 도달하면 표시된 복구·재개 안내를 확인하고 완료한 결과와 남은 일을 기록하세요.
