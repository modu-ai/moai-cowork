**릴리스 날짜**: 2026-09-14
**버전**: v1.2.6 (최신)
**업데이트 방법**: 두 데스크톱 앱 모두 **플러그인(Plugins) 메뉴 → 해당 코워커 → Update**. 화면별 위치는 [플러그인 설치와 관리](/plugins/install/) 4절에 정리해 두었습니다.

## 하이라이트

이번 릴리스는 **법무 코워커의 선행조사가 커진** 작업입니다.

특허·상표를 준비할 때 제일 먼저 하는 일이 남보다 먼저 출원된 것이 없는지 살펴보는 선행조사입니다. 그동안은 검색 사이트를 옮겨 다니며 확인하는 형태였는데, 이번에 한국·미국·일본·유럽 특허청의 공식 데이터를 코워커가 직접 받아 보는 통로를 새로 깔았습니다. 조사 결과를 출원 판단용 보고서로 정리해 주는 스킬도 함께 들어왔습니다. 이미지 쪽에서는 OpenAI의 새 이미지 모델 GPT Image 2.5에 맞춰 프롬프트 스킬을 새로 작성했습니다.

- **법무 담당이 한국·미국·일본·유럽 특허·상표 공식 데이터를 직접 조회합니다.** 선행조사 리포트 스킬이 새로 생겼습니다.
- **미디어 크리에이터의 이미지 프롬프트 스킬이 GPT Image 2.5 기준으로 새로 작성됐습니다.** 옛 스킬 자리를 새 스킬이 대신합니다.
- **ChatGPT Work 앱의 내부 배선을 다듬었습니다.** 두 앱을 함께 쓰셔도 코워커와 명령이 같게 동작하도록 정의를 맞췄습니다.

## 새로 생긴 것

### 특허·상표 공식 데이터 조회 — 법무 담당

법무 코워커 안에 특허·상표 공식 데이터를 읽어 오는 연결 통로 `moai-mcp-ip`가 생겼습니다. 하나의 스킬 흐름에서 네 곳을 봅니다.

- 한국 — KIPRIS Plus (특허정보검색서비스)
- 미국 — USPTO ODP·TSDR
- 일본 — 일본 특허청 공개 데이터
- 유럽 — EPO OPS

기존의 특허 검색·특허 분석 스킬도 이 통로를 함께 씁니다. 그동안은 검색 결과 화면을 읽어 오는 형태였다면, 이제는 각 기관이 공식 제공하는 데이터를 직접 받아 봅니다.

### 선행조사 리포트 — legal-ip-search-report

새 스킬도 들어왔습니다. 상표 선행검색과 특허 선행기술·권리상태를 조사해 <strong>검색 로그·위험 평가·국가별 출원 전략이 담긴 보고서</strong>를 만들어 드립니다. 출원을 넣을지 판단할 때 펴 보는 결론용 문서입니다.

조사에 앞서 각 기관의 API 키가 있는지 확인하고, 없으면 기관별 등록 방법을 안내합니다. 키 넣는 법은 [API 키 넣는 법](/plugins/mcp/credentials/)에 정리돼 있습니다.

## 달라진 것

### 이미지 프롬프트 스킬이 새로 작성됐습니다 — 미디어 크리에이터 2.0.0

`media-gpt-image-2-prompt` 스킬을 GPT Image 2.5에 맞춰 새로 작성하면서 `media-gpt-image-prompt`로 이름을 바꿨습니다. 편집 패턴·파라미터·글자 렌더링·워크플로 레시피 같은 참고 문서도 새로 구성했고, 프리셋과 테스트 케이스도 함께 갱신했습니다.

미디어 코워커의 프로듀서·브랜드 감수 에이전트가 새 스킬을 부르도록 고쳤고, Higgsfield·Midjourney·Codex 이미지·Gemini 쪽 프롬프트 스킬도 표현을 맞춰 다듬었습니다.

### 마케터·사무관 스킬 다듬기

마케터의 카드뉴스 스킬과 사무관의 HTML 슬라이드 스킬의 문구와 안내를 다듬었습니다. 쓰는 방법이 바뀌는 변경은 아닙니다.

### ChatGPT Work 배선 정비

ChatGPT Work 앱에서도 코워커와 `/moai` 명령이 Claude Cowork와 같게 동작하도록 에이전트 정의·훅 배선·명령 스킬 사본을 맞췄습니다. 사용법이 달라지는 것은 없고, 두 앱을 함께 쓰실 때 결과가 어긋나는 자리를 줄였습니다.

## 알아 두실 것

**특허·상표 조회에는 각 기관의 API 키가 필요합니다.** 키가 없으면 코워커가 조회 대신 등록 방법을 안내합니다. 기관별 항목 이름은 [API 키 넣는 법](/plugins/mcp/credentials/)에 적어 두었습니다.

**옛 이미지 프롬프트 스킬 이름은 사라졌습니다.** `media-gpt-image-2-prompt`라는 이름을 쓰던 대화나 문서가 있다면 `media-gpt-image-prompt`로 바꾸시면 됩니다. 같은 일을 하는 스킬이라 사용법을 다시 익히실 것은 없습니다.

## 업데이트 방법

두 데스크톱 앱 모두 **플러그인(Plugins) 메뉴 → 해당 코워커 → Update**입니다. 이번에 바뀐 네 코워커(법무 담당·미디어 크리에이터·마케터·사무관)를 쓰신다면 업데이트해 주세요.

업데이트 후 대화를 새로 시작하면 새 스킬과 배선이 적용됩니다.
