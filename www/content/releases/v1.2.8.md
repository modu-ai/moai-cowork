**릴리스 날짜**: 2026-10-09
**버전**: v1.2.8 (최신)
**업데이트 방법**: 앱의 플러그인 관리 메뉴에서 해당 코워커의 버전·업데이트 상태를 확인한 뒤 새 작업에서 기능을 확인하세요.
화면별 경로는 [플러그인 설치와 관리](/plugins/install/)를 참고하세요.

## 하이라이트

이번 릴리스는 사용하지 않는 서비스의 실제 서버까지 미리 실행하지 않도록 연결 방식을 다듬었습니다.

- 도구 목록을 확인할 때는 가벼운 연결 프로그램만 실행합니다. 실제 서버는 해당 도구를 처음 호출할 때 시작합니다.
- 연결이 끝나면 그 연결에서 시작한 서버를 정리합니다. 큰 요청을 보내다가 연결이 끊겼을 때의 종료 처리도 보강했습니다.

## 달라진 것

특허·상표 조회, OpenAI 이미지 생성, 스마트스토어·아임웹·카페24 판매자 기능, Threads 발행을 담당하는 자체 연결에 적용했습니다.
기존 도구 이름과 인증 설정은 유지합니다.

첫 호출에는 서버를 준비하는 시간이 들 수 있습니다.
한 번 시작한 서버는 연결이 끝날 때까지 유지되며 사용하지 않는 시간이 길어졌다는 이유로 자동 종료하지 않습니다.
가벼운 연결 프로그램은 세션마다 실행되므로 여러 세션의 프로세스 총수를 제한하거나 서버 하나를 함께 쓰는 기능은 아닙니다.

## 고친 것

- 통신이 막힌 상태에서도 연결 종료를 처리하도록 보강했습니다. 서버 준비에 실패한 도구 호출을 자동으로 다시 실행하지 않습니다.
- 메시지를 제때 읽지 못해 대기 데이터가 계속 쌓이면 연결을 종료하고 서버를 정리합니다. 큰 이미지 응답은 계속 전달할 수 있습니다.
- 서비스가 안내한 재시도 대기 시간을 처리하는 방식을 고치고 스마트스토어 연결 종료와 특허·상표 조회의 인증 교체 때 남은 연결을 닫도록 했습니다.
