**예제 메모를 한 장짜리 보고서로 바꿔 봅니다.** 아래 내용은 실습용 가상 자료이며 외부 계정·API 키·유료 생성 서비스가 필요하지 않습니다. 플러그인을 아직 설치하지 않았다면 기본 기능으로 실습한 뒤, 같은 작업을 스킬로 반복해 보세요.


<!--more-->


## 1. 메모와 요청을 함께 보내세요

ChatGPT Work 또는 Claude Cowork의 새 작업에 복사합니다.

```text
아래 가상 메모로 팀장에게 보여 줄 주간보고 초안을 만들어 줘.
성과, 문제, 다음 행동을 각각 표로 정리해 줘.
메모에 없는 숫자나 담당자는 만들지 말고 '확인 필요'로 표시해 줘.
실제 메일 발송이나 외부 서비스 변경은 하지 마.

[실습 메모]
- 이번 주 고객 문의 12건에 답변함.
- FAQ 초안 4개를 작성함. 최종 검토는 아직 끝나지 않음.
- 배송 지연 문의가 반복됨. 원인은 아직 확인하지 못함.
- 다음 주에는 배송 안내 문구를 고치고 FAQ를 검토할 예정.
```

## 2. 필요한 질문에 답하세요

독자나 분량을 물으면 “팀장용, 한 장”처럼 답합니다. 기한이나 담당자를 모르면 “미정으로 표시해 줘”라고 하세요. 질문을 건너뛰었다면 그 항목이 확정된 것으로 처리되지 않아야 합니다.

## 3. 결과를 확인하세요

| 확인 항목 | 통과 기준 |
|---|---|
| 숫자 | 문의 12건, FAQ 초안 4개가 원문과 일치 |
| 사실과 미정 | 배송 지연 원인·담당자·기한을 지어내지 않음 |
| 구조 | 성과·문제·다음 행동을 찾을 수 있음 |
| 실행 범위 | 실제 발송·계정 변경을 하지 않음 |

빠진 항목이 있으면 같은 작업에서 고칩니다.

```text
FAQ 4개는 완료가 아니라 초안 상태야. 그 부분을 고치고,
원인이 확인되지 않은 문제는 따로 표시해 줘.
```

## 4. 반복해서 쓰는 방법

이번 형식이 마음에 들면 [프로젝트 설정](/getting-started/projects/)에 보고서 기준을 저장하세요. 보고서 업무에는 [코워커](/moai-agents/coworker/), 문서 파일 제작에는 [사무관](/moai-agents/officer/)의 스킬을 검토할 수 있습니다. 실제 파일이 필요하면 확장자와 저장 위치를 함께 요청하고 다운로드해 열어 보세요.

**완료 기준:** 원문과 맞는 보고서 초안을 받고 수정 사항을 반영했습니다. 예제 결과는 실제 회사 실적을 증명하는 자료로 사용하지 않습니다.
