예를 들어 “우리 팀의 주간보고를 만들어 줘”라고 요청한다고 생각해 보세요. **프로젝트에는 팀 자료와 기준을 담고, 스킬은 보고서를 만드는 절차를 알려 줍니다.** 외부 업무 기록을 가져와야 할 때만 연결 도구가 추가로 필요합니다.

## 먼저 알아둘 여섯 가지

| 개념 | 뜻 | 주간보고에서는 |
|---|---|---|
| 프로젝트(Projects) | 관련 작업·자료·지침을 묶는 공간 | 팀 보고서를 이어서 만드는 곳 |
| 지침 | 업무 기준과 지켜야 할 조건 | 수치를 지어내지 않기, 표 양식 유지 |
| 스킬(skill) | 반복 업무의 절차와 참고 자료 | 성과·문제·다음 행동 순서로 작성 |
| 에이전트(agent) | 일을 맡아 수행하는 역할 | 자료 분석 담당, 작성 담당, 검토 담당 |
| 플러그인(plugin) | 스킬과 연결 도구 등을 설치하는 패키지 | 보고서 관련 기능을 추가하는 묶음 |
| MCP | AI가 서비스 도구를 사용하는 연결 규격 | 승인된 업무 서비스에서 기록 조회 |

플러그인에 모든 구성 요소가 반드시 들어 있는 것은 아닙니다. 에이전트 파일이 포함돼 있어도 현재 앱이 그 형식을 지원해야 별도 담당자로 실행할 수 있습니다. 스킬의 업무 방법과 MCP의 실제 조회·변경 권한도 구분합니다.

## 함께 자주 만나는 말

- **대화·작업**: 요청과 결과를 주고받는 기록입니다. 결과물 하나마다 작업을 나누면 찾기 쉽습니다.
- **파일·아티팩트**: 검토할 문서·표·시안입니다. 화면의 미리보기와 다운로드 가능한 파일은 각각 확인합니다.
- **메모리**: 앱이 유지하는 기억입니다. 중요한 업무 기준은 확인할 수 있는 프로젝트 지침에도 기록하세요.
- **워크플로우**: 자료 확인 → 초안 → 검토처럼 업무를 처리하는 순서입니다.

## 헷갈리기 쉬운 구분

설치와 연결, 파일 생성과 지침 적용은 서로 다른 단계입니다. “설치됨”은 계정 연결 완료를 뜻하지 않고, “지침 파일 생성됨”은 앱의 Projects에 저장됐다는 뜻도 아닙니다.

개념을 익혔다면 [첫 결과물 만들기](/getting-started/first-task/)로 이어가세요.
