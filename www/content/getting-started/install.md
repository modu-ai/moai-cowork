**앱 설치와 플러그인 설치는 두 단계입니다.** 앱을 설치하고 로그인한 다음 필요한 업무 방법을 플러그인으로 추가합니다. 이미 앱이 있다면 [플러그인 추가](/plugins/install/)로 이동하세요. 두 앱을 모두 설치하거나 구독할 필요는 없습니다.

{{< concept-diagram install-journey >}}

## 설치 전에 준비할 것

| 확인할 것 | 확인 방법 |
|---|---|
| 사용할 컴퓨터 | Mac은 Apple 메뉴의 ‘이 Mac에 관하여’, Windows는 설정의 ‘시스템 → 정보’에서 운영체제와 프로세서 확인 |
| 사용할 계정 | 개인 계정인지 회사·학교의 관리 계정인지 확인. 회사 기기의 설치 제한은 관리자에게 확인 |
| 첫 실습 자료 | [가상 문의 자료](/downloads/classroom/) 사용. API 키나 외부 서비스 연결은 첫 실습에 필요 없음 |

다운로드는 아래 공식 페이지에서 시작합니다. 최신 지원 조건과 설치 파일 형식을 확인하세요. Linux는 공급자별 공식 설치 안내를 따라 진행합니다. 앱 지원과 컴퓨터 제어 기능 지원은 따로 확인합니다.

## ChatGPT Desktop 설치

### 1 · 공식 페이지에서 내 컴퓨터용 파일 선택

[ChatGPT Desktop 공식 다운로드](https://learn.chatgpt.com/docs/app)를 엽니다. **Download ChatGPT** 옆의 화살표를 누르면 운영체제별 선택지가 나옵니다.

![ChatGPT 공식 다운로드에서 운영체제별 메뉴를 펼친 실제 웹 화면](/screenshots/20261006/chatgpt-download.jpg)

2026년 10월 6일 촬영한 **공식 안내 웹사이트**입니다. 설치된 앱 화면은 아닙니다. 영어 메뉴는 다음처럼 읽습니다.

| 화면의 이름 | 고를 때 |
|---|---|
| macOS (Apple silicon) | ‘이 Mac에 관하여’의 칩 이름이 Apple M 계열일 때 |
| macOS (Intel) | 프로세서가 Intel일 때 |
| Windows | Windows용 공식 설치 파일을 받을 때 |
| Linux installation guide | 배포판·패키지 형식을 공식 안내와 대조할 때 |

### 2 · 받은 파일을 열어 설치

Mac에서 `.dmg`를 받았다면 열고 설치 창에서 안내하는 응용 프로그램 폴더로 앱을 옮깁니다. Windows에서는 받은 설치 파일을 열고 화면의 절차를 따릅니다. 회사 기기에서 설치가 차단되면 설치 권한을 확인합니다. 이미 앱이 있으면 업데이트 상태를 먼저 확인하세요.

응용 프로그램 폴더 또는 시작 메뉴에서 **ChatGPT를 직접 실행할 수 있는지** 확인합니다. 다운로드 버튼을 누른 것만으로 설치가 끝난 것은 아닙니다. 이 문서에는 운영체제의 설치 진행 창 사진이 아직 없습니다.

### 3 · 로그인하고 Work 시작

앱을 열고 ChatGPT 계정으로 로그인합니다. 브라우저로 이동했다면 완료 후 앱으로 돌아옵니다. 사용할 워크스페이스를 확인하고 ChatGPT 입력창 위에서 **Work**를 선택합니다. ChatGPT와 Codex 선택이 함께 있으면 이번 수업은 ChatGPT Work로 시작합니다. [공식 앱 시작 안내](https://learn.chatgpt.com/docs/app).

![2026년 10월 5일 ChatGPT 웹에서 촬영한 Work 입력창](/screenshots/20261005/chatgpt-web-start.jpg)

이 사진은 **웹의 입력창 위치**를 설명합니다. ChatGPT Desktop은 촬영 도구의 앱 접근 제한으로 직접 촬영하지 못했습니다. 데스크톱의 로그인·Work 선택·폴더 연결은 자신의 앱에서 확인해야 합니다.

## Claude Desktop 설치

### 1 · 공식 다운로드에서 데스크톱 선택

[Claude 공식 다운로드](https://claude.com/download)를 엽니다. ‘데스크톱’의 macOS 또는 Windows 항목을 선택합니다. Windows에 arm64 선택이 보이면 컴퓨터의 시스템 종류와 맞는지 확인합니다. Chrome·Excel 확장 프로그램과 모바일 앱은 다른 설치 항목입니다.

![Claude 공식 다운로드 웹페이지의 macOS 버튼을 직접 촬영한 화면](/screenshots/20261006/claude-download.jpg)

2026년 10월 6일 촬영한 **다운로드 웹페이지**입니다. 위쪽은 Mac용 바로가기이고 아래 ‘시작하기’에서 다른 환경을 찾습니다. [설치 조건과 Linux 안내](https://support.claude.com/en/articles/10065433-install-claude-desktop)를 함께 확인하세요.

### 2 · 설치하고 로그인

받은 파일을 열어 설치 안내를 따릅니다. Mac의 응용 프로그램 폴더 또는 Windows의 시작 메뉴에서 **Claude**를 실행하고 계정으로 로그인합니다. 실행과 로그인은 각각 확인합니다. 이 문서에는 운영체제의 설치 진행 창과 로그인 화면 사진이 아직 없습니다.

### 3 · Cowork 또는 통합 입력창 확인

이전 화면에는 **Chat·Cowork** 선택이 있고 새 통합 화면에서는 같은 입력창에 업무를 설명합니다. Cowork 탭이 없다는 이유만으로 설치 실패라고 판단하지 마세요. [공식 Cowork 안내](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork)와 계정의 이용 범위를 확인합니다.

로컬 파일·브라우저가 필요한 업무는 해당 컴퓨터의 Desktop이 열려 있고 연결되어 있는지 확인합니다. 클라우드에서 계속하는 작업에도 컴퓨터의 파일 접근이 자동으로 유지되는 것은 아닙니다.

## 준비 완료 확인

새 작업에 다음 요청을 입력합니다. 붙여넣은 글만으로 연습할 수 있습니다.

```text
아래 가상 메모를 세 줄 보고서로 정리해 줘.
문의 12건 답변 완료. FAQ 4개는 검토 전 초안. 배송 지연 원인은 미확인.
완료·초안·미확인을 구분하고 없는 사실은 추가하지 마.
외부 서비스에 접속하지 말고 부족한 정보가 있으면 질문해 줘.
```

**문의 12건·답변 완료**, **FAQ 4개·초안**, **지연 원인·미확인**이 유지되는지 확인합니다. 여기까지 되면 [첫 결과물](/getting-started/first-task/)로 진행합니다.

## 막힌 위치별 해결

| 멈춘 위치 | 먼저 확인할 것 | 다음 행동 |
|---|---|---|
| 다운로드 | 공식 페이지·운영체제·회사 정책 | 공식 항목 또는 관리자 안내 확인 |
| 앱 실행 | 지원 조건·설치 완료·오류 문구 | 오류를 기록하고 공급자 설치 안내 확인 |
| 로그인 | 사용 계정·브라우저 로그인·조직 인증 | [계정 안내](/help/account/) |
| Work·Cowork 선택 | 제품 선택·통합 화면·구독·조직 정책 | 공식 시작 안내와 현재 계정 비교 |
| 파일 읽기 | 업로드와 로컬 폴더 연결의 차이 | [파일과 권한](/workflows/permissions/) |
