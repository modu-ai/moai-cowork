두 제품 모두 여러 단계를 거쳐 결과물을 만드는 일을 맡길 수 있습니다. 이미 사용하는 계정으로 시작하고, 필요한 기능이 현재 화면에 있는지 확인하세요.

| 확인할 항목 | ChatGPT Work | Claude Cowork |
|---|---|---|
| 작업 시작 | Work 선택 후 목표 입력 | Cowork 선택 또는 통합된 Claude 입력창에서 목표 입력 |
| 반복 업무 자료 | Projects의 자료·지침 또는 로컬 프로젝트 | Projects의 자료·지침 및 현재 작업의 파일 접근 |
| 플러그인 | Plugins에서 설치·연결 상태 확인 | 사용자 지정(Customize) → Plugins에서 확인 |
| 직접 지정 | 화면에 표시되는 `@` 선택 메뉴 사용 | 화면에 표시되는 `/` 또는 `+` 스킬 메뉴 사용 |
| 로컬 파일 | 로컬 프로젝트·연결된 컴퓨터 접근 여부 확인 | 현재 작업의 폴더 접근·클라우드 실행 여부 확인 |

**웹 프로젝트를 만들었다고 컴퓨터 폴더가 연결되는 것은 아닙니다.** 웹에서는 파일을 올리거나 자료 연결을 선택하세요. 로컬 도구가 필요한 업무는 지원되는 데스크톱 환경에서 접근 여부를 확인합니다.

## 화면이 설명과 다를 때

Claude는 Chat과 Cowork를 통합한 화면을 순차 제공하고 있습니다. Cowork 버튼이 없더라도 곧바로 기능이 없다고 판단하지 마세요. 공식 안내와 본인 계정의 화면을 함께 확인합니다. 이 문서의 화면은 촬영일의 한 계정에서 확인한 예시입니다.

2026년 10월 6일 다시 확인한 공식 안내에 따르면, Pro·Max의 새 Cowork 작업은 이날부터 클라우드에서 실행됩니다. 기존 로컬 작업은 로컬에 남습니다. 앱을 닫아도 클라우드 작업은 계속될 수 있지만 로컬 파일·브라우저를 사용하려면 연결된 Desktop이 열려 있어야 합니다. 로컬 파일이 필요한 수업에서는 실행 위치뿐 아니라 컴퓨터의 Claude Desktop이 연결되어 있는지도 확인하세요. 수업 당일에는 아래 공식 시작 안내와 실제 계정의 상태를 다시 비교합니다.

- 앱이 없다면 [앱과 웹 준비](/getting-started/install/).
- 준비됐다면 [첫 결과물 만들기](/getting-started/first-task/).
